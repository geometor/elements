[bell:proposition] [style:brisk] Euclid's Elements, Book One, Proposition Seven. <pause> On the same segment and on the same side, there cannot be constructed two distinct triangles with both pairs of conterminous sides equal. <pause> Given segments A C and C B meeting at point C on segment A B, we prove that no distinct point D on the same side can have A D equal to A C and B D equal to B C.

[bell:construction] [style:brisk] For if possible, suppose distinct segments A D and D B on the same side of A B meet at point D, with C A equal to D A and C B equal to D B. <pause> Construct segment C D between points C and D, by Postulate One.

[bell:insight] [style:brisk] Since segment A C equals segment A D in isosceles triangle A C D, Proposition Five gives angle A C D equal to angle A D C. <pause> By Common Notion Five, the whole is greater than the part: angle A C D is greater than its part, angle D C B, so angle A D C is greater than angle D C B, and the whole angle C D B is much greater than angle D C B. <pause> Yet since segment C B equals segment D B in isosceles triangle B C D, Proposition Five gives angle C D B equal to angle D C B, which is a contradiction. <pause> Therefore on the same segment A B and on the same side, no distinct point D can have both pairs of conterminous sides equal, <pause> as was required to prove.
