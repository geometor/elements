Book Four, Proposition One. Into a given circle to fit a segment equal to a given segment which is not greater than the diameter of the circle. <pause> Let A B C be the given circle, and D the given segment not greater than the diameter of the circle; it is required to fit into the circle A B C a chord equal to the segment D.

[bell:construction]
[style: methodical, precise constructive cadence]
Draw a diameter B C of the circle A B C. If B C equals D, that which was enjoined has been done. But if B C is greater than D, cut off C E equal to D by One Three. <pause> With center C and defining radius point E, describe the circle E A F, cutting the circle A B C at A and F, and join C A.

[bell:insight]
[style: luminous, deductive geometric clarity]
Because the point C is the center of the circle E A F, the radius C A equals the radius C E by Definition Fifteen. <pause> Yet C E was constructed equal to D; therefore by Common Notion One, C A also equals D. Thus into the given circle A B C there has been fitted the chord C A equal to the given segment D. Which was to be done.
