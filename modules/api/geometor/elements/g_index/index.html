geometor.elements.g_index¶

Generate the G-Index for Euclid’s Elements.

Processes the composed Heath Edition in ../euclid/docsrc/heath/ to produce: - Strictly numbered G-Index nodes (G.1, G.2, …) in topological dependency order - GEOMETOR symbolic element indications in :g: roles (/ A B /, < A B C >, < B A C ), ( B C D ), [ A B ], A) - G-Index step justifications (:just:`[G.4] <G.4>`, .. assertion:: [G.2] <G.2>) - Interactive inline SVG figures copied per G-node - Rich metadata (:type:, :subtype:, :categories:, :tags:, :dependencies:) - Transitive Graphviz dependency graphs and Required for back-links

geometor.elements.g_index.transform_geom_roles(rst_text: str) → str¶

Replace cryptic $AB$ display labels in :g: roles with GEOMETOR symbolic indications.

Examples: - :g:`$AB$ <0255.g1:/ A B />` -> :g:`/ A B / <0255.g1:/ A B />` - :g:`$ABC$ <0255.g1:< A B C >>` -> :g:`< A B C > <0255.g1:< A B C >>` - :g:`$BAC$ <0261.g1:< B A C )>` -> :g:`< B A C ) <0261.g1:< B A C )>` - :g:`$BCD$ <0255.g1:( B C D )>` -> :g:`( B C D ) <0255.g1:( B C D )>` - :g:`$A$ <0255.g1:A>` -> :g:`A <0255.g1:A>`
