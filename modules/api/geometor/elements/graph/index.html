geometor.elements.graph¶

Graph construction and semantic metadata extraction for GEOMETOR Elements.

Crawls the composed Heath Edition RST source in ../euclid/docsrc/heath/ across all 3 volumes (Books I–XIII), extracting discrete nodes for definitions, postulates, common notions, and propositions, along with their dependency edges, interactive SVG diagrams, categories, and semantic tags.
