G.104
=====

.. rubric:: `III.25 <https://geometor.github.io/euclid/heath/volume_II/book_iii/propositions/25/>`_

.. enunciation::

   Given a segment of a circle, to describe the complete circle of which it is a segment.

Let :g:`( A B C ) <0061.g1:( A B C )>` be the given segment of a circle;
thus it is required to describe the complete circle belonging
to the segment :g:`( A B C ) <0061.g1:( A B C )>`, that is, of which it is a segment.

For let :g:`/ A C / <0061.g1:/ A C />` be :eq:`bisected <0061.g1:/ A D / = 0061.g1:/ D C />` at :g:`D <0061.g1:D>`, let :g:`/ D B / <0061.g1:/ D B />` be drawn from the
point :g:`D <0061.g1:D>` at right angles to :g:`/ A C / <0061.g1:/ A C />`, and let :g:`/ A B / <0061.g1:/ A B />` be joined;

the angle :g:`< A B D ) <0061.g1:< A B D )>` is then greater than, equal to, or less
than the angle :g:`< B A D ) <0061.g1:< B A D )>`.

First let it be greater;
and on the straight line :g:`/ B A / <0061.g1:/ B A />`, and at the point :g:`A <0061.g1:A>` on it, let
the angle :g:`< B A E ) <0061.g1:< B A E )>` be constructed :eq:`equal <0061.g1:< B A E ) = 0061.g1:< A B D )>` to
the angle :g:`< A B D ) <0061.g1:< A B D )>`; let :g:`/ D B / <0061.g1:/ D B />` be drawn through
to :g:`E <0061.g1:E>`, and let :g:`/ E C / <0061.g1:/ E C />` be joined.

.. picture:: 0061.g1.svg
   :alt: Diagram for Proposition 25, Case 1

Then, since the angle :g:`< A B E ) <0061.g1:< A B E )>` is :eq:`equal <0061.g1:< A B E ) = 0061.g1:< B A E )>` to
the angle :g:`< B A E ) <0061.g1:< B A E )>`,
the straight line :g:`/ E B / <0061.g1:/ E B />` is also :eq:`equal <0061.g1:/ E B / = 0061.g1:/ E A />` to
:g:`/ E A / <0061.g1:/ E A />`. :just:`[G.13] <G.13>`

And, since :g:`/ A D / <0061.g1:/ A D />` is :eq:`equal <0061.g1:/ A D / = 0061.g1:/ D C />` to :g:`/ D C / <0061.g1:/ D C />`,
and :g:`/ D E / <0061.g1:/ D E />` is common,
the two sides :g:`/ A D / <0061.g1:/ A D />`, :g:`/ D E / <0061.g1:/ D E />` are :eq:`equal <0061.g1:/ A D / = 0061.g1:/ C D />` to the two sides :g:`/ C D / <0061.g1:/ C D />`, :g:`/ D E / <0061.g1:/ D E />`
respectively;
and the angle :g:`< A D E ) <0061.g1:< A D E )>` is :eq:`equal <0061.g1:< A D E ) = 0061.g1:< C D E )>` to the angle :g:`< C D E ) <0061.g1:< C D E )>`, for each is
:eq:`right <0061.g1:< A D E ) = 0061.g1:< C D E )>`;

.. assertion::

   therefore the base :g:`/ A E / <0061.g1:/ A E />` is :eq:`equal <0061.g1:/ A E / = 0061.g1:/ C E />` to the base :g:`/ C E / <0061.g1:/ C E />`.

But :g:`/ A E / <0061.g1:/ A E />` was proved :eq:`equal <0061.g1:/ A E / = 0061.g1:/ B E />` to :g:`/ B E / <0061.g1:/ B E />`;

.. assertion::

   therefore :g:`/ B E / <0061.g1:/ B E />` is also :eq:`equal <0061.g1:/ B E / = 0061.g1:/ C E />` to :g:`/ C E / <0061.g1:/ C E />`;

therefore the three straight lines :g:`/ A E / <0061.g1:/ A E />`, :g:`/ E B / <0061.g1:/ E B />`, :g:`/ E C / <0061.g1:/ E C />` are :eq:`equal <0061.g1:/ A E / = 0061.g1:/ E B / = 0061.g1:/ E C />` to
one another.

Therefore the circle drawn with centre :g:`E <0061.g1:E>` and distance
one of the straight lines :g:`/ A E / <0061.g1:/ A E />`, :g:`/ E B / <0061.g1:/ E B />`, :g:`/ E C / <0061.g1:/ E C />` will also pass through
the remaining points and will have been completed. :just:`[G.84] <G.84>`

Therefore, given a segment of a circle, the complete circle
has been described.

And it is manifest that the segment :g:`( A B C ) <0061.g1:( A B C )>` is less than a
semicircle, because the centre :g:`E <0061.g1:E>` happens to be outside it.

Similarly, even if the angle :g:`< A B D ) <0061.g2:< A B D )>` be :eq:`equal <0061.g2:< A B D ) = 0061.g2:< B A D )>` to the angle
:g:`< B A D ) <0061.g2:< B A D )>`,
:g:`/ A D / <0061.g2:/ A D />` being :eq:`equal <0061.g2:/ A D / = 0061.g2:/ B D / = 0061.g2:/ D C />` to each of the two :g:`/ B D / <0061.g2:/ B D />`, :g:`/ D C / <0061.g2:/ D C />`,

.. picture:: 0061.g2.svg
   :alt: Diagram for Proposition 25, Case 2

the three straight lines :g:`/ D A / <0061.g2:/ D A />`, :g:`/ D B / <0061.g2:/ D B />`, :g:`/ D C / <0061.g2:/ D C />` will
be :eq:`equal <0061.g2:/ D A / = 0061.g2:/ D B / = 0061.g2:/ D C />` to one another,
:g:`D <0061.g2:D>` will be the centre of the completed circle,
and :g:`( A B C ) <0061.g2:( A B C )>` will clearly be a semicircle.

But, if the angle :g:`< A B D ) <0062.g1:< A B D )>` be less than the angle :g:`< B A D ) <0062.g1:< B A D )>`,
and if we construct, on the straight line :g:`/ B A / <0062.g1:/ B A />`
and at the point :g:`A <0062.g1:A>` on it, an angle :eq:`equal <0062.g1:< B A E ) = 0062.g1:< A B D )>` to
the angle :g:`< A B D ) <0062.g1:< A B D )>`, the centre will fall on :g:`/ D B / <0062.g1:/ D B />`
within the segment :g:`( A B C ) <0062.g1:( A B C )>`, and the segment
:g:`( A B C ) <0062.g1:( A B C )>` will clearly be greater than a semicircle
.

.. picture:: 0062.g1.svg
   :alt: Diagram for Proposition 25, Case 3

Therefore, given a segment of a circle,
the complete circle has been described.

.. qed::

   :just:`Q. E. F.`
