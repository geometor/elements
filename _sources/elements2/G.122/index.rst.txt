G.122
=====

.. rubric:: `IV.5 <https://geometor.github.io/euclid/heath/volume_II/book_iv/propositions/05/>`_

.. enunciation::

   About a given triangle to circumscribe a circle.

Let :g:`< A B C > <0094.g1:< A B C >>` be the given triangle;
thus it is required to circumscribe a circle about the given
triangle $ABC$.

.. picture:: 0094.g1.svg
   :alt: Proposition 5 diagrams

Let the straight lines :g:`/ A B / <0094.g1:/ A B />`, :g:`/ A C / <0094.g1:/ A C />` be bisected at the points
:g:`D <0094.g1:D>`, :g:`E <0094.g1:E>` :just:`[G.17] <G.17>`, and from the points :g:`D <0094.g1:D>`, :g:`E <0094.g1:E>` let :g:`/ D F / <0094.g1:/ D F />`, :g:`/ E F / <0094.g1:/ E F />` be drawn
at right angles to :g:`/ A B / <0094.g1:/ A B />`, :g:`/ A C / <0094.g1:/ A C />`;
they will then meet within the triangle :g:`< A B C > <0094.g1:< A B C >>`, or on the
straight line :g:`/ B C / <0094.g1:/ B C />`, or outside :g:`/ B C / <0094.g1:/ B C />`.

First let them meet within at :g:`F <0094.g1:F>`, and let :g:`/ F B / <0094.g1:/ F B />`, :g:`/ F C / <0094.g1:/ F C />`, :g:`/ F A / <0094.g1:/ F A />` be
joined.

Then, since :g:`/ A D / <0094.g1:/ A D />` is :eq:`equal <0094.g1:/ A D / = 0094.g1:/ D B />` to :g:`/ D B / <0094.g1:/ D B />`,
and :g:`/ D F / <0094.g1:/ D F />` is common and at right angles,
therefore the base :g:`/ A F / <0094.g1:/ A F />` is :eq:`equal <0094.g1:/ A F / = 0094.g1:/ F B />` to the base :g:`/ F B / <0094.g1:/ F B />`. :just:`[G.11] <G.11>`

Similarly we can prove that

.. assertion::

   :g:`/ C F / <0094.g1:/ C F />` is also :eq:`equal <0094.g1:/ C F / = 0094.g1:/ A F />` to :g:`/ A F / <0094.g1:/ A F />`;

so that :g:`/ F B / <0094.g1:/ F B />` is also :eq:`equal <0094.g1:/ F B / = 0094.g1:/ F C />` to :g:`/ F C / <0094.g1:/ F C />`;

.. assertion::

   therefore the three straight lines :g:`/ F A / <0094.g1:/ F A />`, :g:`/ F B / <0094.g1:/ F B />`, :g:`/ F C / <0094.g1:/ F C />` are :eq:`equal <0094.g1:/ F A / = 0094.g1:/ F B / = 0094.g1:/ F C />` to one another.

Therefore the circle described with centre :g:`F <0094.g1:F>` and distance
one of the straight lines :g:`/ F A / <0094.g1:/ F A />`, :g:`/ F B / <0094.g1:/ F B />`, :g:`/ F C / <0094.g1:/ F C />` will pass also through
the remaining points, and the circle will have been circumscribed
about the triangle :g:`< A B C > <0094.g1:< A B C >>`.

Let it be circumscribed, as :g:`( A B C ) <0094.g1:( A B C )>`.

Next, let :g:`/ D F / <0094.g1:/ D F />`, :g:`/ E F / <0094.g1:/ E F />` meet on the straight line :g:`/ B C / <0094.g1:/ B C />` at :g:`F <0094.g1:F>`,
as is the case in the second figure; and let :g:`/ A F / <0094.g1:/ A F />` be joined.

Then, similarly, we shall prove that the point :g:`F <0094.g1:F>` is the
centre of the circle circumscribed about the triangle :g:`< A B C > <0094.g1:< A B C >>`.

Again, let :g:`/ D F / <0094.g1:/ D F />`, :g:`/ E F / <0094.g1:/ E F />` meet outside the triangle :g:`< A B C > <0094.g1:< A B C >>` at :g:`F <0094.g1:F>`,
as is the case in the third figure, and let :g:`/ A F / <0094.g1:/ A F />`, :g:`/ B F / <0094.g1:/ B F />`, :g:`/ C F / <0094.g1:/ C F />` be
joined.

Then again, since :g:`/ A D / <0094.g1:/ A D />` is :eq:`equal <0094.g1:/ A D / = 0094.g1:/ D B />` to :g:`/ D B / <0094.g1:/ D B />`,
and :g:`/ D F / <0094.g1:/ D F />` is common and at right angles,
therefore the base :g:`/ A F / <0094.g1:/ A F />` is :eq:`equal <0094.g1:/ A F / = 0094.g1:/ F B />` to the base :g:`/ F B / <0094.g1:/ F B />`. :just:`[G.11] <G.11>`

Similarly we can prove that

.. assertion::

   :g:`/ C F / <0094.g1:/ C F />` is also :eq:`equal <0094.g1:/ C F / = 0094.g1:/ A F />` to :g:`/ A F / <0094.g1:/ A F />`;

so that :g:`/ B F / <0094.g1:/ B F />` is also :eq:`equal <0094.g1:/ B F / = 0094.g1:/ F C />` to :g:`/ F C / <0094.g1:/ F C />`;
therefore the circle described with centre :g:`F <0094.g1:F>` and distance one
of the straight lines :g:`/ F A / <0094.g1:/ F A />`, :g:`/ F B / <0094.g1:/ F B />`, :g:`/ F C / <0094.g1:/ F C />` will pass also through
the remaining points, and will have been circumscribed about
the triangle :g:`< A B C > <0094.g1:< A B C >>`.

Therefore about the given triangle a circle has been
circumscribed.

.. qed::

   :just:`Q. E. F.`

And it is manifest that, when the centre of the circle falls
within the triangle, the angle :g:`< B A C ) <0094.g1:< B A C )>`, being in a segment
greater than the semicircle, is less than a right angle;

when the centre falls on the straight line :g:`/ B C / <0094.g1:/ B C />`, the angle :g:`< B A C ) <0094.g1:< B A C )>`,
being in a semicircle, is right;
and when the centre of the circle falls outside the triangle,
the angle :g:`< B A C ) <0094.g1:< B A C )>`, being in a segment less than the semicircle,
is greater than a right angle. :just:`[G.110] <G.110>`
