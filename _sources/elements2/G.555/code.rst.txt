G.555 there pyramids height — Code
==================================

.. rubric:: `XII.4 <https://geometor.github.io/euclid/heath/volume_III/book_xii/propositions/04/>`_

.. enunciation::

   If there be two :term:`pyramids <G.553>` of the same :term:`height <G.209>` which have triangular bases, and each of them be divided into two pyramids equal to one another and similar to the whole, and into two equal :term:`prisms <G.537>`, then, as the base of the one pyramid is to the base of the other pyramid, so will all the prisms in the one pyramid be to all the prisms, being equal in multitude, in the other pyramid.
