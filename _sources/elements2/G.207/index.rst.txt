G.207
=====

.. rubric:: `VII.8 <https://geometor.github.io/euclid/heath/volume_II/book_vii/propositions/08/>`_

.. enunciation::

   If a number be the same parts of a number that a number subtracted is of a number subtracted, the remainder will also be the same parts of the remainder that the whole is of the whole.

For let the number :g:`/ A B / <0313.g1:/ A B />` be the same parts of the number :g:`/ C D / <0313.g1:/ C D />` that :g:`/ A E / <0313.g1:/ A E />` subtracted is of :g:`/ C F / <0313.g1:/ C F />` subtracted;

I say that the remainder :g:`/ E B / <0313.g1:/ E B />` is also the same parts of the remainder :g:`/ F D / <0313.g1:/ F D />` that the whole :g:`/ A B / <0313.g1:/ A B />` is of the whole :g:`/ C D / <0313.g1:/ C D />`.

.. picture:: 0313.g1.svg
   :alt: Book VII, Proposition 8

For let :g:`/ G H / <0313.g1:/ G H />` be made :eq:`equal <0313.g1:/ G H / = 0313.g1:/ A B />` to :g:`/ A B / <0313.g1:/ A B />`.

.. assertion::

   Therefore, whatever parts :g:`/ G H / <0313.g1:/ G H />` is of :g:`/ C D / <0313.g1:/ C D />`, the same parts also is :g:`/ A E / <0313.g1:/ A E />` of :g:`/ C F / <0313.g1:/ C F />`.

Let :g:`/ G H / <0313.g1:/ G H />` be divided into the parts of :g:`/ C D / <0313.g1:/ C D />`, namely :g:`/ G K / <0313.g1:/ G K />`, :g:`/ K H / <0313.g1:/ K H />`, and :g:`/ A E / <0313.g1:/ A E />` into the parts of :g:`/ C F / <0313.g1:/ C F />`, namely :g:`/ A L / <0313.g1:/ A L />`, :g:`/ L E / <0313.g1:/ L E />`;

.. assertion::

   thus the multitude of :g:`/ G K / <0313.g1:/ G K />`, :g:`/ K H / <0313.g1:/ K H />` will be equal to the multitude of :g:`/ A L / <0313.g1:/ A L />`, :g:`/ L E / <0313.g1:/ L E />`.

.. subclause::

   Now since, whatever part :g:`/ G K / <0313.g1:/ G K />` is of :g:`/ C D / <0313.g1:/ C D />`, the same part also is :g:`/ A L / <0313.g1:/ A L />` of :g:`/ C F / <0313.g1:/ C F />`, while :g:`/ C D / <0313.g1:/ C D />` is greater than :g:`/ C F / <0313.g1:/ C F />`,

.. assertion::

   therefore :g:`/ G K / <0313.g1:/ G K />` is also greater than :g:`/ A L / <0313.g1:/ A L />`.

.. subclause::

   Let :g:`/ G M / <0313.g1:/ G M />` be made :eq:`equal <0313.g1:/ G M / = 0313.g1:/ A L />` to :g:`/ A L / <0313.g1:/ A L />`.

.. assertion::

   Therefore, whatever part :g:`/ G K / <0313.g1:/ G K />` is of :g:`/ C D / <0313.g1:/ C D />`, the same part also is :g:`/ G M / <0313.g1:/ G M />` of :g:`/ C F / <0313.g1:/ C F />`;

.. assertion::

   therefore also the remainder :g:`/ M K / <0313.g1:/ M K />` is the same part of the remainder :g:`/ F D / <0313.g1:/ F D />` that the whole :g:`/ G K / <0313.g1:/ G K />` is of the whole :g:`/ C D / <0313.g1:/ C D />`. :just:`[G.206] <G.206>`

.. subclause::

   Again, since, whatever part :g:`/ K H / <0313.g1:/ K H />` is of :g:`/ C D / <0313.g1:/ C D />`, the same part also is :g:`/ L E / <0313.g1:/ L E />` of :g:`/ C F / <0313.g1:/ C F />`, while :g:`/ C D / <0313.g1:/ C D />` is greater than :g:`/ C F / <0313.g1:/ C F />`,

.. assertion::

   therefore :g:`/ K H / <0313.g1:/ K H />` is also greater than :g:`/ L E / <0313.g1:/ L E />`.

.. subclause::

   Let :g:`/ K N / <0313.g1:/ K N />` be made :eq:`equal <0313.g1:/ K N / = 0313.g1:/ L E />` to :g:`/ L E / <0313.g1:/ L E />`.

.. assertion::

   Therefore, whatever part :g:`/ K H / <0313.g1:/ K H />` is of :g:`/ C D / <0313.g1:/ C D />`, the same part also is :g:`/ K N / <0313.g1:/ K N />` of :g:`/ C F / <0313.g1:/ C F />`;

.. assertion::

   therefore also the remainder :g:`/ N H / <0313.g1:/ N H />` is the same part of the remainder :g:`/ F D / <0313.g1:/ F D />` that the whole :g:`/ K H / <0313.g1:/ K H />` is of the whole :g:`/ C D / <0313.g1:/ C D />`. :just:`[G.206] <G.206>`

.. subclause::

   But the remainder :g:`/ M K / <0313.g1:/ M K />` was also proved to be the same part of the remainder :g:`/ F D / <0313.g1:/ F D />` that the whole :g:`/ G K / <0313.g1:/ G K />` is of the whole :g:`/ C D / <0313.g1:/ C D />`;

.. assertion::

   therefore also the sum of :g:`/ M K / <0313.g1:/ M K />`, :g:`/ N H / <0313.g1:/ N H />` is the same parts of :g:`/ F D / <0313.g1:/ F D />` that the whole :g:`/ G H / <0313.g1:/ G H />` is of the whole :g:`/ C D / <0313.g1:/ C D />`.

.. subclause::

   But the sum of :g:`/ M K / <0313.g1:/ M K />`, :g:`/ N H / <0313.g1:/ N H />` is equal to :g:`/ E B / <0313.g1:/ E B />`, and :g:`/ G H / <0313.g1:/ G H />` is :eq:`equal <0313.g1:/ G H / = 0313.g1:/ A B />` to :g:`/ A B / <0313.g1:/ A B />`;

.. assertion::

   therefore the remainder :g:`/ E B / <0313.g1:/ E B />` is the same parts of the remainder :g:`/ F D / <0313.g1:/ F D />` that the whole :g:`/ A B / <0313.g1:/ A B />` is of the whole :g:`/ C D / <0313.g1:/ C D />`.

.. qed::

   Therefore etc. :just:`Q. E. D.`
