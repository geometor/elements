G.239 parallelograms applied segment — Heath
============================================

.. rubric:: `VI.27 <https://geometor.github.io/euclid/heath/volume_II/book_vi/propositions/27/>`_

.. enunciation::

   Of all the parallelograms applied to the same :term:`straight line <G.4>` and deficient by parallelogrammic :term:`figures <G.9>` similar and similarly situated to that described on the half of the straight line, that parallelogram is greatest which is applied to the half of the straight line and is similar to the defect.

Let :g:`/ A B / <g1:/ A B />` be a straight line and let it be :eq:`bisected <g1:/ A C / = g1:/ C B />` at :g:`C <g1:C>` ; let there be applied to the straight line :g:`/ A B / <g1:/ A B />` the parallelogram :g:`< A D > <g1:< A D >>` deficient by the parallelogrammic figure :g:`< D B > <g1:< D B >>` described on the half of :g:`/ A B / <g1:/ A B />`, that is, :g:`/ C B / <g1:/ C B />` ;

I say that, of all the parallelograms applied to :g:`/ A B / <g1:/ A B />` and deficient by parallelogrammic figures similar and similarly situated to :g:`< D B > <g1:< D B >>`, :g:`< A D > <g1:< A D >>` is greatest.

.. picture:: g1.svg
   :alt: Proposition 27

.. subclause::

   For let there be applied to the straight line :g:`/ A B / <g1:/ A B />` the parallelogram :g:`< A F > <g1:< A F >>` deficient by the parallelogrammic figure :g:`< F B > <g1:< F B >>` similar and similarly situated to :g:`< D B > <g1:< D B >>` ;

I say that :g:`< A D > <g1:< A D >>` is greater than :g:`< A F > <g1:< A F >>`.

.. subclause::

   For, since the parallelogram :g:`< D B > <g1:< D B >>` is similar to the parallelogram :g:`< F B > <g1:< F B >>`,

.. assertion:: [G.238] <G.238>

   they are about the same :term:`diameter <G.61>`.

.. subclause::

   Let their diameter :g:`/ D B / <g1:/ D B />` be drawn, and let the figure be described.

.. subclause::

   Then, since :g:`< C F > <g1:< C F >>` is :eq:`equal <g1:< C F > = g1:< F E >>` to :g:`< F E > <g1:< F E >>`, :just:`[G.72] <G.72>` and :g:`< F B > <g1:< F B >>` is common,

.. assertion::

   therefore the whole :g:`< C H > <g1:< C H >>` is :eq:`equal <g1:< C H > = g1:< K E >>` to the whole :g:`< K E > <g1:< K E >>`.

.. assertion::

   But :g:`< C H > <g1:< C H >>` is :eq:`equal <g1:< C H > = g1:< C G >>` to :g:`< C G > <g1:< C G >>`, since :g:`/ A C / <g1:/ A C />` is also :eq:`equal <g1:/ A C / = g1:/ C B />` to :g:`/ C B / <g1:/ C B />`. :just:`[G.65] <G.65>`

.. assertion::

   Therefore :g:`< C G > <g1:< C G >>` is also :eq:`equal <g1:< C G > = g1:< K E >>` to :g:`< K E > <g1:< K E >>`.

.. subclause::

   Let :g:`< C F > <g1:< C F >>` be added to each ;

.. assertion::

   therefore the whole :g:`< A F > <g1:< A F >>` is :eq:`equal <g1:< A F > = g1:< L M N >>` to the :term:`gnomon <G.86>` :g:`< L M N > <g1:< L M N >>` ;

.. assertion::

   so that the parallelogram :g:`< D B > <g1:< D B >>`, that is, :g:`< A D > <g1:< A D >>`, is greater than the parallelogram :g:`< A F > <g1:< A F >>`.

.. qed::

   Therefore etc. :just:`Q. E. D.`
