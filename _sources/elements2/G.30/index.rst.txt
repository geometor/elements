G.30
====

.. rubric:: `I.19 <https://geometor.github.io/euclid/heath/volume_I/book_i/propositions/19/>`_

.. enunciation::

   In any triangle the greater angle is subtended by the greater side.

.. picture:: 0298.g1.svg
   :alt: Proposition 19 figure

Let :g:`< A B C > <0298.g1:< A B C >>` be a triangle having the angle :g:`< A B C ) <0298.g1:< A B C )>` greater than the angle :g:`< B C A ) <0298.g1:< B C A )>`;

I say that the side :g:`/ A C / <0298.g1:/ A C />` is also greater than the side :g:`/ A B / <0298.g1:/ A B />`.

For, if not, :g:`/ A C / <0298.g1:/ A C />` is either :eq:`equal <0298.g1:/ A C / = 0298.g1:/ A B />` to :g:`/ A B / <0298.g1:/ A B />` or less.

Now :g:`/ A C / <0298.g1:/ A C />` is not :eq:`equal <0298.g1:/ A C / = 0298.g1:/ A B />` to :g:`/ A B / <0298.g1:/ A B />`; for then the angle :g:`< A B C ) <0298.g1:< A B C )>` would also have been :eq:`equal <0298.g1:< A B C ) = 0298.g1:< A C B )>` to the angle :g:`< A C B ) <0298.g1:< A C B )>`; :just:`[G.12] <G.12>`

but it is not;

.. assertion::

   therefore :g:`/ A C / <0298.g1:/ A C />` is not :eq:`equal <0298.g1:/ A C / = 0298.g1:/ A B />` to :g:`/ A B / <0298.g1:/ A B />`.

Neither is :g:`/ A C / <0298.g1:/ A C />` less than :g:`/ A B / <0298.g1:/ A B />`, for then the angle :g:`< A B C ) <0298.g1:< A B C )>` would also have been less than the angle :g:`< A C B ) <0298.g1:< A C B )>`; :just:`[G.29] <G.29>`

but it is not;

.. assertion::

   therefore :g:`/ A C / <0298.g1:/ A C />` is not less than :g:`/ A B / <0298.g1:/ A B />`.

And it was proved that it is not :eq:`equal <0298.g1:/ A C / = 0298.g1:/ A B />` either.

.. assertion::

   Therefore :g:`/ A C / <0298.g1:/ A C />` is greater than :g:`/ A B / <0298.g1:/ A B />`.

.. qed::

   Therefore etc. :just:`Q. E. D.`
