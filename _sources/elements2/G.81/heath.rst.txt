G.81 — Heath
============

.. rubric:: `III.6 <https://geometor.github.io/euclid/heath/volume_II/book_iii/propositions/06/>`_

.. enunciation::

   If two circles touch one another, they will not have the same centre.

For let the two circles :g:`( A B C ) <g1:( A B C )>`, :g:`( C D E ) <g1:( C D E )>` touch one another at the point :g:`C <g1:C>`;

I say that they will not have the same centre.

.. picture:: g1.svg
   :alt: Proposition 6 Diagram

For, if possible, let it be :g:`F <g1:F>`; let :g:`/ F C / <g1:/ F C />` be joined, and let :g:`/ F E B / <g1:/ F E B />` be drawn through at random.

Then, since the point :g:`F <g1:F>` is the centre of the circle :g:`( A B C ) <g1:( A B C )>`,

.. assertion::

   :g:`/ F C / <g1:/ F C />` is :eq:`equal <g1:/ F C / = g1:/ F B />` to :g:`/ F B / <g1:/ F B />`.

Again, since the point :g:`F <g1:F>` is the centre of the circle :g:`( C D E ) <g1:( C D E )>`,

.. assertion::

   :g:`/ F C / <g1:/ F C />` is :eq:`equal <g1:/ F C / = g1:/ F E />` to :g:`/ F E / <g1:/ F E />`.

But :g:`/ F C / <g1:/ F C />` was proved :eq:`equal <g1:/ F C / = g1:/ F B />` to :g:`/ F B / <g1:/ F B />`; therefore :g:`/ F E / <g1:/ F E />` is also :eq:`equal <g1:/ F E / = g1:/ F B />` to :g:`/ F B / <g1:/ F B />`, the less to the greater: which is impossible.

.. assertion::

   Therefore :g:`F <g1:F>` is not the centre of the circles :g:`( A B C ) <g1:( A B C )>`, :g:`( C D E ) <g1:( C D E )>`.

.. qed::

   Therefore etc. :just:`Q. E. D.`
