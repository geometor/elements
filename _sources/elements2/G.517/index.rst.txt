G.517
=====

.. rubric:: `XIII.10 <https://geometor.github.io/euclid/heath/volume_III/book_xiii/propositions/10/>`_

.. enunciation::

   If an equilateral pentagon be inscribed in a circle, the square on the side of the pentagon is equal to the squares on the side of the hexagon and on that of the decagon inscribed in the same circle.

Let :g:`( A B C D E ) <0462.g1:( A B C D E )>` be a circle, and let the :eq:`equilateral <0462.g1:/ A B / = 0462.g1:/ B C / = 0462.g1:/ C D / = 0462.g1:/ D E / = 0462.g1:/ E A />` pentagon :g:`< A B C D E > <0462.g1:< A B C D E >>` be inscribed in the circle :g:`( A B C D E ) <0462.g1:( A B C D E )>`. I say that the square on the side of the pentagon :g:`< A B C D E > <0462.g1:< A B C D E >>` is equal to the squares on the side of the hexagon and on that of the decagon inscribed in the circle :g:`( A B C D E ) <0462.g1:( A B C D E )>`.

For let the centre of the circle, the point :g:`F <0462.g1:F>`, be taken, let :g:`/ A F / <0462.g1:/ A F />` be joined and carried through to the point :g:`G <0462.g1:G>`, let :g:`/ F B / <0462.g1:/ F B />` be joined, let :g:`/ F H / <0462.g1:/ F H />` be drawn from :g:`F <0462.g1:F>` perpendicular to :g:`/ A B / <0462.g1:/ A B />` and be carried through to :g:`K <0462.g1:K>`,
let :g:`/ A K / <0462.g1:/ A K />`, :g:`/ K B / <0462.g1:/ K B />` be joined, let :g:`/ F L / <0462.g1:/ F L />` be again drawn from :g:`F <0462.g1:F>` perpendicular to :g:`/ A K / <0462.g1:/ A K />`, and be carried through to :g:`M <0462.g1:M>`, and let :g:`/ K N / <0462.g1:/ K N />` be joined.

.. picture:: 0462.g1.svg
   :alt: Proposition 10

.. subclause::

   Since the circumference :g:`( A B C G ) <0462.g1:( A B C G )>` is :eq:`equal <0462.g1:( A B C G ) = 0462.g1:( A E D G )>` to the circumference :g:`( A E D G ) <0462.g1:( A E D G )>`, and in them :g:`( A B C ) <0462.g1:( A B C )>` is :eq:`equal <0462.g1:( A B C ) = 0462.g1:( A E D )>` to :g:`( A E D ) <0462.g1:( A E D )>`,

.. assertion::

   therefore the remainder, the circumference :g:`( C G ) <0462.g1:( C G )>`, is :eq:`equal <0462.g1:( C G ) = 0462.g1:( G D )>` to the remainder :g:`( G D ) <0462.g1:( G D )>`.

.. subclause::

   But :g:`/ C D / <0462.g1:/ C D />` belongs to a pentagon;

.. assertion::

   therefore :g:`( C G ) <0462.g1:( C G )>` belongs to a decagon.

.. subclause::

   And, since :g:`/ F A / <0462.g1:/ F A />` is :eq:`equal <0462.g1:/ F A / = 0462.g1:/ F B />` to :g:`/ F B / <0462.g1:/ F B />`, and :g:`/ F H / <0462.g1:/ F H />` is perpendicular,

.. assertion::

   therefore the angle :g:`< A F K ) <0462.g1:< A F K )>` is also :eq:`equal <0462.g1:< A F K ) = 0462.g1:< K F B )>` to the angle :g:`< K F B ) <0462.g1:< K F B )>`. :just:`[G.12, G.37] <G.12, G.37>`

.. assertion::

   Hence the circumference :g:`( A K ) <0462.g1:( A K )>` is also :eq:`equal <0462.g1:( A K ) = 0462.g1:( K B )>` to :g:`( K B ) <0462.g1:( K B )>`; :just:`[G.105] <G.105>` therefore the circumference :g:`( A B ) <0462.g1:( A B )>` is double of the circumference :g:`( B K ) <0462.g1:( B K )>`; therefore the straight line :g:`/ A K / <0462.g1:/ A K />` is a side of a decagon.

.. assertion::

   For the same reason :g:`( A K ) <0462.g1:( A K )>` is also double of :g:`( K M ) <0462.g1:( K M )>`.

.. subclause::

   Now, since the circumference :g:`( A B ) <0462.g1:( A B )>` is double of the circumference :g:`( B K ) <0462.g1:( B K )>`, while the circumference :g:`( C D ) <0462.g1:( C D )>` is :eq:`equal <0462.g1:( C D ) = 0462.g1:( A B )>` to the circumference :g:`( A B ) <0462.g1:( A B )>`,

.. assertion::

   therefore the circumference :g:`( C D ) <0462.g1:( C D )>` is also double of the circumference :g:`( B K ) <0462.g1:( B K )>`.

.. subclause::

   But the circumference :g:`( C D ) <0462.g1:( C D )>` is also double of :g:`( C G ) <0462.g1:( C G )>`;

.. assertion::

   therefore the circumference :g:`( C G ) <0462.g1:( C G )>` is :eq:`equal <0462.g1:( C G ) = 0462.g1:( B K )>` to the circumference :g:`( B K ) <0462.g1:( B K )>`.

.. subclause::

   But :g:`( B K ) <0462.g1:( B K )>` is double of :g:`( K M ) <0462.g1:( K M )>`, since :g:`( A K ) <0462.g1:( A K )>` is so also;

.. assertion::

   therefore :g:`( C G ) <0462.g1:( C G )>` is also double of :g:`( K M ) <0462.g1:( K M )>`.

.. subclause::

   But, further, the circumference :g:`( C B ) <0462.g1:( C B )>` is also double of the circumference :g:`( B K ) <0462.g1:( B K )>`, for the circumference :g:`( C B ) <0462.g1:( C B )>` is :eq:`equal <0462.g1:( C B ) = 0462.g1:( B A )>` to :g:`( B A ) <0462.g1:( B A )>`.

.. assertion::

   Therefore the whole circumference :g:`( G B ) <0462.g1:( G B )>` is also double of :g:`( B M ) <0462.g1:( B M )>`; hence the angle :g:`< G F B ) <0462.g1:< G F B )>` is also double of the angle :g:`< B F M ) <0462.g1:< B F M )>`. :just:`[G.198] <G.198>`

.. subclause::

   But the angle :g:`< G F B ) <0462.g1:< G F B )>` is also double of the angle :g:`< F A B ) <0462.g1:< F A B )>`, for the angle :g:`< F A B ) <0462.g1:< F A B )>` is :eq:`equal <0462.g1:< F A B ) = 0462.g1:< A B F )>` to the angle :g:`< A B F ) <0462.g1:< A B F )>`.

.. assertion::

   Therefore the angle :g:`< B F N ) <0462.g1:< B F N )>` is also :eq:`equal <0462.g1:< B F N ) = 0462.g1:< F A B )>` to the angle :g:`< F A B ) <0462.g1:< F A B )>`.

.. subclause::

   But the angle :g:`< A B F ) <0462.g1:< A B F )>` is common to the two triangles :g:`< A B F > <0462.g1:< A B F >>` and :g:`< B F N > <0462.g1:< B F N >>`;

.. assertion::

   therefore the remaining angle :g:`< A F B ) <0462.g1:< A F B )>` is :eq:`equal <0462.g1:< A F B ) = 0462.g1:< B N F )>` to the remaining angle :g:`< B N F ) <0462.g1:< B N F )>`; :just:`[G.45] <G.45>` therefore the triangle :g:`< A B F > <0462.g1:< A B F >>` is equiangular with the triangle :g:`< B F N > <0462.g1:< B F N >>`.

.. assertion::

   Therefore, proportionally, as the straight line :g:`/ A B / <0462.g1:/ A B />` is to :g:`/ B F / <0462.g1:/ B F />`, so is :g:`/ F B / <0462.g1:/ F B />` to :g:`/ B N / <0462.g1:/ B N />`; :just:`[G.166] <G.166>` therefore the rectangle :g:`/ A B / <0462.g1:/ A B />`, :g:`/ B N / <0462.g1:/ B N />` is equal to the square on :g:`/ B F / <0462.g1:/ B F />`. :just:`[G.180] <G.180>`

.. subclause::

   Again, since :g:`/ A L / <0462.g1:/ A L />` is :eq:`equal <0462.g1:/ A L / = 0462.g1:/ L K />` to :g:`/ L K / <0462.g1:/ L K />`, while :g:`/ L N / <0462.g1:/ L N />` is common and at right angles,

.. assertion::

   therefore the base :g:`/ K N / <0462.g1:/ K N />` is :eq:`equal <0462.g1:/ K N / = 0462.g1:/ A N />` to the base :g:`/ A N / <0462.g1:/ A N />`; :just:`[G.11] <G.11>` therefore the angle :g:`< L K N ) <0462.g1:< L K N )>` is also :eq:`equal <0462.g1:< L K N ) = 0462.g1:< L A N )>` to the angle :g:`< L A N ) <0462.g1:< L A N )>`.

.. subclause::

   But the angle :g:`< L A N ) <0462.g1:< L A N )>` is :eq:`equal <0462.g1:< L A N ) = 0462.g1:< K B N )>` to the angle :g:`< K B N ) <0462.g1:< K B N )>`;

.. assertion::

   therefore the angle :g:`< L K N ) <0462.g1:< L K N )>` is also :eq:`equal <0462.g1:< L K N ) = 0462.g1:< K B N )>` to the angle :g:`< K B N ) <0462.g1:< K B N )>`.

.. subclause::

   And the angle at :g:`A <0462.g1:A>` is common to the two triangles :g:`< A K B > <0462.g1:< A K B >>` and :g:`< A K N > <0462.g1:< A K N >>`.

.. assertion::

   Therefore the remaining angle :g:`< A K B ) <0462.g1:< A K B )>` is :eq:`equal <0462.g1:< A K B ) = 0462.g1:< K N A )>` to the remaining angle :g:`< K N A ) <0462.g1:< K N A )>`; :just:`[G.45] <G.45>` therefore the triangle :g:`< K B A > <0462.g1:< K B A >>` is equiangular with the triangle :g:`< K N A > <0462.g1:< K N A >>`.

.. assertion::

   Therefore, proportionally, as the straight line :g:`/ B A / <0462.g1:/ B A />` is to :g:`/ A K / <0462.g1:/ A K />`, so is :g:`/ K A / <0462.g1:/ K A />` to :g:`/ A N / <0462.g1:/ A N />`; :just:`[G.166] <G.166>` therefore the rectangle :g:`/ B A / <0462.g1:/ B A />`, :g:`/ A N / <0462.g1:/ A N />` is equal to the square on :g:`/ A K / <0462.g1:/ A K />`. :just:`[G.180] <G.180>`

.. subclause::

   But the rectangle :g:`/ A B / <0462.g1:/ A B />`, :g:`/ B N / <0462.g1:/ B N />` was also proved equal to the square on :g:`/ B F / <0462.g1:/ B F />`;

.. assertion::

   therefore the rectangle :g:`/ A B / <0462.g1:/ A B />`, :g:`/ B N / <0462.g1:/ B N />` together with the rectangle :g:`/ B A / <0462.g1:/ B A />`, :g:`/ A N / <0462.g1:/ A N />`, that is, the square on :g:`/ B A / <0462.g1:/ B A />` :just:`[G.63] <G.63>`, is equal to the square on :g:`/ B F / <0462.g1:/ B F />` together with the square on :g:`/ A K / <0462.g1:/ A K />`.

.. assertion::

   And :g:`/ B A / <0462.g1:/ B A />` is a side of the pentagon, :g:`/ B F / <0462.g1:/ B F />` of the hexagon :just:`[G.133] <G.133>`, and :g:`/ A K / <0462.g1:/ A K />` of the decagon.

.. qed::

   Therefore etc. :just:`Q. E. D.`
