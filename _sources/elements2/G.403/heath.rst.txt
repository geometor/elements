G.403 find two rational segments commensurable in square only — Heath
=====================================================================

.. rubric:: `X.29 <https://geometor.github.io/euclid/heath/volume_III/book_x/propositions/029/>`_

.. enunciation::

   To find two :term:`rational <G.392>` :term:`straight lines <G.4>` :term:`commensurable in square only <G.380>` and such that the :term:`square <G.63>` on the greater is greater than the square on the less by the square on a straight line :term:`commensurable <G.372>` in length with the greater.

For let there be set out any rational straight line :g:`/ A B / <g1:/ A B />`, and two :term:`square numbers <G.308>` :g:`/ C D / <g1:/ C D />`, :g:`/ E D / <g1:/ E D />` such that their difference :g:`/ C E / <g1:/ C E />` is not square; :just:`[Lemma 1]` let there be described on :g:`/ A B / <g1:/ A B />` the :term:`semicircle <G.96>` :g:`( A F B ) <g1:( A F B )>`,
and let it be contrived that, as :g:`/ D C / <g1:/ D C />` is to :g:`/ C E / <g1:/ C E />`, so is the square on :g:`/ B A / <g1:/ B A />` to the square on :g:`/ A F / <g1:/ A F />`. :just:`[G.377] <G.377>` Let :g:`/ F B / <g1:/ F B />` be joined.

.. picture:: g1.svg
   :alt: Proposition 29

.. subclause::

   Since, as the square on :g:`/ B A / <g1:/ B A />` is to the square on :g:`/ A F / <g1:/ A F />`, so is :g:`/ D C / <g1:/ D C />` to :g:`/ C E / <g1:/ C E />`,

.. assertion::

   therefore the square on :g:`/ B A / <g1:/ B A />` has to the square on :g:`/ A F / <g1:/ A F />` the :term:`ratio <G.173>` which the :term:`number <G.248>` :g:`/ D C / <g1:/ D C />` has to the number :g:`/ C E / <g1:/ C E />`; therefore the square on :g:`/ B A / <g1:/ B A />` is commensurable with the square on :g:`/ A F / <g1:/ A F />`. :just:`[G.377] <G.377>`

.. subclause:: [G.392] <G.392>

   But the square on :g:`/ A B / <g1:/ A B />` is rational;

.. assertion::

   therefore the square on :g:`/ A F / <g1:/ A F />` is also rational; :just:`[G.392] <G.392>` therefore :g:`/ A F / <g1:/ A F />` is also rational.

.. subclause::

   And, since :g:`/ D C / <g1:/ D C />` has not to :g:`/ C E / <g1:/ C E />` the ratio which a square number has to a square number,

.. assertion::

   neither has the square on :g:`/ B A / <g1:/ B A />` to the square on :g:`/ A F / <g1:/ A F />` the ratio which a square number has to a square number; therefore :g:`/ A B / <g1:/ A B />` is incommensurable in length with :g:`/ A F / <g1:/ A F />`. :just:`[G.381] <G.381>`

.. assertion::

   Therefore :g:`/ B A / <g1:/ B A />`, :g:`/ A F / <g1:/ A F />` are rational straight lines commensurable in square only.

.. subclause::

   And since, as :g:`/ D C / <g1:/ D C />` is to :g:`/ C E / <g1:/ C E />`, so is the square on :g:`/ B A / <g1:/ B A />` to the square on :g:`/ A F / <g1:/ A F />`,

.. assertion::

   therefore, :term:`*convertendo* <G.200>`, as :g:`/ C D / <g1:/ C D />` is to :g:`/ E D / <g1:/ E D />`, so is the square on :g:`/ A B / <g1:/ A B />` to the square on :g:`/ B F / <g1:/ B F />`. :just:`[G.201, G.139, G.79] <G.201, G.139, G.79>`

.. subclause::

   But :g:`/ C D / <g1:/ C D />` has to :g:`/ E D / <g1:/ E D />` the ratio which a square number has to a square number;

.. assertion::

   therefore also the square on :g:`/ A B / <g1:/ A B />` has to the square on :g:`/ B F / <g1:/ B F />` the ratio which a square number has to a square number; therefore :g:`/ A B / <g1:/ A B />` is commensurable in length with :g:`/ B F / <g1:/ B F />`. :just:`[G.381] <G.381>`

.. subclause::

   And the square on :g:`/ A B / <g1:/ A B />` is equal to the squares on :g:`/ A F / <g1:/ A F />`, :g:`/ F B / <g1:/ F B />`;

.. assertion::

   therefore the square on :g:`/ A B / <g1:/ A B />` is greater than the square on :g:`/ A F / <g1:/ A F />` by the square on :g:`/ B F / <g1:/ B F />` commensurable with :g:`/ A B / <g1:/ A B />`.

.. qed::

   Therefore there have been found two rational straight lines :g:`/ B A / <g1:/ B A />`, :g:`/ A F / <g1:/ A F />` commensurable in square only and such that the square on the greater :g:`/ A B / <g1:/ A B />` is greater than the square on the less :g:`/ A F / <g1:/ A F />` by the square on :g:`/ B F / <g1:/ B F />` commensurable in length with :g:`/ A B / <g1:/ A B />`.
