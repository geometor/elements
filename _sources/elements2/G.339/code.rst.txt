G.339 many numbers please — Code
================================

.. rubric:: `IX.10 <https://geometor.github.io/euclid/heath/volume_II/book_ix/propositions/10/>`_

.. enunciation::

   If as many :term:`numbers <G.248>` as we please beginning from an :term:`unit <G.247>` be in :term:`continued proportion <G.180>`, and the number after the unit be not :term:`square <G.63>`, neither will any other be square except the third from the unit and all those which leave out one. And, if the number after the unit be not cube, neither will any other be cube except the fourth from the unit and all those which leave out two.
