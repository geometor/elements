G.337 many numbers please — Code
================================

.. rubric:: `IX.8 <https://geometor.github.io/euclid/heath/volume_II/book_ix/propositions/08/>`_

.. enunciation::

   If as many :term:`numbers <G.248>` as we please beginning from an :term:`unit <G.247>` be in :term:`continued proportion <G.180>`, the third from the unit is :term:`square <G.63>`, as will also those which successively leave out one; the fourth is cube, as will also all those which leave out two; and the seventh is at once cube and square, as will also those which leave out five.
