G.189 — Heath
=============

.. rubric:: `VI.24 <https://geometor.github.io/euclid/heath/volume_II/book_vi/propositions/24/>`_

.. enunciation::

   In any parallelogram the parallelograms about the diameter are similar both to the whole and to one another.

Let :g:`< A B C D > <g1:< A B C D >>` be a parallelogram, and :g:`/ A C / <g1:/ A C />` its diameter, and let :g:`< E G > <g1:< E G >>`, :g:`< H K > <g1:< H K >>` be parallelograms about :g:`/ A C / <g1:/ A C />` ;

I say that each of the parallelograms :g:`< E G > <g1:< E G >>`, :g:`< H K > <g1:< H K >>` is similar both to the whole :g:`< A B C D > <g1:< A B C D >>` and to the other.

.. picture:: g1.svg
   :alt: Proposition 24 Diagram

.. subclause::

   For, since :g:`/ E F / <g1:/ E F />` has been drawn parallel to :g:`/ B C / <g1:/ B C />`, one of the sides of the triangle :g:`< A B C > <g1:< A B C >>`,

.. assertion:: [G.164] <G.164>

   proportionally, as :g:`/ B E / <g1:/ B E />` is to :g:`/ E A / <g1:/ E A />`, so is :g:`/ C F / <g1:/ C F />` to :g:`/ F A / <g1:/ F A />`.

.. subclause::

   Again, since :g:`/ F G / <g1:/ F G />` has been drawn parallel to :g:`/ C D / <g1:/ C D />`, one of the sides of the triangle :g:`< A C D > <g1:< A C D >>`,

.. assertion::

   proportionally, as :g:`/ C F / <g1:/ C F />` is to :g:`/ F A / <g1:/ F A />`, so is :g:`/ D G / <g1:/ D G />` to :g:`/ G A / <g1:/ G A />`. :just:`[G.164] <G.164>`.

.. subclause::

   But it was proved that,

.. assertion::

   as :g:`/ C F / <g1:/ C F />` is to :g:`/ F A / <g1:/ F A />`, so also is :g:`/ B E / <g1:/ B E />` to :g:`/ E A / <g1:/ E A />` ;

.. assertion::

   therefore also, as :g:`/ B E / <g1:/ B E />` is to :g:`/ E A / <g1:/ E A />`, so is :g:`/ D G / <g1:/ D G />` to :g:`/ G A / <g1:/ G A />`,

.. subclause::

   and therefore, :term:`*componendo* <componendo>`,

.. assertion:: [G.155] <G.155>

   as :g:`/ B A / <g1:/ B A />` is to :g:`/ A E / <g1:/ A E />`, so is :g:`/ D A / <g1:/ D A />` to :g:`/ A G / <g1:/ A G />`,

.. subclause::

   and, alternately,

.. assertion:: [G.153] <G.153>

   as :g:`/ B A / <g1:/ B A />` is to :g:`/ A D / <g1:/ A D />`, so is :g:`/ E A / <g1:/ E A />` to :g:`/ A G / <g1:/ A G />`.

.. assertion::

   Therefore in the parallelograms :g:`< A B C D > <g1:< A B C D >>`, :g:`< E G > <g1:< E G >>`, the sides about the common angle :g:`< B A D ) <g1:< B A D )>` are proportional.

.. subclause::

   And, since :g:`/ G F / <g1:/ G F />` is parallel to :g:`/ D C / <g1:/ D C />`,

.. assertion::

   the angle :g:`< A F G ) <g1:< A F G )>` is :eq:`equal <g1:< A F G ) = g1:< D C A )>` to the angle :g:`< D C A ) <g1:< D C A )>` ;

.. subclause::

   and the angle :g:`< D A C ) <g1:< D A C )>` is common to the two triangles :g:`< A D C > <g1:< A D C >>`, :g:`< A G F > <g1:< A G F >>` ;

.. assertion::

   therefore the triangle :g:`< A D C > <g1:< A D C >>` is :eq:`equiangular <g1:< A F G ) = g1:< D C A ); g1:< D A C ) = g1:< D A C )>` with the triangle :g:`< A G F > <g1:< A G F >>`.

.. subclause::

   For the same reason

.. assertion::

   the triangle :g:`< A C B > <g1:< A C B >>` is also equiangular with the triangle :g:`< A F E > <g1:< A F E >>`,

.. assertion::

   and the whole parallelogram :g:`< A B C D > <g1:< A B C D >>` is equiangular with the parallelogram :g:`< E G > <g1:< E G >>`.

.. subclause::

   Therefore, proportionally,

.. assertion::

   as :g:`/ A D / <g1:/ A D />` is to :g:`/ D C / <g1:/ D C />`, so is :g:`/ A G / <g1:/ A G />` to :g:`/ G F / <g1:/ G F />`, as :g:`/ D C / <g1:/ D C />` is to :g:`/ C A / <g1:/ C A />`, so is :g:`/ G F / <g1:/ G F />` to :g:`/ F A / <g1:/ F A />`, as :g:`/ A C / <g1:/ A C />` is to :g:`/ C B / <g1:/ C B />`, so is :g:`/ A F / <g1:/ A F />` to :g:`/ F E / <g1:/ F E />`, and further, as :g:`/ C B / <g1:/ C B />` is to :g:`/ B A / <g1:/ B A />`, so is :g:`/ F E / <g1:/ F E />` to :g:`/ E A / <g1:/ E A />`.

.. subclause::

   And, since it was proved that, as :g:`/ D C / <g1:/ D C />` is to :g:`/ C A / <g1:/ C A />`, so is :g:`/ G F / <g1:/ G F />` to :g:`/ F A / <g1:/ F A />`, and, as :g:`/ A C / <g1:/ A C />` is to :g:`/ C B / <g1:/ C B />`, so is :g:`/ A F / <g1:/ A F />` to :g:`/ F E / <g1:/ F E />`,

.. assertion:: [G.159] <G.159>

   therefore, :term:`*ex aequali* <ex-aequali>`, as :g:`/ D C / <g1:/ D C />` is to :g:`/ C B / <g1:/ C B />`, so is :g:`/ G F / <g1:/ G F />` to :g:`/ F E / <g1:/ F E />`.

.. assertion::

   Therefore in the parallelograms :g:`< A B C D > <g1:< A B C D >>`, :g:`< E G > <g1:< E G >>` the sides about the equal angles are proportional ;

.. assertion::

   therefore the parallelogram :g:`< A B C D > <g1:< A B C D >>` is similar to the parallelogram :g:`< E G > <g1:< E G >>`. :just:`[G.170] <G.170>`

.. subclause::

   For the same reason

.. assertion::

   the parallelogram :g:`< A B C D > <g1:< A B C D >>` is also similar to the parallelogram :g:`< K H > <g1:< K H >>` ;

.. assertion::

   therefore each of the parallelograms :g:`< E G > <g1:< E G >>`, :g:`< H K > <g1:< H K >>` is similar to :g:`< A B C D > <g1:< A B C D >>`.

.. subclause::

   But figures similar to the same rectilineal figure are also similar to one another ; :just:`[G.186] <G.186>`

.. assertion::

   therefore the parallelogram :g:`< E G > <g1:< E G >>` is also similar to the parallelogram :g:`< H K > <g1:< H K >>`.

.. qed::

   Therefore etc. :just:`Q. E. D.`
