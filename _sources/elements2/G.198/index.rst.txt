G.198
=====

.. rubric:: `VI.33 <https://geometor.github.io/euclid/heath/volume_II/book_vi/propositions/33/>`_

.. enunciation::

   In equal circles angles have the same ratio as the circumferences on which they stand, whether they stand at the centres or at the circumferences.

Let :g:`( A B C ) <0279.g2:( A B C )>`, :g:`( D E F ) <0279.g2:( D E F )>` be :eq:`equal <0279.g2:( A B C ) = 0279.g2:( D E F )>` circles, and let the angles :g:`< B G C ) <0279.g2:< B G C )>`, :g:`< E H F ) <0279.g2:< E H F )>` be angles at their centres :g:`G <0279.g2:G>`, :g:`H <0279.g2:H>`, and the angles :g:`< B A C ) <0279.g2:< B A C )>`, :g:`< E D F ) <0279.g2:< E D F )>` angles at the circumferences;

I say that, as the circumference :g:`( B C ) <0279.g2:( B C )>` is to the circumference :g:`( E F ) <0279.g2:( E F )>`, so is the angle :g:`< B G C ) <0279.g2:< B G C )>` to the angle :g:`< E H F ) <0279.g2:< E H F )>`, and the angle :g:`< B A C ) <0279.g2:< B A C )>` to the angle :g:`< E D F ) <0279.g2:< E D F )>`.

.. picture:: 0279.g2.svg
   :alt: Proposition 33

For let any number of consecutive circumferences :g:`( C K ) <0279.g2:( C K )>`, :g:`( K L ) <0279.g2:( K L )>` be made :eq:`equal <0279.g2:( C K ) = 0279.g2:( K L ) = 0279.g2:( B C )>` to the circumference :g:`( B C ) <0279.g2:( B C )>`, and any number of consecutive circumferences :g:`( F M ) <0279.g2:( F M )>`, :g:`( M N ) <0279.g2:( M N )>` :eq:`equal <0279.g2:( F M ) = 0279.g2:( M N ) = 0279.g2:( E F )>` to the circumference :g:`( E F ) <0279.g2:( E F )>`; and let :g:`/ G K / <0279.g2:/ G K />`, :g:`/ G L / <0279.g2:/ G L />`, :g:`/ H M / <0279.g2:/ H M />`, :g:`/ H N / <0279.g2:/ H N />` be joined.

.. subclause::

   Then, since the circumferences :g:`( B C ) <0279.g2:( B C )>`, :g:`( C K ) <0279.g2:( C K )>`, :g:`( K L ) <0279.g2:( K L )>` are :eq:`equal <0279.g2:( B C ) = 0279.g2:( C K ) = 0279.g2:( K L )>` to one another,

.. assertion:: [G.106] <G.106>

   the angles :g:`< B G C ) <0279.g2:< B G C )>`, :g:`< C G K ) <0279.g2:< C G K )>`, :g:`< K G L ) <0279.g2:< K G L )>` are also :eq:`equal <0279.g2:< B G C ) = 0279.g2:< C G K ) = 0279.g2:< K G L )>` to one another;

.. assertion::

   therefore, whatever multiple the circumference :g:`( B L ) <0279.g2:( B L )>` is of :g:`( B C ) <0279.g2:( B C )>`, that multiple also is the angle :g:`< B G L ) <0279.g2:< B G L )>` of the angle :g:`< B G C ) <0279.g2:< B G C )>`.

.. subclause::

   For the same reason also,

.. assertion::

   whatever multiple the circumference :g:`( N E ) <0279.g2:( N E )>` is of :g:`( E F ) <0279.g2:( E F )>`, that multiple also is the angle :g:`< N H E ) <0279.g2:< N H E )>` of the angle :g:`< E H F ) <0279.g2:< E H F )>`.

.. assertion::

   If then the circumference :g:`( B L ) <0279.g2:( B L )>` is :eq:`equal <0279.g2:( B L ) = 0279.g2:( E N )>` to the circumference :g:`( E N ) <0279.g2:( E N )>`, the angle :g:`< B G L ) <0279.g2:< B G L )>` is also :eq:`equal <0279.g2:< B G L ) = 0279.g2:< E H N )>` to the angle :g:`< E H N ) <0279.g2:< E H N )>`; :just:`[G.106] <G.106>` if the circumference :g:`( B L ) <0279.g2:( B L )>` is greater than the circumference :g:`( E N ) <0279.g2:( E N )>`, the angle :g:`< B G L ) <0279.g2:< B G L )>` is also greater than the angle :g:`< E H N ) <0279.g2:< E H N )>`; and, if less, less.

.. subclause::

   There being then four magnitudes, two circumferences :g:`( B C ) <0279.g2:( B C )>`, :g:`( E F ) <0279.g2:( E F )>`, and two angles :g:`< B G C ) <0279.g2:< B G C )>`, :g:`< E H F ) <0279.g2:< E H F )>`, there have been taken, of the circumference :g:`( B C ) <0279.g2:( B C )>` and the angle :g:`< B G C ) <0279.g2:< B G C )>` equimultiples, namely the circumference :g:`( B L ) <0279.g2:( B L )>` and the angle :g:`< B G L ) <0279.g2:< B G L )>`, and of the circumference :g:`( E F ) <0279.g2:( E F )>` and the angle :g:`< E H F ) <0279.g2:< E H F )>` equimultiples, namely the circumference :g:`( E N ) <0279.g2:( E N )>` and the angle :g:`< E H N ) <0279.g2:< E H N )>`.

.. subclause::

   And it has been proved that, if the circumference :g:`( B L ) <0279.g2:( B L )>` is in excess of the circumference :g:`( E N ) <0279.g2:( E N )>`, the angle :g:`< B G L ) <0279.g2:< B G L )>` is also in excess of the angle :g:`< E H N ) <0279.g2:< E H N )>`; if :eq:`equal <0279.g2:( B L ) = 0279.g2:( E N )>`, :eq:`equal <0279.g2:< B G L ) = 0279.g2:< E H N )>`; and if less, less.

.. assertion::

   Therefore, as the circumference :g:`( B C ) <0279.g2:( B C )>` is to :g:`( E F ) <0279.g2:( E F )>`, so is the angle :g:`< B G C ) <0279.g2:< B G C )>` to the angle :g:`< E H F ) <0279.g2:< E H F )>`. :just:`[G.138] <G.138>`

.. subclause::

   But, as the angle :g:`< B G C ) <0279.g2:< B G C )>` is to the angle :g:`< E H F ) <0279.g2:< E H F )>`, so is the angle :g:`< B A C ) <0279.g2:< B A C )>` to the angle :g:`< E D F ) <0279.g2:< E D F )>`; for they are doubles respectively.

.. assertion::

   Therefore also, as the circumference :g:`( B C ) <0279.g2:( B C )>` is to the circumference :g:`( E F ) <0279.g2:( E F )>`, so is the angle :g:`< B G C ) <0279.g2:< B G C )>` to the angle :g:`< E H F ) <0279.g2:< E H F )>`, and the angle :g:`< B A C ) <0279.g2:< B A C )>` to the angle :g:`< E D F ) <0279.g2:< E D F )>`.

.. qed::

   Therefore etc. :just:`Q. E. D.`
