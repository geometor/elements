G.128 segment there constructed — Heath
=======================================

.. rubric:: `III.23 <https://geometor.github.io/euclid/heath/volume_II/book_iii/propositions/23/>`_

.. enunciation::

   On the same :term:`straight line <G.4>` there cannot be constructed two similar and unequal :term:`segments of circles <G.126>` on the same side.

For, if possible, on the same straight line :g:`/ A B / <g1:/ A B />` let two
similar and unequal segments of circles
:g:`( A C B ) <g1:( A C B )>`, :g:`( A D B ) <g1:( A D B )>` be constructed on the same
side;
let :g:`/ A C D / <g1:/ A C D />` be drawn through, and let :g:`/ C B / <g1:/ C B />`,
:g:`/ D B / <g1:/ D B />` be joined.

.. picture:: g1.svg
   :alt: Diagram for Proposition 23

Then, since the segment :g:`( A C B ) <g1:( A C B )>` is
similar to the segment :g:`( A D B ) <g1:( A D B )>`,
and :term:`similar segments of circles <G.127>` are those which admit equal
:term:`angles <G.22>`, :just:`[G.127] <G.127>`
the angle :g:`< A C B ) <g1:< A C B )>` is :eq:`equal <g1:< A C B ) = g1:< A D B )>` to the angle :g:`< A D B ) <g1:< A D B )>`, the exterior
to the interior: which is impossible. :just:`[G.41] <G.41>`

.. qed::

   Therefore etc. :just:`Q. E. D.`
