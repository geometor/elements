G.399 rectangle contained medial — Heath
========================================

.. rubric:: `X.25 <https://geometor.github.io/euclid/heath/volume_III/book_x/propositions/025/>`_

.. enunciation::

   The :term:`rectangle contained <G.81>` by medial :term:`straight lines <G.4>` :term:`commensurable in square only <G.380>` is either :term:`rational <G.392>` or medial.

.. picture:: g1.svg
   :alt: Proposition 25

For let the rectangle :g:`< A C > <g1:< A C >>` be contained by the medial straight lines :g:`/ A B / <g1:/ A B />`, :g:`/ B C / <g1:/ B C />` which are commensurable in square only; I say that :g:`< A C > <g1:< A C >>` is either rational or medial.

For on :g:`/ A B / <g1:/ A B />`, :g:`/ B C / <g1:/ B C />` let the :term:`squares <G.63>` :g:`< A D > <g1:< A D >>`, :g:`< B E > <g1:< B E >>` be described;

.. assertion::

   therefore each of the squares :g:`< A D > <g1:< A D >>`, :g:`< B E > <g1:< B E >>` is medial.

Let a rational straight line :g:`/ F G / <g1:/ F G />` be set out, to :g:`/ F G / <g1:/ F G />` let there be applied the rectangular parallelogram :g:`< G H > <g1:< G H >>` :eq:`equal <g1:< G H > = g1:< A D >>` to :g:`< A D > <g1:< A D >>`, producing :g:`/ F H / <g1:/ F H />` as breadth, to :g:`/ H M / <g1:/ H M />` let there be applied the rectangular parallelogram :g:`< M K > <g1:< M K >>` :eq:`equal <g1:< M K > = g1:< A C >>` to :g:`< A C > <g1:< A C >>`, producing :g:`/ H K / <g1:/ H K />` as breadth, and further to :g:`/ K N / <g1:/ K N />` let there be similarly applied :g:`< N L > <g1:< N L >>` :eq:`equal <g1:< N L > = g1:< B E >>` to :g:`< B E > <g1:< B E >>`, producing :g:`/ K L / <g1:/ K L />` as breadth;

.. assertion::

   therefore :g:`/ F H / <g1:/ F H />`, :g:`/ H K / <g1:/ H K />`, :g:`/ K L / <g1:/ K L />` are in a straight line.

.. subclause::

   Since then each of the squares :g:`< A D > <g1:< A D >>`, :g:`< B E > <g1:< B E >>` is medial, and :g:`< A D > <g1:< A D >>` is :eq:`equal <g1:< A D > = g1:< G H >; g1:< B E > = g1:< N L >>` to :g:`< G H > <g1:< G H >>`, and :g:`< B E > <g1:< B E >>` to :g:`< N L > <g1:< N L >>`,

.. assertion::

   therefore each of the rectangles :g:`< G H > <g1:< G H >>`, :g:`< N L > <g1:< N L >>` is also medial.

.. subclause::

   And they are applied to the rational straight line :g:`/ F G / <g1:/ F G />`;

.. assertion::

   therefore each of the straight lines :g:`/ F H / <g1:/ F H />`, :g:`/ K L / <g1:/ K L />` is rational and :term:`incommensurable <G.372>` in length with :g:`/ F G / <g1:/ F G />`. :just:`[G.396] <G.396>`

.. subclause::

   And, since :g:`< A D > <g1:< A D >>` is commensurable with :g:`< B E > <g1:< B E >>`,

.. assertion::

   therefore :g:`< G H > <g1:< G H >>` is also commensurable with :g:`< N L > <g1:< N L >>`.

.. subclause:: [G.210] <G.210>

   And, as :g:`< G H > <g1:< G H >>` is to :g:`< N L > <g1:< N L >>`, so is :g:`/ F H / <g1:/ F H />` to :g:`/ K L / <g1:/ K L />`;

.. assertion:: [G.382] <G.382>

   therefore :g:`/ F H / <g1:/ F H />` is commensurable in length with :g:`/ K L / <g1:/ K L />`.

.. assertion::

   Therefore :g:`/ F H / <g1:/ F H />`, :g:`/ K L / <g1:/ K L />` are rational straight lines commensurable in length;

.. assertion:: [G.393] <G.393>

   therefore the rectangle :g:`/ F H / <g1:/ F H />`, :g:`/ K L / <g1:/ K L />` is rational.

.. subclause::

   And, since :g:`/ D B / <g1:/ D B />` is :eq:`equal <g1:/ D B / = g1:/ B A /; g1:/ O B / = g1:/ B C />` to :g:`/ B A / <g1:/ B A />`, and :g:`/ O B / <g1:/ O B />` to :g:`/ B C / <g1:/ B C />`,

.. assertion::

   therefore, as :g:`/ D B / <g1:/ D B />` is to :g:`/ B C / <g1:/ B C />`, so is :g:`/ A B / <g1:/ A B />` to :g:`/ B O / <g1:/ B O />`.

.. subclause::

   But, as :g:`/ D B / <g1:/ D B />` is to :g:`/ B C / <g1:/ B C />`, so is :g:`< D A > <g1:< D A >>` to :g:`< A C > <g1:< A C >>`, :just:`[G.210] <G.210>` and, as :g:`/ A B / <g1:/ A B />` is to :g:`/ B O / <g1:/ B O />`, so is :g:`< A C > <g1:< A C >>` to :g:`< C O > <g1:< C O >>`; :just:`[G.210] <G.210>`

.. assertion::

   therefore, as :g:`< D A > <g1:< D A >>` is to :g:`< A C > <g1:< A C >>`, so is :g:`< A C > <g1:< A C >>` to :g:`< C O > <g1:< C O >>`.

.. subclause::

   But :g:`< A D > <g1:< A D >>` is :eq:`equal <g1:< A D > = g1:< G H >; g1:< A C > = g1:< M K >; g1:< C O > = g1:< N L >>` to :g:`< G H > <g1:< G H >>`, :g:`< A C > <g1:< A C >>` to :g:`< M K > <g1:< M K >>` and :g:`< C O > <g1:< C O >>` to :g:`< N L > <g1:< N L >>`;

.. assertion::

   therefore, as :g:`< G H > <g1:< G H >>` is to :g:`< M K > <g1:< M K >>`, so is :g:`< M K > <g1:< M K >>` to :g:`< N L > <g1:< N L >>`;

.. assertion::

   therefore also, as :g:`/ F H / <g1:/ F H />` is to :g:`/ H K / <g1:/ H K />`, so is :g:`/ H K / <g1:/ H K />` to :g:`/ K L / <g1:/ K L />`; :just:`[G.210, G.189] <G.210, G.189>` therefore the rectangle :g:`/ F H / <g1:/ F H />`, :g:`/ K L / <g1:/ K L />` is equal to the square on :g:`/ H K / <g1:/ H K />`. :just:`[G.228] <G.228>`

.. subclause::

   But the rectangle :g:`/ F H / <g1:/ F H />`, :g:`/ K L / <g1:/ K L />` is rational;

.. assertion::

   therefore the square on :g:`/ H K / <g1:/ H K />` is also rational.

.. assertion::

   Therefore :g:`/ H K / <g1:/ H K />` is rational.

.. subclause::

   And, if it is commensurable in length with :g:`/ F G / <g1:/ F G />`,

.. assertion:: [G.393] <G.393>

   :g:`< H N > <g1:< H N >>` is rational;

.. subclause::

   but, if it is incommensurable in length with :g:`/ F G / <g1:/ F G />`,

.. assertion::

   :g:`/ K H / <g1:/ K H />`, :g:`/ H M / <g1:/ H M />` are rational straight lines commensurable in square only, and therefore :g:`< H N > <g1:< H N >>` is medial. :just:`[G.395] <G.395>`

.. assertion::

   Therefore :g:`< H N > <g1:< H N >>` is either rational or medial.

.. subclause::

   But :g:`< H N > <g1:< H N >>` is :eq:`equal <g1:< H N > = g1:< A C >>` to :g:`< A C > <g1:< A C >>`;

.. assertion::

   therefore :g:`< A C > <g1:< A C >>` is either rational or medial.

.. qed::

   Therefore etc.
