G.574 circles center inscribe — Heath
=====================================

.. rubric:: `XII.16 <https://geometor.github.io/euclid/heath/volume_III/book_xii/propositions/16/>`_

.. enunciation::

   Given two :term:`circles <G.10>` about the same :term:`centre <G.14>`, to inscribe in the greater circle an :term:`equilateral <G.12>` polygon with an :term:`even number <G.302>` of sides which does not touch the lesser circle.

Let :g:`( A B C D ) <g1:( A B C D )>`, :g:`( E F G H ) <g1:( E F G H )>` be the two given circles about the same centre :g:`K <g1:K>` ; thus it is required to inscribe in the greater circle :g:`( A B C D ) <g1:( A B C D )>` an equilateral polygon with an even number of sides which does not :term:`touch the circle <G.111>` :g:`( E F G H ) <g1:( E F G H )>`.

.. picture:: g1.svg
   :alt: Proposition 16

For let the :term:`straight line <G.4>` :g:`/ B K D / <g1:/ B K D />` be drawn through the centre :g:`K <g1:K>`, and from the :term:`point <G.1>` :g:`G <g1:G>` let :g:`/ G A / <g1:/ G A />` be drawn :term:`at right angles <G.32>` to the straight line :g:`/ B D / <g1:/ B D />` and carried through to :g:`C <g1:C>` ;

.. assertion:: [G.118] <G.118>

   therefore :g:`/ A C / <g1:/ A C />` touches the circle :g:`( E F G H ) <g1:( E F G H )>`.

Then, bisecting the circumference :g:`( B A D ) <g1:( B A D )>`, bisecting the half of it, and doing this continually, we shall leave a circumference less than :g:`( A D ) <g1:( A D )>`. :just:`[G.371] <G.371>` Let such be left, and let it be :g:`( L D ) <g1:( L D )>` ; from :g:`L <g1:L>` let :g:`/ L M / <g1:/ L M />` be drawn perpendicular to :g:`/ B D / <g1:/ B D />` and carried through to :g:`N <g1:N>`, and let :g:`/ L D / <g1:/ L D />`, :g:`/ D N / <g1:/ D N />` be joined ;

.. assertion:: [G.100, G.24] <G.100, G.24>

   therefore :g:`/ L D / <g1:/ L D />` is :eq:`equal <g1:/ L D / = g1:/ D N />` to :g:`/ D N / <g1:/ D N />`.

.. subclause::

   Now, since :g:`/ L N / <g1:/ L N />` is :term:`parallel <G.52>` to :g:`/ A C / <g1:/ A C />`, and :g:`/ A C / <g1:/ A C />` touches the circle :g:`( E F G H ) <g1:( E F G H )>`,

.. assertion::

   therefore :g:`/ L N / <g1:/ L N />` does not touch the circle :g:`( E F G H ) <g1:( E F G H )>` ; therefore :g:`/ L D / <g1:/ L D />`, :g:`/ D N / <g1:/ D N />` are far from touching the circle :g:`( E F G H ) <g1:( E F G H )>`.

.. qed::

   If then we :term:`fit into the circle <G.146>` :g:`( A B C D ) <g1:( A B C D )>` straight lines equal to the straight line :g:`/ L D / <g1:/ L D />` and placed continuously, there will be :term:`inscribed in the circle <G.148>` :g:`( A B C D ) <g1:( A B C D )>` an equilateral polygon with an even number of sides which does not touch the lesser circle :g:`( E F G H ) <g1:( E F G H )>`. :just:`Q. E. F.`
