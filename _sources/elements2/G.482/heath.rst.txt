G.482 — Heath
=============

.. rubric:: `XI.35 <https://geometor.github.io/euclid/heath/volume_III/book_xi/propositions/35/>`_

.. enunciation::

   If there be two equal plane angles, and on their vertices there be set up elevated straight lines containing equal angles with the original straight lines respectively, if on the elevated straight lines points be taken at random and perpendiculars be drawn from them to the planes in which the original angles are, and if from the points so arising in the planes straight lines be joined to the vertices of the original angles, they will contain, with the elevated straight lines, equal angles.

Let the angles :g:`< B A C ) <g1:< B A C )>`, :g:`< E D F ) <g1:< E D F )>` be two :eq:`equal <g1:< B A C ) = g1:< E D F )>` rectilineal angles, and from the points :g:`A <g1:A>`, :g:`D <g1:D>` let the elevated straight lines :g:`/ A G / <g1:/ A G />`, :g:`/ D M / <g1:/ D M />` be set up containing, with the original straight lines, :eq:`equal <g1:< M D E ) = g1:< G A B ); g1:< M D F ) = g1:< G A C )>` angles respectively, namely, the angle :g:`< M D E ) <g1:< M D E )>` to the angle :g:`< G A B ) <g1:< G A B )>` and the angle :g:`< M D F ) <g1:< M D F )>` to the angle :g:`< G A C ) <g1:< G A C )>`, let points :g:`G <g1:G>`, :g:`M <g1:M>` be taken at random on :g:`/ A G / <g1:/ A G />`, :g:`/ D M / <g1:/ D M />`, let :g:`/ G L / <g1:/ G L />`, :g:`/ M N / <g1:/ M N />` be drawn from the points :g:`G <g1:G>`, :g:`M <g1:M>` perpendicular to the planes through :g:`/ B A / <g1:/ B A />`, :g:`/ A C / <g1:/ A C />` and :g:`/ E D / <g1:/ E D />`, :g:`/ D F / <g1:/ D F />`, and let them meet the planes at :g:`L <g1:L>`, :g:`N <g1:N>`, and let :g:`/ L A / <g1:/ L A />`, :g:`/ N D / <g1:/ N D />` be joined ; I say that the angle :g:`< G A L ) <g1:< G A L )>` is :eq:`equal <g1:< G A L ) = g1:< M D N )>` to the angle :g:`< M D N ) <g1:< M D N )>`.

.. picture:: g1.svg
   :alt: Book XI, Proposition 35

Let :g:`/ A H / <g1:/ A H />` be made :eq:`equal <g1:/ A H / = g1:/ D M />` to :g:`/ D M / <g1:/ D M />`, and let :g:`/ H K / <g1:/ H K />` be drawn through the point :g:`H <g1:H>` parallel to :g:`/ G L / <g1:/ G L />`.

.. subclause::

   But :g:`/ G L / <g1:/ G L />` is perpendicular to the plane through :g:`/ B A / <g1:/ B A />`, :g:`/ A C / <g1:/ A C />`;

.. assertion::

   therefore :g:`/ H K / <g1:/ H K />` is also perpendicular to the plane through :g:`/ B A / <g1:/ B A />`, :g:`/ A C / <g1:/ A C />`. :just:`[G.451] <G.451>`

From the points :g:`K <g1:K>`, :g:`N <g1:N>` let :g:`/ K C / <g1:/ K C />`, :g:`/ N F / <g1:/ N F />`, :g:`/ K B / <g1:/ K B />`, :g:`/ N E / <g1:/ N E />` be drawn :eq:`perpendicular <g1:/ K C / = g1:/ A C /; g1:/ N F / = g1:/ D F /; g1:/ K B / = g1:/ A B /; g1:/ N E / = g1:/ D E />` to the straight lines :g:`/ A C / <g1:/ A C />`, :g:`/ D F / <g1:/ D F />`, :g:`/ A B / <g1:/ A B />`, :g:`/ D E / <g1:/ D E />`, and let :g:`/ H C / <g1:/ H C />`, :g:`/ C B / <g1:/ C B />`, :g:`/ M F / <g1:/ M F />`, :g:`/ F E / <g1:/ F E />` be joined.

.. subclause::

   Since the square on :g:`/ H A / <g1:/ H A />` is equal to the squares on :g:`/ H K / <g1:/ H K />`, :g:`/ K A / <g1:/ K A />`, and the squares on :g:`/ K C / <g1:/ K C />`, :g:`/ C A / <g1:/ C A />` are equal to the square on :g:`/ K A / <g1:/ K A />`, :just:`[G.60] <G.60>`

.. assertion::

   therefore the square on :g:`/ H A / <g1:/ H A />` is also equal to the squares on :g:`/ H K / <g1:/ H K />`, :g:`/ K C / <g1:/ K C />`, :g:`/ C A / <g1:/ C A />`.

.. subclause::

   But the square on :g:`/ H C / <g1:/ H C />` is equal to the squares on :g:`/ H K / <g1:/ H K />`, :g:`/ K C / <g1:/ K C />`; :just:`[G.60] <G.60>`

.. assertion::

   therefore the square on :g:`/ H A / <g1:/ H A />` is equal to the squares on :g:`/ H C / <g1:/ H C />`, :g:`/ C A / <g1:/ C A />`.

.. assertion:: [G.61] <G.61>

   Therefore the angle :g:`< H C A ) <g1:< H C A )>` is :eq:`right <g1:< H C A )>`.

.. assertion::

   For the same reason the angle :g:`< D F M ) <g1:< D F M )>` is also :eq:`right <g1:< D F M )>`.

.. assertion::

   Therefore the angle :g:`< A C H ) <g1:< A C H )>` is :eq:`equal <g1:< A C H ) = g1:< D F M )>` to the angle :g:`< D F M ) <g1:< D F M )>`.

.. subclause::

   But the angle :g:`< H A C ) <g1:< H A C )>` is also :eq:`equal <g1:< H A C ) = g1:< M D F )>` to the angle :g:`< M D F ) <g1:< M D F )>`.

.. assertion::

   Therefore :g:`< M D F > <g1:< M D F >>`, :g:`< H A C > <g1:< H A C >>` are two triangles which have two angles equal to two angles respectively, and one side equal to one side, namely, that subtending one of the equal angles, that is, :g:`/ H A / <g1:/ H A />` :eq:`equal <g1:/ H A / = g1:/ M D />` to :g:`/ M D / <g1:/ M D />`; therefore they will also have the remaining sides equal to the remaining sides respectively. :just:`[G.37] <G.37>`

.. assertion::

   Therefore :g:`/ A C / <g1:/ A C />` is :eq:`equal <g1:/ A C / = g1:/ D F />` to :g:`/ D F / <g1:/ D F />`.

.. assertion::

   Similarly we can prove that :g:`/ A B / <g1:/ A B />` is also :eq:`equal <g1:/ A B / = g1:/ D E />` to :g:`/ D E / <g1:/ D E />`.

.. assertion::

   Since then :g:`/ A C / <g1:/ A C />` is :eq:`equal <g1:/ A C / = g1:/ D F /; g1:/ A B / = g1:/ D E />` to :g:`/ D F / <g1:/ D F />`, and :g:`/ A B / <g1:/ A B />` to :g:`/ D E / <g1:/ D E />`, the two sides :g:`/ C A / <g1:/ C A />`, :g:`/ A B / <g1:/ A B />` are :eq:`equal <g1:/ C A / = g1:/ F D /; g1:/ A B / = g1:/ D E />` to the two sides :g:`/ F D / <g1:/ F D />`, :g:`/ D E / <g1:/ D E />`.

.. subclause::

   But the angle :g:`< C A B ) <g1:< C A B )>` is also :eq:`equal <g1:< C A B ) = g1:< F D E )>` to the angle :g:`< F D E ) <g1:< F D E )>`;

.. assertion::

   therefore the base :g:`/ B C / <g1:/ B C />` is :eq:`equal <g1:/ B C / = g1:/ E F />` to the base :g:`/ E F / <g1:/ E F />`, the triangle to the triangle, and the remaining angles to the remaining angles; :just:`[G.11] <G.11>` therefore the angle :g:`< A C B ) <g1:< A C B )>` is :eq:`equal <g1:< A C B ) = g1:< D F E )>` to the angle :g:`< D F E ) <g1:< D F E )>`.

.. subclause::

   But the right angle :g:`< A C K ) <g1:< A C K )>` is also :eq:`equal <g1:< A C K ) = g1:< D F N )>` to the right angle :g:`< D F N ) <g1:< D F N )>`;

.. assertion::

   therefore the remaining angle :g:`< B C K ) <g1:< B C K )>` is also :eq:`equal <g1:< B C K ) = g1:< E F N )>` to the remaining angle :g:`< E F N ) <g1:< E F N )>`.

.. assertion::

   For the same reason the angle :g:`< C B K ) <g1:< C B K )>` is also :eq:`equal <g1:< C B K ) = g1:< F E N )>` to the angle :g:`< F E N ) <g1:< F E N )>`.

.. assertion::

   Therefore :g:`< B C K > <g1:< B C K >>`, :g:`< E F N > <g1:< E F N >>` are two triangles which have two angles equal to two angles respectively, and one side equal to one side, namely, that adjacent to the equal angles, that is, :g:`/ B C / <g1:/ B C />` :eq:`equal <g1:/ B C / = g1:/ E F />` to :g:`/ E F / <g1:/ E F />`; therefore they will also have the remaining sides equal to the remaining sides. :just:`[G.37] <G.37>`

.. assertion::

   Therefore :g:`/ C K / <g1:/ C K />` is :eq:`equal <g1:/ C K / = g1:/ F N />` to :g:`/ F N / <g1:/ F N />`.

.. subclause::

   But :g:`/ A C / <g1:/ A C />` is also :eq:`equal <g1:/ A C / = g1:/ D F />` to :g:`/ D F / <g1:/ D F />`;

.. assertion::

   therefore the two sides :g:`/ A C / <g1:/ A C />`, :g:`/ C K / <g1:/ C K />` are :eq:`equal <g1:/ A C / = g1:/ D F /; g1:/ C K / = g1:/ F N />` to the two sides :g:`/ D F / <g1:/ D F />`, :g:`/ F N / <g1:/ F N />`; and they contain right angles.

.. assertion:: [G.11] <G.11>

   Therefore the base :g:`/ A K / <g1:/ A K />` is :eq:`equal <g1:/ A K / = g1:/ D N />` to the base :g:`/ D N / <g1:/ D N />`.

.. subclause::

   And, since :g:`/ A H / <g1:/ A H />` is :eq:`equal <g1:/ A H / = g1:/ D M />` to :g:`/ D M / <g1:/ D M />`,

.. assertion::

   the square on :g:`/ A H / <g1:/ A H />` is also :eq:`equal <g1:/ A H / = g1:/ D M />` to the square on :g:`/ D M / <g1:/ D M />`.

.. subclause::

   But the squares on :g:`/ A K / <g1:/ A K />`, :g:`/ K H / <g1:/ K H />` are equal to the square on :g:`/ A H / <g1:/ A H />`, for the angle :g:`< A K H ) <g1:< A K H )>` is :eq:`right <g1:< A K H )>`; :just:`[G.60] <G.60>` and the squares on :g:`/ D N / <g1:/ D N />`, :g:`/ N M / <g1:/ N M />` are equal to the square on :g:`/ D M / <g1:/ D M />`, for the angle :g:`< D N M ) <g1:< D N M )>` is :eq:`right <g1:< D N M )>`; :just:`[G.60] <G.60>`

.. assertion::

   therefore the squares on :g:`/ A K / <g1:/ A K />`, :g:`/ K H / <g1:/ K H />` are equal to the squares on :g:`/ D N / <g1:/ D N />`, :g:`/ N M / <g1:/ N M />`; and of these the square on :g:`/ A K / <g1:/ A K />` is :eq:`equal <g1:/ A K / = g1:/ D N />` to the square on :g:`/ D N / <g1:/ D N />`; therefore the remaining square on :g:`/ K H / <g1:/ K H />` is :eq:`equal <g1:/ K H / = g1:/ N M />` to the square on :g:`/ N M / <g1:/ N M />`; therefore :g:`/ H K / <g1:/ H K />` is :eq:`equal <g1:/ H K / = g1:/ M N />` to :g:`/ M N / <g1:/ M N />`.

.. subclause::

   And, since the two sides :g:`/ H A / <g1:/ H A />`, :g:`/ A K / <g1:/ A K />` are :eq:`equal <g1:/ H A / = g1:/ M D /; g1:/ A K / = g1:/ D N />` to the two sides :g:`/ M D / <g1:/ M D />`, :g:`/ D N / <g1:/ D N />` respectively, and the base :g:`/ H K / <g1:/ H K />` was proved :eq:`equal <g1:/ H K / = g1:/ M N />` to the base :g:`/ M N / <g1:/ M N />`,

.. assertion:: [G.15] <G.15>

   therefore the angle :g:`< H A K ) <g1:< H A K )>` is :eq:`equal <g1:< H A K ) = g1:< M D N )>` to the angle :g:`< M D N ) <g1:< M D N )>`.

.. assertion::

   Therefore etc.

.. qed::

   **PORISM.** From this it is manifest that, if there be two equal plane angles, and if there be set up on them elevated straight lines which are equal and contain equal angles with the original straight lines respectively, the perpendiculars drawn from their extremities to the planes in which are the original angles are equal to one another. :just:`Q. E. D.`
