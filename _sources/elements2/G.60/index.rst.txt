G.60
====

.. rubric:: `I.47 <https://geometor.github.io/euclid/heath/volume_I/book_i/propositions/47/>`_

.. enunciation::

   In right-angled triangles the square on\ [#f1]_ the side subtending the right angle\ [#f2]_ is equal to the squares on the sides containing the right angle.

Let :g:`< A B C > <0363.g1:< A B C >>` be a right-angled triangle having the angle :g:`< B A C ) <0363.g1:< B A C )>` right;

I say that the square on :g:`/ B C / <0363.g1:/ B C />` is equal to the squares on :g:`/ B A / <0363.g1:/ B A />`, :g:`/ A C / <0363.g1:/ A C />`.

.. picture:: 0363.g1.svg
   :alt: Folio 0363 Figure 1 - Proposition 47

For let there be described on :g:`/ B C / <0363.g1:/ B C />` the square :g:`< B D E C > <0363.g1:< B D E C >>`, and on :g:`/ B A / <0363.g1:/ B A />`, :g:`/ A C / <0363.g1:/ A C />` the squares :g:`< G B > <0363.g1:< G B >>`, :g:`< H C > <0363.g1:< H C >>`; :just:`[G.59] <G.59>`

through :g:`A <0363.g1:A>` let :g:`/ A L / <0363.g1:/ A L />` be drawn parallel to either :g:`/ B D / <0363.g1:/ B D />` or :g:`/ C E / <0363.g1:/ C E />`, and let :g:`/ A D / <0363.g1:/ A D />`, :g:`/ F C / <0363.g1:/ F C />` be joined.

Then, since each of the angles :g:`< B A C ) <0363.g1:< B A C )>`, :g:`< B A G ) <0363.g1:< B A G )>` is :eq:`right <0363.g1:< B A C ) = 0363.g1:< B A G )>`, it follows that with a straight line :g:`/ B A / <0363.g1:/ B A />`, and at the point :g:`A <0363.g1:A>` on it, the two straight lines :g:`/ A C / <0363.g1:/ A C />`, :g:`/ A G / <0363.g1:/ A G />` not lying on the same side make the adjacent angles equal to two right angles;

.. assertion:: [G.24] <G.24>

   therefore :g:`/ C A / <0363.g1:/ C A />` is in a straight line with :g:`/ A G / <0363.g1:/ A G />`.

.. subclause::

   For the same reason :g:`/ B A / <0363.g1:/ B A />` is also in a straight line with :g:`/ A H / <0363.g1:/ A H />`.

And, since the angle :g:`< D B C ) <0363.g1:< D B C )>` is :eq:`equal <0363.g1:< D B C ) = 0363.g1:< F B A )>` to the angle :g:`< F B A ) <0363.g1:< F B A )>`: for each is right: let the angle :g:`< A B C ) <0363.g1:< A B C )>` be added to each;

.. assertion:: [G.21] <G.21>

   therefore the whole angle :g:`< D B A ) <0363.g1:< D B A )>` is :eq:`equal <0363.g1:< D B A ) = 0363.g1:< F B C )>` to the whole angle :g:`< F B C ) <0363.g1:< F B C )>`.

And, since :g:`/ D B / <0363.g1:/ D B />` is :eq:`equal <0363.g1:/ D B / = 0363.g1:/ B C /; 0363.g1:/ F B / = 0363.g1:/ B A />` to :g:`/ B C / <0363.g1:/ B C />`, and :g:`/ F B / <0363.g1:/ F B />` to :g:`/ B A / <0363.g1:/ B A />`, the two sides :g:`/ A B / <0363.g1:/ A B />`, :g:`/ B D / <0363.g1:/ B D />`\ [#f3]_ are :eq:`equal <0363.g1:/ A B / = 0363.g1:/ F B /; 0363.g1:/ B D / = 0363.g1:/ B C />` to the two sides :g:`/ F B / <0363.g1:/ F B />`, :g:`/ B C / <0363.g1:/ B C />` respectively, and the angle :g:`< A B D ) <0363.g1:< A B D )>` is :eq:`equal <0363.g1:< A B D ) = 0363.g1:< F B C )>` to the angle :g:`< F B C ) <0363.g1:< F B C )>`;

.. subclause::

   therefore the base :g:`/ A D / <0363.g1:/ A D />` is :eq:`equal <0363.g1:/ A D / = 0363.g1:/ F C />` to the base :g:`/ F C / <0363.g1:/ F C />`,

.. assertion:: [G.11] <G.11>

   and the triangle :g:`< A B D > <0363.g1:< A B D >>` is :eq:`equal <0363.g1:< A B D > = 0363.g1:< F B C >>` to the triangle :g:`< F B C > <0363.g1:< F B C >>`.

Now the parallelogram :g:`< B L > <0363.g1:< B L >>` is double of the triangle :g:`< A B D > <0363.g1:< A B D >>`, for they have the same base :g:`/ B D / <0363.g1:/ B D />` and are in the same parallels :g:`/ B D / <0363.g1:/ B D />`, :g:`/ A L / <0363.g1:/ A L />`. :just:`[G.54] <G.54>`

And the square :g:`< G B > <0363.g1:< G B >>` is double of the triangle :g:`< F B C > <0363.g1:< F B C >>`, for they again have the same base :g:`/ F B / <0363.g1:/ F B />` and are in the same parallels :g:`/ F B / <0363.g1:/ F B />`, :g:`/ G C / <0363.g1:/ G C />`. :just:`[G.54] <G.54>`

[But the doubles of equals are equal to one another.]\ [#f4]_

.. assertion::

   Therefore the parallelogram :g:`< B L > <0363.g1:< B L >>` is also :eq:`equal <0363.g1:< B L > = 0363.g1:< G B >>` to the square :g:`< G B > <0363.g1:< G B >>`.

Similarly, if :g:`/ A E / <0363.g1:/ A E />`, :g:`/ B K / <0363.g1:/ B K />` be joined, the parallelogram :g:`< C L > <0363.g1:< C L >>` can also be proved :eq:`equal <0363.g1:< C L > = 0363.g1:< H C >>` to the square :g:`< H C > <0363.g1:< H C >>`;

.. assertion::

   therefore the whole square :g:`< B D E C > <0363.g1:< B D E C >>` is equal to the two squares :g:`< G B > <0363.g1:< G B >>`, :g:`< H C > <0363.g1:< H C >>`. :just:`[G.21] <G.21>`

And the square :g:`< B D E C > <0363.g1:< B D E C >>` is described on :g:`/ B C / <0363.g1:/ B C />`, and the squares :g:`< G B > <0363.g1:< G B >>`, :g:`< H C > <0363.g1:< H C >>` on :g:`/ B A / <0363.g1:/ B A />`, :g:`/ A C / <0363.g1:/ A C />`.

.. assertion::

   Therefore the square on the side :g:`/ B C / <0363.g1:/ B C />` is equal to the squares on the sides :g:`/ B A / <0363.g1:/ B A />`, :g:`/ A C / <0363.g1:/ A C />`.

.. qed::

   Therefore etc. :just:`Q. E. D.`

.. [#f1] **the square on**, τὸ ἀπὸ... :term:`τετράγωνον <tetragonon>`, the word ἀναγραφέν or ἀναγεγραμμένον being understood.

.. [#f2] **subtending the right angle.** Here ὑποτεινούσης, “subtending,” is used with the simple accusative (τὴν ὀρθὴν :term:`γωνίαν <angle>`) instead of being followed by ὑπό and the accusative, which seems to be the original and more orthodox construction. Cf. I. 18, note.

.. [#f3] **the two sides AB, BD....** :person:`Euclid <euclid>` actually writes “:g:`/ D B / <0363.g1:/ D B />`, :g:`/ B A / <0363.g1:/ B A />`,” and therefore the equal sides in the two triangles are not mentioned in corresponding order, though he adheres to the words ἑκατέρα ἑκατέρα “respectively.” Here :g:`/ D B / <0363.g1:/ D B />` is :eq:`equal <0363.g1:/ D B / = 0363.g1:/ B C /; 0363.g1:/ B A / = 0363.g1:/ F B />` to :g:`/ B C / <0363.g1:/ B C />` and :g:`/ B A / <0363.g1:/ B A />` to :g:`/ F B / <0363.g1:/ F B />`.

.. [#f4] **[But the doubles of equals are equal to one another.]** :person:`Heiberg <heiberg>` brackets these words as an interpolation, since it quotes a Common Notion which is itself interpolated. Cf. notes on I. 37, p. 332, and on interpolated Common Notions, pp. 223–4.
