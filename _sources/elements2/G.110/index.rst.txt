G.110
=====

.. rubric:: `III.31 <https://geometor.github.io/euclid/heath/volume_II/book_iii/propositions/31/>`_

.. enunciation::

   In a circle the angle in the semicircle is right, that in a greater segment less than a right angle, and that in a less segment greater than a right angle; and further the angle of the greater segment is greater than a right angle, and the angle of the less segment less than a right angle.

Let :g:`( A B C D ) <0068.g1:( A B C D )>` be a circle, let :g:`/ B C / <0068.g1:/ B C />` be its diameter, and :g:`E <0068.g1:E>` its
centre, and let :g:`/ B A / <0068.g1:/ B A />`, :g:`/ A C / <0068.g1:/ A C />`, :g:`/ A D / <0068.g1:/ A D />`, :g:`/ D C / <0068.g1:/ D C />`
be joined;
I say that the angle :g:`< B A C ) <0068.g1:< B A C )>` in the
semicircle :g:`( B A C ) <0068.g1:( B A C )>` is right,
the angle :g:`< A B C ) <0068.g1:< A B C )>` in the segment :g:`( A B C ) <0068.g1:( A B C )>`
greater than the semicircle is less
than a right angle,
and the angle :g:`< A D C ) <0068.g1:< A D C )>` in the segment
:g:`( A D C ) <0068.g1:( A D C )>` less than the semicircle is
greater than a right angle.

.. picture:: 0068.g1.svg
   :alt: Diagram

Let :g:`/ A E / <0068.g1:/ A E />` be joined, and let :g:`/ B A / <0068.g1:/ B A />`
be carried through to :g:`F <0068.g1:F>`.

Then, since :g:`/ B E / <0068.g1:/ B E />` is :eq:`equal <0068.g1:/ B E / = 0068.g1:/ E A />` to :g:`/ E A / <0068.g1:/ E A />`,

.. assertion:: [G.12] <G.12>

   the angle :g:`< A B E ) <0068.g1:< A B E )>` is also :eq:`equal <0068.g1:< A B E ) = 0068.g1:< B A E )>` to the angle :g:`< B A E ) <0068.g1:< B A E )>`.

Again, since :g:`/ C E / <0068.g1:/ C E />` is :eq:`equal <0068.g1:/ C E / = 0068.g1:/ E A />` to :g:`/ E A / <0068.g1:/ E A />`,

.. assertion:: [G.12] <G.12>

   the angle :g:`< A C E ) <0068.g1:< A C E )>` is also :eq:`equal <0068.g1:< A C E ) = 0068.g1:< C A E )>` to the angle :g:`< C A E ) <0068.g1:< C A E )>`.

Therefore the whole angle :g:`< B A C ) <0068.g1:< B A C )>` is equal to the two angles
:g:`< A B C ) <0068.g1:< A B C )>`, :g:`< A C B ) <0068.g1:< A C B )>`.

But the angle :g:`< F A C ) <0068.g1:< F A C )>` exterior to the triangle :g:`< A B C > <0068.g1:< A B C >>` is also
equal to the two angles :g:`< A B C ) <0068.g1:< A B C )>`, :g:`< A C B ) <0068.g1:< A C B )>`; :just:`[G.45] <G.45>`

.. assertion::

   therefore the angle :g:`< B A C ) <0068.g1:< B A C )>` is also :eq:`equal <0068.g1:< B A C ) = 0068.g1:< F A C )>` to the angle :g:`< F A C ) <0068.g1:< F A C )>`;

.. assertion:: [G.18] <G.18>

   therefore each is right;

.. assertion::

   therefore the angle :g:`< B A C ) <0068.g1:< B A C )>` in the semicircle :g:`( B A C ) <0068.g1:( B A C )>` is right.

Next, since in the triangle :g:`< A B C > <0068.g1:< A B C >>` the two angles :g:`< A B C ) <0068.g1:< A B C )>`,
:g:`< B A C ) <0068.g1:< B A C )>` are less than two right angles, :just:`[G.28] <G.28>`
and the angle :g:`< B A C ) <0068.g1:< B A C )>` is a right angle,

.. assertion::

   the angle :g:`< A B C ) <0068.g1:< A B C )>` is less than a right angle;

and it is the angle in the segment :g:`( A B C ) <0068.g1:( A B C )>` greater than the
semicircle.

Next, since :g:`< A B C D > <0068.g1:< A B C D >>` is a quadrilateral in a circle,
and the opposite angles of quadrilaterals in circles are equal
to two right angles, :just:`[G.100] <G.100>`
while the angle :g:`< A B C ) <0068.g1:< A B C )>` is less than a right angle,
therefore the angle :g:`< A D C ) <0068.g1:< A D C )>` which remains is greater than a
right angle;
and it is the angle in the segment :g:`( A D C ) <0068.g1:( A D C )>` less than the semicircle
.

I say further that the angle of the greater segment, namely
that contained by the circumference :g:`( A B C ) <0068.g1:( A B C )>` and the straight
line :g:`/ A C / <0068.g1:/ A C />`, is greater than a right angle;
and the angle of the less segment, namely that contained by
the circumference :g:`( A D C ) <0068.g1:( A D C )>` and the straight line :g:`/ A C / <0068.g1:/ A C />`, is less than
a right angle.

This is at once manifest.
For, since the angle contained by the straight lines :g:`/ B A / <0068.g1:/ B A />`, :g:`/ A C / <0068.g1:/ A C />`
is right,

.. assertion::

   the angle contained by the circumference :g:`( A B C ) <0068.g1:( A B C )>` and the straight line :g:`/ A C / <0068.g1:/ A C />` is greater than a right angle.

Again, since the angle contained by the straight lines
:g:`/ A C / <0068.g1:/ A C />`, :g:`/ A F / <0068.g1:/ A F />` is right,

.. assertion::

   the angle contained by the straight line :g:`/ C A / <0068.g1:/ C A />` and the circumference :g:`( A D C ) <0068.g1:( A D C )>` is less than a right angle.

.. qed::

   Therefore etc. :just:`Q. E. D.`
