G.187 magnitudes ratio equal
============================

.. rubric:: `V.9 <https://geometor.github.io/euclid/heath/volume_II/book_v/propositions/09/>`_

.. enunciation::

   Magnitudes which have the :term:`same ratio <G.176>` to the same are equal; and magnitudes to which the same has the same ratio are equal.

.. signature:: theorem

   | :fn:`magnitudes_ratio_equal <G.187>`\ ()
   | **prove** :g:`A <g1:A>` is :eq:`equal <g1:A = g1:B>` to :g:`B <g1:B>`; :g:`A <g1:A>` is :eq:`equal <g1:A = g1:B>` to :g:`B <g1:B>`

.. picture:: g1.svg
   :alt: Folio 0160 Figure 1

.. step:: assert

   Let each of the magnitudes :g:`A <g1:A>`, :g:`B <g1:B>` have the same ratio to :g:`C <g1:C>`

.. step:: assert ∵ unequal_magnitudes_greater <G.186>

   Otherwise, each of the magnitudes :g:`A <g1:A>`, :g:`B <g1:B>` would not have had the same ratio to :g:`C <g1:C>`

.. step:: assert

   But it has

.. step:: assert

   Therefore :g:`A <g1:A>` is :eq:`equal <g1:A = g1:B>` to :g:`B <g1:B>`.

.. step:: assert

   Let :g:`C <g1:C>` have the same ratio to each of the magnitudes :g:`A <g1:A>`, :g:`B <g1:B>`

.. step:: assert ∵ unequal_magnitudes_greater <G.186>

   Otherwise, :g:`C <g1:C>` would not have had the same ratio to each of the magnitudes :g:`A <g1:A>`, :g:`B <g1:B>`

.. step:: assert

   But it has

.. step:: conclude

   Therefore :g:`A <g1:A>` is :eq:`equal <g1:A = g1:B>` to :g:`B <g1:B>`.
