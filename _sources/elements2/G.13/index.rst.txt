G.13
====

.. rubric:: `I.6 <https://geometor.github.io/euclid/heath/volume_I/book_i/propositions/06/>`_

.. enunciation::

   If in a triangle two angles be equal to one another, the sides which subtend the equal angles will also be equal to one another.

.. picture:: 0269.g1.svg
   :alt: Proposition 6 figure

Let :g:`< A B C > <0269.g1:< A B C >>` be a triangle having the angle :g:`< A B C ) <0269.g1:< A B C )>` :eq:`equal <0269.g1:< A B C ) = 0269.g1:< A C B )>` to the angle :g:`< A C B ) <0269.g1:< A C B )>`;

I say that the side :g:`/ A B / <0269.g1:/ A B />` is also :eq:`equal <0269.g1:/ A B / = 0269.g1:/ A C />` to the side :g:`/ A C / <0269.g1:/ A C />`.

For, if :g:`/ A B / <0269.g1:/ A B />` is unequal to :g:`/ A C / <0269.g1:/ A C />`, one of them is greater.

Let :g:`/ A B / <0269.g1:/ A B />` be greater; and from :g:`/ A B / <0269.g1:/ A B />` the greater let :g:`/ D B / <0269.g1:/ D B />` be cut off :eq:`equal <0269.g1:/ D B / = 0269.g1:/ A C />` to :g:`/ A C / <0269.g1:/ A C />` the less; let :g:`/ D C / <0269.g1:/ D C />` be joined.

Then, since :g:`/ D B / <0269.g1:/ D B />` is :eq:`equal <0269.g1:/ D B / = 0269.g1:/ A C />` to :g:`/ A C / <0269.g1:/ A C />`, and :g:`/ B C / <0269.g1:/ B C />` is common,

.. subclause::

   the two sides :g:`/ D B / <0269.g1:/ D B />`, :g:`/ B C / <0269.g1:/ B C />` are :eq:`equal <0269.g1:/ D B / = 0269.g1:/ A C />` to the two sides :g:`/ A C / <0269.g1:/ A C />`, :g:`/ C B / <0269.g1:/ C B />` respectively;

and the angle :g:`< D B C ) <0269.g1:< D B C )>` is :eq:`equal <0269.g1:< D B C ) = 0269.g1:< A C B )>` to the angle :g:`< A C B ) <0269.g1:< A C B )>`;

.. subclause::

   therefore the base :g:`/ D C / <0269.g1:/ D C />` is :eq:`equal <0269.g1:/ D C / = 0269.g1:/ A B />` to the base :g:`/ A B / <0269.g1:/ A B />`,

and the triangle :g:`< D B C > <0269.g1:< D B C >>` will be :eq:`equal <0269.g1:< D B C > = 0269.g1:< A C B >>` to the triangle :g:`< A C B > <0269.g1:< A C B >>`,

.. assertion::

   the less to the greater: which is absurd.

Therefore :g:`/ A B / <0269.g1:/ A B />` is not unequal to :g:`/ A C / <0269.g1:/ A C />`;

.. assertion::

   it is therefore :eq:`equal <0269.g1:/ A B / = 0269.g1:/ A C />` to it.

.. qed::

   Therefore etc. :just:`Q. E. D.`
