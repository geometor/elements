G.144 point taken outside — Heath
=================================

.. rubric:: `III.36 <https://geometor.github.io/euclid/heath/volume_II/book_iii/propositions/36/>`_

.. enunciation::

   If a :term:`point <G.1>` be taken outside a :term:`circle <G.10>` and from it there fall on the circle two :term:`straight lines <G.4>`, and if one of them cut the circle and the other touch it, the :term:`rectangle contained <G.81>` by the whole of the straight line which cuts the circle and the straight

.. enunciation::

   :term:`line <G.2>` intercepted on it outside between the point and the convex circumference will be equal to the :term:`square <G.63>` on the tangent.

For let a point :g:`D <g1:D>` be taken outside the circle :g:`( A B C ) <g1:( A B C )>`,
and from :g:`D <g1:D>` let the two straight lines :g:`/ D C A / <g1:/ D C A />`,
:g:`/ D B / <g1:/ D B />` fall on the circle :g:`( A B C ) <g1:( A B C )>`; let :g:`/ D C A / <g1:/ D C A />` cut
the circle :g:`( A B C ) <g1:( A B C )>` and let :g:`/ B D / <g1:/ B D />` touch it;
I say that the rectangle contained by :g:`/ A D / <g1:/ A D />`,
:g:`/ D C / <g1:/ D C />` is equal to the square on :g:`/ D B / <g1:/ D B />`.

.. picture:: g1.svg
   :alt: Proposition 36 Case 1 diagram

Then :g:`/ D C A / <g1:/ D C A />` is either through the :term:`centre <G.14>`
or not through the centre.

First let it be through the centre, and
let :g:`F <g1:F>` be the centre of the circle :g:`( A B C ) <g1:( A B C )>`;
let :g:`/ F B / <g1:/ F B />` be joined;

.. assertion:: [G.120] <G.120>

   therefore the :term:`angle <G.22>` :g:`< F B D ) <g1:< F B D )>` is right.

And, since :g:`/ A C / <g1:/ A C />` has been bisected at :g:`F <g1:F>`, and :g:`/ C D / <g1:/ C D />` is added
to it,
the rectangle :g:`/ A D / <g1:/ A D />`, :g:`/ D C / <g1:/ D C />` together with the square on :g:`/ F C / <g1:/ F C />` is
equal to the square on :g:`/ F D / <g1:/ F D />`. :just:`[G.88] <G.88>`

But :g:`/ F C / <g1:/ F C />` is :eq:`equal <g1:/ F C / = g1:/ F B />` to :g:`/ F B / <g1:/ F B />`;
therefore the rectangle :g:`/ A D / <g1:/ A D />`, :g:`/ D C / <g1:/ D C />` together with the square on
:g:`/ F B / <g1:/ F B />` is equal to the square on :g:`/ F D / <g1:/ F D />`.

And the squares on :g:`/ F B / <g1:/ F B />`, :g:`/ B D / <g1:/ B D />` are equal to the square on
:g:`/ F D / <g1:/ F D />`; :just:`[G.79] <G.79>`
therefore the rectangle :g:`/ A D / <g1:/ A D />`, :g:`/ D C / <g1:/ D C />` together with the square on
:g:`/ F B / <g1:/ F B />` is equal to the squares on :g:`/ F B / <g1:/ F B />`, :g:`/ B D / <g1:/ B D />`.

Let the square on :g:`/ F B / <g1:/ F B />` be subtracted from each;
therefore the rectangle :g:`/ A D / <g1:/ A D />`, :g:`/ D C / <g1:/ D C />` which remains is equal to
the square on the tangent :g:`/ D B / <g1:/ D B />`.

Again, let :g:`/ D C A / <g2:/ D C A />` not be through the centre of the circle
:g:`( A B C ) <g2:( A B C )>`;
let the centre :g:`E <g2:E>` be taken, and from :g:`E <g2:E>`
let :g:`/ E F / <g2:/ E F />` be drawn :term:`perpendicular <G.32>` to :g:`/ A C / <g2:/ A C />`;
let :g:`/ E B / <g2:/ E B />`, :g:`/ E C / <g2:/ E C />`, :g:`/ E D / <g2:/ E D />` be joined.

.. picture:: g2.svg
   :alt: Proposition 36 Case 2 diagram

Then the angle :g:`< E B D ) <g2:< E B D )>` is right.
:just:`[G.120] <G.120>`

And, since a straight line :g:`/ E F / <g2:/ E F />`
through the centre cuts a straight line
:g:`/ A C / <g2:/ A C />` not through the centre at right angles,

.. assertion:: [G.100] <G.100>

   it also bisects it;

.. assertion::

   therefore :g:`/ A F / <g2:/ A F />` is :eq:`equal <g2:/ A F / = g2:/ F C />` to :g:`/ F C / <g2:/ F C />`.

Now, since the straight line :g:`/ A C / <g2:/ A C />` has been bisected at the
point :g:`F <g2:F>`, and :g:`/ C D / <g2:/ C D />` is added to it,
the rectangle contained by :g:`/ A D / <g2:/ A D />`, :g:`/ D C / <g2:/ D C />` together with the square
on :g:`/ F C / <g2:/ F C />` is equal to the square on :g:`/ F D / <g2:/ F D />`. :just:`[G.88] <G.88>`

Let the square on :g:`/ F E / <g2:/ F E />` be added to each;
therefore the rectangle :g:`/ A D / <g2:/ A D />`, :g:`/ D C / <g2:/ D C />` together with the squares
on :g:`/ C F / <g2:/ C F />`, :g:`/ F E / <g2:/ F E />` is equal to the squares on :g:`/ F D / <g2:/ F D />`, :g:`/ F E / <g2:/ F E />`.

But the square on :g:`/ E C / <g2:/ E C />` is equal to the squares on :g:`/ C F / <g2:/ C F />`, :g:`/ F E / <g2:/ F E />`,
for the angle :g:`< E F C ) <g2:< E F C )>` is right; :just:`[G.79] <G.79>`
and the square on :g:`/ E D / <g2:/ E D />` is equal to the squares on :g:`/ D F / <g2:/ D F />`, :g:`/ F E / <g2:/ F E />`;
therefore the rectangle :g:`/ A D / <g2:/ A D />`, :g:`/ D C / <g2:/ D C />` together with the square on
:g:`/ E C / <g2:/ E C />` is equal to the square on :g:`/ E D / <g2:/ E D />`.

And :g:`/ E C / <g2:/ E C />` is :eq:`equal <g2:/ E C / = g2:/ E B />` to :g:`/ E B / <g2:/ E B />`;
therefore the rectangle :g:`/ A D / <g2:/ A D />`, :g:`/ D C / <g2:/ D C />` together with the square on
:g:`/ E B / <g2:/ E B />` is equal to the square on :g:`/ E D / <g2:/ E D />`.

But the squares on :g:`/ E B / <g2:/ E B />`, :g:`/ B D / <g2:/ B D />` are equal to the square on
:g:`/ E D / <g2:/ E D />`, for the angle :g:`< E B D ) <g2:< E B D )>` is right; :just:`[G.79] <G.79>`
therefore the rectangle :g:`/ A D / <g2:/ A D />`, :g:`/ D C / <g2:/ D C />` together with the square on
:g:`/ E B / <g2:/ E B />` is equal to the squares on :g:`/ E B / <g2:/ E B />`, :g:`/ B D / <g2:/ B D />`.

Let the square on :g:`/ E B / <g2:/ E B />` be subtracted from each;
therefore the rectangle :g:`/ A D / <g2:/ A D />`, :g:`/ D C / <g2:/ D C />` which remains is equal to
the square on :g:`/ D B / <g2:/ D B />`.

.. qed::

   Therefore etc. :just:`Q. E. D.`
