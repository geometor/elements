G.5
===

.. rubric:: `I.1 <https://geometor.github.io/euclid/heath/volume_I/book_i/propositions/01/>`_

.. enunciation::

   On a given finite straight line\ [#f1]_ to construct an equilateral triangle.

.. picture:: 0255.g1.svg
   :alt: Proposition 1 figure

Let :g:`/ A B / <0255.g1:/ A B />` be the given finite straight line.\ [#f2]_

Thus it is required to construct an equilateral triangle on the straight line :g:`/ A B / <0255.g1:/ A B />`.

With centre :g:`A <0255.g1:A>` and distance :g:`/ A B / <0255.g1:/ A B />` let the circle :g:`( B C D ) <0255.g1:( B C D )>` be described;\ [#f3]_ :just:`[G.4] <G.4>`

again, with centre :g:`B <0255.g1:B>` and distance :g:`/ B A / <0255.g1:/ B A />` let the circle :g:`( A C E ) <0255.g1:( A C E )>` be described; :just:`[G.4] <G.4>`

and from the point :g:`C <0255.g1:C>`,\ [#f4]_ in which the circles cut one another, to the points :g:`A <0255.g1:A>`, :g:`B <0255.g1:B>` let the straight lines :g:`/ C A / <0255.g1:/ C A />`, :g:`/ C B / <0255.g1:/ C B />` be joined. :just:`[G.3] <G.3>`

Now, since the point :g:`A <0255.g1:A>` is the centre of the circle :g:`( C D B ) <0255.g1:( C D B )>`,

.. assertion:: [G.2] <G.2>

   :g:`/ A C / <0255.g1:/ A C />` is :eq:`equal <0255.g1:/ A C / = 0255.g1:/ A B />` to :g:`/ A B / <0255.g1:/ A B />`.

Again, since the point :g:`B <0255.g1:B>` is the centre of the circle :g:`( C A E ) <0255.g1:( C A E )>`,

.. assertion:: [G.2] <G.2>

   :g:`/ B C / <0255.g1:/ B C />` is :eq:`equal <0255.g1:/ B C / = 0255.g1:/ B A />` to :g:`/ B A / <0255.g1:/ B A />`.

But :g:`/ C A / <0255.g1:/ C A />` was also proved :eq:`equal <0255.g1:/ C A / = 0255.g1:/ A B />` to :g:`/ A B / <0255.g1:/ A B />`; therefore each of the straight lines :g:`/ C A / <0255.g1:/ C A />`, :g:`/ C B / <0255.g1:/ C B />`\ [#f5]_ is :eq:`equal <0255.g1:/ C A / = 0255.g1:/ C B / = 0255.g1:/ A B />` to :g:`/ A B / <0255.g1:/ A B />`.

And things which are equal to the same thing are also equal to one another; :just:`[G.1] <G.1>`

.. assertion::

   therefore :g:`/ C A / <0255.g1:/ C A />` is also :eq:`equal <0255.g1:/ C A / = 0255.g1:/ C B />` to :g:`/ C B / <0255.g1:/ C B />`.

Therefore the three straight lines :g:`/ C A / <0255.g1:/ C A />`, :g:`/ A B / <0255.g1:/ A B />`, :g:`/ B C / <0255.g1:/ B C />` are :eq:`equal <0255.g1:/ C A / = 0255.g1:/ A B / = 0255.g1:/ B C />` to one another.

Therefore the triangle :g:`< A B C > <0255.g1:< A B C >>` is :eq:`equilateral <0255.g1:/ C A / = 0255.g1:/ A B / = 0255.g1:/ B C />`; and it has been constructed on the given finite straight line :g:`/ A B / <0255.g1:/ A B />`.

.. qed::

   (Being) what it was required to do.

.. [#f1] **On a given finite straight line.** The Greek usage differs from ours in that the definite article is employed in such a phrase as this where we have the indefinite. ἐπὶ τῆς δοθείσης εὐθείας πεπερασμένης, "on *the* given finite straight line," i.e. the finite straight line which we choose to take.

.. [#f2] **Let AB be the given finite straight line.** To be strictly literal we should have to translate in the reverse order "let the given finite straight line be the (straight line) :g:`/ A B / <0255.g1:/ A B />`"; but this order is inconvenient in other cases where there is more than one datum, e.g. in the *setting-out* of I. 2, "let the given point be $A$, and the given straight line $BC$," the awkwardness arising from the omission of the verb in the second clause. Hence I have, for clearness' sake, adopted the other order throughout the book.

.. [#f3] **let the circle BCD be described.** Two things are here to be noted, (1) the elegant and practically universal use of the perfect passive imperative in constructions, γεγράφθω meaning of course "let it *have been described*" or "suppose it described," (2) the impossibility of expressing shortly in a translation the force of the words in their original order. :term:`κύκλος <circle>` γεγράφθω ὁ ΒΓΔ means literally "let a circle have been described, the (circle, namely, which I denote by) :g:`( B C D ) <0255.g1:( B C D )>`." Similarly we have lower down "let straight lines, (namely) the (straight lines) :g:`/ C A / <0255.g1:/ C A />`, :g:`/ C B / <0255.g1:/ C B />`, be joined," ἐπεζεύχθωσαν :term:`εὐθεῖαι <straight-line>` αἱ ΓΑ, ΓΒ. There seems to be no practicable alternative, in English, but to translate as I have done in the text.

.. [#f4] **from the point C....** :person:`Euclid <euclid>` is careful to adhere to the phraseology of Postulate 1 except that he speaks of "joining" (ἐπεζεύχθωσαν) instead of "drawing" (γράφειν). He does not allow himself to use the shortened expression "let the straight line $FC$ be joined" (without mention of the points $F$, $C$) until I. 5.

.. [#f5] **each of the straight lines CA, CB**, ἑκατέρα τῶν ΓΑ, ΓΒ and **the three straight lines CA, AB, BC**, αἱ τρεῖς αἱ ΓΑ, ΑΒ, ΒΓ. I have, here and in all similar expressions, inserted the words "straight lines" which are not in the Greek. The possession of the inflected definite article enables the Greek to omit the words, but this is not possible in English, and it would scarcely be English to write "each of :g:`/ C A / <0255.g1:/ C A />`, :g:`/ C B / <0255.g1:/ C B />`" or "the three :g:`/ C A / <0255.g1:/ C A />`, :g:`/ A B / <0255.g1:/ A B />`, :g:`/ B C / <0255.g1:/ B C />`."
