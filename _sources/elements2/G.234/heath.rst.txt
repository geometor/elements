G.234 segments proportional polygons — Heath
============================================

.. rubric:: `VI.22 <https://geometor.github.io/euclid/heath/volume_II/book_vi/propositions/22/>`_

.. enunciation::

   If four :term:`straight lines <G.4>` be :term:`proportional <G.180>`, the :term:`rectilineal figures <G.12>` similar and :term:`similarly described <G.217>` upon them will also be proportional; and, if the rectilineal figures similar and similarly described upon them be proportional, the straight lines will themselves also be proportional.

Let the four straight lines :g:`/ A B / <g1:/ A B />`, :g:`/ C D / <g1:/ C D />`, :g:`/ E F / <g1:/ E F />`, :g:`/ G H / <g1:/ G H />` be proportional, so that, as :g:`/ A B / <g1:/ A B />` is to :g:`/ C D / <g1:/ C D />`, so is :g:`/ E F / <g1:/ E F />` to :g:`/ G H / <g1:/ G H />`, and let there be described on :g:`/ A B / <g1:/ A B />`, :g:`/ C D / <g1:/ C D />` the similar and similarly situated rectilineal figures :g:`< K A B > <g1:< K A B >>`, :g:`< L C D > <g1:< L C D >>`, and on :g:`/ E F / <g1:/ E F />`, :g:`/ G H / <g1:/ G H />` the similar and similarly situated rectilineal figures :g:`< M F > <g1:< M F >>`, :g:`< N H > <g1:< N H >>`;

I say that, as :g:`< K A B > <g1:< K A B >>` is to :g:`< L C D > <g1:< L C D >>`, so is :g:`< M F > <g1:< M F >>` to :g:`< N H > <g1:< N H >>`.

For let there be taken a third proportional :g:`O <g1:O>` to :g:`/ A B / <g1:/ A B />`, :g:`/ C D / <g1:/ C D />`, and a third proportional :g:`P <g1:P>` to :g:`/ E F / <g1:/ E F />`, :g:`/ G H / <g1:/ G H />`. :just:`[G.221] <G.221>`

.. subclause::

   Then since, as :g:`/ A B / <g1:/ A B />` is to :g:`/ C D / <g1:/ C D />`, so is :g:`/ E F / <g1:/ E F />` to :g:`/ G H / <g1:/ G H />`, and, as :g:`/ C D / <g1:/ C D />` is to :g:`O <g1:O>`, so is :g:`/ G H / <g1:/ G H />` to :g:`P <g1:P>`,

.. assertion:: [G.205] <G.205>

   therefore, :term:`*ex aequali* <G.174>`, as :g:`/ A B / <g1:/ A B />` is to :g:`O <g1:O>`, so is :g:`/ E F / <g1:/ E F />` to :g:`P <g1:P>`.

.. assertion::

   But, as :g:`/ A B / <g1:/ A B />` is to :g:`O <g1:O>`, so is :g:`< K A B > <g1:< K A B >>` to :g:`< L C D > <g1:< L C D >>`, and, as :g:`/ E F / <g1:/ E F />` is to :g:`P <g1:P>`, so is :g:`< M F > <g1:< M F >>` to :g:`< N H > <g1:< N H >>`; :just:`[G.231] <G.231>`

.. assertion:: [G.189] <G.189>

   therefore also, as :g:`< K A B > <g1:< K A B >>` is to :g:`< L C D > <g1:< L C D >>`, so is :g:`< M F > <g1:< M F >>` to :g:`< N H > <g1:< N H >>`.

.. picture:: g1.svg
   :alt: Book VI, Proposition 22

Next, let :g:`< M F > <g1:< M F >>` be to :g:`< N H > <g1:< N H >>` as :g:`< K A B > <g1:< K A B >>` is to :g:`< L C D > <g1:< L C D >>`; I say also that, as :g:`/ A B / <g1:/ A B />` is to :g:`/ C D / <g1:/ C D />`, so is :g:`/ E F / <g1:/ E F />` to :g:`/ G H / <g1:/ G H />`.

.. subclause::

   For, if :g:`/ E F / <g1:/ E F />` is not to :g:`/ G H / <g1:/ G H />` as :g:`/ A B / <g1:/ A B />` to :g:`/ C D / <g1:/ C D />`,

.. assertion::

   let :g:`/ E F / <g1:/ E F />` be to :g:`/ Q R / <g1:/ Q R />` as :g:`/ A B / <g1:/ A B />` to :g:`/ C D / <g1:/ C D />`, :just:`[G.222] <G.222>` and on :g:`/ Q R / <g1:/ Q R />` let the rectilineal figure :g:`< S R > <g1:< S R >>` be described similar and similarly situated to either of the two :g:`< M F > <g1:< M F >>`, :g:`< N H > <g1:< N H >>`. :just:`[G.229] <G.229>`

.. subclause::

   Since then, as :g:`/ A B / <g1:/ A B />` is to :g:`/ C D / <g1:/ C D />`, so is :g:`/ E F / <g1:/ E F />` to :g:`/ Q R / <g1:/ Q R />`, and there have been described on :g:`/ A B / <g1:/ A B />`, :g:`/ C D / <g1:/ C D />` the similar and similarly situated :term:`figures <G.9>` :g:`< K A B > <g1:< K A B >>`, :g:`< L C D > <g1:< L C D >>`, and on :g:`/ E F / <g1:/ E F />`, :g:`/ Q R / <g1:/ Q R />` the similar and similarly situated figures :g:`< M F > <g1:< M F >>`, :g:`< S R > <g1:< S R >>`,

.. assertion::

   therefore, as :g:`< K A B > <g1:< K A B >>` is to :g:`< L C D > <g1:< L C D >>`, so is :g:`< M F > <g1:< M F >>` to :g:`< S R > <g1:< S R >>`.

.. subclause::

   But also, by hypothesis, as :g:`< K A B > <g1:< K A B >>` is to :g:`< L C D > <g1:< L C D >>`, so is :g:`< M F > <g1:< M F >>` to :g:`< N H > <g1:< N H >>`;

.. assertion:: [G.189] <G.189>

   therefore also, as :g:`< M F > <g1:< M F >>` is to :g:`< S R > <g1:< S R >>`, so is :g:`< M F > <g1:< M F >>` to :g:`< N H > <g1:< N H >>`.

.. assertion::

   Therefore :g:`< M F > <g1:< M F >>` has the :term:`same ratio <G.176>` to each of the figures :g:`< N H > <g1:< N H >>`, :g:`< S R > <g1:< S R >>`;

.. assertion:: [G.187] <G.187>

   therefore :g:`< N H > <g1:< N H >>` is :eq:`equal <g1:< N H > = g1:< S R >>` to :g:`< S R > <g1:< S R >>`.

.. subclause::

   But it is also similar and similarly situated to it;

.. assertion::

   therefore :g:`/ G H / <g1:/ G H />` is :eq:`equal <g1:/ G H / = g1:/ Q R />` to :g:`/ Q R / <g1:/ Q R />`.

.. subclause::

   And, since, as :g:`/ A B / <g1:/ A B />` is to :g:`/ C D / <g1:/ C D />`, so is :g:`/ E F / <g1:/ E F />` to :g:`/ Q R / <g1:/ Q R />`, while :g:`/ Q R / <g1:/ Q R />` is :eq:`equal <g1:/ Q R / = g1:/ G H />` to :g:`/ G H / <g1:/ G H />`,

.. assertion::

   therefore, as :g:`/ A B / <g1:/ A B />` is to :g:`/ C D / <g1:/ C D />`, so is :g:`/ E F / <g1:/ E F />` to :g:`/ G H / <g1:/ G H />`.

.. qed::

   Therefore etc. :just:`Q. E. D.`
