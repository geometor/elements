G.220 — Heath
=============

.. rubric:: `VII.20 <https://geometor.github.io/euclid/heath/volume_II/book_vii/propositions/20/>`_

.. enunciation::

   The least numbers of those which have the same ratio with them measure those which have the same ratio the same number of times, the greater the greater and the less the less.

For let :g:`/ C D / <g1:/ C D />`, :g:`/ E F / <g1:/ E F />` be the least numbers of those which have the same ratio with :g:`A <g1:A>`, :g:`B <g1:B>`;

I say that :g:`/ C D / <g1:/ C D />` measures :g:`A <g1:A>` the same number of times that :g:`/ E F / <g1:/ E F />` measures :g:`B <g1:B>`.

.. picture:: g1.svg
   :alt: Book VII, Proposition 20

.. assertion::

   Now :g:`/ C D / <g1:/ C D />` is not parts of :g:`A <g1:A>`.

.. subclause::

   For, if possible, let it be so;

.. assertion::

   therefore :g:`/ E F / <g1:/ E F />` is also the same parts of :g:`B <g1:B>` that :g:`/ C D / <g1:/ C D />` is of :g:`A <g1:A>`. :just:`[G.213, G.210] <G.213, G.210>`

.. assertion::

   Therefore, as many parts of :g:`A <g1:A>` as there are in :g:`/ C D / <g1:/ C D />`, so many parts of :g:`B <g1:B>` are there also in :g:`/ E F / <g1:/ E F />`.

Let :g:`/ C D / <g1:/ C D />` be divided into the parts of :g:`A <g1:A>`, namely :g:`/ C G / <g1:/ C G />`, :g:`/ G D / <g1:/ G D />`, and :g:`/ E F / <g1:/ E F />` into the parts of :g:`B <g1:B>`, namely :g:`/ E H / <g1:/ E H />`, :g:`/ H F / <g1:/ H F />`;

.. assertion::

   thus the multitude of :g:`/ C G / <g1:/ C G />`, :g:`/ G D / <g1:/ G D />` will be equal to the multitude of :g:`/ E H / <g1:/ E H />`, :g:`/ H F / <g1:/ H F />`.

.. subclause::

   Now, since the numbers :g:`/ C G / <g1:/ C G />`, :g:`/ G D / <g1:/ G D />` are :eq:`equal <g1:/ C G / = g1:/ G D />` to one another, and the numbers :g:`/ E H / <g1:/ E H />`, :g:`/ H F / <g1:/ H F />` are also :eq:`equal <g1:/ E H / = g1:/ H F />` to one another, while the multitude of :g:`/ C G / <g1:/ C G />`, :g:`/ G D / <g1:/ G D />` is equal to the multitude of :g:`/ E H / <g1:/ E H />`, :g:`/ H F / <g1:/ H F />`,

.. assertion::

   therefore, as :g:`/ C G / <g1:/ C G />` is to :g:`/ E H / <g1:/ E H />`, so is :g:`/ G D / <g1:/ G D />` to :g:`/ H F / <g1:/ H F />`.

.. assertion::

   Therefore also, as one of the antecedents is to one of the consequents, so will all the antecedents be to all the consequents. :just:`[G.212] <G.212>`

.. assertion::

   Therefore, as :g:`/ C G / <g1:/ C G />` is to :g:`/ E H / <g1:/ E H />`, so is :g:`/ C D / <g1:/ C D />` to :g:`/ E F / <g1:/ E F />`.

.. assertion::

   Therefore :g:`/ C G / <g1:/ C G />`, :g:`/ E H / <g1:/ E H />` are in the same ratio with :g:`/ C D / <g1:/ C D />`, :g:`/ E F / <g1:/ E F />`, being less than they : which is impossible, for by hypothesis :g:`/ C D / <g1:/ C D />`, :g:`/ E F / <g1:/ E F />` are the least numbers of those which have the same ratio with them.

.. assertion::

   Therefore :g:`/ C D / <g1:/ C D />` is not parts of :g:`A <g1:A>` ; therefore it is a part of it. :just:`[G.203] <G.203>`

.. subclause::

   And :g:`/ E F / <g1:/ E F />` is the same part of :g:`B <g1:B>` that :g:`/ C D / <g1:/ C D />` is of :g:`A <g1:A>` ; :just:`[G.213, G.210] <G.213, G.210>`

.. assertion::

   therefore :g:`/ C D / <g1:/ C D />` measures :g:`A <g1:A>` the same number of times that :g:`/ E F / <g1:/ E F />` measures :g:`B <g1:B>`.

.. qed::

   Therefore etc. :just:`Q. E. D.`
