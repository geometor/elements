G.85 square of a sum — Heath
============================

.. rubric:: `II.4 <https://geometor.github.io/euclid/heath/volume_I/book_ii/propositions/04/>`_

.. enunciation::

   If a :term:`straight line <G.4>` be cut at random, the :term:`square <G.63>` on the whole is equal to the squares on the segments and twice the :term:`rectangle contained <G.81>` by the segments.

For let the straight line :g:`/ A B / <g1:/ A B />` be cut at random at :g:`C <g1:C>`;

I say that the square on :g:`/ A B / <g1:/ A B />` is equal to the squares on :g:`/ A C / <g1:/ A C />`, :g:`/ B C / <g1:/ B C />` and twice the rectangle contained by :g:`/ A C / <g1:/ A C />`, :g:`/ B C / <g1:/ B C />`.

.. picture:: g1.svg
   :alt: Diagram

For let the square :g:`< A D E B > <g1:< A D E B >>` be described on :g:`/ A B / <g1:/ A B />`, :just:`[G.75] <G.75>`

let :g:`/ B D / <g1:/ B D />` be joined;

through :g:`C <g1:C>` let :g:`/ C F / <g1:/ C F />` be drawn :term:`parallel <G.52>` to either :g:`/ A D / <g1:/ A D />` or :g:`/ B E / <g1:/ B E />`, and through :g:`G <g1:G>` let :g:`/ H K / <g1:/ H K />` be drawn parallel to either :g:`/ A B / <g1:/ A B />` or :g:`/ D E / <g1:/ D E />`. :just:`[G.58] <G.58>`

Then, since :g:`/ C F / <g1:/ C F />` is parallel to :g:`/ A D / <g1:/ A D />`, and :g:`/ B D / <g1:/ B D />` has fallen on them, the exterior :term:`angle <G.22>` :g:`< C G B ) <g1:< C G B )>` is :eq:`equal <g1:< C G B ) = g1:< A D B )>` to the interior and opposite angle :g:`< A D B ) <g1:< A D B )>`. :just:`[G.56] <G.56>`

But the angle :g:`< A D B ) <g1:< A D B )>` is :eq:`equal <g1:< A D B ) = g1:< A B D )>` to the angle :g:`< A B D ) <g1:< A B D )>`, since the side :g:`/ A B / <g1:/ A B />` is also :eq:`equal <g1:/ A B / = g1:/ A D />` to :g:`/ A D / <g1:/ A D />`; :just:`[G.25] <G.25>`

therefore the angle :g:`< C G B ) <g1:< C G B )>` is also :eq:`equal <g1:< C G B ) = g1:< G B C )>` to the angle :g:`< G B C ) <g1:< G B C )>`, so that the side :g:`/ B C / <g1:/ B C />` is also :eq:`equal <g1:/ B C / = g1:/ C G />` to the side :g:`/ C G / <g1:/ C G />`. :just:`[G.27] <G.27>`
But :g:`/ B C / <g1:/ B C />` is :eq:`equal <g1:/ B C / = g1:/ G K /; g1:/ C G / = g1:/ B K />` to :g:`/ G K / <g1:/ G K />`, and :g:`/ C G / <g1:/ C G />` to :g:`/ B K / <g1:/ B K />`; :just:`[G.62] <G.62>`

therefore :g:`/ G K / <g1:/ G K />` is also :eq:`equal <g1:/ G K / = g1:/ B K />` to :g:`/ B K / <g1:/ B K />`;

.. assertion::

   therefore :g:`< C G K B > <g1:< C G K B >>` is :eq:`equilateral <g1:/ B C / = g1:/ C G / = g1:/ G K / = g1:/ B K />`.

I say next that it is also right-angled.

For, since :g:`/ C G / <g1:/ C G />` is parallel to :g:`/ B K / <g1:/ B K />`, the angles :g:`< K B C ) <g1:< K B C )>`, :g:`< G C B ) <g1:< G C B )>` are equal to two :term:`right angles <G.33>`. :just:`[G.56] <G.56>`

But the angle :g:`< K B C ) <g1:< K B C )>` is right;

.. assertion::

   therefore the angle :g:`< G C B ) <g1:< G C B )>` is also :eq:`right <g1:< G C B ) = g1:< K B C )>`,

so that the opposite angles :g:`< C G K ) <g1:< C G K )>`, :g:`< G K B ) <g1:< G K B )>` are also :eq:`right <g1:< C G K ) = g1:< G K B ) = g1:< K B C ) = g1:< G C B )>`. :just:`[G.62] <G.62>`

Therefore :g:`< C G K B > <g1:< C G K B >>` is right-angled; and it was also proved :eq:`equilateral <g1:/ B C / = g1:/ C G / = g1:/ G K / = g1:/ B K />`;

.. assertion::

   therefore it is a square;

and it is described on :g:`/ B C / <g1:/ B C />`.

.. assertion::

   For the same reason :g:`< H F > <g1:< H F >>` is also a square;

and it is described on :g:`/ H G / <g1:/ H G />`, that is :g:`/ A C / <g1:/ A C />`. :just:`[G.62] <G.62>`

.. assertion::

   Therefore the squares :g:`< H F > <g1:< H F >>`, :g:`< K C > <g1:< K C >>` are the squares on :g:`/ A C / <g1:/ A C />`, :g:`/ B C / <g1:/ B C />`.

Now, since :g:`< A G > <g1:< A G >>` is :eq:`equal <g1:< A G > = g1:< G E >>` to :g:`< G E > <g1:< G E >>`, and :g:`< A G > <g1:< A G >>` is the rectangle :g:`/ A C / <g1:/ A C />`, :g:`/ B C / <g1:/ B C />`, for :g:`/ C G / <g1:/ C G />` is :eq:`equal <g1:/ C G / = g1:/ B C />` to :g:`/ B C / <g1:/ B C />`, therefore :g:`< G E > <g1:< G E >>` is also equal to the rectangle :g:`/ A C / <g1:/ A C />`, :g:`/ B C / <g1:/ B C />`.

.. assertion::

   Therefore :g:`< A G > <g1:< A G >>`, :g:`< G E > <g1:< G E >>` are equal to twice the rectangle :g:`/ A C / <g1:/ A C />`, :g:`/ B C / <g1:/ B C />`.

But the squares :g:`< H F > <g1:< H F >>`, :g:`< C K > <g1:< C K >>` are also the squares on :g:`/ A C / <g1:/ A C />`, :g:`/ B C / <g1:/ B C />`; therefore the four areas :g:`< H F > <g1:< H F >>`, :g:`< C K > <g1:< C K >>`, :g:`< A G > <g1:< A G >>`, :g:`< G E > <g1:< G E >>` are equal to the squares on :g:`/ A C / <g1:/ A C />`, :g:`/ B C / <g1:/ B C />` and twice the rectangle contained by :g:`/ A C / <g1:/ A C />`, :g:`/ B C / <g1:/ B C />`.

But :g:`< H F > <g1:< H F >>`, :g:`< C K > <g1:< C K >>`, :g:`< A G > <g1:< A G >>`, :g:`< G E > <g1:< G E >>` are the whole :g:`< A D E B > <g1:< A D E B >>`, which is the square on :g:`/ A B / <g1:/ A B />`.

.. assertion::

   Therefore the square on :g:`/ A B / <g1:/ A B />` is equal to the squares on :g:`/ A C / <g1:/ A C />`, :g:`/ B C / <g1:/ B C />` and twice the rectangle contained by :g:`/ A C / <g1:/ A C />`, :g:`/ B C / <g1:/ B C />`.

.. qed::

   Therefore etc. :just:`Q. E. D.`
