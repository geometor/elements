G.179
=====

.. rubric:: `VI.16 <https://geometor.github.io/euclid/heath/volume_II/book_vi/propositions/16/>`_

.. enunciation::

   If four straight lines be proportional, the rectangle contained by the extremes is equal to the rectangle contained by the means; and, if the rectangle contained by the extremes be equal to the rectangle contained by the means, the four straight lines will be proportional.

Let the four straight lines :g:`/ A B / <0227.g2:/ A B />`, :g:`/ C D / <0227.g3:/ C D />`, :g:`/ E / <0227.g2:/ E />`, :g:`/ F / <0227.g3:/ F />` be proportional, so that,

.. assertion::

   as :g:`/ A B / <0227.g2:/ A B />` is to :g:`/ C D / <0227.g3:/ C D />`, so is :g:`/ E / <0227.g2:/ E />` to :g:`/ F / <0227.g3:/ F />`;

I say that the rectangle contained by :g:`/ A B / <0227.g2:/ A B />`, :g:`/ F / <0227.g3:/ F />` is :eq:`equal <0227.g2:< B G > = 0227.g3:< D H >>` to the rectangle contained by :g:`/ C D / <0227.g3:/ C D />`, :g:`/ E / <0227.g2:/ E />`.

.. picture:: 0227.g2.svg
   :alt: Book VI Proposition 16 (BG and E)

.. picture:: 0227.g3.svg
   :alt: Book VI Proposition 16 (DH and F)

Let :g:`/ A G / <0227.g2:/ A G />`, :g:`/ C H / <0227.g3:/ C H />` be drawn from the points :g:`A <0227.g2:A>`, :g:`C <0227.g3:C>` at right angles to the straight lines :g:`/ A B / <0227.g2:/ A B />`, :g:`/ C D / <0227.g3:/ C D />`, and let :g:`/ A G / <0227.g2:/ A G />` be made :eq:`equal <0227.g2:/ A G / = 0227.g3:/ F />` to :g:`/ F / <0227.g3:/ F />`, and :g:`/ C H / <0227.g3:/ C H />` :eq:`equal <0227.g3:/ C H / = 0227.g2:/ E />` to :g:`/ E / <0227.g2:/ E />`.

Let the parallelograms :g:`< B G > <0227.g2:< B G >>`, :g:`< D H > <0227.g3:< D H >>` be completed.

Then since, as :g:`/ A B / <0227.g2:/ A B />` is to :g:`/ C D / <0227.g3:/ C D />`, so is :g:`/ E / <0227.g2:/ E />` to :g:`/ F / <0227.g3:/ F />`,

.. subclause::

   while :g:`/ E / <0227.g2:/ E />` is :eq:`equal <0227.g2:/ E / = 0227.g3:/ C H /; 0227.g3:/ F / = 0227.g2:/ A G />` to :g:`/ C H / <0227.g3:/ C H />`, and :g:`/ F / <0227.g3:/ F />` to :g:`/ A G / <0227.g2:/ A G />`,

.. assertion::

   therefore, as :g:`/ A B / <0227.g2:/ A B />` is to :g:`/ C D / <0227.g3:/ C D />`, so is :g:`/ C H / <0227.g3:/ C H />` to :g:`/ A G / <0227.g2:/ A G />`.

.. assertion::

   Therefore in the parallelograms :g:`< B G > <0227.g2:< B G >>`, :g:`< D H > <0227.g3:< D H >>` the sides about the equal angles are reciprocally proportional.

But those equiangular parallelograms in which the sides about the equal angles are reciprocally proportional are equal; :just:`[G.177] <G.177>`

.. assertion::

   therefore the parallelogram :g:`< B G > <0227.g2:< B G >>` is :eq:`equal <0227.g2:< B G > = 0227.g3:< D H >>` to the parallelogram :g:`< D H > <0227.g3:< D H >>`.

.. subclause::

   And :g:`< B G > <0227.g2:< B G >>` is the rectangle :g:`/ A B / <0227.g2:/ A B />`, :g:`/ F / <0227.g3:/ F />`, for :g:`/ A G / <0227.g2:/ A G />` is :eq:`equal <0227.g2:/ A G / = 0227.g3:/ F />` to :g:`/ F / <0227.g3:/ F />`; and :g:`< D H > <0227.g3:< D H >>` is the rectangle :g:`/ C D / <0227.g3:/ C D />`, :g:`/ E / <0227.g2:/ E />`, for :g:`/ E / <0227.g2:/ E />` is :eq:`equal <0227.g2:/ E / = 0227.g3:/ C H />` to :g:`/ C H / <0227.g3:/ C H />`;

.. assertion::

   therefore the rectangle contained by :g:`/ A B / <0227.g2:/ A B />`, :g:`/ F / <0227.g3:/ F />` is :eq:`equal <0227.g2:< B G > = 0227.g3:< D H >>` to the rectangle contained by :g:`/ C D / <0227.g3:/ C D />`, :g:`/ E / <0227.g2:/ E />`.

Next, let the rectangle contained by :g:`/ A B / <0227.g2:/ A B />`, :g:`/ F / <0227.g3:/ F />` be :eq:`equal <0227.g2:< B G > = 0227.g3:< D H >>` to the rectangle contained by :g:`/ C D / <0227.g3:/ C D />`, :g:`/ E / <0227.g2:/ E />`;

I say that the four straight lines will be proportional, so that, as :g:`/ A B / <0227.g2:/ A B />` is to :g:`/ C D / <0227.g3:/ C D />`, so is :g:`/ E / <0227.g2:/ E />` to :g:`/ F / <0227.g3:/ F />`.

For, with the same construction, since the rectangle :g:`/ A B / <0227.g2:/ A B />`, :g:`/ F / <0227.g3:/ F />` is :eq:`equal <0227.g2:< B G > = 0227.g3:< D H >>` to the rectangle :g:`/ C D / <0227.g3:/ C D />`, :g:`/ E / <0227.g2:/ E />`, and the rectangle :g:`/ A B / <0227.g2:/ A B />`, :g:`/ F / <0227.g3:/ F />` is :g:`< B G > <0227.g2:< B G >>`, for :g:`/ A G / <0227.g2:/ A G />` is :eq:`equal <0227.g2:/ A G / = 0227.g3:/ F />` to :g:`/ F / <0227.g3:/ F />`, and the rectangle :g:`/ C D / <0227.g3:/ C D />`, :g:`/ E / <0227.g2:/ E />` is :g:`< D H > <0227.g3:< D H >>`, for :g:`/ C H / <0227.g3:/ C H />` is :eq:`equal <0227.g3:/ C H / = 0227.g2:/ E />` to :g:`/ E / <0227.g2:/ E />`,

.. assertion::

   therefore :g:`< B G > <0227.g2:< B G >>` is :eq:`equal <0227.g2:< B G > = 0227.g3:< D H >>` to :g:`< D H > <0227.g3:< D H >>`.

.. subclause::

   And they are equiangular

But in equal and equiangular parallelograms the sides about the equal angles are reciprocally proportional. :just:`[G.177] <G.177>`

.. assertion::

   Therefore, as :g:`/ A B / <0227.g2:/ A B />` is to :g:`/ C D / <0227.g3:/ C D />`, so is :g:`/ C H / <0227.g3:/ C H />` to :g:`/ A G / <0227.g2:/ A G />`.

.. subclause::

   But :g:`/ C H / <0227.g3:/ C H />` is :eq:`equal <0227.g3:/ C H / = 0227.g2:/ E /; 0227.g2:/ A G / = 0227.g3:/ F />` to :g:`/ E / <0227.g2:/ E />`, and :g:`/ A G / <0227.g2:/ A G />` to :g:`/ F / <0227.g3:/ F />`;

.. assertion::

   therefore, as :g:`/ A B / <0227.g2:/ A B />` is to :g:`/ C D / <0227.g3:/ C D />`, so is :g:`/ E / <0227.g2:/ E />` to :g:`/ F / <0227.g3:/ F />`.

.. qed::

   Therefore etc. :just:`Q. E. D.`
