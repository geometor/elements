G.260 number parts number — Heath
=================================

.. rubric:: `VII.8 <https://geometor.github.io/euclid/heath/volume_II/book_vii/propositions/08/>`_

.. enunciation::

   If a :term:`number <G.248>` be the :term:`same parts <G.254>` of a number that a number subtracted is of a number subtracted, the remainder will also be the same parts of the remainder that the whole is of the whole.

For let the number :g:`/ A B / <g1:/ A B />` be the same parts of the number :g:`/ C D / <g1:/ C D />` that :g:`/ A E / <g1:/ A E />` subtracted is of :g:`/ C F / <g1:/ C F />` subtracted;

I say that the remainder :g:`/ E B / <g1:/ E B />` is also the same parts of the remainder :g:`/ F D / <g1:/ F D />` that the whole :g:`/ A B / <g1:/ A B />` is of the whole :g:`/ C D / <g1:/ C D />`.

.. picture:: g1.svg
   :alt: Book VII, Proposition 8

For let :g:`/ G H / <g1:/ G H />` be made :eq:`equal <g1:/ G H / = g1:/ A B />` to :g:`/ A B / <g1:/ A B />`.

.. assertion::

   Therefore, whatever parts :g:`/ G H / <g1:/ G H />` is of :g:`/ C D / <g1:/ C D />`, the same parts also is :g:`/ A E / <g1:/ A E />` of :g:`/ C F / <g1:/ C F />`.

Let :g:`/ G H / <g1:/ G H />` be divided into the parts of :g:`/ C D / <g1:/ C D />`, namely :g:`/ G K / <g1:/ G K />`, :g:`/ K H / <g1:/ K H />`, and :g:`/ A E / <g1:/ A E />` into the parts of :g:`/ C F / <g1:/ C F />`, namely :g:`/ A L / <g1:/ A L />`, :g:`/ L E / <g1:/ L E />`;

.. assertion::

   thus the multitude of :g:`/ G K / <g1:/ G K />`, :g:`/ K H / <g1:/ K H />` will be equal to the multitude of :g:`/ A L / <g1:/ A L />`, :g:`/ L E / <g1:/ L E />`.

.. subclause::

   Now since, whatever part :g:`/ G K / <g1:/ G K />` is of :g:`/ C D / <g1:/ C D />`, the :term:`same part <G.253>` also is :g:`/ A L / <g1:/ A L />` of :g:`/ C F / <g1:/ C F />`, while :g:`/ C D / <g1:/ C D />` is greater than :g:`/ C F / <g1:/ C F />`,

.. assertion::

   therefore :g:`/ G K / <g1:/ G K />` is also greater than :g:`/ A L / <g1:/ A L />`.

.. subclause::

   Let :g:`/ G M / <g1:/ G M />` be made :eq:`equal <g1:/ G M / = g1:/ A L />` to :g:`/ A L / <g1:/ A L />`.

.. assertion::

   Therefore, whatever part :g:`/ G K / <g1:/ G K />` is of :g:`/ C D / <g1:/ C D />`, the same part also is :g:`/ G M / <g1:/ G M />` of :g:`/ C F / <g1:/ C F />`;

.. assertion::

   therefore also the remainder :g:`/ M K / <g1:/ M K />` is the same part of the remainder :g:`/ F D / <g1:/ F D />` that the whole :g:`/ G K / <g1:/ G K />` is of the whole :g:`/ C D / <g1:/ C D />`. :just:`[G.259] <G.259>`

.. subclause::

   Again, since, whatever part :g:`/ K H / <g1:/ K H />` is of :g:`/ C D / <g1:/ C D />`, the same part also is :g:`/ L E / <g1:/ L E />` of :g:`/ C F / <g1:/ C F />`, while :g:`/ C D / <g1:/ C D />` is greater than :g:`/ C F / <g1:/ C F />`,

.. assertion::

   therefore :g:`/ K H / <g1:/ K H />` is also greater than :g:`/ L E / <g1:/ L E />`.

.. subclause::

   Let :g:`/ K N / <g1:/ K N />` be made :eq:`equal <g1:/ K N / = g1:/ L E />` to :g:`/ L E / <g1:/ L E />`.

.. assertion::

   Therefore, whatever part :g:`/ K H / <g1:/ K H />` is of :g:`/ C D / <g1:/ C D />`, the same part also is :g:`/ K N / <g1:/ K N />` of :g:`/ C F / <g1:/ C F />`;

.. assertion::

   therefore also the remainder :g:`/ N H / <g1:/ N H />` is the same part of the remainder :g:`/ F D / <g1:/ F D />` that the whole :g:`/ K H / <g1:/ K H />` is of the whole :g:`/ C D / <g1:/ C D />`. :just:`[G.259] <G.259>`

.. subclause::

   But the remainder :g:`/ M K / <g1:/ M K />` was also proved to be the same part of the remainder :g:`/ F D / <g1:/ F D />` that the whole :g:`/ G K / <g1:/ G K />` is of the whole :g:`/ C D / <g1:/ C D />`;

.. assertion::

   therefore also the sum of :g:`/ M K / <g1:/ M K />`, :g:`/ N H / <g1:/ N H />` is the same parts of :g:`/ F D / <g1:/ F D />` that the whole :g:`/ G H / <g1:/ G H />` is of the whole :g:`/ C D / <g1:/ C D />`.

.. subclause::

   But the sum of :g:`/ M K / <g1:/ M K />`, :g:`/ N H / <g1:/ N H />` is equal to :g:`/ E B / <g1:/ E B />`, and :g:`/ G H / <g1:/ G H />` is :eq:`equal <g1:/ G H / = g1:/ A B />` to :g:`/ A B / <g1:/ A B />`;

.. assertion::

   therefore the remainder :g:`/ E B / <g1:/ E B />` is the same parts of the remainder :g:`/ F D / <g1:/ F D />` that the whole :g:`/ A B / <g1:/ A B />` is of the whole :g:`/ C D / <g1:/ C D />`.

.. qed::

   Therefore etc. :just:`Q. E. D.`
