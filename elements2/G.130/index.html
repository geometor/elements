G.130 complete a circle from a given segment¶

III.25

Given a segment of a circle, complete the full circle of which it is a segment.
complete_circle_from_segment(( A B C )) → E, ( E A )
given circle segment ( A B C ) with base chord / A C /
construct @fn(I.post.3)(E, A) → ( E A ) completing ( A B C )
∵ segment_circle_figure_defgiven circle segment ( A B C ) on chord / A C /
