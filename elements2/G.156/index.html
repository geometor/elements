G.156¶

V.19

If, as a whole is to a whole, so is a part subtracted to a part subtracted, the remainder is to the remainder as whole to whole.
whole_whole_part()
prove the remainder / E B / will also be to the remainder / F D / as the whole / A B / to the whole / C D /
assert As the whole / A B / is to the whole / C D /, so let the part / A E / subtracted be to the part / C F / subtracted
assert Since, as / A B / is to / C D /, so is / A E / to / C F /,
∵ magnitudes_proportional_proportionalassert Alternately also, as / A B / is to / A E /, so is / C D / to / C F /.
∵ magnitudes_proportional_componendoassert And, since the magnitudes are proportional componendo, they will also be proportional separando.
assert That is, as / E B / is to / A E /, so is / F D / to / C F /, and, alternately,
∵ magnitudes_proportional_proportionalassert As / E B / is to / F D /, so is / A E / to / C F /.
assert But, as / A E / is to / C F /, so by hypothesis is the whole / A B / to the whole / C D /.
∵ ratios_ratioconclude Therefore also the remainder / E B / will be to the remainder / F D / as the whole / A B / is to the whole / C D /.

From this it is manifest that, if magnitudes be proportional componendo, they will also be proportional convertendo.
