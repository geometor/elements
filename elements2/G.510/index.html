G.510¶

XIII.3

If a straight line be cut in extreme and mean ratio, the square on the lesser segment added to the half of the greater segment is five times the square on the half of the greater segment.
straight_line_cut_xiii_3()
prove the square on / B D / is five times the square on / D C /
construct Let any straight line / A B / be cut in extreme and mean ratio at C
assert Let / A C / be the greater segment, and let / A C / be bisected at D
construct Let the square < A E > be described on / A B /
construct Let the figure be drawn double.
assert Since / A C / is double of / D C /,
assert Therefore the square on / A C / is quadruple of the square on / D C /, that is, < R S > is quadruple of < F G >.
assert And, since the rectangle / A B /, / B C / is equal to the square on / A C /, and < C E > is the rectangle / A B /, / B C /,
assert Therefore < C E > is equal to < R S >.
assert < R S > is quadruple of < F G > ;
assert Therefore < C E > is also quadruple of < F G >.
assert Since / A D / is equal to / D C /,
assert / H K / is also equal to / K F /.
assert Hence the square < G F > is also equal to the square < H L >.
assert Therefore / G K / is equal to / K L /, that is, / M N / to / N E / ; hence < M F > is also equal to < F E >.
assert < M F > is equal to < C G > ;
assert Therefore < C G > is also equal to < F E >.
construct Let < C N > be added to each ;
assert Therefore the gnomon < O P Q > is equal to < C E >.
assert < C E > was proved quadruple of < G F > ;
assert Therefore the gnomon < O P Q > is also quadruple of the square < F G >.
assert Therefore the gnomon < O P Q > and the square < F G > are five times < F G >.
assert The gnomon < O P Q > and the square < F G > are the square < D N >.
assert < D N > is the square on / D B /, and < G F > the square on / D C /.
conclude Therefore the square on / D B / is five times the square on / D C /.
