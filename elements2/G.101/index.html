G.101 circle segments cut¶

III.4

If in a circle two segments cut one another which are not through the center, they do not bisect one another.
circle_segments_cut(( A B C D ), / A C /, / B D /, E)
given ( A B C D ) be a circle, in it let / A C /, / B D /, which are not through the center, cut one another at E
prove they do not bisect one another
given ( A B C D ) be a circle, in it let / A C /, / B D /, which are not through the center, cut one another at E
assert If possible, let them bisect one another, so that / A E / is equal to / E C /, and / B E / to / E D /
construct find_circle_center: Let the center of ( A B C D ) be taken
assert Let it be F
construct segment(F, E) → / F E /
∵ circle_segment_centerassert Since a segment / F E / through the center bisects a segment / A C / not through the center → it also cuts it at right angles;
assert Therefore < F E A ) is right.
∵ circle_segment_centerassert Since a segment / F E / bisects a segment / B D / → it also cuts it at right angles;
assert Therefore < F E B ) is right.
assert < F E A ) was also proved right
assert Therefore < F E A ) is equal to < F E B ), the less to the greater: which is impossible.
conclude Therefore / A C /, / B D / do not bisect one another.
