G.53¶

I.40

Equal triangles which are on equal bases and on the same side are also in the same parallels.

Let < A B C >, < C D E > be equal triangles on equal bases / B C /, / C E / and on the same side.

I say that they are also in the same parallels.

For let / A D / be joined;

I say that / A D / is parallel to / B E /.

For, if not, let / A F / be drawn through A parallel to / B E / [G.44], and let / F E / be joined.

Therefore the triangle < A B C > is equal to the triangle < F C E >; for they are on equal bases / B C /, / C E / and in the same parallels / B E /, / A F /. [G.51]

But the triangle < A B C > is equal to the triangle < D C E >;

therefore the triangle < D C E > is also equal to the triangle < F C E >, [G.1] the greater to the less: which is impossible.
Therefore / A F / is not parallel to / B E /.

Similarly we can prove that neither is any other straight line except / A D /;

therefore / A D / is parallel to / B E /.
Therefore etc. Q. E. D.]
