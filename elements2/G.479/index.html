G.479¶

XI.32

Parallelepipedal solids which are of the same height are to one another as their bases.
parallelepipedal_solids_height(< A B >, < C D >)
given < A B >, < C D > be parallelepipedal solids of the same height
prove the parallelepipedal solids < A B >, < C D > are to one another as their bases, that is, that, as the base < A E > is to the base < C F >, so is the solid < A B > to the solid < C D >
given < A B >, < C D > be parallelepipedal solids of the same height
construct parallelogram_from_polygon: Let < F H > equal to < A E > be applied to / F G /, and on < F H > as base, and with the same height as that of < C D >, let the parallelepipedal solid < G K > be completed.
∵ parallelepipedal_solids_equalassert Then the solid < A B > is equal to the solid < G K >; for they are on equal bases < A E >, < F H > and of the same height.
assert And, since the parallelepipedal solid < C K > is cut by the plane < D G > which is parallel to opposite planes,
∵ parallelepipedal_solid_cutassert Therefore, as the base < C F > is to the base < F H >, so is the solid < C D > to the solid < D H >.
assert The base < F H > is equal to the base < A E >, and the solid < G K > to the solid < A B >;
conclude Therefore also, as the base < A E > is to the base < C F >, so is the solid < A B > to the solid < C D >.
