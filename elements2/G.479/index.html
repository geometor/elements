G.479 area contained rational¶

X.93

If an area be contained by a rational segment and a third apotome, the “side” of the area is a second apotome of a medial segment.
area_contained_rational_x_93()
prove the “side” of the area < A B > is a second apotome of a medial segment; / L N / is a second apotome of a medial segment
assert Let the area < A B > be contained by the rational segment / A C / and the third apotome / A D /
assert For let / D G / be the annex to / A D /
∵ commensurable_length_rational_defassert / A G /, / G D / are rational segments commensurable in square only, and neither of / A G /, / G D / is commensurable in length with the rational segment / A C / set out, while the square on / A G / > the square on the annex / D G / by the square on a segment commensurable with / A G /
assert then the square on / A G / > the square on / G D / by the square on a segment commensurable with / A G /,
∵ there_unequal_segmentsassert if there be applied to / A G / a parallelogram equal to the fourth part of the square on / G D / and deficient by a square figure, it will divide it into commensurable parts
construct Let then / D G / be bisected at E, let there be applied to / A G / a parallelogram equal to the square on / E G / and deficient by a square figure
assert Let it be the rectangle / A F /, / F G /
construct Let / E H /, / F I /, / G K / be drawn through E, F, G parallel to / A C /.
∵ triangles_parallelograms_height, magnitudes_proportional_commensurableassert / A F /, / F G / are commensurable; therefore < A I > is also commensurable with < F K >
assert since / A F /, / F G / are commensurable in length,
∵ commensurable_magnitudes_addedassert / A G / is also commensurable in length with each of / A F /, / F G /
assert / A G / is rational and incommensurable in length with / A C /
∵ magnitudes_commensurable_incommensurableassert So that / A F /, / F G / are so also
∵ rectangle_contained_rational_x_21assert each of the rectangles < A I >, < F K > is medial
assert / D E / is commensurable in length with / E G /,
∵ commensurable_magnitudes_addedassert / D G / is also commensurable in length with each of / D E /, / E G /
assert / G D / is rational and incommensurable in length with / A C /
∵ magnitudes_commensurable_incommensurable, rectangle_contained_rational_x_21assert each of / D E /, / E G / is also rational and incommensurable in length with / A C /; therefore each of the rectangles < D H >, < E K > is medial
assert since / A G /, / G D / are commensurable in square only
assert / A G / is incommensurable in length with / G D /
assert / A G / is commensurable in length with / A F /, and / D G / with / E G /
∵ magnitudes_commensurable_incommensurableassert / A F / is incommensurable in length with / E G /
∵ triangles_parallelograms_heightassert But, as / A F / is to / E G /, so is < A I > to < E K >
∵ magnitudes_proportional_commensurableassert < A I > is incommensurable with < E K >
construct Now let the square < L M > be constructed equal to < A I >
construct Let there be subtracted < N O > equal to < F K > and being about the same angle with < L M >
∵ parallelogram_there_takenassert < L M >, < N O > are about the same diameter
construct Let / P R / be their diameter, and let the figure be drawn.
assert the rectangle / A F /, / F G / is equal to the square on / E G /,
∵ segments_proportional_rectangle_vi_17assert as / A F / is to / E G /, so is / E G / to / F G /
∵ triangles_parallelograms_heightassert But, as / A F / is to / E G /, so is < A I > to < E K >, and, as / E G / is to / F G /, so is < E K > to < F K >
∵ ratios_ratioassert also, as < A I > is to < E K >, so is < E K > to < F K >; therefore < E K > is a mean proportional between < A I >, < F K >
assert < M N > is also a mean proportional between the squares < L M >, < N O >, and < A I > is equal to < L M >, and < F K > to < N O >
assert < E K > is also equal to < M N >
assert < M N > is equal to < L O >, and < E K > equal to < D H >
assert < D K > is also equal to the gnomon < U V W > and < N O >
assert < A K > is also equal to < L M >, < N O >
assert < A B > is equal to < S T >, that is, to the square on / L N /; therefore / L N / is the “side” of the area < A B >
assert < A I >, < F K > were proved medial, and are equal to the squares on / L P /, / P N /,
assert each of the squares on / L P /, / P N / is also medial; therefore each of / L P /, / P N / is medial
∵ triangles_parallelograms_height, magnitudes_proportional_commensurableassert since < A I > is commensurable with < F K >,
assert the square on / L P / is also commensurable with the square on / P N /
assert < A I > was proved incommensurable with < E K >,
∵ triangles_parallelograms_height, magnitudes_proportional_commensurableassert < L M > is also incommensurable with < M N >, that is, the square on / L P / with the rectangle / L P /, / P N /; so that / L P / is also incommensurable in length with / P N /; therefore / L P /, / P N / are medial segments commensurable in square only
assert I say next that they also contain a medial rectangle
assert < E K > was proved medial, and is equal to the rectangle / L P /, / P N /,
assert the rectangle / L P /, / P N / is also medial, so that / L P /, / P N / are medial segments commensurable in square only which contain a medial rectangle
∵ medial_segment_there_x_75∴ / L N / is a second apotome of a medial segment; and it is the “side” of the area < A B >
