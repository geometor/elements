G.48 — Heath¶

I.35

Parallelograms which are on the same base and in the same parallels are equal to one another.

Let < A B C D >, < E B C F > be parallelograms on the same base / B C / and in the same parallels / A F /, / B C /;

I say that < A B C D > is equal to the parallelogram < E B C F >.

For, since < A B C D > is a parallelogram, / A D / is equal to / B C /. [G.47] For the same reason also / E F / is equal to / B C /,

[G.1]so that / A D / is also equal to / E F /;

and / D E / is common;

[G.21]therefore the whole / A E / is equal to the whole / D F /.

But / A B / is also equal to / D C /; [G.47]

therefore the two sides / E A /, / A B / are equal to the two sides / F D /, / D C / respectively,

and the angle < F D C ) is equal to the angle < E A B ), the exterior to the interior; [G.42]

therefore the base / E B / is equal to the base / F C /,
[G.11]and the triangle < E A B > will be equal to the triangle < F D C >.

Let < D G E > be subtracted from each;

[G.6]therefore the trapezium < A B G D > which remains is equal to the trapezium < E G C F > which remains.

Let the triangle < G B C > be added to each;

[G.21]therefore the whole parallelogram < A B C D > is equal to the whole parallelogram < E B C F >.
Therefore etc. Q. E. D.
