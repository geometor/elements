XII.2

Circles are to one another as the squares on the diameters.
given ( A B C D ), ( E F G H ) be circles, / B D /, / F H / their diameters
assert If the square on / B D / is not to the square on / F H / as ( A B C D ) is to ( E F G H ), then, as the square on / B D / is to the square on / F H /, so will ( A B C D ) be either to some less area than ( E F G H ), or to a greater.
assert First, let it be in that ratio to a less area S.
assert Let the square < E F G H > be inscribed in ( E F G H )
assert Then the inscribed square is greater than the half of ( E F G H ), inasmuch as, if through E, F, G, H we draw tangents to the circle, the square < E F G H > is half the square circumscribed about the circle, and the circle is less than the circumscribed square
assert Hence the inscribed square < E F G H > is greater than the half of ( E F G H ).
assert Let the circumferences ( E F ), ( F G ), ( G H ), ( H E ) be bisected at K, L, M, N
construct segment / E K /, / K F /, / F L /, / L G /, / G M /, / M H /, / H N /, / N E /
assert Therefore each of < E K F >, < F L G >, < G M H >, < H N E > is also greater than the half of the segment of the circle about it, inasmuch as, if through K, L, M, N we draw tangents to the circle and complete the parallelograms on / E F /, / F G /, / G H /, / H E /, each of < E K F >,
assert < F L G >, < G M H >, < H N E > will be half of the parallelogram about it, while the segment about it is less than the parallelogram
assert Hence each of < E K F >, < F L G >, < G M H >, < H N E > is greater than the half of the segment of the circle about it.
assert Thus, by bisecting the remaining circumferences and joining straight lines, and by doing this continually, we shall leave some segments of the circle which will be less than the excess by which ( E F G H ) exceeds the area S. For it was proved in the first theorem of the tenth book that, if two unequal magnitudes be set out, and if from the greater there be subtracted a magnitude greater than the half, and from that which is left a greater than the half, and if this be done continually, there will be left some magnitude which will be less than the lesser magnitude set out.
assert Let segments be left such as described, and let the segments of ( E F G H ) on / E K /, / K F /, / F L /, / L G /, / G M /, / M H /, / H N /, / N E / be less than the excess by which ( E F G H ) exceeds the area S.
assert Therefore the remainder, the polygon < E K F L G M H N >, is greater than the area S.
assert Let there be inscribed, also, in ( A B C D ) the polygon < A O B P C Q D R > similar to the polygon < E K F L G M H N >
[G.487]assert Therefore, as the square on / B D / is to the square on / F H /, so is the polygon < A O B P C Q D R > to the polygon < E K F L G M H N >.
assert But, as the square on / B D / is to the square on / F H /, so also is ( A B C D ) to the area S;
[G.148]assert Therefore also, as ( A B C D ) is to the area S, so is the polygon < A O B P C Q D R > to the polygon < E K F L G M H N >.
[G.153]assert Therefore, alternately, as ( A B C D ) is to the polygon inscribed in it, so is the area S to the polygon < E K F L G M H N >.
assert ( A B C D ) is greater than the polygon inscribed in it;
assert Therefore the area S is also greater than the polygon < E K F L G M H N >.
assert It is also less: which is impossible.
assert Therefore, as the square on / B D / is to the square on / F H /, so is not ( A B C D ) to any area less than ( E F G H ).
assert Similarly we can prove that neither is ( E F G H ) to any area less than ( A B C D ) as the square on / F H / is to the square on / B D /.
assert I say next that neither is ( A B C D ) to any area greater than ( E F G H ) as the square on / B D / is to the square on / F H /.
assert If possible, let it be in that ratio to a greater area S.
assert Therefore, inversely, as the square on / F H / is to the square on / D B /, so is the area S to ( A B C D ).
assert But, as the area S is to ( A B C D ), so is ( E F G H ) to some area less than ( A B C D );
[G.148]assert Therefore also, as the square on / F H / is to the square on / B D /, so is ( E F G H ) to some area less than ( A B C D ): which was proved impossible.
assert Therefore, as the square on / B D / is to the square on / F H /, so is not ( A B C D ) to any area greater than ( E F G H ).
assert It was proved that neither is it in that ratio to any area less than ( E F G H );
assert Therefore, as the square on / B D / is to the square on / F H /, so is ( A B C D ) to ( E F G H ).
assert LEMMA. ~~~~~~
assert For let it be contrived that, as the area S is to ( A B C D ), so is ( E F G H ) to the area T.
assert For since, as the area S is to ( A B C D ), so is ( E F G H ) to the area T,
[G.153]assert Therefore, alternately, as the area S is to ( E F G H ), so is ( A B C D ) to the area T.
assert The area S is greater than ( E F G H );
assert Therefore ( A B C D ) is also greater than the area T.
conclude Hence, as the area S is to ( A B C D ), so is ( E F G H ) to some area less than ( A B C D ).
