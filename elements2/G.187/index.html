VI.22

If four straight lines be proportional, the polygons similar and similarly described upon them is proportional; and, if the polygons similar and similarly described upon them be proportional, the straight lines will themselves also be proportional.
straight_lines_proportional_vi_22()
prove as / A B / is to / C D /, so is / E F / to / G H /
construct Let the four straight lines / A B /, / C D /, / E F /, / G H / be proportional, so that, as / A B / is to / C D /, so is / E F / to / G H /, and let there be described on / A B /, / C D / the similar and similarly situated rectilineal figures < K A B >, < L C D >, and on / E F /, / G H / the similar and similarly situated rectilineal figures < M F >, < N H >
assert I say that, as < K A B > is to < L C D >, so is < M F > to < N H >.
construct third_proportional: Let there be taken a third proportional O to / A B /, / C D /, and a third proportional P to / E F /, / G H /.
assert Then since, as / A B / is to / C D /, so is / E F / to / G H /, and, as / C D / is to O, so is / G H / to P,
∵ there_number_magnitudes_v_22assert Therefore, ex aequali, as / A B / is to O, so is / E F / to P.
∵ similar_triangles_duplicateassert But, as / A B / is to O, so is < K A B > to < L C D >, and, as / E F / is to P, so is < M F > to < N H >.
∵ ratios_ratioassert Therefore also, as < K A B > is to < L C D >, so is < M F > to < N H >.
assert Next, let < M F > be to < N H > as < K A B > is to < L C D >
assert I say also that, as / A B / is to / C D /, so is / E F / to / G H /.
assert If / E F / is not to / G H / as / A B / to / C D /,
construct fourth_proportional: Let / E F / be to / Q R / as / A B / to / C D /, and on / Q R / let the rectilineal figure < S R > be described similar and similarly situated to either of the two < M F >, < N H >.
assert Since then, as / A B / is to / C D /, so is / E F / to / Q R /, and there have been described on / A B /, / C D / the similar and similarly situated figures < K A B >, < L C D >, and on / E F /, / Q R / the similar and similarly situated figures < M F >, < S R >,
assert Therefore, as < K A B > is to < L C D >, so is < M F > to < S R >.
assert Also, by hypothesis, as < K A B > is to < L C D >, so is < M F > to < N H >;
∵ ratios_ratioassert Therefore also, as < M F > is to < S R >, so is < M F > to < N H >.
assert Therefore < M F > has the same ratio to each of the figures < N H >, < S R >;
∵ magnitudes_ratio_equalassert Therefore < N H > is equal to < S R >.
assert It is also similar and similarly situated to it;
assert Therefore / G H / is equal to / Q R /.
assert And, since, as / A B / is to / C D /, so is / E F / to / Q R /, while / Q R / is equal to / G H /,
conclude Therefore, as / A B / is to / C D /, so is / E F / to / G H /.
