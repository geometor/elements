G.36¶

I.25

If two triangles have two sides equal to two sides respectively, the one with the greater base has the greater included angle.
given < A B C >, < D E F > be two triangles having the two sides / A B /, / A C / equal to the two sides / D E /, / D F / respectively, namely / A B / to / D E /, / A C / to / D F /
assert And let the base / B C / be greater than the base / E F /
assert If not, it is either equal to it or less.
assert Now < B A C ) is not equal to < E D F )
[G.11]assert For then the base / B C / would also have been equal to the base / E F /,
assert But it is not;
assert Therefore < B A C ) is not equal to < E D F ).
assert Neither again is < B A C ) less than < E D F )
[G.35]assert For then the base / B C / would also have been less than the base / E F /,
assert But it is not;
assert Therefore < B A C ) is not less than < E D F ).
assert It was proved that it is not equal either
conclude Therefore < B A C ) is greater than < E D F ).
