G.17¶

I.10

To bisect a given finite straight line.

Let / A B / be the given finite straight line. Thus it is required to bisect the finite straight line / A B /.

Let the equilateral triangle < A B C > be constructed on it, [G.5]

and let the angle < A C B ) be bisected by the straight line / C D /; [G.16]

I say that the straight line / A B / has been bisected at the point D.

For, since / A C / is equal to / C B /, and / C D / is common,

the two sides / A C /, / C D / are equal to the two sides / B C /, / C D / respectively;

and the angle < A C D ) is equal to the angle < B C D );

[G.11]therefore the base / A D / is equal to the base / B D /.

Therefore the given finite straight line / A B / has been bisected at D.
