XI.17

If two straight lines be cut by parallel planes, they is cut in the same ratios.
straight_lines_cut_xi_17()
prove also, as / A E / is to / E B /, so is / C F / to / F D /
construct Let / A B /, / C D / be cut by the parallel planes < G H >, < K L >, < M N > at A, E, B and C, F, D
assert I say that, as / A E / is to / E B /, so is / C F / to / F D /.
construct segment(A, C) → / A C /, segment(B, D) → / B D /, segment(A, D) → / A D /
construct segment(A, D) → / A D /, segment() → < K L >, segment() → O, segment(E, O) → / E O /, segment(O, F) → / O F /
assert Since the two parallel planes < K L >, < M N > are cut by the plane < E B D O >,
∵ parallel_planes_cutassert Their common sections / E O /, / B D / are parallel.
assert For the same reason, since the two parallel planes < G H >, < K L > are cut by the plane < A O F C >,
∵ parallel_planes_cutassert Their common sections / A C /, / O F / are parallel.
assert And, since / E O / has been drawn parallel to / B D /, one of the sides of < A B D >,
∵ straight_line_drawn_vi_2assert Therefore, proportionally, as / A E / is to / E B /, so is / A O / to / O D /.
assert Since / O F / has been drawn parallel to / A C /, one of the sides of < A D C >,
∵ straight_line_drawn_vi_2assert Proportionally, as / A O / is to / O D /, so is / C F / to / F D /.
assert It was also proved that, as / A O / is to / O D /, so is / A E / to / E B /;
∵ ratios_ratioconclude Therefore also, as / A E / is to / E B /, so is / C F / to / F D /.
