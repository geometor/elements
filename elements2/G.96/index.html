G.96¶

III.18

If a straight line touch a circle, and a straight line be joined from the centre to the point of contact, the straight line so joined is perpendicular to the tangent.
construct For let a straight line / D E / touch ( A B C ) at C, let the center F of ( A B C ) be taken
construct Let / F C / be joined from F to C
construct If not, let / F G / be drawn from F perpendicular to / D E /.
[G.28]assert Since < F G C ) is right → < F C G ) is acute;
[G.30]assert And the greater angle is subtended by the greater side
assert Therefore / F C / is greater than / F G /.
assert / F C / is equal to / F B /
assert Therefore / F B / is also greater than / F G /, the less than the greater: which is impossible.
assert Therefore / F G / is not perpendicular to / D E /.
assert Similarly we can prove that neither is any other straight line except / F C /
conclude Therefore / F C / is perpendicular to / D E /.
