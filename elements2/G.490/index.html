G.490¶

XII.4

If there be two pyramids of the same height which have triangular bases, and each of them be divided into two pyramids equal to one another and similar to the whole, and into two equal prisms, then, as the base of the one pyramid is to the base of the other pyramid, so will all the prisms in the one pyramid be to all the prisms, being equal in multitude, in the other pyramid.
there_pyramids_height(< A B C >, < D E F >, G, H)
given there be two pyramids of the same height which have the triangular bases < A B C >, < D E F >, vertices G, H, let each of them be divided into two pyramids equal to one another and similar to the whole and into two equal prisms
prove also, as the base < A B C > is to the base < D E F >, so are the four prisms to the four prisms
given there be two pyramids of the same height which have the triangular bases < A B C >, < D E F >, vertices G, H, let each of them be divided into two pyramids equal to one another and similar to the whole and into two equal prisms
assert I say that, as the base < A B C > is to the base < D E F >, so are all the prisms in the pyramid < A B C G > to all the prisms, being equal in multitude, in the pyramid < D E F H >,
assert Since / B O / is equal to / O C /, and / A L / to / L C /,
assert Therefore / L O / is parallel to / A B /, and < A B C > is similar to < L O C >.
assert For the same reason < D E F > is also similar to < R V F >.
assert And, since / B C / is double of / C O /, and / E F / of / F V /,
assert Therefore, as / B C / is to / C O /, so is / E F / to / F V /.
assert On / B C /, / C O / are described the similar and similarly situated rectilineal figures < A B C >, < L O C >, and on / E F /, / F V / the similar and similarly situated figures < D E F >, < R V F >;
∵ straight_lines_proportional_vi_22, magnitudes_proportional_proportionalassert Therefore, as < A B C > is to < L O C >, so is < D E F > to < R V F >; therefore, alternately, as < A B C > is to < D E F >, so is < L O C > to < R V F >.
∵ Lemma followingassert But, as < L O C > is to < R V F >, so is the prism in which < L O C > is the base and < P M N > its opposite to the prism in which < R V F > is the base and < S T U > its opposite.
assert Therefore also, as < A B C > is to < D E F >, so is the prism in which < L O C > is the base and < P M N > its opposite to the prism in which < R V F > is the base and < S T U > its opposite.
∵ there_prisms_equal, pyramid_triangular_baseassert But, as the said prisms are to one another, so is the prism in which the parallelogram < K B O L > is the base and / P M / its opposite to the prism in which the parallelogram < Q E V R > is the base and / S T / its opposite.
∵ number_magnitudes_proportionalassert Therefore also the two prisms, that in which the parallelogram < K B O L > is the base and / P M / its opposite, and that in which < L O C > is the base and < P M N > its opposite, are to the prisms in which < Q E V R > is the base and / S T / its opposite and in which < R V F > is the base and < S T U > its opposite in the same ratio.
assert Therefore also, as the base < A B C > is to the base < D E F >, so are the said two prisms to the said two prisms.
assert Similarly, if the pyramids < P M N G >, < S T U H > be divided into two prisms and two pyramids,
assert As the base < P M N > is to the base < S T U >, so will the two prisms in the pyramid < P M N G > be to the two prisms in the pyramid < S T U H >.
assert But, as the base < P M N > is to the base < S T U >, so is the base < A B C > to the base < D E F >; for < P M N >, < S T U > are equal to < L O C >, < R V F > respectively.
conclude Therefore also, as the base < A B C > is to the base < D E F >, so are the four prisms to the four prisms.
