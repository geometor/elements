G.108 — Heath¶

III.29

In equal circles equal circumferences are subtended by equal straight lines.

Let ( A B C ), ( D E F ) be equal circles, and in them let equal circumferences ( B G C ), ( E H F ) be cut off; and let the straight lines / B C /, / E F / be joined; I say that / B C / is equal to / E F /.

For let the centres of the circles be taken, and let them be K, L; let / B K /, / K C /, / E L /, / L F / be joined.

Now, since the circumference ( B G C ) is equal to the circumference ( E H F ),

[G.106]the angle < B K C ) is also equal to the angle < E L F ).

And, since the circles ( A B C ), ( D E F ) are equal,

the radii are also equal;

therefore the two sides / B K /, / K C / are equal to the two sides / E L /, / L F /; and they contain equal angles;

[G.11]therefore the base / B C / is equal to the base / E F /.
Therefore etc.
