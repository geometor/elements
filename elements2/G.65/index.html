G.65¶

II.4

If a straight line be cut at random, the square on the whole is equal to the squares on the segments and twice the rectangle contained by the segments.
construct For let / A B / be cut at random at C
[G.59]construct For let the square < A D E B > be described on / A B /.
construct segment / B D /
construct Through C let / C F / be drawn parallel to either / A D / or / B E /
[G.44]construct Through G let / H K / be drawn parallel to either / A B / or / D E /.
[G.42]assert Since / C F / is parallel to / A D /, and / B D / has fallen on them, the exterior angle < C G B ) is equal to the interior and opposite angle < A D B ).
[G.12]assert < A D B ) is equal to < A B D ), since the side / A B / is also equal to / A D /
[G.13, G.47]assert Therefore < C G B ) is also equal to < G B C ), so that the side / B C / is also equal to the side / C G /. But / B C / is equal to / G K /, and / C G / to / B K /
assert Therefore / G K / is also equal to / B K /
assert Therefore < C G K B > is equilateral.
assert I say next that it is also right-angled.
[G.42]assert Since / C G / is parallel to / B K /, < K B C ), < G C B ) are equal to two right angles.
assert < K B C ) is right
assert Therefore < G C B ) is also right,
[G.47]assert So that the opposite angles < C G K ), < G K B ) are also right.
assert Therefore < C G K B > is right-angled
assert And it was also proved equilateral
assert Therefore it is a square;
assert And it is described on / B C /.
assert For the same reason < H F > is also a square;
[G.47]assert And it is described on / H G /, that is / A C /.
assert Therefore the squares < H F >, < K C > are the squares on / A C /, / B C /.
assert Since < A G > is equal to < G E >, and < A G > is the rectangle / A C /, / B C /, for / C G / is equal to / B C /, therefore < G E > is also equal to the rectangle / A C /, / B C /.
assert Therefore < A G >, < G E > are equal to twice the rectangle / A C /, / B C /.
assert The squares < H F >, < C K > are also the squares on / A C /, / B C /
assert Therefore the four areas < H F >, < C K >, < A G >, < G E > are equal to the squares on / A C /, / B C / and twice the rectangle contained by / A C /, / B C /.
assert < H F >, < C K >, < A G >, < G E > are the whole < A D E B >, which is the square on / A B /.
conclude Therefore the square on / A B / is equal to the squares on / A C /, / B C / and twice the rectangle contained by / A C /, / B C /.
