III.32

If a straight line touch a circle, and from the point of contact there be drawn across, in the circle, a straight line cutting the circle, the angles which it makes with the tangent will equals the angles in the alternate segments of the circle.
straight_line_touch_iii_32()
prove the angles which / B D / makes with the tangent / E F / will be equal to the angles in the alternate segments of the circle, that is, that < F B D ) is equal to the angle constructed in the segment ( B A D ), and < E B D ) is equal to the angle constructed in the segment ( D C B )
construct Let a straight line / E F / touch ( A B C D ) at B, and from B let there be drawn across, in ( A B C D ), a straight line / B D / cutting it
construct perpendicular_at(/ E F /, B) → / B A /
construct point(the circumference ( B D )) → C
construct segment(A, D) → / A D /, segment(D, C) → / D C /, segment(C, B) → / C B /

assert Therefore / B A / is a diameter of ( A B C D )
∵ thales_semicircle_theoremassert Therefore < A D B ), being an angle in a semicircle, is right.
∵ triangle_angle_sumassert Therefore the remaining angles < B A D ), < A B D ) are equal to one right angle.
assert < A B F ) is also right
assert Therefore < A B F ) is equal to < B A D ), < A B D ).
construct Let < A B D ) be subtracted from each
assert Therefore < D B F ) which remains is equal to < B A D ) in the alternate segment of the circle.
∵ opposite_angles_quadrilateralsassert Next, since < A B C D > is a quadrilateral in a circle, its opposite angles are equal to two right angles.
assert < D B F ), < D B E ) are also equal to two right angles
assert Therefore < D B F ), < D B E ) are equal to < B A D ), < B C D ),
assert Of which < B A D ) was proved equal to < D B F );
conclude Therefore < D B E ) which remains is equal to < D C B ) in the alternate segment ( D C B ) of the circle.
