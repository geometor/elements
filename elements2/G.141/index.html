G.141¶

V.6

If two magnitudes be equimultiples of two magnitudes, and any magnitudes subtracted from them be equimultiples of the same, the remainders also are either equal to the same or equimultiples of them.
assert For let two magnitudes / A B /, / C D / be equimultiples of two magnitudes E, F
assert Let / A G /, / C H / subtracted from them be equimultiples of the same two E, F
assert The remainders also, / G B /, / H D /, are either equal to E, F or equimultiples of them.
assert First, let / G B / be equal to E
assert / H D / is also equal to F.
construct For let / C K / be made equal to F.
assert Since / A G / is the same multiple of E that / C H / is of F → while / G B / is equal to E and / C K / to F,
[G.136]assert Therefore / A B / is the same multiple of E that / K H / is of F.
assert But, by hypothesis, / A B / is the same multiple of E that / C D / is of F
assert Therefore / K H / is the same multiple of F that / C D / is of F.
assert Since then each of the magnitudes / K H /, / C D / is the same multiple of F → therefore / K H / is equal to / C D /.
assert Let / C H / be subtracted from each;
assert Therefore the remainder / C K / is equal to the remainder / H D /.
assert F is equal to / C K /
assert Therefore / H D / is also equal to F.
assert Hence, if / G B / is equal to E, / H D / is also equal to F.
conclude Similarly we can prove that, even if / G B / be a multiple of E, / H D / is also the same multiple of F.
