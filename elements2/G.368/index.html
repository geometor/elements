G.368 many numbers please¶

IX.35

If as many numbers as we please be in continued proportion, and there be subtracted from the second and the last numbers equal to the first, then, as the excess of the second is to the first, so will the excess of the last be to all those before it.
many_numbers_please_ix_35(A, / B C /, D, / E F /)
given there be as many numbers as we please in continued proportion, A, / B C /, D, / E F /, beginning from A as least, let there be subtracted from / B C / and / E F / the numbers / B G /, / F H /, each = to A
prove as the excess of the second is to the first, so is the excess of the last to all those before it
given there be as many numbers as we please in continued proportion, A, / B C /, D, / E F /, beginning from A as least, let there be subtracted from / B C / and / E F / the numbers / B G /, / F H /, each = to A
assert I say that, as / C G / is to A, so is / E H / to A, / B C /, D
construct cut_equal_segment(/ B C /, and / F L / equal to D) → / F K / (equal)
assert / F K / = / B C /, and of these the part / F H / = the part / B G /,
assert / H K / = / C G /
assert Since, as / E F / is to D, so is D to / B C /, and / B C / to A, while D = / F L /, / B C / to / F K /, and A to / F H /,
assert as / E F / is to / F L /, so is / F L / to / F K /, and / F K / to / F H /
∵ whole_whole_number, numbers_proportional_proportionalassert Separando, as / E L / is to / F L /, so is / K L / to / F K /, and / H K / to / F H /
∵ there_many_numbersassert also, as one of the antecedents is to one of the consequents, so are all the antecedents to all the consequents; therefore, as / H K / is to / F H /, so are / E L /, / K L /, / H K / to / F L /, / F K /, / F H /
assert / H K / = / C G /, / F H / to A, and / F L /, / F K /, / F H / to D, / B C /, A
assert as / C G / is to A, so is / E H / to D, / B C /, A
∴ as the excess of the second is to the first, so is the excess of the last to all those before it
