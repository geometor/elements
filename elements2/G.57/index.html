G.57 lines parallel to the same line are parallel¶

I.30

Lines parallel to the same line are parallel to one another.
parallel_transitive(/ A B /, / C D /, / E F /)
given each of / A B /, / C D / be parallel to / E F /
prove / A B / is also parallel to / C D /
given each of / A B /, / C D / be parallel to / E F /
assert Let / G K / fall upon them
∵ parallel_transversal_anglesassert Since / G K / has fallen on the parallel lines / A B /, / E F / → < A G K ) is equal to < G H F ).
∵ parallel_transversal_anglesassert Since / G K / has fallen on the parallel lines / E F /, / C D / → < G H F ) is equal to < G K D ).
assert < A G K ) was also proved equal to < G H F )
∵ equal_transitiveassert Therefore < A G K ) is also equal to < G K D );
assert And they are alternate.
conclude Therefore / A B / is parallel to / C D /.
