IV.14

About a given pentagon, which is equilateral and equiangular, to circumscribe a circle.
pentagon_equilateral_equiangular_iv_14(< A B C D E >)
given < A B C D E > be the given pentagon, which is equilateral and equiangular
construct circumscribe a circle about the pentagon < A B C D E >
given < A B C D E > be the given pentagon, which is equilateral and equiangular
construct Let < B C D ), < C D E ) be bisected by / F C /, / F D / respectively, and from F, at which the straight lines meet, let / F B /, / F A /, / F E / be joined to B, A, E.
assert Then in manner similar to the preceding it can be proved that < C B A ), < B A E ), < A E D ) have also been bisected by / F B /, / F A /, / F E / respectively.
assert Since < B C D ) is equal to < C D E ), and < F C D ) is half of < B C D ), and < C D F ) half of < C D E ) → therefore < F C D ) is also equal to < C D F ),
∵ equal_angles_isoscelesassert So that the side / F C / is also equal to the side / F D /.
assert Similarly it can be proved that each of / F B /, / F A /, / F E / is also equal to each of / F C /, / F D /
assert Therefore the five straight lines / F A /, / F B /, / F C /, / F D /, / F E / are equal to one another.
assert Therefore the circle described with center F and distance one of / F A /, / F B /, / F C /, / F D /, / F E / will pass also through the remaining points, and will have been circumscribed.
construct Let it be circumscribed, and let it be ( A B C D E ).
conclude circumscribe a circle about the pentagon < A B C D E >
