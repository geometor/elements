G.440 square binomial segment¶

X.60

The square on the binomial segment applied to a rational segment produces as breadth the first binomial.
square_binomial_segment(/ A B /, C, / A C /)
given / A B / be a binomial segment divided into its terms at C, so that / A C / is the greater term
prove / D G / is a first binomial segment
given / A B / be a binomial segment divided into its terms at C, so that / A C / is the greater term
construct Let a rational segment / D E / be set out, and let < D E F G > equal to the square on / A B / be applied to / D E / producing / D G / as its breadth
construct Let there be applied to / D E / the rectangle < D H > equal to the square on / A C /, and < K L > equal to the square on / B C /
assert the remainder, twice the rectangle / A C /, / C B /, is equal to < M F >
construct Let / M G / be bisected at N, and let / N O / be drawn parallel [to / M L / or / G F /].
assert each of the rectangles < M O >, < N F > is equal to once the rectangle / A C /, / C B /
assert / A B / is a binomial divided into its terms at C,
∵ rational_segments_commensurable, commensurable_magnitudes_addedassert / A C /, / C B / are rational segments commensurable in square only ; therefore the squares on / A C /, / C B / are rational and commensurable with one another, so that the sum of the squares or / A C /, / C B / is also rational
assert It is equal to < D L >
assert < D L > is rational
assert It is applied to the rational segment / D E /
∵ rational_area_appliedassert / D M / is rational and commensurable in length with / D E /
assert / A C /, / C B / are rational segments commensurable in square only,
∵ rectangle_contained_rational_x_21assert twice the rectangle / A C /, / C B /, that is < M F >, is medial
assert It is applied to the rational segment / M L /
∵ square_medial_segmentassert / M G / is also rational and incommensurable in length with / M L /, that is, / D E /
assert / M D / is also rational and is commensurable in length with / D E /
∵ magnitudes_commensurable_incommensurableassert / D M / is incommensurable in length with / M G /
assert They are rational
∵ rational_segments_commensurableassert / D M /, / M G / are rational segments commensurable in square only ; therefore / D G / is binomial
assert It is next to be proved that it is also a first binomial segment
∵ find_sixth_binomialassert the rectangle / A C /, / C B / is a mean proportional between the squares on / A C /, / C B /
assert < M O > is also a mean proportional between < D H >, < K L >
∵ triangles_parallelograms_height, segments_proportional_rectangle_vi_17assert as < D H > is to < M O >, so is < M O > to < K L >, that is, as / D K / is to / M N /, so is / M N / to / M K / ; therefore the rectangle / D K /, / K M / is equal to the square on / M N /
assert since the square on / A C / is commensurable with the square on / C B /,
∵ triangles_parallelograms_height, magnitudes_proportional_commensurableassert < D H > is also commensurable with < K L >, so that / D K / is also commensurable with / K M /
∵ Lemmaassert since the squares on / A C /, / C B / are greater than twice the rectangle / A C /, / C B /
∵ triangles_parallelograms_heightassert < D L > is also greater than < M F >, so that / D M / is also greater than / M G /
assert The rectangle / D K /, / K M / is equal to the square on / M N /, that is, to the fourth part of the square on / M G /, and / D K / is commensurable with / K M /
∵ there_unequal_segmentsassert But, if there be two unequal segments, and to the greater there be applied a parallelogram equal to the fourth part of the square on the less and deficient by a square figure, and if it divide it into commensurable parts, the square on the greater > the square on the less by the square on a segment commensurable with the greater
assert the square on / D M / > the square on / M G / by the square on a segment commensurable with / D M /
assert / D M /, / M G / are rational, and / D M /, which is the greater term, is commensurable in length with the rational segment / D E / set out
