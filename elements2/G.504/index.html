G.504 planes cut common¶

XI.3

If two planes cut one another, their common section is a segment.
planes_cut_common()
prove the line / D B / is a segment
assert Let the two planes < A B >, < B C > cut one another, and let the line / D B / be their common section
construct If not, from D to B let / D E B / be joined in the plane < A B >, and in the plane < B C > / D F B /.
assert Then / D E B /, / D F B / will have the same extremities, and will clearly enclose an area:
assert ⇒⇐
assert / D E B /, / D F B / are not segments
∴ Similarly we can prove that neither will there be any other segment joined from D to B except / D B / the common section of the planes < A B >, < B C >
