G.512¶

XIII.5

If a straight line be cut in extreme and mean ratio, and there be added to it a straight line equal to the greater segment, the whole straight line has been cut in extreme and mean ratio, and the original straight line is the greater segment.
construct For let / A B / be cut in extreme and mean ratio at C, let / A C / be the greater segment
assert Let / A D / be equal to / A C /.
construct For let the square < A E > be described on / A B /
construct Let the figure be drawn.
assert Since / A B / has been cut in extreme and mean ratio at C,
[G.507, G.180]assert Therefore the rectangle / A B /, / B C / is equal to the square on / A C /.
assert < C E > is the rectangle / A B /, / B C /, and < C H > the square on / A C /;
assert Therefore < C E > is equal to < H C >.
assert < H E > is equal to < C E >, and < D H > is equal to < H C >;
assert Therefore < D H > is also equal to < H E >.
assert Therefore the whole < D K > is equal to the whole < A E >.
assert < D K > is the rectangle / B D /, / D A /, for / A D / is equal to / D L /; and < A E > is the square on / A B /;
assert Therefore the rectangle / B D /, / D A / is equal to the square on / A B /.
[G.180]assert Therefore, as / D B / is to / B A /, so is / B A / to / A D /.
assert / D B / is greater than / B A /;
[G.151]assert Therefore / B A / is also greater than / A D /.
conclude Therefore / D B / has been cut in extreme and mean ratio at A, and / A B / is the greater segment.
