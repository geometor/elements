G.20¶

I.12

Construct a perpendicular to a given infinite line from a given point not on it.
perpendicular_from([ A B ], C) → / C H /
given [ A B ], C which is not on it
construct / C H / has been drawn perpendicular to [ A B ] from C which is not on it
given [ A B ], C which is not on it
construct point([ A B ]) → D
construct circle(C, / C D /) → ( C D )
construct bisect_segment(/ E G /) → H (bisected)
construct segment(C, G) → / C G /, segment(C, H) → / C H /, segment(C, E) → / C E /
assert Since / G H / is equal to / H E /, and / H C / is common → the two sides / G H /, / H C / are equal to the two sides / E H /, / H C / respectively;
assert And the base / C G / is equal to the base / C E /
∵ sss_congruenceassert Therefore < C H G ) is equal to < E H C ).
assert They are adjacent angles.
∵ right_angle_perpendicularassert But, when a straight line set up on a straight line makes the adjacent angles equal to one another, each of the equal angles is right, and the straight line standing on the other is called a perpendicular to that on which it stands.
conclude Therefore / C H / has been drawn perpendicular to [ A B ] from C which is not on it.
