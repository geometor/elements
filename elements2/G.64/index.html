G.64 parallelograms on the same base in the same parallels¶

I.35

Parallelograms on the same base and in the same parallels are equal in area.
parallelograms_same_base(< A B C D >, < E B C F >, / B C /, / A F /)
given < A B C D >, < E B C F > be parallelograms on the same base / B C / and in the same parallels / A F /, / B C /
prove < A B C D > is equal to the parallelogram < E B C F >
given < A B C D >, < E B C F > be parallelograms on the same base / B C / and in the same parallels / A F /, / B C /
∵ parallelogram_propertiesassert Since < A B C D > is a parallelogram, / A D / is equal to / B C /
assert The same reason also / E F / is equal to / B C /,
∵ equal_transitiveassert So that / A D / is also equal to / E F /;
assert And / D E / is common
∵ add_equalsassert Therefore the whole / A E / is equal to the whole / D F /.
∵ parallelogram_propertiesassert / A B / is also equal to / D C /
assert Therefore the two sides / E A /, / A B / are equal to the two sides / F D /, / D C / respectively,
∵ parallel_transversal_anglesassert And < F D C ) is equal to < E A B ), the exterior to the interior
assert Therefore the base / E B / is equal to the base / F C /,
∵ sas_congruenceassert And < E A B > will be equal to < F D C >.
construct Let < D G E > be subtracted from each
∵ subtract_equalsassert Therefore the trapezium < A B G D > which remains is equal to the trapezium < E G C F > which remains.
construct Let < G B C > be added to each
∵ add_equalsconclude Therefore the whole parallelogram < A B C D > is equal to the whole parallelogram < E B C F >.
