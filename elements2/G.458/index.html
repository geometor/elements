XI.14

Planes to which the same straight line is at right angles is parallel.
planes_straight_line()
prove the planes are parallel
assert Let any straight line / A B / be at right angles to each of the planes < C D >, < E F >
assert If not, they will meet when produced
assert Let them meet
∵ planes_cut_commonassert They will then make, as common section, a straight line
assert Let them make / G H /
construct point(/ G H /) → K
construct segment(A, K) → / A K /, segment(B, K) → / B K /
∵ straight_line_right_defassert Since / A B / is at right angles to the plane < E F >, therefore / A B / is also at right angles to / B K / which is a straight line in the plane < E F > produced
assert Therefore < A B K ) is right.
assert For the same reason < B A K ) is also right.
assert Thus, in < A B K >, the two angles < A B K ), < B A K ) are equal to two right angles:
∵ two_angles_less_than_two_rightassert Which is impossible.
assert Therefore the planes < C D >, < E F > will not meet when produced
∵ parallel_planes_meet_defassert Therefore the planes < C D >, < E F > are parallel.
conclude Therefore planes to which the same straight line is at right angles are parallel.
