G.434¶

X.107

A straight line commensurable with that which produces with a medial area a medial whole is itself also a straight line which produces with a medial area a medial whole.
straight_line_commensurable_x_107(/ A B /, / C D /)
given / A B / be a straight line which produces with a medial area a medial whole, let / C D / be commensurable with / A B /
prove / C D / is also a straight line which produces with a medial area a medial whole
given / A B / be a straight line which produces with a medial area a medial whole, let / C D / be commensurable with / A B /
construct Let / B E / be the annex to / A B /, and let the same construction be made
∵ straight_line_there_x_78assert Therefore / A E /, / E B / are straight lines incommensurable in square which make the sum of the squares on them medial, the rectangle contained by them medial, and further the sum of the squares on them incommensurable with the rectangle contained by them.
assert As was proved, / A E /, / E B / are commensurable with / C F /, / F D /, the sum of the squares on / A E /, / E B / with the sum of the squares on / C F /, / F D /, and the rectangle / A E /, / E B / with the rectangle / C F /, / F D /;
assert Therefore / C F /, / F D / are also straight lines incommensurable in square which make the sum of the squares on them medial, the rectangle contained by them medial, and further the sum of the squares on them incommensurable with the rectangle contained by them.
∵ straight_line_there_x_78conclude Therefore / C D / is a straight line which produces with a medial area a medial whole.
