G.393 rectangle contained rational¶

X.19

The rectangle contained by rational segments commensurable in length is rational.
rectangle_contained_rational()
prove < A C > is rational
assert Let the rectangle < A C > be contained by the rational segments / A B /, / B C / commensurable in length
construct On / A B / let the square < A D > be described
∵ square_assigned_segment_defassert < A D > is rational
assert since / A B / is commensurable in length with / B C /, while / A B / = / B D /,
assert / B D / is commensurable in length with / B C /
∵ triangles_parallelograms_heightassert as / B D / is to / B C /, so is < D A > to < A C >
∵ magnitudes_proportional_commensurableassert < D A > is commensurable with < A C >
assert < D A > is rational
∵ square_assigned_segment_def∴ < A C > is also rational
