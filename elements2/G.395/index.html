G.395 rectangle contained rational¶

X.21

The rectangle contained by rational segments commensurable in square only is irrational, and the side of the square equal to it is irrational. Let the latter be called medial.
rectangle_contained_rational_x_21()
prove < A C > is irrational, and the side of the square equal to it is irrational
assert Let the rectangle < A C > be contained by the rational segments / A B /, / B C / commensurable in square only
assert let the latter be called medial
construct On / A B / let the square < A D > be described
∵ square_assigned_segment_defassert < A D > is rational
assert since / A B / is incommensurable in length with / B C /, for by hypothesis they are commensurable in square only, while / A B / = / B D /,
assert / D B / is also incommensurable in length with / B C /
∵ triangles_parallelograms_heightassert as / D B / is to / B C /, so is < A D > to < A C >
∵ magnitudes_proportional_commensurableassert < D A > is incommensurable with < A C >
assert < D A > is rational
∵ square_assigned_segment_def∴ < A C > is irrational, so that the side of the square equal to < A C > is also irrational
