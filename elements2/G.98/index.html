G.98 find circle center¶

III.1

Find the center of a given circle.
find_circle_center(( A B C )) → F
given ( A B C )
construct F is the center of ( A B C )
given ( A B C )
construct Let a segment / A B / be drawn through it at random
assert Let it be bisected at D
construct From D let / D C / be drawn at right angles to / A B / and let it be drawn through to E
construct bisect_segment(/ C E /) → F (bisected)
construct Suppose it is not, but, if possible, let G be the center, and let / G A /, / G D /, / G B / be joined.
assert / A D / = / D B /, and / D G / is common → / A D /, / D G / = / B D /, / D G /
assert / G A / = / G B /, for they are radii
∵ sss_congruenceassert < A D G ) = < G D B )
∵ right_angle_perpendicularassert But, when a segment set up on a segment makes the adjacent angles equal to one another, each of the equal angles is right
assert < G D B ) is right
assert < F D B ) is also right
assert < F D B ) = < G D B ), the greater to the less ⇒⇐
assert G is not the center of ( A B C )
assert Similarly we can prove that neither is any other point except F
∵ circle_radii∴ F is the center of ( A B C )
PORISM. From this it is manifest that, if in a circle a straight line cut a straight line into two equal parts and at right angles, the centre of the circle is on the cutting straight line.
