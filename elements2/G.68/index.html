G.68¶

II.7

If a straight line be cut at random, the square on the whole and that on one of the segments both together are equal to twice the rectangle contained by the whole and the said segment and the square on the remaining segment.
square_of_difference()
prove the squares on / A B /, / B C / are equal to twice the rectangle contained by / A B /, / B C / and the square on / C A /
construct Let a straight line / A B / be cut at random at C
construct square_on_segment: Let the square < A D E B > be described on / A B /.
construct And let the figure be drawn.
∵ parallelogram_complementsassert Since < A G > is equal to < G E >.
construct Let < C F > be added to each
assert Therefore the whole < A F > is equal to the whole < C E >.
assert Therefore < A F >, < C E > are double of < A F >.
assert < A F >, < C E > are the gnomon < K L M > and the square < C F >
assert Therefore the gnomon < K L M > and the square < C F > are double of < A F >.
assert Twice the rectangle / A B /, / B C / is also double of < A F >
assert For / B F / is equal to / B C /
assert Therefore the gnomon < K L M > and the square < C F > are equal to twice the rectangle / A B /, / B C /.
construct Let < D G >, which is the square on / A C /, be added to each
assert Therefore the gnomon < K L M > and the squares < B G >, < G D > are equal to twice the rectangle contained by / A B /, / B C / and the square on / A C /.
assert The gnomon < K L M > and the squares < B G >, < G D > are the whole < A D E B > and < C F >, which are squares described on / A B /, / B C /
conclude Therefore the squares on / A B /, / B C / are equal to twice the rectangle contained by / A B /, / B C / together with the square on / A C /.
