G.279¶

IX.9

If as many numbers as we please beginning from an unit be in continued proportion, and the number after the unit be square, all the rest is square. And, if the number after the unit be cube, all the rest is cube.
given there be as many numbers as we please, A, B, C, D, E, F, beginning from an unit and in continued proportion
assert Let A, the number after the unit, be square
[G.278]assert Now it has been proved that B, the third from the unit, is square, as are also all those which leave out one .
assert Since A, B, C are in continued proportion, and A is square,
[G.264]assert Therefore C is also square.
assert Since B, C, D are in continued proportion, and B is square,
[G.264]assert D is also square.
assert Similarly we can prove that all the rest are also square.
assert Next, let A be cube
[G.278]assert Now it has been proved that C, the fourth from the unit, is cube, as also are all those which leave out two .
assert Since, as the unit is to A, so is A to B,
assert Therefore the unit measures A the same number of times as A measures B.
assert The unit measures A according to the units in it ;
assert Therefore A also measures B according to the units in itself ;
assert Therefore A by multiplying itself has made B.
assert A is cube.
[G.272]assert But, if a cube number by multiplying itself make some number, the product is cube.
assert Therefore B is also cube.
assert And, since the four numbers A, B, C, D are in continued proportion, and A is cube,
[G.265]assert D also is cube.
assert For the same reason
conclude E is also cube, and similarly all the rest are cube.
