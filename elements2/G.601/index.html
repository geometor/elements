G.601 set out sides¶

XIII.18

To set out the sides of the five figures and to compare them with one another.
set_out_sides() → / M B /, / N B /
construct / M B /, which is a side of the icosahedron, is by far greater than / N B / which is a side of the dodecahedron
construct Let / A B /, the diameter of the given sphere, be set out, and let it be cut at C so that / A C / is equal to / C B /, and at D so that / A D / is double of / D B /
construct Let the semicircle ( A E B ) be described on / A B /
construct From C, D let / C E /, / D F / be drawn at right angles to / A B /
construct segment(A, F) → / A F /, segment(F, B) → / F B /, segment(E, B) → / E B /
assert / A D / is double of / D B /, therefore / A B / is triple of / D B /
assert :term:`Convertendo <G.200>`, therefore, / A B / is one and a half times / A D /
∵ magnitudes_proportional_said_def, right_angled_triangleassert But, as / A B / is to / A D /, so is the square on / A B / to the square on / A F /, for < A F B > is equiangular with < A F D >
assert the square on / A B / is one and a half times the square on / A F /
∵ construct_pyramid_comprehendassert The square on the diameter of the sphere is also one and a half times the square on the side of the pyramid
assert / A B / is the diameter of the sphere
assert / A F / is equal to the side of the pyramid
assert / A D / is double of / D B /,
assert / A B / is triple of / D B /
∵ right_angled_triangle, magnitudes_proportional_said_defassert But, as / A B / is to / D B /, so is the square on / A B / to the square on / F B /
assert the square on / A B / is triple of the square on / F B /
∵ construct_cube_comprehendassert The square on the diameter of the sphere is also triple of the square on the side of the cube
assert / A B / is the diameter of the sphere
assert / F B / is the side of the cube
assert since / A C / = / C B /,
assert / A B / is double of / C B /
assert But, as / A B / is to / C B /, so is the square on / A B / to the square on / E B /
assert the square on / A B / is double of the square on / E B /
∵ construct_octahedron_comprehendassert The square on the diameter of the sphere is also double of the square on the side of the octahedron
assert / A B / is the diameter of the given sphere
assert / E B / is the side of the octahedron
construct Next, let / A G / be drawn from A at right angles to / A B /
construct cut_equal_segment(/ A B /) → / A G / (equal)
construct segment(G, C) → / G C /
construct From H let / H K / be drawn perpendicular to / A B /.
assert / A G / is double of / A C /, for / A G / = / A B /, and, as / A G / is to / A C /, so is / H K / to / C K /,
assert / H K / is also double of / C K /
assert the square on / H K / is quadruple of the square on / C K /; therefore the squares on / H K /, / C K /, that is, the square on / H C /, is five times the square on / C K /
assert / H C / = / C B /
assert the square on / C B / is five times the square on / C K /
assert since / A B / is double of / C B /, and, in them, / A D / is double of / D B /,
assert / D B / is double of / C D /
assert / C B / is triple of / C D /; therefore the square on / C B / is nine times the square on / C D /
assert The square on / C B / is five times the square on / C K /
assert the square on / C K / > the square on / C D /; therefore / C K / > / C D /
construct cut_equal_segment(/ C K /) → / C L / (equal)
construct From L let / L M / be drawn at right angles to / A B /
construct segment(M, B) → / M B /
assert the square on / C B / is five times the square on / C K /, and / A B / is double of / C B /, and / K L / double of / C K /,
assert the square on / A B / is five times the square on / K L /
∵ construct_icosahedron_comprehendassert The square on the diameter of the sphere is also five times the square on the radius of the circle from which the icosahedron has been described
assert / A B / is the diameter of the sphere
∵ inscribe_hexagon_in_circleassert / K L / is the radius of the circle from which the icosahedron has been described; therefore / K L / is a side of the hexagon in the said circle
∵ construct_icosahedron_comprehendassert since the diameter of the sphere is made up of the side of the hexagon and two of the sides of the decagon inscribed in the same circle, and / A B / is the diameter of the sphere, while / K L / is a side of the hexagon, and / A K / = / L B /
assert each of / A K /, / L B / is a side of the decagon inscribed in the circle from which the icosahedron has been described
assert since / L B / belongs to a decagon, and / L M / to a hexagon, for / L M / = / K L /, since it = / H K /, being the same distance from the center, and each of / H K /, / K L / is double of / C K /,
∵ equilateral_pentagon_inscribedassert / M B / belongs to a pentagon
∵ construct_icosahedron_comprehendassert The side of the pentagon is the side of the icosahedron
assert / M B / belongs to the icosahedron
construct Since / F B / is a side of the cube, let it be cut in extreme and mean ratio at N, and let / N B / be the greater segment ;
∵ construct_dodecahedron_comprehendassert / N B / is a side of the dodecahedron
assert since the square on the diameter of the sphere was proved to be one and a half times the square on / A F / of the pyramid, double of the square on / E B / of the octahedron and triple of / F B / of the cube,
assert of parts of which the square on the diameter of the sphere contains six, the square on the side of the pyramid contains four, the square on the side of the octahedron three, and the square on the side of the cube two
assert the square on the side of the pyramid is four-thirds of the square on the side of the octahedron, and double of the square on the side of the cube ; and the square on the side of the octahedron is one and a half times the square on the side of the cube
assert The said sides, therefore, of the three figures, I mean the pyramid, the octahedron and the cube, are to one another in rational ratios
∵ construct_icosahedron_comprehend, construct_dodecahedron_comprehendassert The remaining two, I mean the side of the icosahedron and the side of the dodecahedron, are not in rational ratios either to one another or to the aforesaid sides ; for they are irrational, the one being minor and the other an apotome
assert That / M B / of the icosahedron > / N B / of the dodecahedron we can prove thus
∵ right_angled_triangleassert < F D B > is equiangular with < A F B >
∵ equiangular_triangles_sidesassert Proportionally, as / D B / is to / F B /, so is / F B / to / A B /
∵ magnitudes_proportional_said_def, similar_polygons_dividedassert since the three segments are proportional, as the first is to the third, so is the square on the first to the square on the second
assert as / D B / is to / A B /, so is the square on / D B / to the square on / F B /
assert inversely, as / A B / is to / D B /, so is the square on / F B / to the square on / D B /
assert / A B / is triple of / D B /
assert the square on / F B / is triple of the square on / D B /
assert The square on / A D / is also quadruple of the square on / D B /, for / A D / is double of / D B /
assert the square on / A D / > the square on / F B / ; therefore / A D / > / F B / ; therefore / A L / is by far greater than / F B /
∵ side_hexagon_decagonassert when / A L / is cut in extreme and mean ratio, / K L / is the greater segment, inasmuch as / K L / belongs to a hexagon, and / A K / to a decagon ; and, when / F B / is cut in extreme and mean ratio, / N B / is the greater segment
assert / K L / > / N B /
assert / K L / = / L M /
assert / L M / > / N B /
∴ / M B /, which is a side of the icosahedron, is by far greater than / N B / which is a side of the dodecahedron
