G.491¶

XII.5

Pyramids which are of the same height and have triangular bases are to one another as the bases.
pyramids_height_triangular(< A B C >, < D E F >, G, H)
given there be pyramids of the same height, of which < A B C >, < D E F > are the bases and G, H the vertices
prove It was proved that neither is it in that ratio to a less solid
given there be pyramids of the same height, of which < A B C >, < D E F > are the bases and G, H the vertices
assert I say that, as the base < A B C > is to the base < D E F >, so is the pyramid < A B C G > to the pyramid < D E F H >.
assert If the pyramid < A B C G > is not to the pyramid < D E F H > as the base < A B C > is to the base < D E F >,
assert Then, as the base < A B C > is to the base < D E F >, so will the pyramid < A B C G > be either to some solid less than the pyramid < D E F H > or to a greater.
assert Let it, first, be in that ratio to a less solid W, and let the pyramid < D E F H > be divided into two pyramids equal to one another and similar to the whole and into two equal prisms
∵ pyramid_triangular_baseassert Then the two prisms are greater than the half of the whole pyramid.
∵ unequal_magnitudes_setassert Let the pyramids arising from the division be similarly divided, and let this be done continually until there are left over from the pyramid < D E F H > some pyramids which are less than the excess by which the pyramid < D E F H > exceeds the solid W.
assert Let such be left, and let them be, for the sake of argument, < D Q R S >, < S T U H >
assert Therefore the remainders, the prisms in the pyramid < D E F H >, are greater than the solid W.
assert Let the pyramid < A B C G > also be divided similarly, and a similar number of times, with the pyramid < D E F H >
∵ there_pyramids_heightassert Therefore, as the base < A B C > is to the base < D E F >, so are the prisms in the pyramid < A B C G > to the prisms in the pyramid < D E F H >.
assert But, as the base < A B C > is to the base < D E F >, so also is the pyramid < A B C G > to the solid W;
∵ ratios_ratio, magnitudes_proportional_proportionalassert Therefore also, as the pyramid < A B C G > is to the solid W, so are the prisms in the pyramid < A B C G > to the prisms in the pyramid < D E F H >; therefore, alternately, as the pyramid < A B C G > is to the prisms in it, so is the solid W to the prisms in the pyramid < D E F H >.
assert The pyramid < A B C G > is greater than the prisms in it;
assert Therefore the solid W is also greater than the prisms in the pyramid < D E F H >.
assert It is also less :
assert Which is impossible.
assert Therefore the prism < A B C G > is not to any solid less than the pyramid < D E F H > as the base < A B C > is to the base < D E F >.
assert Similarly it can be proved that neither is the pyramid < D E F H > to any solid less than the pyramid < A B C G > as the base < D E F > is to the base < A B C >.
assert I say next that neither is the pyramid < A B C G > to any solid greater than the pyramid < D E F H > as the base < A B C > is to the base < D E F >.
assert If possible, let it be in that ratio to a greater solid W;
assert Therefore, inversely, as the base < D E F > is to the base < A B C >, so is the solid W to the pyramid < A B C G >.
∵ circles_squares_diametersassert But, as the solid W is to the solid < A B C G >, so is the pyramid < D E F H > to some solid less than the pyramid < A B C G >, as was before proved.
∵ ratios_ratioassert Therefore also, as the base < D E F > is to the base < A B C >, so is the pyramid < D E F H > to some solid less than the pyramid < A B C G >: which was proved absurd.
assert Therefore the pyramid < A B C G > is not to any solid greater than the pyramid < D E F H > as the base < A B C > is to the base < D E F >.
conclude It was proved that neither is it in that ratio to a less solid.
