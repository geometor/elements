G.155 — Heath¶

V.18

If magnitudes be proportional separando, they will also be proportional componendo.

Let / A E /, / E B /, / C F /, / F D / be magnitudes proportional separando, so that, as / A E / is to / E B /, so is / C F / to / F D /;

I say that they will also be proportional componendo, that is, as / A B / is to / E B /, so is / C D / to / F D /.

For, if / C D / be not to / F D / as / A B / to / E B /, then, as / A B / is to / E B /, so will / C D / be either to some magnitude less than / F D / or to a greater.

First, let it be in that ratio to a less magnitude / G D /.

Then, since, as / A B / is to / E B /, so is / C D / to / G D /, they are magnitudes proportional componendo;

[G.154]so that they will also be proportional separando.
Therefore, as / A E / is to / E B /, so is / C G / to / G D /.

But also, by hypothesis,

as / A E / is to / E B /, so is / C F / to / F D /.
[G.148]Therefore also, as / C G / is to / G D /, so is / C F / to / F D /.

But the first / C G / is greater than the third / C F /;

therefore the second / G D / is also greater than the fourth / F D /. [G.151]
But it is also less: which is impossible.
Therefore, as / A B / is to / E B /, so is not / C D / to a less magnitude than / F D /.

Similarly we can prove that neither is it in that ratio to a greater;

it is therefore in that ratio to / F D / itself.
Therefore etc. Q. E. D.
