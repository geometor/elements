G.85¶

III.10

A circle does not cut a circle at more points than two.
circle_cut_circle()
prove the two circles ( A B C ), ( D E F ) which cut one another have the same center P: which is impossible
assert If possible, let ( A B C ) cut ( D E F ) at more points than two, namely B, G, F, H
construct Let / B H /, / B G / be joined and bisected at K, L, and from K, L let / K C /, / L M / be drawn at right angles to / B H /, / B G / and carried through to A, E.
∵ find_circle_centerassert Since in ( A B C ) a straight line / A C / cuts a straight line / B H / into two equal parts and at right angles → the center of ( A B C ) is on / A C /.
assert Since in the same circle ( A B C ) a straight line / N O / cuts a straight line / B G / into two equal parts and at right angles → the center of ( A B C ) is on / N O /.
intersect It was also proved to be on / A C /, and / A C /, / N O / meet at no point except at P
∵ circle_radiiassert Therefore P is the center of ( A B C ).
assert Similarly we can prove that P is also the center of ( D E F )
∵ circles_cut_centreconclude Therefore the two circles ( A B C ), ( D E F ) which cut one another have the same center P: which is impossible.
