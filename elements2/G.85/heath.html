G.85 square of sum — Heath¶

II.4

If a straight line be cut at random, the square on the whole is equal to the squares on the segments and twice the rectangle contained by the segments.

For let the straight line / A B / be cut at random at C;

I say that the square on / A B / is equal to the squares on / A C /, / B C / and twice the rectangle contained by / A C /, / B C /.

For let the square < A D E B > be described on / A B /, [G.75]

let / B D / be joined;

through C let / C F / be drawn parallel to either / A D / or / B E /, and through G let / H K / be drawn parallel to either / A B / or / D E /. [G.58]

Then, since / C F / is parallel to / A D /, and / B D / has fallen on them, the exterior angle < C G B ) is equal to the interior and opposite angle < A D B ). [G.56]

But the angle < A D B ) is equal to the angle < A B D ), since the side / A B / is also equal to / A D /; [G.25]

therefore the angle < C G B ) is also equal to the angle < G B C ), so that the side / B C / is also equal to the side / C G /. [G.27] But / B C / is equal to / G K /, and / C G / to / B K /; [G.62]

therefore / G K / is also equal to / B K /;

therefore < C G K B > is equilateral.

I say next that it is also right-angled.

For, since / C G / is parallel to / B K /, the angles < K B C ), < G C B ) are equal to two right angles. [G.56]

But the angle < K B C ) is right;

therefore the angle < G C B ) is also right,

so that the opposite angles < C G K ), < G K B ) are also right. [G.62]

Therefore < C G K B > is right-angled; and it was also proved equilateral;

therefore it is a square;

and it is described on / B C /.

For the same reason < H F > is also a square;

and it is described on / H G /, that is / A C /. [G.62]

Therefore the squares < H F >, < K C > are the squares on / A C /, / B C /.

Now, since < A G > is equal to < G E >, and < A G > is the rectangle / A C /, / B C /, for / C G / is equal to / B C /, therefore < G E > is also equal to the rectangle / A C /, / B C /.

Therefore < A G >, < G E > are equal to twice the rectangle / A C /, / B C /.

But the squares < H F >, < C K > are also the squares on / A C /, / B C /; therefore the four areas < H F >, < C K >, < A G >, < G E > are equal to the squares on / A C /, / B C / and twice the rectangle contained by / A C /, / B C /.

But < H F >, < C K >, < A G >, < G E > are the whole < A D E B >, which is the square on / A B /.

Therefore the square on / A B / is equal to the squares on / A C /, / B C / and twice the rectangle contained by / A C /, / B C /.
Therefore etc. Q. E. D.
