G.572 cones cylinders equal — Heath¶

XII.14

Cones and cylinders which are on equal bases are to one another as their heights.

For let < E B >, < F D > be cylinders on equal bases, the circles ( A B ), ( C D ); I say that, as the cylinder < E B > is to the cylinder < F D >, so is the axis / G H / to the axis / K L /.

For let the axis / K L / be produced to the point N, let / L N / be made equal to the axis / G H /, and let the cylinder < C M > be conceived about / L N / as axis.

Since then the cylinders < E B >, < C M > are of the same height, they are to one another as their bases. [G.565]
But the bases are equal to one another:
therefore the cylinders < E B >, < C M > are also equal.
And, since the cylinder < F M > has been cut by the plane ( C D ) which is parallel to its opposite planes,
therefore, as the cylinder < C M > is to the cylinder < F D >, so is the axis / L N / to the axis / K L /. [G.571]
But the cylinder < C M > is equal to the cylinder < E B >, and the axis / L N / to the axis / G H /;
therefore, as the cylinder < E B > is to the cylinder < F D >, so is the axis / G H / to the axis / K L /.
But, as the cylinder < E B > is to the cylinder < F D >, so is the cone < A B G > to the cone < C D K >. [G.563]
Therefore also, as the axis / G H / is to the axis / K L /, so is the cone < A B G > to the cone < C D K > and the cylinder < E B > to the cylinder < F D >.
Q. E. D.
