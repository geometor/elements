G.444¶

XI.2

If two straight lines cut one another, they are in one plane, and every triangle is in one plane.
intersect For let / A B /, / C D / cut one another at E
construct For let points F, G be taken at random on / E C /, / E B /, let / C B /, / F G / be joined
construct Let / F H /, / G K / be drawn across
assert I say first that < E C B > is in one plane.
assert If part of < E C B >, either < F H C > or < G B K >, is in the plane of reference, and the rest in another,
assert A part also of one of / E C /, / E B / will be in the plane of reference, and a part in another.
assert But, if the part < F C B G > of < E C B > be in the plane of reference, and the rest in another,
assert A part also of both / E C /, / E B / will be in the plane of reference and a part in another:
[G.443]assert Which was proved absurd.
assert Therefore < E C B > is in one plane.
[G.443]assert But, in whatever plane < E C B > is, in that plane also is each of / E C /, / E B /, and, in whatever plane each of / E C /, / E B / is, in that plane are / A B /, / C D / also.
conclude Therefore / A B /, / C D / are in one plane, and every triangle is in one plane.
