G.78¶

III.3

If in a circle a straight line through the centre bisect a straight line not through the centre, it also cuts it at right angles; and if it cut it at right angles, it also bisects it.
circle_straight_line(( A B C ), / C D /, / A B /, F)
given ( A B C ) be a circle, in it let a straight line / C D / through the center bisect a straight line / A B / not through the center at F
prove it also cuts it at right angles; it also bisects it, that is, that / A F / is equal to / F B /
given ( A B C ) be a circle, in it let a straight line / C D / through the center bisect a straight line / A B / not through the center at F
construct Let the center of ( A B C ) be taken
assert Let it be E
construct segment(E, A) → / E A /, segment(E, B) → / E B /
assert Since / A F / is equal to / F B /, and / F E / is common → two sides are equal to two sides;
assert And the base / E A / is equal to the base / E B /
∵ sss_congruenceassert Therefore < A F E ) is equal to < B F E ).
∵ right_angle_perpendicularassert But, when a straight line set up on a straight line makes the adjacent angles equal to one another, each of the equal angles is right
assert Therefore each of < A F E ), < B F E ) is right.
assert Therefore / C D /, which is through the center, and bisects / A B / which is not through the center, also cuts it at right angles.
assert Let / C D / cut / A B / at right angles
assert With the same construction → since / E A / is equal to / E B /,
∵ isosceles_base_anglesassert < E A F ) is also equal to < E B F ).
assert The right angle < A F E ) is equal to the right angle < B F E ), therefore < E A F >, < E B F > are two triangles having two angles equal to two angles and one side equal to one side, namely / E F /, which is common to them, and subtends one of the equal angles
∵ asa_aas_congruenceassert Therefore they will also have the remaining sides equal to the remaining sides
conclude Therefore / A F / is equal to / F B /.
