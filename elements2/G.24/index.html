G.24¶

I.14

If two rays at a point on a line on opposite sides make adjacent angles summing to two right angles, the two rays are collinear.
supplementary_angles_collinear()
prove / B D / is in a straight line with / C B /
assert With any straight line / A B /, and at B on it, let / B C /, / B D / not lying on the same side make the adjacent angles < A B C ), < A B D ) equal to two right angles
assert If / B D / is not in a straight line with / B C /, let / B E / be in a straight line with / C B /.
∵ adjacent_angles_supplementaryassert Since / A B / stands on / C B E / → < A B C ), < A B E ) are equal to two right angles.
assert < A B C ), < A B D ) are also equal to two right angles
∵ right_angles_equal, equal_transitiveassert Therefore < C B A ), < A B E ) are equal to < C B A ), < A B D ).
construct Let < C B A ) be subtracted from each;
∵ subtract_equalsassert Therefore the remaining angle < A B E ) is equal to the remaining angle < A B D ).
assert The less to the greater: which is impossible.
assert Therefore / B E / is not in a straight line with / C B /.
assert Similarly we can prove that neither is any other straight line except / B D /.
conclude Therefore / C B / is in a straight line with / B D /.
