G.56¶

I.43

In any parallelogram, the complements of the parallelograms about the diagonal are equal in area.
parallelogram_complements(< A B C D >, / A C /)
given < A B C D > be a parallelogram, / A C / its diameter
prove the complement < E B F K > is equal to the complement < H K G D >
given < A B C D > be a parallelogram, / A C / its diameter
assert And about / A C / let < A E K H >, < K F C G > be parallelograms, and < E B F K >, < H K G D > the so-called complements
∵ parallelogram_propertiesassert Since < A B C D > is a parallelogram, and / A C / its diameter, < A B C > is equal to < A C D >.
assert Since < A E K H > is a parallelogram, and / A K / is its diameter, < A E K > is equal to < A H K >.
assert The same reason < K F C > is also equal to < K G C >.
∵ add_equalsassert Since < A E K > is equal to < A H K >, and < K F C > to < K G C > → < A E K > together with < K G C > is equal to < A H K > together with < K F C >.
assert The whole triangle < A B C > is also equal to the whole < A D C >
∵ subtract_equalsconclude Therefore the complement < E B F K > which remains is equal to the complement < H K G D > which remains.
