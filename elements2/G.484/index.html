G.484¶

XI.37

If four straight lines be proportional, the parallelepipedal solids on them which are similar and similarly described is proportional; and, if the parallelepipedal solids on them which are similar and similarly described be proportional, the straight lines will themselves also be proportional.
straight_lines_proportional_xi_37(/ A B /, / C D /, / E F /, / G H /)
given / A B /, / C D /, / E F /, / G H / be four straight lines in proportion, so that, as / A B / is to / C D /, so is / E F / to / G H /
prove also, as / A B / is to / C D /, so is / E F / to / G H /
given / A B /, / C D /, / E F /, / G H / be four straight lines in proportion, so that, as / A B / is to / C D /, so is / E F / to / G H /
construct And let there be described on / A B /, / C D /, / E F /, / G H / the similar and similarly situated parallelepipedal solids < K A >, < L C >, < M E >, < N G >
assert I say that, as < K A > is to < L C >, so is < M E > to < N G >.
assert Since the parallelepipedal solid < K A > is similar to < L C >,
∵ similar_parallelepipedal_solidsassert Therefore < K A > has to < L C > the ratio triplicate of that which / A B / has to / C D /.
∵ similar_parallelepipedal_solidsassert For the same reason < M E > also has to < N G > the ratio triplicate of that which / E F / has to / G H /.
assert And, as / A B / is to / C D /, so is / E F / to / G H /.
assert Therefore also, as < A K > is to < L C >, so is < M E > to < N G >.
assert Next, as the solid < A K > is to the solid < L C >, so let the solid < M E > be to the solid < N G >
assert I say that, as / A B / is to / C D /, so is / E F / to / G H /.
∵ similar_parallelepipedal_solidsassert For since, again, < K A > has to < L C > the ratio triplicate of that which / A B / has to / C D /, and < M E > also has to < N G > the ratio triplicate of that which / E F / has to / G H /, and, as < K A > is to < L C >, so is < M E > to < N G >.
conclude Therefore also, as / A B / is to / C D /, so is / E F / to / G H /.
