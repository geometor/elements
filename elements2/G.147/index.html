G.147 fit a chord in a circle equal to a segment¶

IV.1

Fit into a given circle a chord equal to a given segment not greater than the diameter of the circle.
fit_chord_in_circle(( A B C ), D) → / C A /
given ( A B C ), D not greater than the diameter of ( A B C )
construct / C A / is fitted into ( A B C ) with / C A / = D
∵ segment_def, circle_radii, circle_diameter, segment_said_fitted_defgiven ( A B C ), D not greater than the diameter of ( A B C )
∵ circle_diameter, cut_equal_segmentconstruct Draw diameter / B C / of ( A B C ); if / B C / = D, it is done; if / B C / > D, cut_equal_segment(/ B C /, D) → / C E / = D
∵ circle, segmentconstruct circle(C, E) → ( E A F ), segment(C, A) → / C A /
∵ circle_radiiassert C is the center of ( E A F ) → / C A / = / C E /
∵ equal_transitive, segment_said_fitted_def∴ / C E / = D → / C A / = D fitted into ( A B C )
