G.72 complements of parallelograms about the diagonal are equal¶

I.43

In any parallelogram, the complements of the parallelograms about the diagonal are equal in area.
parallelogram_complements(< A B C D >, / A C /)
given < A B C D >, / A C /, < A E K H >, < K F C G >, < E B F K >, < H K G D >
prove < E B F K > = < H K G D >
given < A B C D >, / A C /, < A E K H >, < K F C G >, < E B F K >, < H K G D >
∵ parallelogram_propertiesassert < A B C D >, / A C / → < A B C > = < A C D >
∵ parallelogram_propertiesassert < A E K H >, < K F C G > → < A E K > = < A H K >, < K F C > = < K G C >
∵ add_equalsassert < A E K > = < A H K >, < K F C > = < K G C > → < A E K > + < K F C > = < A H K > + < K G C >
∵ subtract_equals∴ < A B C > = < A C D > → < E B F K > = < H K G D >
