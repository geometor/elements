IV.11

Inscribe in a given circle an equilateral and equiangular pentagon.
inscribe_pentagon_in_circle(( A B C D E ))
given ( A B C D E )
construct It was also proved equilateral
given ( A B C D E )
∵ golden_isosceles_triangleassert Let the isosceles triangle < F G H > be set out having each of the angles at < F G H ), < F H G ) double of the angle at < G F H )
construct inscribe_triangle_in_circle: Let there be inscribed in ( A B C D E ) < A C D > equiangular with < F G H >, so that < C A D ) is equal to the angle at < G F H ) and the angles at < F G H ), < F H G ) respectively equal to < A C D ), < C D A )
assert Therefore each of < A C D ), < C D A ) is also double of < C A D ).
construct segment() → < A C D ), segment() → < C D A ), segment(C, E) → / C E /, segment(D, B) → / D B /, segment(A, B) → / A B /, segment(B, C) → / B C /, segment(D, E) → / D E /, segment(E, A) → / E A /
assert Since each of < A C D ), < C D A ) is double of < C A D ), and they have been bisected by / C E /, / D B / → therefore the five angles < D A C ), < A C E ), < E C D ), < C D B ), < B D A ) are equal to one another.
∵ equal_circles_equalassert Equal angles stand on equal circumferences
assert Therefore the five circumferences ( A B ), ( B C ), ( C D ), ( D E ), ( E A ) are equal to one another.
∵ equal_circles_equal_iii_29assert Equal circumferences are subtended by equal straight lines
assert Therefore the five straight lines / A B /, / B C /, / C D /, / D E /, / E A / are equal to one another;
assert Therefore the pentagon < A B C D E > is equilateral.
assert I say next that it is also equiangular.
construct Since the circumference ( A B ) is equal to the circumference ( D E ), let ( B C D ) be added to each
assert Therefore the whole circumference ( A B C D ) is equal to the whole circumference ( E D C B ).
assert < A E D ) stands on the circumference ( A B C D ), and < B A E ) on the circumference ( E D C B )
∵ equal_circles_anglesassert Therefore < B A E ) is also equal to < A E D ).
assert The same reason each of < A B C ), < B C D ), < C D E ) is also equal to each of < B A E ), < A E D )
assert Therefore the pentagon < A B C D E > is equiangular.
conclude It was also proved equilateral
