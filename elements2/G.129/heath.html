G.129 similar segments circles — Heath¶

III.24

Similar segments of circles on equal straight lines are equal to one another.

For let ( A E B ), ( C F D ) be similar segments of circles on equal straight lines / A B /, / C D /; I say that the segment ( A E B ) is equal to the segment ( C F D ).

For, if the segment ( A E B ) be :coincide:`applied <g1:( A E B ) ≡ g1:( C F D )>` to ( C F D ), and if the point A be :coincide:`placed on <g1:A ≡ g1:C; g1:/ A B / ≡ g1:/ C D />` C and the straight line / A B / on / C D /, the point B will also :coincide:`coincide <g1:B ≡ g1:D>` with the point D, because / A B / is equal to / C D /;

and, / A B / :coincide:`coinciding <g1:/ A B / ≡ g1:/ C D />` with / C D /,

the segment ( A E B ) will also :coincide:`coincide <g1:( A E B ) ≡ g1:( C F D )>` with ( C F D ).

For, if the straight line / A B / :coincide:`coincide <g1:/ A B / ≡ g1:/ C D />` with / C D / but the segment ( A E B ) do not coincide with ( C F D ), it will either fall within it, or outside it; or it will fall awry, as ( C G D ), and a circle cuts a circle at more points than two: which is impossible. [G.108]

Therefore, if the straight line / A B / be :coincide:`applied <g1:/ A B / ≡ g1:/ C D />` to / C D /, the segment ( A E B ) will not fail to :coincide:`coincide <g1:( A E B ) ≡ g1:( C F D )>` with ( C F D ) also;

therefore it will :coincide:`coincide <g1:( A E B ) ≡ g1:( C F D )>` with it and will be equal to it.
Therefore etc. Q. E. D.
