G.525¶

XIII.18

To set out the sides of the five figures and to compare them with one another.
given / A B /, the diameter of the given sphere, be set out
construct Let it be cut at C so that / A C / is equal to / C B /, and at D so that / A D / is double of / D B /
construct Let the semicircle ( A E B ) be described on / A B /, from C, D let / C E /, / D F / be drawn at right angles to / A B /
construct segment / A F /, / F B /, / E B /
assert Since / A D / is double of / D B /, therefore / A B / is triple of / D B /.
assert Convertendo, therefore, / A B / is one and a half times / A D /.
[G.182, G.171]assert But, as / A B / is to / A D /, so is the square on / A B / to the square on / A F /, for < A F B > is equiangular with < A F D >.
assert Therefore the square on / A B / is one and a half times the square on / A F /.
[G.520]assert The square on the diameter of the sphere is also one and a half times the square on the side of the pyramid.
assert / A B / is the diameter of the sphere;
assert Therefore / A F / is equal to the side of the pyramid.
assert Since / A D / is double of / D B /,
assert Therefore / A B / is triple of / D B /.
[G.171, G.182]assert But, as / A B / is to / D B /, so is the square on / A B / to the square on / F B /.
assert Therefore the square on / A B / is triple of the square on / F B /.
[G.522]assert The square on the diameter of the sphere is also triple of the square on the side of the cube.
assert / A B / is the diameter of the sphere;
assert Therefore / F B / is the side of the cube.
assert And, since / A C / is equal to / C B /,
assert Therefore / A B / is double of / C B /.
assert But, as / A B / is to / C B /, so is the square on / A B / to the square on / E B /;
assert Therefore the square on / A B / is double of the square on / E B /.
[G.521]assert The square on the diameter of the sphere is also double of the square on the side of the octahedron.
assert / A B / is the diameter of the given sphere;
assert Therefore / E B / is the side of the octahedron.
construct Next, let / A G / be drawn from A at right angles to / A B /, let / A G / be made equal to / A B /, let / G C / be joined
construct From H let / H K / be drawn perpendicular to / A B /.
assert Since / A G / is double of / A C /, for / A G / is equal to / A B /, and, as / A G / is to / A C /, so is / H K / to / C K /,
assert Therefore / H K / is also double of / C K /.
assert Therefore the square on / H K / is quadruple of the square on / C K /; therefore the squares on / H K /, / C K /, that is, the square on / H C /, is five times the square on / C K /.
assert / H C / is equal to / C B /;
assert Therefore the square on / C B / is five times the square on / C K /.
assert And, since / A B / is double of / C B /, and, in them, / A D / is double of / D B /,
assert Therefore the remainder / D B / is double of the remainder / C D /.
assert Therefore / C B / is triple of / C D /; therefore the square on / C B / is nine times the square on / C D /.
assert The square on / C B / is five times the square on / C K /;
assert Therefore the square on / C K / is greater than the square on / C D /; therefore / C K / is greater than / C D /.
construct Let / C L / be made equal to / C K /, from L let / L M / be drawn at right angles to / A B /
construct segment / M B /
assert Since the square on / C B / is five times the square on / C K /, and / A B / is double of / C B /, and / K L / double of / C K /,
assert Therefore the square on / A B / is five times the square on / K L /.
[G.523]assert The square on the diameter of the sphere is also five times the square on the radius of the circle from which the icosahedron has been described.
assert / A B / is the diameter of the sphere;
[G.133]assert Therefore / K L / is the radius of the circle from which the icosahedron has been described; therefore / K L / is a side of the hexagon in the said circle.
[G.523]assert And, since the diameter of the sphere is made up of the side of the hexagon and two of the sides of the decagon inscribed in the same circle, and / A B / is the diameter of the sphere, while / K L / is a side of the hexagon, and / A K / is equal to / L B /.
assert Therefore each of / A K /, / L B / is a side of the decagon inscribed in the circle from which the icosahedron has been described.
assert And, since / L B / belongs to a decagon, and / L M / to a hexagon, for / L M / is equal to / K L /, since it is also equal to / H K /, being the same distance from the center, and each of / H K /, / K L / is double of / C K /,
[G.517]assert Therefore / M B / belongs to a pentagon.
[G.523]assert The side of the pentagon is the side of the icosahedron .
assert Therefore / M B / belongs to the icosahedron.
assert Since / F B / is a side of the cube, let it be cut in extreme and mean ratio at N, and let / N B / be the greater segment ;
[G.524]assert Therefore / N B / is a side of the dodecahedron.
assert And, since the square on the diameter of the sphere was proved to be one and a half times the square on the side / A F / of the pyramid, double of the square on the side / E B / of the octahedron and triple of the side / F B / of the cube,
assert Therefore, of parts of which the square on the diameter of the sphere contains six, the square on the side of the pyramid contains four, the square on the side of the octahedron three, and the square on the side of the cube two.
assert Therefore the square on the side of the pyramid is four-thirds of the square on the side of the octahedron, and double of the square on the side of the cube ; and the square on the side of the octahedron is one and a half times the square on the side of the cube.
assert The said sides, therefore, of the three figures, I mean the pyramid, the octahedron and the cube, are to one another in rational ratios.
[G.523, G.524]assert The remaining two, I mean the side of the icosahedron and the side of the dodecahedron, are not in rational ratios either to one another or to the aforesaid sides ; for they are irrational, the one being minor and the other an apotome.
assert That the side / M B / of the icosahedron is greater than the side / N B / of the dodecahedron we can prove thus.
[G.171]assert Since < F D B > is equiangular with < A F B >.
[G.166]assert Proportionally, as / D B / is to / F B /, so is / F B / to / A B /.
[G.182, G.185]assert And, since the three straight lines are proportional, as the first is to the third, so is the square on the first to the square on the second .
assert Therefore, as / D B / is to / A B /, so is the square on / D B / to the square on / F B /;
assert Therefore, inversely, as / A B / is to / D B /, so is the square on / F B / to the square on / D B /.
assert / A B / is triple of / D B / ;
assert Therefore the square on / F B / is triple of the square on / D B /.
assert The square on / A D / is also quadruple of the square on / D B /, for / A D / is double of / D B / ;
assert Therefore the square on / A D / is greater than the square on / F B / ; therefore / A D / is greater than / F B / ; therefore / A L / is by far greater than / F B /.
[G.516]assert And, when / A L / is cut in extreme and mean ratio, / K L / is the greater segment, inasmuch as / K L / belongs to a hexagon, and / A K / to a decagon ; and, when / F B / is cut in extreme and mean ratio, / N B / is the greater segment .
assert Therefore / K L / is greater than / N B /.
assert / K L / is equal to / L M / ;
assert Therefore / L M / is greater than / N B /.
conclude Therefore / M B /, which is a side of the icosahedron, is by far greater than / N B / which is a side of the dodecahedron.
