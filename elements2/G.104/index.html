G.104¶

III.25

Given a segment of a circle, to describe the complete circle of which it is a segment.
given ( A B C ) be the given segment of a circle
construct For let / A C / be bisected at D, let / D B / be drawn from D at right angles to / A C /
construct segment / A B /
assert < A B D ) is then greater than, equal to, or less than < B A D ).
assert First let it be greater
assert And on / B A /
construct At A on it, let < B A E ) be constructed equal to < A B D )
construct Let / D B / be drawn through to E
construct segment / E C /
[G.13]assert Since < A B E ) is equal to < B A E ), / E B / is also equal to / E A /.
assert And, since / A D / is equal to / D C /, and / D E / is common, the two sides / A D /, / D E / are equal to the two sides / C D /, / D E / respectively
assert And < A D E ) is equal to < C D E ), for each is right
assert Therefore the base / A E / is equal to the base / C E /.
assert / A E / was proved equal to / B E /
assert Therefore / B E / is also equal to / C E /;
assert Therefore / A E /, / E B /, / E C / are equal to one another.
[G.84]assert Therefore the circle drawn with center E and distance one of / A E /, / E B /, / E C / will also pass through the remaining points and will have been completed.
assert Therefore, given a segment of a circle, the complete circle has been described.
assert It is manifest that the segment ( A B C ) is less than a semicircle, because the center E happens to be outside it.
assert Similarly, even if < A B D ) be equal to < B A D ), / A D / being equal to each of the two / B D /, / D C /,
assert / D A /, / D B /, / D C / will be equal to one another, D will be the center of the completed circle, and ( A B C ) will clearly be a semicircle.
assert But, if < A B D ) be less than < B A D ), and if we construct, on / B A / and at A on it, an angle equal to < A B D ), the center will fall on / D B / within the segment ( A B C ), and the segment ( A B C ) will clearly be greater than a semicircle .
conclude Therefore, given a segment of a circle, the complete circle has been described.
