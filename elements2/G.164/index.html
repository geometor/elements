given ( A B C D E )

assert Of which the square on / F C / is equal to the square on / F B /;

assert Therefore / B K / is equal to / C K /.

assert And the base / B K / equal to the base / C K /

assert < F C K ) is also equal to < F C L )
assert Therefore < F K C >, < F L C > are two triangles having two angles equal to two angles and one side equal to one side, namely / F C / which is common to them
∵ asa_aas_congruenceassert Therefore they will also have the remaining sides equal to the remaining sides, and the remaining angle to the remaining angle

assert Therefore / K L / is double of / K C /.

assert / H K / is also double of / B K /.
assert / B K / is equal to / K C /
assert Therefore / H K / is also equal to / K L /.
