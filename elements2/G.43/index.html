G.43¶

I.30

Lines parallel to the same line are parallel to one another.
given each of / A B /, / C D / be parallel to / E F /
assert For let / G K / fall upon them
[G.42]assert Since / G K / has fallen on the parallel straight lines / A B /, / E F / → < A G K ) is equal to < G H F ).
[G.42]assert Since / G K / has fallen on the parallel straight lines / E F /, / C D / → < G H F ) is equal to < G K D ).
assert < A G K ) was also proved equal to < G H F )
[G.1]assert Therefore < A G K ) is also equal to < G K D );
assert And they are alternate.
conclude Therefore / A B / is parallel to / C D /.
