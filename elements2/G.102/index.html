G.102¶

III.23

On the same straight line there cannot be constructed two similar and unequal segments of circles on the same side.
construct If possible, on the same straight line / A B / let two similar and unequal segments of circles ( A C B ), ( A D B ) be constructed on the same side
construct Let / A C D / be drawn through
construct segment / C B /, / D B /
[G.101, G.27]conclude Since the segment ( A C B ) is similar to the segment ( A D B ), and similar segments of circles are those which admit equal angles, < A C B ) is equal to < A D B ), the exterior to the interior: which is impossible.
