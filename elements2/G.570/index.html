G.570 similar cones cylinders¶

XII.12

Similar cones and cylinders are to one another in the triplicate ratio of the diameters in their bases.
similar_cones_cylinders(( A B C D ), ( E F G H ), / B D /, / F H /)
given there be similar cones and cylinders, let ( A B C D ), ( E F G H ) be their bases, / B D /, / F H / the diameters of the bases, / K L /, / M N / the axes of the cones and cylinders
prove the cone of which ( A B C D ) is the base and L the vertex has to the cone of which ( E F G H ) is the base and N the vertex the ratio triplicate of that which / B D / has to / F H /
given there be similar cones and cylinders, let ( A B C D ), ( E F G H ) be their bases, / B D /, / F H / the diameters of the bases, / K L /, / M N / the axes of the cones and cylinders
assert If the cone < A B C D L > has not to the cone < E F G H N > the ratio triplicate of that which / B D / has to / F H /,
assert The cone < A B C D L > will have that triplicate ratio either to some solid less than the cone < E F G H N > or to a greater
assert First, let it have that triplicate ratio to a less solid O
construct inscribe_square_in_circle: Let the square < E F G H > be inscribed in ( E F G H )
assert the square < E F G H > > the half of ( E F G H )
construct Now let there be set up on the square < E F G H > a pyramid having the same vertex with the cone
assert the pyramid so set up > the half part of the cone
construct segment() → ( E P F ), segment() → ( F Q G ), segment() → ( G R H ), segment() → ( H S E ), segment() → P, segment() → Q, segment() → R, segment() → S, segment(E, P) → / E P /, segment(P, F) → / P F /, segment(F, Q) → / F Q /, segment(Q, G) → / Q G /, segment(G, R) → / G R /, segment(R, H) → / R H /, segment(H, S) → / H S /, segment(S, E) → / S E /
assert each of < E P F >, < F Q G >, < G R H >, < H S E > is also greater than the half part of that segment of ( E F G H ) which is about it
construct Now on each of < E P F >, < F Q G >, < G R H >, < H S E > let a pyramid be set up having the same vertex with the cone
assert each of the pyramids so set up is also greater than the half part of that segment of the cone which is about it
assert bisecting the arcs so left, joining segments, setting up on each of the triangles pyramids having the same vertex with the cone, and doing this continually,
∵ unequal_magnitudes_setassert We shall leave some segments of the cone which will be less than the excess by which the cone < E F G H N > exceeds the solid O
assert Let such be left, and let them be the segments on / E P /, / P F /, / F Q /, / Q G /, / G R /, / R H /, / H S /, / S E /
assert the remainder, the pyramid of which the polygon < E P F Q G R H S > is the base and N the vertex, > the solid O
construct Let there be also inscribed in ( A B C D ) the polygon < A T B U C V D W > similar and similarly situated to the polygon < E P F Q G R H S >, and let there be set up on the polygon < A T B U C V D W > a pyramid having the same vertex with the cone
assert Of the triangles containing the pyramid of which the polygon < A T B U C V D W > is the base and L the vertex let < L B T > be one, and of the triangles containing the pyramid of which the polygon < E P F Q G R H S > is the base and N the vertex let < N F P > be one
construct segment(K, T) → / K T /, segment(M, P) → / M P /
assert the cone < A B C D L > is similar to the cone < E F G H N >,
∵ similar_cones_cylinders_defassert as / B D / is to / F H /, so is the axis / K L / to the axis / M N /
assert But, as / B D / is to / F H /, so is / B K / to / F M /
assert also, as / B K / is to / F M /, so is / K L / to / M N /
∵ magnitudes_proportional_proportionalassert alternately, as / B K / is to / K L /, so is / F M / to / M N /
assert The sides are proportional about = angles, namely < B K L ), < F M N )
∵ triangles_angle_equalassert < B K L > is similar to < F M N >
assert Since, as / B K / is to / K T /, so is / F M / to / M P /, and they are about = angles, namely < B K T ), < F M P ), inasmuch as, whatever part < B K T ) is of the four right angles at the center K, the same part also is < F M P ) of the four right angles at the center M; since then the sides are proportional about = angles,
∵ triangles_angle_equalassert < B K T > is similar to < F M P >
assert it was proved that, as / B K / is to / K L /, so is / F M / to / M N /, while / B K / = / K T /, and / F M / to / P M /,
assert as / T K / is to / K L /, so is / P M / to / M N /
assert the sides are proportional about = angles, namely < T K L ), < P M N ), for they are right
∵ triangles_angle_equalassert < L K T > is similar to < N M P >
assert Since, owing to the similarity of < L K B >, < N M F >, as / L B / is to / B K /, so is / N F / to / F M /, and, owing to the similarity of < B K T >, < F M P >, as / K B / is to / B T /, so is / M F / to / F P /,
∵ there_number_magnitudes_v_22assert :term:`ex aequali <G.174>`, as / L B / is to / B T /, so is / N F / to / F P /
assert Again since, owing to the similarity of < L T K >, < N P M >, as / L T / is to / T K /, so is / N P / to / P M /, and, owing to the similarity of < T K B >, < P M F >, as / K T / is to / T B /, so is / M P / to / P F /
∵ there_number_magnitudes_v_22assert ex aequali, as / L T / is to / T B /, so is / N P / to / P F /
assert It was also proved that, as / T B / is to / B L /, so is / P F / to / F N /
∵ there_number_magnitudes_v_22assert ex aequali, as / T L / is to / L B /, so is / P N / to / N F /
∵ triangles_sides_proportional, similar_polygons_angles_defassert in < L T B >, < N P F > the sides are proportional ; therefore < L T B >, < N P F > are equiangular ; hence they are also similar
∵ similar_solid_figures_defassert the pyramid of which < B K T > is the base and L the vertex is also similar to the pyramid of which < F M P > is the base and N the vertex, for they are contained by similar planes equal in multitude
∵ similar_pyramids_triangularassert Similar pyramids which have triangular bases are to one another in the triplicate ratio of their corresponding sides
assert the pyramid < B K T L > has to the pyramid < F M P N > the ratio triplicate of that which / B K / has to / F M /
assert Similarly, by joining segments from A, W, D, V, C, U to K, and from E, S, H, R, G, Q to M, and setting up on each of the triangles pyramids which have the same vertex with the cones, we can prove that each of the similarly arranged pyramids will also have to each similarly arranged pyramid the ratio triplicate of that which the corresponding side / B K / has to the corresponding side / F M /, that is, which / B D / has to / F H /
∵ number_magnitudes_proportionalassert as one of the antecedents is to one of the consequents, so are all the antecedents to all the consequents
assert also, as the pyramid < B K T L > is to the pyramid < F M P N >, so is the whole pyramid of which the polygon < A T B U C V D W > is the base and L the vertex to the whole pyramid of which the polygon < E P F Q G R H S > is the base and N the vertex ; hence also the pyramid of which < A T B U C V D W > is the base and L the vertex has to the pyramid of which the polygon < E P F Q G R H S > is the base and N the vertex the ratio triplicate of that which / B D / has to / F H /
assert But, by hypothesis, the cone of which ( A B C D )
assert Is the base and L the vertex has also to the solid O the ratio triplicate of that which / B D / has to / F H /
∵ magnitudes_proportional_proportionalassert as the cone of which ( A B C D ) is the base and L the vertex is to the solid O, so is the pyramid of which the polygon < A T B U C V D W > is the base and L the vertex to the pyramid of which the polygon < E P F Q G R H S > is the base and N the vertex ; therefore, alternately, as the cone of which ( A B C D ) is the base and L the vertex is to the pyramid contained in it of which the polygon < A T B U C V D W > is the base and L the vertex, so is the solid O to the pyramid of which the polygon < E P F Q G R H S > is the base and N the vertex
assert The said cone > the pyramid in it; for it encloses it
assert the solid O is also greater than the pyramid of which the polygon < E P F Q G R H S > is the base and N the vertex
assert It is also less :
assert ⇒⇐
assert the cone of which ( A B C D ) is the base and L the vertex has not to any solid less than the cone of which ( E F G H ) is the base and N the vertex the ratio triplicate of that which / B D / has to / F H /
assert Similarly we can prove that neither has the cone < E F G H N > to any solid less than the cone < A B C D L > the ratio triplicate of that which / F H / has to / B D /
assert I say next that neither has the cone < A B C D L > to any solid greater than the cone < E F G H N > the ratio triplicate of that which / B D / has to / F H /
assert If possible, let it have that ratio to a greater solid O
assert inversely, the solid O has to the cone < A B C D L > the ratio triplicate of that which / F H / has to / B D /
assert But, as the solid O is to the cone < A B C D L >, so is the cone < E F G H N > to some solid less than the cone < A B C D L >
assert the cone < E F G H N > also has to some solid less than the cone < A B C D L > the ratio triplicate of that which / F H / has to / B D /: which was proved impossible
assert the cone < A B C D L > has not to any solid greater than the cone < E F G H N > the ratio triplicate of that which / B D / has to / F H /
assert It was proved that neither has it this ratio to a less solid than the cone < E F G H N >
assert the cone < A B C D L > has to the cone < E F G H N > the ratio triplicate of that which / B D / has to / F H /
∵ cone_part_cylinderassert But, as the cone is to the cone, so is the cylinder to the cylinder, for the cylinder which is on the same base as the cone and of equal height with it is triple of the cone
∴ the cylinder also has to the cylinder the ratio triplicate of that which / B D / has to / F H /
