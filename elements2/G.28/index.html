G.28¶

I.17

In any triangle, the sum of any two angles is less than two right angles.
two_angles_less_than_two_right(< A B C >)
given < A B C > be a triangle
prove two angles of < A B C > taken together in any manner are less than two right angles
given < A B C > be a triangle
construct extend(/ B C /) → D
assert Since < A C D ) is an exterior angle of < A B C > → it is greater than the interior and opposite angle < A B C ).
construct Let < A C B ) be added to each;
assert Therefore < A C D ), < A C B ) are greater than < A B C ), < B C A ).
∵ adjacent_angles_supplementaryassert < A C D ), < A C B ) are equal to two right angles.
assert Therefore < A B C ), < B C A ) are less than two right angles.
conclude Similarly we can prove that < B A C ), < A C B ) are also less than two right angles, and so are < C A B ), < A B C ) as well.
