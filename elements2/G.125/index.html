G.125¶

IV.7

Circumscribe about a given circle a square.
circumscribe_circle_square(( A B C D ))
given ( A B C D )
construct about the given circle a square has been circumscribed
given ( A B C D )
construct Let two diameters / A C /, / B D / of ( A B C D ) be drawn at right angles to one another
construct straight_line_drawn: Through A, B, C, D let / F G /, / G H /, / H K /, / K F / be drawn touching ( A B C D ).
∵ straight_line_touchassert Since / F G / touches ( A B C D ), and / E A / has been joined from the center E to the point of contact at A → therefore the angles at A are right.
assert The same reason
assert The angles at B, C, D are also right.
∵ corresponding_angles_parallelassert Since < A E B ) is right, and < E B G ) is also right → therefore / G H / is parallel to / A C /.
assert The same reason
assert / A C / is also parallel to / F K /,
∵ parallel_transitiveassert So that / G H / is also parallel to / F K /.
assert Similarly we can prove that
assert Each of / G F /, / H K / is parallel to / B E D /.
assert Therefore < F G H K >, < G H C A >, < A C K F >, < F G B D >, < B H K D > are parallelograms
∵ parallelogram_propertiesassert Therefore / G F / is equal to / H K /, and / G H / to / F K /.
assert And, since / A C / is equal to / B D /, and / A C / is also equal to each of / G H /, / F K /,
∵ parallelogram_propertiesassert While / B D / is equal to each of / G F /, / H K /,
assert Therefore the quadrilateral < F G H K > is equilateral.
assert I say next that it is also right-angled.
∵ parallelogram_propertiesassert Since < G B E A > is a parallelogram, and < A E B ) is right, therefore < A G B ) is also right.
assert Similarly we can prove that
assert The angles at < G H K ), < H K F ), < K F G ) are also right.
assert Therefore < F G H K > is right-angled.
assert It was also proved equilateral
assert Therefore it is a square;
assert And it has been circumscribed about ( A B C D ).
conclude Therefore about the given circle a square has been circumscribed.
