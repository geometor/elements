XI.24

If a solid be contained by parallel planes, the opposite planes in it are equal and parallelogrammic.
assert For let the solid < C D H G > be contained by the parallel planes < A C >, < G F >, < A H >, < D F >, < B F >, < A E >
assert Since the two parallel planes < B G >, < C E > are cut by the plane < A C >,
[G.460]assert Their common sections are parallel.
assert Therefore / A B / is parallel to / D C /.
assert Since the two parallel planes < B F >, < A E > are cut by the plane < A C >,
[G.460]assert Their common sections are parallel.
assert Therefore / B C / is parallel to / A D /.
assert / A B / was also proved parallel to / D C /;
assert Therefore < A C > is a parallelogram.
assert Similarly we can prove that each of the planes < D F >, < F G >, < G B >, < B F >, < A E > is a parallelogram.
construct segment / A H /, / D F /
assert Since / A B / is parallel to / D C /, and / B H / to / C F /, / A B /, / B H / which meet one another are parallel to / D C /, / C F / which meet one another, not in the same plane;
[G.453]assert Therefore they will contain equal angles; therefore < A B H ) is equal to < D C F ).
[G.47]assert And, since the two sides / A B /, / B H / are equal to the two sides / D C /, / C F /, and < A B H ) is equal to < D C F ).
[G.11]assert Therefore the base / A H / is equal to the base / D F /, and < A B H > is equal to < D C F >.
[G.47]assert The parallelogram < B G > is double of < A B H >, and the parallelogram < C E > double of < D C F >.
assert Therefore the parallelogram < B G > is equal to the parallelogram < C E >.
conclude Similarly we can prove that < A C > is also equal to < G F >, and < A E > to < B F >.
