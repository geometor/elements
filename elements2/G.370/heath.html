G.370 — Heath¶

X.54

If an area be contained by a rational straight line and the first binomial, the “side” of the area is the irrational straight line which is called binomial.

For let the area < A C > be contained by the rational straight line / A B / and the first binomial / A D /; I say that the “side” of the area < A C > is the irrational straight line which is called binomial.

For, since / A D / is a first binomial straight line, let it be divided into its terms at E, and let / A E / be the greater term.

It is then manifest that / A E /, / E D / are rational straight lines commensurable in square only, the square on / A E / is greater than the square on / E D / by the square on a straight line commensurable with / A E /, and / A E / is commensurable in length with the rational straight line / A B / set out. [G.369]

Let / E D / be bisected at the point F.

Then, since the square on / A E / is greater than the square on / E D / by the square on a straight line commensurable with / A E /,
therefore, if there be applied to the greater / A E / a parallelogram equal to the fourth part of the square on the less, that is, to the square on / E F /, and deficient by a square figure, it divides it into commensurable parts. [G.330]

Let then the rectangle / A G /, / G E / equal to the square on / E F / be applied to / A E /;

therefore / A G / is commensurable in length with / G E /.

Let / G H /, / E K /, / F L / be drawn from G, E, F parallel to either of the straight lines / A B /, / D C /; let the square < S N > be constructed equal to the parallelogram < A H >, and the square < N Q > equal to < G K >, [G.75] and let them be placed so that / M N / is in a straight line with / N O /;

therefore / R N / is also in a straight line with / N P /.

And let the parallelogram < S Q > be completed;

[Lemma]therefore < S Q > is a square.
Now, since the rectangle / A G /, / G E / is equal to the square on / E F /,
[G.180]therefore, as / A G / is to / E F /, so is / E F / to / G E /;
[G.163]therefore also, as < A H > is to < E L >, so is < E L > to < G K >;
therefore < E L > is a mean proportional between < A H >, < G K >.
But < A H > is equal to < S N >, and < G K > to < N Q >;
therefore < E L > is a mean proportional between < S N >, < N Q >.
But < M R > is also a mean proportional between the same < S N >, < N Q >; [Lemma]
therefore < E L > is equal to < M R >,
so that it is also equal to < P O >.
But < A H >, < G K > are also equal to < S N >, < N Q >;
therefore the whole < A C > is equal to the whole < S Q >, that is, to the square on / M O /;
therefore / M O / is the “side” of < A C >.

I say next that / M O / is binomial.

For, since / A G / is commensurable with / G E /,
therefore / A E / is also commensurable with each of the straight lines / A G /, / G E /. [G.328]
But / A E / is also, by hypothesis, commensurable with / A B /;
[G.325]therefore / A G /, / G E / are also commensurable with / A B /.
And / A B / is rational;
therefore each of the straight lines / A G /, / G E / is also rational;
therefore each of the rectangles < A H >, < G K > is rational, [G.333] and < A H > is commensurable with < G K >.
But < A H > is equal to < S N >, and < G K > to < N Q >;
therefore < S N >, < N Q >, that is, the squares on / M N /, / N O /, are rational and commensurable.
And, since / A E / is incommensurable in length with / E D /, while / A E / is commensurable with / A G /, and / E D / is commensurable with / E F /,
[G.326]therefore / A G / is also incommensurable with / E F /,
[G.163, G.323]so that < A H > is also incommensurable with < E L >.
But < A H > is equal to < S N >, and < E L > to < M R >;
therefore < S N > is also incommensurable with < M R >.
[G.163]But, as < S N > is to < M R >, so is / N P / to / R N /;
[G.323]therefore / N P / is incommensurable with / R N /.
But / N P / is equal to / M N /, and / R N / to / N O /;
therefore / M N / is incommensurable with / N O /.
And the square on / M N / is commensurable with the square on / N O /, and each is rational;
therefore / M N /, / N O / are rational straight lines commensurable in square only.
Therefore / M O / is binomial [G.351] and the “side” of < A C >. Q. E. D.
