G.312¶

IX.36

If as many numbers as we please beginning from an unit be set out continuously in double proportion, until the sum of all becomes prime, and if the sum multiplied into the last make some number, the product is perfect.
assert For let as many numbers as we please, A, B, C, D, beginning from an unit be set out in double proportion, until the sum of all becomes prime, let E be equal to the sum
assert Let E by multiplying D make / F G /
construct However many A, B, C, D are in multitude, let so many E, / H K /, L, M be taken in double proportion beginning from E
[G.214]assert Therefore, ex aequali, as A is to D, so is E to M.
[G.219]assert Therefore the product of E, D is equal to the product of A, M.
assert The product of E, D is / F G / ;
assert Therefore the product of A, M is also / F G /.
assert Therefore A by multiplying M has made / F G / ; therefore M measures / F G / according to the units in A.
assert A is a dyad ;
assert Therefore / F G / is double of M.
assert M, L, / H K /, E are continuously double of each other ;
assert Therefore E, / H K /, L, M, / F G / are continuously proportional in double proportion.
assert Now let there be subtracted from the second / H K / and the last / F G / the numbers / H N /, / F O /, each equal to the first E
[G.310]assert Therefore, as the excess of the second is to the first, so is the excess of the last to all those before it.
assert Therefore, as / K N / is to E, so is / G O / to M, L, / H K /, E.
assert / K N / is equal to E ;
assert Therefore / G O / is also equal to M, L, / H K /, E.
assert / F O / is also equal to E, and E is equal to A, B, C, D and the unit.
assert Therefore the whole / F G / is equal to E, / H K /, L, M and A, B, C, D and the unit ; and it is measured by them.
assert I say also that / F G / will not be measured by any other number except A, B, C, D, E, / H K /, L, M and the unit.
assert If possible, let some number P measure / F G /
assert Let P not be the same with any of the numbers A, B, C, D, E, / H K /, L, M.
assert And, as many times as P measures / F G /, so many units let there be in Q ;
assert Therefore Q by multiplying P has made / F G /.
assert But, further, E has also by multiplying D made / F G / ;
[G.219]assert Therefore, as E is to Q, so is P to D.
assert And, since A, B, C, D are continuously proportional beginning from an unit,
[G.284]assert Therefore D will not be measured by any other number except A, B, C.
assert And, by hypothesis, P is not the same with any of the numbers A, B, C ;
assert Therefore P will not measure D.
assert But, as P is to D, so is E to Q ;
[G.210]assert Therefore neither does E measure Q.
[G.230]assert E is prime ; and any prime number is prime to any number which it does not measure.
assert Therefore E, Q are prime to one another.
[G.221, G.220]assert Primes are also least, and the least numbers measure those which have the same ratio the same number of times, the antecedent the antecedent and the consequent the consequent ; and, as E is to Q, so is P to D .
assert Therefore E measures P the same number of times that Q measures D.
assert D is not measured by any other number except A, B, C ;
assert Therefore Q is the same with one of the numbers A, B, C.
assert Let it be the same with B.
construct And, however many B, C, D are in multitude, let so many E, / H K /, L be taken beginning from E.
assert Now E, / H K /, L are in the same ratio with B, C, D ;
[G.214]assert Therefore, ex aequali, as B is to D, so is E to L.
[G.219]assert Therefore the product of B, L is equal to the product of D, E.
assert The product of D, E is equal to the product of Q, P ;
assert Therefore the product of Q, P is also equal to the product of B, L.
[G.219]assert Therefore, as Q is to B, so is L to P.
assert Q is the same with B ;
assert Therefore L is also the same with P :
assert Which is impossible, for by hypothesis P is not the same with any of the numbers set out.
assert Therefore no number will measure / F G / except A, B, C, D, E, / H K /, L, M and the unit.
[G.311]assert / F G / was proved equal to A, B, C, D, E, / H K /, L, M and the unit ; and a perfect number is that which is equal to its own parts .
conclude Therefore / F G / is perfect.
