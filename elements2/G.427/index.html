G.427¶

X.100

The square on a minor straight line applied to a rational straight line produces as breadth a fourth apotome.
given / A B / be a minor and / C D / a rational straight line, to the rational straight line / C D / let < C F E D > be applied equal to the square on / A B / and producing / C F / as breadth
assert For let / B G / be the annex to / A B /;
[G.397]assert Therefore / A G /, / B G / are straight lines incommensurable in square which make the sum of the squares on / A G /, / B G / rational, but twice the rectangle / A G /, / B G / medial.
construct To / C D / let there be applied < C K H D > equal to the square on / A G / and producing / C K / as breadth, and < K M L H > equal to the square on / B G /, producing / K M / as breadth
assert Therefore the whole < C M L D > is equal to the squares on / A G /, / B G /.
assert The sum of the squares on / A G /, / B G / is rational;
assert Therefore < C M L D > is also rational.
assert It is applied to the rational straight line / C D /, producing / C M / as breadth;
[G.334]assert Therefore / C M / is also rational and commensurable in length with / C D /.
assert And, since the whole < C M L D > is equal to the squares on / A G /, / B G /, and, in these, < C F E D > is equal to the square on / A B /,
[G.68]assert Therefore the remainder < F M L E > is equal to twice the rectangle / A G /, / B G /.
assert Let then / F M / be bisected at N
construct Let / N O / be drawn through N parallel to either of / C D /, / M L /
assert Therefore each of the rectangles < F N O E >, < N M L O > is equal to the rectangle / A G /, / B G /.
assert And, since twice the rectangle / A G /, / B G / is medial and is equal to < F M L E >,
assert Therefore < F M L E > is also medial.
assert It is applied to the rational straight line / F E /, producing / F M / as breadth;
[G.336]assert Therefore / F M / is rational and incommensurable in length with / C D /.
assert And, since the sum of the squares on / A G /, / B G / is rational, while twice the rectangle / A G /, / B G / is medial,
assert The squares on / A G /, / B G / are incommensurable with twice the rectangle / A G /, / B G /.
assert < C M L D > is equal to the squares on / A G /, / B G /, and < F M L E > equal to twice the rectangle / A G /, / B G /;
assert Therefore < C M L D > is incommensurable with < F M L E >.
[G.163]assert But, as < C M L D > is to < F M L E >, so is / C M / to / F M /;
[G.323]assert Therefore / C M / is incommensurable in length with / F M /.
assert Both are rational;
[G.394]assert Therefore / C M /, / F M / are rational straight lines commensurable in square only; therefore / C F / is an apotome.
assert Since / A G /, / B G / are incommensurable in square,
assert Therefore the square on / A G / is also incommensurable with the square on / B G /.
assert < C K H D > is equal to the square on / A G /, and < K M L H > equal to the square on / B G /;
assert Therefore < C K H D > is incommensurable with < K M L H >.
[G.163]assert But, as < C K H D > is to < K M L H >, so is / C K / to / K M /;
[G.323]assert Therefore / C K / is incommensurable in length with / K M /.
assert And, since the rectangle / A G /, / B G / is a mean proportional between the squares on / A G /, / B G /, and the square on / A G / is equal to < C K H D >, the square on / B G / to < K M L H >, and the rectangle / A G /, / B G / to < N M L O >,
assert Therefore < N M L O > is a mean proportional between < C K H D >, < K M L H >; therefore, as < C K H D > is to < N M L O >, so is < N M L O > to < K M L H >.
[G.163]assert But, as < C K H D > is to < N M L O >, so is / C K / to / N M /, and, as < N M L O > is to < K M L H >, so is / N M / to / K M /.
[G.148, G.180]assert Therefore, as / C K / is to / N M /, so is / N M / to / K M /; therefore the rectangle / C K /, / K M / is equal to the square on / N M /, that is, to the fourth part of the square on / F M /.
assert Since then / C M /, / F M / are two unequal straight lines, and the rectangle / C K /, / K M / equal to the fourth part of the square on / F M / and deficient by a square figure has been applied to / C M / and divides it into incommensurable parts,
[G.331]assert Therefore the square on / C M / is greater than the square on / F M / by the square on a straight line incommensurable with / C M /.
assert The whole / C M / is commensurable in length with the rational straight line / C D / set out;
[G.412]conclude Therefore / C F / is a fourth apotome.
