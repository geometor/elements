G.124¶

IV.6

Inscribe in a given circle a square.
given ( A B C D )
construct Let two diameters / A C /, / B D / of ( A B C D ) be drawn at right angles to one another
construct segment / A B /, / B C /, / C D /, / D A /
[G.11]assert Since / B E / is equal to / E D /, for E is the center, and / E A / is common and at right angles, therefore the base / A B / is equal to the base / A D /.
assert For the same reason each of / B C /, / C D / is also equal to each of / A B /, / A D /
assert Therefore the quadrilateral < A B C D > is equilateral.
assert I say next that it is also right-angled.
assert Since / B D / is a diameter of ( A B C D ), therefore ( B A D ) is a semicircle
[G.110]assert Therefore < B A D ) is right.
assert For the same reason each of < A B C ), < B C D ), < C D A ) is also right
assert Therefore the quadrilateral < A B C D > is right-angled.
assert It was also proved equilateral
[G.123]assert Therefore it is a square
assert And it has been inscribed in ( A B C D ).
conclude Therefore in the given circle the square < A B C D > has been inscribed.
