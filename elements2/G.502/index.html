G.502 part segment plane¶

XI.1

A part of a segment cannot be in the plane of reference and a part in a plane more elevated.
part_segment_plane()
prove a part of a segment cannot be in the plane of reference, and a part in a plane more elevated
assert If possible, let a part / A B / of / A B C / be in the plane of reference, and a part / B C / in a plane more elevated.
assert There will then be in the plane of reference some segment continuous with / A B / in a segment.
assert Let it be / B D /
assert Therefore / A B / is a common segment of / A B C /, / A B D /:
assert Which is impossible, inasmuch as, if we describe a circle with center B and distance / A B /, the diameters will cut off unequal arcs of the circle.
conclude Therefore a part of a segment cannot be in the plane of reference, and a part in a plane more elevated.
