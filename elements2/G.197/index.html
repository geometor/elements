VI.32

If two triangles having two sides proportional to two sides be placed together at one angle so that their corresponding sides are also parallel, the remaining sides of the triangles is in a straight line.
triangles_sides_proportional_vi_32(< A B C >, < D C E >, / B A /, / A C /)
given < A B C >, < D C E > be two triangles having the two sides / B A /, / A C / proportional to the two sides / D C /, / D E /, so that, as / A B / is to / A C /, so is / D C / to / D E /, / A B / parallel to / D C /, / A C / to / D E /
prove / B C / is in a straight line with / C E /
given < A B C >, < D C E > be two triangles having the two sides / B A /, / A C / proportional to the two sides / D C /, / D E /, so that, as / A B / is to / A C /, so is / D C / to / D E /, / A B / parallel to / D C /, / A C / to / D E /
assert Since / A B / is parallel to / D C /, and / A C / has fallen upon them,
∵ parallel_transversal_anglesassert The alternate angles < B A C ), < A C D ) are equal to one another.
assert For the same reason
assert < C D E ) is also equal to < A C D );
assert So that < B A C ) is equal to < C D E ).
assert And, since < A B C >, < D C E > are two triangles having one angle, the angle at A, equal to one angle, the angle at D, and the sides about the equal angles proportional, so that, as / B A / is to / A C /, so is / C D / to / D E /,
∵ triangles_angle_equalassert Therefore < A B C > is equiangular with < D C E >.
assert Therefore < A B C ) is equal to < D C E ).
assert < A C D ) was also proved equal to < B A C );
assert Therefore the whole angle < A C E ) is equal to the two angles < A B C ), < B A C ).
construct Let < A C B ) be added to each;
assert Therefore < A C E ), < A C B ) are equal to < B A C ), < A C B ), < C B A ).
∵ triangle_angle_sumassert < B A C ), < A B C ), < A C B ) are equal to two right angles.
assert Therefore < A C E ), < A C B ) are also equal to two right angles.
assert Therefore with a straight line / A C /, and at C on it, / B C /, / C E / not lying on the same side make the adjacent angles < A C E ), < A C B ) equal to two right angles;
