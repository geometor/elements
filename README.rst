**Elements 2.0 • Constructive G-Index (G.1–G.601) of Euclid's Elements • semantic digital archive**

Mission
-------

``geometor/elements`` is part of the interconnected `GEOMETOR <https://geometor.com>`_ semantic digital archive. It codifies the axiomatic architecture of Euclid's *Elements* into a computable directed acyclic dependency graph—the G-Index (``G.1`` through ``G.601``)—paired with exact symbolic proofs and executable Python constructions. By decomposing classical demonstrations into atomic signatures, step-by-step constructive procedures, and interactive vector graphics, the archive transforms Euclidean geometry into an interconnected, computationally verifiable foundation across the GEOMETOR corpus.

Catalogs in This Archive
------------------------

- `Elements 2.0 (G-Index) <https://geometor.github.io/elements/elements2/>`_ — Computable constructive dependency DAG, formal pseudocode, and exact symbolic proofs across all 601 Euclidean definitions, postulates, common notions, and propositions.

Repository Contents
-------------------

- ``docsrc/`` — RST tracks and Book Codex sources compiled into the online catalog by `PHOTON publish <https://github.com/photon-platform/publish>`_.
- ``resources/`` — Enunciation registries, construction scripts, dependency manifests, and serialized graph data.
- ``src/geometor/elements/`` — Python graph-crawling, topological sequencing, and pseudocode generation engine.
