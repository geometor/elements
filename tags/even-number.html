G.302 even number

An:term:**even number** <even-number> is that which is divisible into two equal parts.

If there be as many numbers as we please in continued proportion, and the first do not measure the second, neither will any other measure any other.

G.351 many even numbers

If as many even numbers as we please be added together, the whole is even.
theorem proof number-theory book-ix segment even-number number

G.352 odd number

An:term:**odd number** <odd-number> is that which is not divisible into two equal parts, or that which differs by an:term:unit <G.247> from an:term:even number <G.302>.

G.363 even-times even number

Each of the numbers which are continually doubled beginning from a dyad is even-times even only.

G.365 even-times odd number

G.366 number half odd

If a number have its half odd, it is even-times odd only.

If a number neither be one of those which are continually doubled from a dyad, nor have its half odd, it is both even-times even and even-times odd.
