Posts tagged 'cube-number'

G.253

Between two cube numbers there are two mean proportional numbers, and the cube has to the cube the ratio triplicate of that which the side has to the side.
theorem proof number-theory proportions book-viii point ratio proportion mean-proportional number cube-number cube

G.256

If a cube number measure a cube number, the side will also measure the side; and, if the side measure the side, the cube will also measure the cube.
theorem proof number-theory proportions book-viii point number cube-number cube

G.258

If a cube number do not measure a cube number, neither will the side measure the side; and, if the side do not measure the side, neither will the cube measure the cube.
theorem proof number-theory proportions book-viii point number cube-number cube

G.267

If two numbers have to one another the ratio which a cube number has to a cube number, and the first be cube, the second is cube.
theorem proof number-theory proportions book-viii point ratio number cube-number cube

G.269

Similar solid numbers have to one another the ratio which a cube number has to a cube number.
theorem proof number-theory proportions book-viii point ratio similar number solid-number cube-number cube

G.272

If a cube number by multiplying itself make some number, the product is cube.
theorem proof number-theory book-ix point number cube-number cube

G.273

If a cube number by multiplying a cube number make some number, the product is cube.

G.274

If a cube number by multiplying any number make a cube number, the multiplied number is cube.

G.275

If a number by multiplying itself make a cube number, it will itself also be cube.
