Posts tagged 'parallelepiped'

G.470

If a parallelepipedal solid be cut by a plane which is parallel to the opposite planes, then, as the base is to the base, so will the solid be to the solid.
theorem proof solid-geometry book-xi segment quadrilateral polygon parallel plane parallelepiped equality

G.473

Describe on a given segment a parallelepipedal solid similar and similarly situated to a given parallelepipedal solid.
problem construction solid-geometry book-xi point segment angle polygon ex-aequali similar parallelepiped equality

G.475

If a parallelepipedal solid be cut by a plane through the diagonals of the opposite planes, the solid is bisected by the plane.
theorem proof solid-geometry book-xi segment triangle quadrilateral polygon bisect plane parallelepiped equality

G.476

Parallelepipedal solids which are on the same base and of the same height, and in which the extremities of the sides which stand up are on the same straight lines, are equal.
theorem proof solid-geometry book-xi segment triangle quadrilateral polygon parallelepiped equality

G.477

Parallelepipedal solids which are on the same base and of the same height, and in which the extremities of the sides which stand up are not on the same straight lines, are equal.
theorem proof solid-geometry book-xi point segment quadrilateral polygon parallelepiped equality

G.478

Parallelepipedal solids which are on equal bases and of the same height are equal.
theorem proof solid-geometry book-xi point segment angle quadrilateral polygon parallelepiped equality

G.479

Parallelepipedal solids which are of the same height are to one another as their bases.
theorem proof solid-geometry book-xi segment polygon parallelepiped equality

G.480

Similar parallelepipedal solids are to one another in the triplicate ratio of their corresponding sides.
theorem proof solid-geometry book-xi segment angle polygon ratio triplicate-ratio similar parallelepiped equality porism

G.481

In equal parallelepipedal solids the bases are reciprocally proportional to the heights; and those parallelepipedal solids in which the bases are reciprocally proportional to the heights are equal.
theorem proof solid-geometry book-xi point segment polygon proportion parallelepiped equality

G.483

If three straight lines be proportional, the parallelepipedal solid formed out of the three is equal to the parallelepipedal solid on the mean which is equilateral, but equiangular with the aforesaid solid.
theorem proof solid-geometry book-xi point segment angle polygon equilateral proportion parallelepiped equality

G.484

If four straight lines be proportional, the parallelepipedal solids on them which are similar and similarly described is proportional; and, if the parallelepipedal solids on them which are similar and similarly described be proportional, the straight lines will themselves also be proportional.
theorem proof solid-geometry book-xi segment polygon proportion similar parallelepiped
