G.352 odd number

An:term:**odd number** <odd-number> is that which is not divisible into two equal parts, or that which differs by an:term:unit <G.247> from an:term:even number <G.302>.
Pseudocode · Heath
definition number-theory book-vii odd-number unit even-number number

If as many odd numbers as we please be added together, and their multitude be even, the whole is even.

G.365 even-times odd number

An:term:**even-times odd number** <even-times-odd-number> is that which is:term:measured <G.253> by an:term:even number <G.302> according to an:term:odd number <G.352>.

definition number-theory book-vii even-times-odd-number part-aliquot even-number odd-number number
