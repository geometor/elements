Posts tagged 'continued-proportion'

G.241

If there be as many numbers as we please in continued proportion, and the extremes of them be prime to one another, the numbers are the least of those which have the same ratio with them.
theorem proof number-theory proportions book-viii point ex-aequali ratio proportion number prime continued-proportion reductio-ad-absurdum

G.242

Find numbers in continued proportion, as many as may be prescribed, and the least that are in a given ratio.
problem finding number-theory proportions book-viii point ratio proportion number continued-proportion porism

G.243

If as many numbers as we please in continued proportion be the least of those which have the same ratio with them, the extremes of them are prime to one another.
theorem proof number-theory proportions book-viii point ratio proportion number prime continued-proportion equality

G.244

Given as many ratios as we please in least numbers, to find numbers in continued proportion which are the least in the given ratios.
problem finding number-theory proportions book-viii point ratio proportion number continued-proportion reductio-ad-absurdum

G.246

If there be as many numbers as we please in continued proportion, and the first do not measure the second, neither will any other measure any other.
theorem proof number-theory proportions book-viii point ex-aequali proportion number continued-proportion reductio-ad-absurdum

G.247

If there be as many numbers as we please in continued proportion, and the first measure the last, it will measure the second also.
theorem proof number-theory proportions book-viii point proportion number continued-proportion

G.248

If between two numbers there fall numbers in continued proportion with them, then, however many numbers fall between them in continued proportion, so many will also fall in continued proportion between the numbers which have the same ratio with the original numbers.
theorem proof number-theory proportions book-viii point ex-aequali ratio proportion number continued-proportion

G.249

If two numbers be prime to one another, and numbers fall between them in continued proportion, then, however many numbers fall between them in continued proportion, so many will also fall between each of them and an unit in continued proportion.
theorem proof number-theory proportions book-viii point proportion unit number prime continued-proportion equality

G.250

If numbers fall between each of two numbers and an unit in continued proportion, however many numbers fall between each of them and an unit in continued proportion, so many also will fall between the numbers themselves in continued proportion.
theorem proof number-theory proportions book-viii point proportion unit number continued-proportion

G.254

If there be as many numbers as we please in continued proportion, and each by multiplying itself make some number, the products is proportional; and, if the original numbers by multiplying the products make certain numbers, the latter is proportional.
theorem proof number-theory proportions book-viii point ex-aequali proportion number continued-proportion

G.264

If three numbers be in continued proportion, and the first be square, the third is square.
theorem proof number-theory proportions book-viii point square proportion number continued-proportion

G.265

If four numbers be in continued proportion, and the first be cube, the fourth is cube.
theorem proof number-theory proportions book-viii point proportion number continued-proportion cube

G.278

If as many numbers as we please beginning from an unit be in continued proportion, the third from the unit is square, as will also those which successively leave out one; the fourth is cube, as will also all those which leave out two; and the seventh is at once cube and square, as will also those which leave out five.
theorem proof number-theory book-ix point square proportion unit number continued-proportion cube

G.279

If as many numbers as we please beginning from an unit be in continued proportion, and the number after the unit be square, all the rest is square. And, if the number after the unit be cube, all the rest is cube.
theorem proof number-theory book-ix point square proportion unit number continued-proportion cube

G.280

If as many numbers as we please beginning from an unit be in continued proportion, and the number after the unit be not square, neither will any other be square except the third from the unit and all those which leave out one. And, if the number after the unit be not cube, neither will any other be cube except the fourth from the unit and all those which leave out two.
theorem proof number-theory book-ix point square proportion unit number continued-proportion cube reductio-ad-absurdum

G.281

If as many numbers as we please beginning from an unit be in continued proportion, the less measures the greater according to some one of the numbers which have place among the proportional numbers.
theorem proof number-theory book-ix point proportion unit number continued-proportion porism

G.283

If as many numbers as we please beginning from an unit be in continued proportion, by however many prime numbers the last is measured, the next to the unit is measured by the same.
theorem proof number-theory book-ix point proportion unit number prime continued-proportion reductio-ad-absurdum

G.284

If as many numbers as we please beginning from an unit be in continued proportion, and the number after the unit be prime, the greatest will not be measured by any except those which have a place among the proportional numbers.
theorem proof number-theory book-ix point proportion unit number prime continued-proportion reductio-ad-absurdum

G.286

If three numbers in continued proportion be the least of those which have the same ratio with them, any two whatever added together is prime to the remaining number.
theorem proof number-theory book-ix point segment separando ratio proportion number prime continued-proportion

G.288

If there be as many numbers as we please in continued proportion, and the extremes of them be prime to one another, the last will not be to any other number as the first to the second.
theorem proof number-theory book-ix point proportion number prime continued-proportion reductio-ad-absurdum

G.310

If as many numbers as we please be in continued proportion, and there be subtracted from the second and the last numbers equal to the first, then, as the excess of the second is to the first, so will the excess of the last be to all those before it.
theorem proof number-theory book-ix point segment proportion number continued-proportion equality
