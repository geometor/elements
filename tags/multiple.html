G.170 multiple of a magnitude

The greater is a:term:**multiple** <multiple> of the less when it is:term:measured <part-aliquot> by the less.
definition proportions magnitudes book-v multiple part-aliquot

G.171 there number magnitudes

If there be any number of magnitudes whatever which are, respectively, equimultiples of any magnitudes equal in multitude, then, whatever multiple one of the magnitudes is of one, that multiple also will all be of all.
theorem proof proportions magnitudes book-v point segment multiple number equality

G.172 magnitude multiple fifth

If a first magnitude be the same multiple of a second that a third is of a fourth, and a fifth also be the same multiple of the second that a sixth is of the fourth, the sum of the first and fifth is the same multiple of the second that the sum of the third and sixth is of the fourth.
theorem proof proportions magnitudes book-v point segment multiple

G.175 magnitude multiple equimultiples

If a first magnitude be the same multiple of a second that a third is of a fourth, and if equimultiples be taken of the first and third, then also :term:`ex aequali <G.174>` the magnitudes taken is equimultiples respectively, the one of the second and the other of the fourth.
theorem proof proportions magnitudes book-v point segment multiple ex-aequali equality

G.176 magnitudes in the same ratio

Magnitudes are said to:term:**be in the same ratio** <in-the-same-ratio>, the first to the second and the third to the fourth, when, if any:term:equimultiples <multiple> whatever be taken of the first and third, and any equimultiples whatever of the second and fourth, the former equimultiples alike exceed, are alike equal to, or alike fall short of, the latter equimultiples respectively taken in corresponding order.
definition proportions magnitudes book-v in-the-same-ratio multiple ratio

G.177 magnitude ratio equimultiples

If a first magnitude have to a second the same ratio as a third to a fourth, any equimultiples whatever of the first and third will also have the same ratio to any equimultiples whatever of the second and fourth respectively, taken in corresponding order.
theorem proof proportions magnitudes book-v point in-the-same-ratio multiple ratio equality

G.178 magnitude multiple magnitude

If a magnitude be the same multiple of a magnitude that a part subtracted is of a part subtracted, the remainder is the same multiple of the remainder that the whole is of the whole.
theorem proof proportions magnitudes book-v segment multiple equality

G.179 magnitudes equimultiples magnitudes

If two magnitudes be equimultiples of two magnitudes, and any magnitudes subtracted from them be equimultiples of the same, the remainders also are either equal to the same or equimultiples of them.
theorem proof proportions magnitudes book-v point segment multiple equality

G.183 equal magnitudes ratio

Equal magnitudes have to the same the same ratio, as also has the same to equal magnitudes.
theorem proof proportions magnitudes book-v point in-the-same-ratio multiple proportional invertendo ratio equality porism

G.185 greater ratio

When, of the:term:equimultiples <multiple>, the multiple of the first magnitude exceeds the multiple of the second, but the multiple of the third does not exceed the multiple of the fourth, then the first is said to:term:**have a greater ratio** <greater-ratio> to the second than the third has to the fourth.
definition proportions magnitudes book-v multiple greater-ratio ratio

G.186 unequal magnitudes greater

Of unequal magnitudes, the greater has to the same a greater ratio than the less has; and the same has to the less a greater ratio than it has to the greater.
theorem proof proportions magnitudes book-v point segment greater-ratio ratio multiple equality

G.189 ratios ratio

Ratios which are the same with the same ratio are also the same with one another.
theorem proof proportions magnitudes book-v point ratio in-the-same-ratio multiple equality

G.190 number magnitudes proportional

If any number of magnitudes be proportional, as one of the antecedents is to one of the consequents, so will all the antecedents be to all the consequents.
theorem proof proportions magnitudes book-v point proportional corresponding-magnitudes multiple proportion number equality

G.191 magnitude ratio greater

If a first magnitude have to a second the same ratio as a third to a fourth, and the third have to the fourth a greater ratio than a fifth has to a sixth, the first will also have to the second a greater ratio than the fifth to the sixth.
theorem proof proportions magnitudes book-v point in-the-same-ratio greater-ratio multiple ratio equality

G.193 parts ratio multiples

Parts have the same ratio as the same multiples of them taken in corresponding order.
theorem proof proportions magnitudes book-v point segment in-the-same-ratio multiple corresponding-magnitudes ratio equality

G.195 magnitudes proportional proportional

If four magnitudes be proportional, they is proportional alternately.
theorem proof proportions magnitudes book-v point proportional alternando multiple in-the-same-ratio proportion equality

G.198 magnitudes proportional componendo

If magnitudes be proportional componendo, they is proportional separando.
theorem proof proportions magnitudes book-v segment proportional componendo separando multiple proportion equality

G.205 there number magnitudes

If there be any number of magnitudes whatever, and others equal to them in multitude, which taken two and two together are in the same ratio, they is in the same ratio ex aequali.
theorem proof proportions magnitudes book-v point in-the-same-ratio ex-aequali multiple ratio number equality

G.206 there magnitudes others

If there be three magnitudes, and others equal to them in multitude, which taken two and two together are in the same ratio, and the proportion of them be perturbed, they is in the same ratio ex aequali.
theorem proof proportions magnitudes book-v point in-the-same-ratio perturbed-proportion multiple alternando ex-aequali ratio proportion equality

G.210 triangles parallelograms height

Triangles and parallelograms which are under the same height are to one another as their bases.

G.246 equal circles angles

In equal circles angles have the same ratio as the arcs on which they stand, whether they stand at the centres or at the arcs.
theorem proof plane-geometry proportions similar-figures book-vi point segment circle angle equal-circles plane-angle in-the-same-ratio stand-upon-circumference centre multiple arc ratio plane equality

G.256 multiple of a number

G.257 number part number

If a number be a part of a number, and another be the same part of another, the sum is the same part of the sum that the one is of the one.
theorem proof number-theory book-vii point segment number part-aliquot multiple equality

G.263 proportional numbers

Numbers are:term:**proportional** <G.180> when the first is the:term:same multiple <G.256>, or the:term:same part <G.253>, or the:term:same parts <G.254>, of the second that the third is of the fourth.
definition number-theory book-vii proportional multiple part-aliquot parts-non-aliquot proportion number

G.371 unequal magnitudes set

Two unequal magnitudes being set out, if from the greater there be subtracted a magnitude greater than its half, and from that which is left a magnitude greater than its half, and if this process be repeated continually, there is left some magnitude which is less than the lesser magnitude set out.

G.531 parallelepipedal solid cut

If a parallelepipedal solid be cut by a plane which is parallel to the opposite planes, then, as the base is to the base, so will the solid be to the solid.
