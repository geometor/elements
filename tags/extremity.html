G.545 there equal plane

If there be two equal plane angles, and on their vertices there be set up elevated segments containing equal angles with the original segments respectively, if on the elevated segments points be taken at random and perpendiculars be drawn from them to the planes in which the original angles are, and if from the points so arising in the planes segments be joined to the vertices of the original angles, they will contain, with the elevated segments, equal angles.
