Posts tagged 'greater-ratio'

G.185 greater ratio

When, of the:term:equimultiples <multiple>, the multiple of the first magnitude exceeds the multiple of the second, but the multiple of the third does not exceed the multiple of the fourth, then the first is said to:term:**have a greater ratio** <greater-ratio> to the second than the third has to the fourth.
definition proportions magnitudes book-v multiple greater-ratio ratio

G.186 unequal magnitudes greater

Of unequal magnitudes, the greater has to the same a greater ratio than the less has; and the same has to the less a greater ratio than it has to the greater.
theorem proof proportions magnitudes book-v point segment greater-ratio ratio multiple equality

G.188 magnitudes ratio greater

Of magnitudes which have a ratio to the same, that which has a greater ratio is greater; and that to which the same has a greater ratio is less.
theorem proof proportions magnitudes book-v point have-a-ratio greater-ratio in-the-same-ratio ratio equality reductio-ad-absurdum

G.191 magnitude ratio greater

If a first magnitude have to a second the same ratio as a third to a fourth, and the third have to the fourth a greater ratio than a fifth has to a sixth, the first will also have to the second a greater ratio than the fifth to the sixth.
theorem proof proportions magnitudes book-v point in-the-same-ratio greater-ratio multiple ratio equality

G.192 magnitude ratio greater

If a first magnitude have to a second the same ratio as a third has to a fourth, and the first be greater than the third, the second is greater than the fourth; if equal, equal; and if less, less.
theorem proof proportions magnitudes book-v point in-the-same-ratio greater-ratio ratio equality

G.202 there magnitudes others

If there be three magnitudes, and others equal to them in multitude, which taken two and two are in the same ratio, and if :term:`ex aequali <G.174>` the first be greater than the third, the fourth is greater than the sixth; if equal, equal; and, if less, less.
theorem proof proportions magnitudes book-v point in-the-same-ratio ex-aequali greater-ratio invertendo have-a-ratio ratio equality

G.204 there magnitudes others

If there be three magnitudes, and others equal to them in multitude, which taken two and two together are in the same ratio, and the proportion of them be perturbed, then, if ex aequali the first magnitude is greater than the third, the fourth is greater than the sixth; if equal, equal; and if less, less.
