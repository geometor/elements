Posts tagged 'unit'

G.199

Numbers prime to one another are those which are measured by an unit alone as a common measure.
Category: definition number-theory Tags: book-vii prime-to-one-another unit number prime

G.200

Two unequal numbers being set out, and the less being continually subtracted in turn from the greater, if the number which is left never measures the one before it until an unit is left, the original numbers is prime to one another.
Category: theorem proof number-theory Tags: book-vii point segment unit number prime reductio-ad-absurdum

G.215

If an unit measure any number, and another number measure any other number the same number of times, alternately also, the unit will measure the third number the same number of times that the second measures the fourth.
Category: theorem proof number-theory Tags: book-vii point segment unit number equality

G.222

A number is said to:term:**multiply** <multiply> a number when that which is multiplied is added to itself as many times as there are units in the other, and thus some number is produced.
Category: definition number-theory Tags: book-vii multiply unit number

G.249

If two numbers be prime to one another, and numbers fall between them in continued proportion, then, however many numbers fall between them in continued proportion, so many will also fall between each of them and an unit in continued proportion.
Category: theorem proof number-theory proportions Tags: book-viii point proportion unit number prime continued-proportion equality

G.250

If numbers fall between each of two numbers and an unit in continued proportion, however many numbers fall between each of them and an unit in continued proportion, so many also will fall between the numbers themselves in continued proportion.
Category: theorem proof number-theory proportions Tags: book-viii point proportion unit number continued-proportion

G.278

If as many numbers as we please beginning from an unit be in continued proportion, the third from the unit is square, as will also those which successively leave out one; the fourth is cube, as will also all those which leave out two; and the seventh is at once cube and square, as will also those which leave out five.
Category: theorem proof number-theory Tags: book-ix point square proportion unit number continued-proportion cube

G.279

If as many numbers as we please beginning from an unit be in continued proportion, and the number after the unit be square, all the rest is square. And, if the number after the unit be cube, all the rest is cube.
Category: theorem proof number-theory Tags: book-ix point square proportion unit number continued-proportion cube

G.280

If as many numbers as we please beginning from an unit be in continued proportion, and the number after the unit be not square, neither will any other be square except the third from the unit and all those which leave out one. And, if the number after the unit be not cube, neither will any other be cube except the fourth from the unit and all those which leave out two.
Category: theorem proof number-theory Tags: book-ix point square proportion unit number continued-proportion cube reductio-ad-absurdum

G.281

If as many numbers as we please beginning from an unit be in continued proportion, the less measures the greater according to some one of the numbers which have place among the proportional numbers.
Category: theorem proof number-theory Tags: book-ix point proportion unit number continued-proportion porism

G.283

If as many numbers as we please beginning from an unit be in continued proportion, by however many prime numbers the last is measured, the next to the unit is measured by the same.
Category: theorem proof number-theory Tags: book-ix point proportion unit number prime continued-proportion reductio-ad-absurdum

G.284

If as many numbers as we please beginning from an unit be in continued proportion, and the number after the unit be prime, the greatest will not be measured by any except those which have a place among the proportional numbers.
Category: theorem proof number-theory Tags: book-ix point proportion unit number prime continued-proportion reductio-ad-absurdum

G.294

An:term:**odd number** <odd-number> is that which is not divisible into two equal parts, or that which differs by an unit from an even number.
Category: definition number-theory Tags: book-vii odd-number unit number even-number

G.312

If as many numbers as we please beginning from an unit be set out continuously in double proportion, until the sum of all becomes prime, and if the sum multiplied into the last make some number, the product is perfect.
Category: theorem proof number-theory Tags: book-ix point segment ex-aequali proportion unit number prime equality reductio-ad-absurdum
