G.269 multiplication of numbers

A:term:number <G.248> is said to:term:**multiply** <multiply> a number when that which is multiplied is added to itself as many times as there are:term:units <G.247> in the other, and thus some number is produced.
definition number-theory book-vii number multiply unit

G.270 numbers multiplying make

If two numbers by multiplying one another make certain numbers, the numbers so produced are equal.
theorem proof number-theory book-vii point number multiply part-aliquot unit alternando equality

G.271 number multiplying numbers

If a number by multiplying two numbers make certain numbers, the numbers so produced will have the same ratio as the numbers multiplied.
theorem proof number-theory book-vii point number multiply in-the-same-ratio part-aliquot unit alternando ratio

G.272 numbers multiplying number

If two numbers by multiplying any number make certain numbers, the numbers so produced will have the same ratio as the multipliers.
theorem proof number-theory book-vii point number multiply in-the-same-ratio ratio

G.273 numbers proportional number

If four numbers be proportional, the number produced from the first and fourth will equals the number produced from the second and third; and, if the number produced from the first and fourth equals that produced from the second and third, the four numbers is proportional.
theorem proof number-theory book-vii point number proportional multiply in-the-same-ratio proportion equality

G.281 numbers prime multiplying

G.300 plane and solid numbers

And, when two:term:numbers <G.248> having:term:multiplied <G.269> one another make some number, the number so produced is called:term:**plane** <plane-number>, and its:term:**sides** <side-of-number> are the numbers which have multiplied one another.

G.311 square number

G.337 many numbers please

If as many numbers as we please beginning from an unit be in continued proportion, the third from the unit is square, as will also those which successively leave out one; the fourth is cube, as will also all those which leave out two; and the seventh is at once cube and square, as will also those which leave out five.
