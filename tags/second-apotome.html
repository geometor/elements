G.456 second apotome

G.457 medial segment there

If from a medial segment there be subtracted a medial segment which is commensurable with the whole in square only, and which contains with the whole a medial rectangle, the remainder is irrational; and let it be called a second apotome of a medial segment.

G.463 apotome medial segment

To a second apotome of a medial segment only one medial segment can be annexed which is commensurable with the whole in square only and which contains with the whole a medial rectangle.
