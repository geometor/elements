G.312 cube numbers there

Between two cube numbers there are two mean proportional numbers, and the cube has to the cube the ratio triplicate of that which the side has to the side.

G.315 cube number measure

If a cube number measure a cube number, the side will also measure the side; and, if the side measure the side, the cube will also measure the cube.

G.317 cube number measure

If a cube number do not measure a cube number, neither will the side measure the side; and, if the side do not measure the side, neither will the cube measure the cube.

G.325 numbers continued proportion

G.335 number multiplying itself

G.337 many numbers please

If as many numbers as we please beginning from an unit be in continued proportion, the third from the unit is square, as will also those which successively leave out one; the fourth is cube, as will also all those which leave out two; and the seventh is at once cube and square, as will also those which leave out five.
theorem proof number-theory book-ix point number unit proportional square part-aliquot multiply proportion continued-proportion cube

G.338 many numbers please

If as many numbers as we please beginning from an unit be in continued proportion, and the number after the unit be square, all the rest is square. And, if the number after the unit be cube, all the rest is cube.
theorem proof number-theory book-ix point number unit proportional square part-aliquot multiply cube-number proportion continued-proportion cube

G.339 many numbers please

If as many numbers as we please beginning from an unit be in continued proportion, and the number after the unit be not square, neither will any other be square except the third from the unit and all those which leave out one. And, if the number after the unit be not cube, neither will any other be cube except the fourth from the unit and all those which leave out two.
theorem proof number-theory book-ix point number unit proportional square ratio square-number similar-plane-and-solid-numbers part-aliquot multiply cube-number proportion continued-proportion cube reductio-ad-absurdum
