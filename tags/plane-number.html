G.271

If two numbers by multiplying one another make a square number, they are similar plane numbers.
Category: theorem proof number-theory Tags: book-ix point square similar number plane-number square-number plane

G.270

If two similar plane numbers by multiplying one another make some number, the product is square.
Category: theorem proof number-theory Tags: book-ix point square similar number plane-number plane

G.268

Similar plane numbers have to one another the ratio which a square number has to a square number.
Category: theorem proof number-theory proportions Tags: book-viii point square ratio similar number plane-number square-number plane

G.262

If one mean proportional number fall between two numbers, the numbers is similar plane numbers.
Category: theorem proof number-theory proportions Tags: book-viii point proportion mean-proportional similar number plane-number plane

G.260

Between two similar plane numbers there is one mean proportional number; and the plane number has to the plane number the ratio duplicate of that which the corresponding side has to the corresponding side.
Category: theorem proof number-theory proportions Tags: book-viii point ratio proportion mean-proportional similar number plane-number plane

G.245

Plane numbers have to one another the ratio compounded of the ratios of their sides.
