G.300 plane and solid numbers

And, when two:term:numbers <G.248> having:term:multiplied <G.269> one another make some number, the number so produced is called:term:**plane** <plane-number>, and its:term:**sides** <side-of-number> are the numbers which have multiplied one another.
definition number-theory book-vii number multiply plane-number side-of-number plane

G.301 plane numbers ratio

Plane numbers have to one another the ratio compounded of the ratios of their sides.
theorem proof number-theory proportions book-viii point plane-number ratio number multiply ex-aequali plane

G.319 similar plane numbers

Between two similar plane numbers there is one mean proportional number; and the plane number has to the plane number the ratio duplicate of that which the corresponding side has to the corresponding side.
theorem proof number-theory proportions book-viii point similar-plane-and-solid-numbers proportional number plane-number ratio alternando plane-surface multiply proportion similar plane

G.322 mean proportional number

If one mean proportional number fall between two numbers, the numbers is similar plane numbers.
theorem proof number-theory proportions book-viii point proportional number similar-plane-and-solid-numbers in-the-same-ratio part-aliquot unit multiply plane-surface plane-number alternando proportion similar plane

G.328 similar plane numbers

Similar plane numbers have to one another the ratio which a square number has to a square number.
theorem proof number-theory proportions book-viii point similar-plane-and-solid-numbers ratio square-number proportional number in-the-same-ratio square similar plane-number plane

G.330 similar plane numbers

If two similar plane numbers by multiplying one another make some number, the product is square.
theorem proof number-theory book-ix point similar-plane-and-solid-numbers multiply number square proportional in-the-same-ratio similar plane-number plane

G.331 numbers multiplying make

If two numbers by multiplying one another make a square number, they are similar plane numbers.
theorem proof number-theory book-ix point number multiply square-number similar-plane-and-solid-numbers square proportional similar plane-number plane
