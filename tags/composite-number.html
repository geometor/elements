G.286 composite number

A:term:**composite number** <composite-number> is that which is:term:measured <G.253> by some:term:number <G.248>.
Pseudocode · Heath
definition number-theory book-vii composite-number part-aliquot number composite

G.287 composite number measured

Any composite number is measured by some prime number.
Pseudocode · Code · Heath
theorem proof number-theory book-vii point composite-number part-aliquot prime-number number prime composite reductio-ad-absurdum

G.288 number prime measured

Any number either is prime or is measured by some prime number.
Pseudocode · Code · Heath
theorem proof number-theory book-vii point number prime-number part-aliquot composite-number prime

G.336 composite number multiplying

If a composite number by multiplying any number make some number, the product is solid.
Pseudocode · Code · Heath
theorem proof number-theory book-ix point composite-number multiply number part-aliquot unit composite

G.343 many numbers please

If as many numbers as we please beginning from an unit be in continued proportion, and the number after the unit be prime, the greatest will not be measured by any except those which have a place among the proportional numbers.
Pseudocode · Code · Heath
theorem proof number-theory book-ix point number unit proportional prime-number part-aliquot composite-number multiply square proportion prime continued-proportion reductio-ad-absurdum
