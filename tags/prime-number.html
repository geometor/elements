G.283 prime number

A:term:**prime number** <prime-number> is that which is:term:measured <G.253> by an:term:unit <G.247> alone.
definition number-theory book-vii prime-number part-aliquot unit number prime

G.284 prime number prime

Any prime number is prime to any number which it does not measure.

G.285 numbers multiplying make

If two numbers by multiplying one another make some number, and any prime number measure the product, it will also measure one of the original numbers.
theorem proof number-theory book-vii point number multiply prime-number part-aliquot prime-to-one-another unit in-the-same-ratio corresponding-magnitudes prime

G.287 composite number measured

Any composite number is measured by some prime number.

G.288 number prime measured

Any number either is prime or is measured by some prime number.

G.296 there many numbers

If there be as many numbers as we please in continued proportion, and the extremes of them be prime to one another, the numbers are the least of those which have the same ratio with them.

G.305 numbers there fall

If between two numbers there fall numbers in continued proportion with them, then, however many numbers fall between them in continued proportion, so many will also fall in continued proportion between the numbers which have the same ratio with the original numbers.

G.323 mean proportional numbers

If two mean proportional numbers fall between two numbers, the numbers are similar solid numbers.

G.342 many numbers please

If as many numbers as we please beginning from an unit be in continued proportion, by however many prime numbers the last is measured, the next to the unit is measured by the same.
theorem proof number-theory book-ix point number unit proportional prime-number part-aliquot prime-to-one-another multiply in-the-same-ratio corresponding-magnitudes square composite-to-one-another proportion prime continued-proportion reductio-ad-absurdum

G.343 many numbers please

If as many numbers as we please beginning from an unit be in continued proportion, and the number after the unit be prime, the greatest will not be measured by any except those which have a place among the proportional numbers.
theorem proof number-theory book-ix point number unit proportional prime-number part-aliquot composite-number multiply square proportion prime continued-proportion reductio-ad-absurdum

G.344 number least measured

If a number be the least that is measured by prime numbers, it will not be measured by any other prime number except those originally measuring it.
theorem proof number-theory book-ix point number part-aliquot prime-number multiply prime reductio-ad-absurdum

G.346 numbers prime number

If two numbers be prime to one another, the second will not be to any other number as the first is to the second.
