G.333 — Heath
=============

.. rubric:: `X.19 <https://geometor.github.io/euclid/heath/volume_III/book_x/propositions/019/>`_

.. enunciation::

   The rectangle contained by rational straight lines commensurable in length is rational.

For let the rectangle :g:`< A C > <g1:< A C >>` be contained by the rational straight lines :g:`/ A B / <g1:/ A B />`, :g:`/ B C / <g1:/ B C />` commensurable in length; I say that :g:`< A C > <g1:< A C >>` is rational.

.. picture:: g1.svg
   :alt: Proposition 19

For on :g:`/ A B / <g1:/ A B />` let the square :g:`< A D > <g1:< A D >>` be described;

.. assertion:: [G.332] <G.332>

   therefore :g:`< A D > <g1:< A D >>` is rational.

.. subclause::

   And, since :g:`/ A B / <g1:/ A B />` is commensurable in length with :g:`/ B C / <g1:/ B C />`, while :g:`/ A B / <g1:/ A B />` is :eq:`equal <g1:/ A B / = g1:/ B D />` to :g:`/ B D / <g1:/ B D />`,

.. assertion::

   therefore :g:`/ B D / <g1:/ B D />` is commensurable in length with :g:`/ B C / <g1:/ B C />`.

.. subclause:: [G.163] <G.163>

   And, as :g:`/ B D / <g1:/ B D />` is to :g:`/ B C / <g1:/ B C />`, so is :g:`< D A > <g1:< D A >>` to :g:`< A C > <g1:< A C >>`.

.. assertion:: [G.323] <G.323>

   Therefore :g:`< D A > <g1:< D A >>` is commensurable with :g:`< A C > <g1:< A C >>`.

.. subclause::

   But :g:`< D A > <g1:< D A >>` is rational;

.. assertion:: [G.332] <G.332>

   therefore :g:`< A C > <g1:< A C >>` is also rational.

.. qed::

   Therefore etc.
