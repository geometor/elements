G.29
====

.. rubric:: `I.18 <https://geometor.github.io/euclid/heath/volume_I/book_i/propositions/18/>`_

.. enunciation::

   In any triangle the greater side subtends the greater angle.

.. picture:: 0297.g1.svg
   :alt: Proposition 18 figure

For let :g:`< A B C > <0297.g1:< A B C >>` be a triangle having the side :g:`/ A C / <0297.g1:/ A C />` greater than :g:`/ A B / <0297.g1:/ A B />`;

I say that the angle :g:`< A B C ) <0297.g1:< A B C )>` is also greater than the angle :g:`< B C A ) <0297.g1:< B C A )>`.

For, since :g:`/ A C / <0297.g1:/ A C />` is greater than :g:`/ A B / <0297.g1:/ A B />`, let :g:`/ A D / <0297.g1:/ A D />` be made :eq:`equal <0297.g1:/ A D / = 0297.g1:/ A B />` to :g:`/ A B / <0297.g1:/ A B />` :just:`[G.9] <G.9>`, and let :g:`/ B D / <0297.g1:/ B D />` be joined.

Then, since the angle :g:`< A D B ) <0297.g1:< A D B )>` is an exterior angle of the triangle :g:`< B C D > <0297.g1:< B C D >>`,

.. assertion:: [G.27] <G.27>

   it is greater than the interior and opposite angle :g:`< D C B ) <0297.g1:< D C B )>`.

But the angle :g:`< A D B ) <0297.g1:< A D B )>` is :eq:`equal <0297.g1:< A D B ) = 0297.g1:< A B D )>` to the angle :g:`< A B D ) <0297.g1:< A B D )>`,

.. subclause::

   since the side :g:`/ A B / <0297.g1:/ A B />` is :eq:`equal <0297.g1:/ A B / = 0297.g1:/ A D />` to :g:`/ A D / <0297.g1:/ A D />`;

.. assertion::

   therefore the angle :g:`< A B D ) <0297.g1:< A B D )>` is also greater than the angle :g:`< A C B ) <0297.g1:< A C B )>`;

.. assertion::

   therefore the angle :g:`< A B C ) <0297.g1:< A B C )>` is much greater than the angle :g:`< A C B ) <0297.g1:< A C B )>`.

.. qed::

   Therefore etc. :just:`Q. E. D.`
