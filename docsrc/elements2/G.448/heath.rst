G.448 segment commensurable major — Heath
=========================================

.. rubric:: `X.68 <https://geometor.github.io/euclid/heath/volume_III/book_x/propositions/068/>`_

.. enunciation::

   A :term:`straight line <G.4>` :term:`commensurable <G.372>` with a major straight line is itself also major.

Let :g:`/ A B / <g1:/ A B />` be major, and let :g:`/ C D / <g1:/ C D />` be commensurable with :g:`/ A B / <g1:/ A B />`; I say that :g:`/ C D / <g1:/ C D />` is major.

Let :g:`/ A B / <g1:/ A B />` be divided at :g:`E <g1:E>`;

.. assertion::

   therefore :g:`/ A E / <g1:/ A E />`, :g:`/ E B / <g1:/ E B />` are straight lines :term:`incommensurable in square <G.380>` which make the sum of the :term:`squares <G.63>` on them :term:`rational <G.392>`, but the :term:`rectangle contained <G.81>` by them medial. :just:`[G.413] <G.413>`

.. picture:: g1.svg
   :alt: Proposition 68

Let the same construction be made as before.

.. subclause::

   Then since, as :g:`/ A B / <g1:/ A B />` is to :g:`/ C D / <g1:/ C D />`, so is :g:`/ A E / <g1:/ A E />` to :g:`/ C F / <g1:/ C F />`, and :g:`/ E B / <g1:/ E B />` to :g:`/ F D / <g1:/ F D />`,

.. assertion:: [G.189] <G.189>

   therefore also, as :g:`/ A E / <g1:/ A E />` is to :g:`/ C F / <g1:/ C F />`, so is :g:`/ E B / <g1:/ E B />` to :g:`/ F D / <g1:/ F D />`.

.. subclause::

   But :g:`/ A B / <g1:/ A B />` is commensurable with :g:`/ C D / <g1:/ C D />`;

.. assertion::

   therefore :g:`/ A E / <g1:/ A E />`, :g:`/ E B / <g1:/ E B />` are also commensurable with :g:`/ C F / <g1:/ C F />`, :g:`/ F D / <g1:/ F D />` respectively. :just:`[G.382] <G.382>`

.. subclause::

   And since, as :g:`/ A E / <g1:/ A E />` is to :g:`/ C F / <g1:/ C F />`, so is :g:`/ E B / <g1:/ E B />` to :g:`/ F D / <g1:/ F D />`, :term:`alternately <G.194>` also, as :g:`/ A E / <g1:/ A E />` is to :g:`/ E B / <g1:/ E B />`, so is :g:`/ C F / <g1:/ C F />` to :g:`/ F D / <g1:/ F D />`; :just:`[G.195] <G.195>`

.. assertion::

   therefore also, :term:`*componendo* <G.196>`, as :g:`/ A B / <g1:/ A B />` is to :g:`/ B E / <g1:/ B E />`, so is :g:`/ C D / <g1:/ C D />` to :g:`/ D F / <g1:/ D F />`; :just:`[G.199] <G.199>` therefore also, as the square on :g:`/ A B / <g1:/ A B />` is to the square on :g:`/ B E / <g1:/ B E />`, so is the square on :g:`/ C D / <g1:/ C D />` to the square on :g:`/ D F / <g1:/ D F />`. :just:`[G.232] <G.232>`

.. assertion::

   Similarly we can prove that, as the square on :g:`/ A B / <g1:/ A B />` is to the square on :g:`/ A E / <g1:/ A E />`, so also is the square on :g:`/ C D / <g1:/ C D />` to the square on :g:`/ C F / <g1:/ C F />`.

.. assertion::

   Therefore also, as the square on :g:`/ A B / <g1:/ A B />` is to the squares on :g:`/ A E / <g1:/ A E />`, :g:`/ E B / <g1:/ E B />`, so is the square on :g:`/ C D / <g1:/ C D />` to the squares on :g:`/ C F / <g1:/ C F />`, :g:`/ F D / <g1:/ F D />`; therefore also, alternately, as the square on :g:`/ A B / <g1:/ A B />` is to the square on :g:`/ C D / <g1:/ C D />`, so are the squares on :g:`/ A E / <g1:/ A E />`, :g:`/ E B / <g1:/ E B />` to the squares on :g:`/ C F / <g1:/ C F />`, :g:`/ F D / <g1:/ F D />`. :just:`[G.195] <G.195>`

.. subclause::

   But the square on :g:`/ A B / <g1:/ A B />` is commensurable with the square on :g:`/ C D / <g1:/ C D />`;

.. assertion::

   therefore the squares on :g:`/ A E / <g1:/ A E />`, :g:`/ E B / <g1:/ E B />` are also commensurable with the squares on :g:`/ C F / <g1:/ C F />`, :g:`/ F D / <g1:/ F D />`.

.. subclause::

   And the squares on :g:`/ A E / <g1:/ A E />`, :g:`/ E B / <g1:/ E B />` together are rational;

.. assertion::

   therefore the squares on :g:`/ C F / <g1:/ C F />`, :g:`/ F D / <g1:/ F D />` together are rational.

.. assertion::

   Similarly also twice the rectangle :g:`/ A E / <g1:/ A E />`, :g:`/ E B / <g1:/ E B />` is commensurable with twice the rectangle :g:`/ C F / <g1:/ C F />`, :g:`/ F D / <g1:/ F D />`.

.. subclause::

   And twice the rectangle :g:`/ A E / <g1:/ A E />`, :g:`/ E B / <g1:/ E B />` is medial;

.. assertion:: [G.397] <G.397>

   therefore twice the rectangle :g:`/ C F / <g1:/ C F />`, :g:`/ F D / <g1:/ F D />` is also medial.

.. assertion::

   Therefore :g:`/ C F / <g1:/ C F />`, :g:`/ F D / <g1:/ F D />` are straight lines incommensurable in square which make, at the same time, the sum of the squares on them rational, but the rectangle contained by them medial; therefore the whole :g:`/ C D / <g1:/ C D />` is the irrational straight line called major. :just:`[G.413] <G.413>`

.. qed::

   Therefore a straight line commensurable with the major straight line is major. :just:`Q. E. D.`
