G.528 construct a solid angle out of three plane — Heath
========================================================

.. rubric:: `XI.23 <https://geometor.github.io/euclid/heath/volume_III/book_xi/propositions/23/>`_

.. enunciation::

   To construct a :term:`solid angle <G.524>` out of three :term:`plane angles <G.22>` two of which, taken together in any manner, are greater than the remaining one: thus the three angles must be less than four :term:`right angles <G.32>`.

Let the angles :g:`< A B C ) <g1:< A B C )>`, :g:`< D E F ) <g1:< D E F )>`, :g:`< G H K ) <g1:< G H K )>` be the three given plane angles, and let two of these, taken together in any manner, be greater than the remaining one, while, further, the three are less than four right angles;

thus it is required to construct a solid angle out of angles equal to the angles :g:`< A B C ) <g1:< A B C )>`, :g:`< D E F ) <g1:< D E F )>`, :g:`< G H K ) <g1:< G H K )>`.

.. picture:: g1.svg
   :alt: Proposition 23, Figure 1

Let :g:`/ A B / <g1:/ A B />`, :g:`/ B C / <g1:/ B C />`, :g:`/ D E / <g1:/ D E />`, :g:`/ E F / <g1:/ E F />`, :g:`/ G H / <g1:/ G H />`, :g:`/ H K / <g1:/ H K />` be cut off :eq:`equal <g1:/ A B / = g1:/ B C / = g1:/ D E / = g1:/ E F / = g1:/ G H / = g1:/ H K />` to one another, and let :g:`/ A C / <g1:/ A C />`, :g:`/ D F / <g1:/ D F />`, :g:`/ G K / <g1:/ G K />` be joined; it is therefore possible to construct a :term:`triangle <G.11>` out of :term:`straight lines <G.4>` equal to :g:`/ A C / <g1:/ A C />`, :g:`/ D F / <g1:/ D F />`, :g:`/ G K / <g1:/ G K />`. :just:`[G.527] <G.527>`

Let :g:`< L M N > <g2:< L M N >>` be so constructed that :g:`/ A C / <g1:/ A C />` is :eq:`equal <g1:/ A C / = g2:/ L M /; g1:/ D F / = g2:/ M N /; g1:/ G K / = g2:/ N L />` to :g:`/ L M / <g2:/ L M />`, :g:`/ D F / <g1:/ D F />` to :g:`/ M N / <g2:/ M N />`, and further :g:`/ G K / <g1:/ G K />` to :g:`/ N L / <g2:/ N L />`, let the :term:`circle <G.10>` :g:`( L M N ) <g2:( L M N )>` be described about the triangle :g:`< L M N > <g2:< L M N >>`, let its :term:`centre <G.14>` be taken, and let it be :g:`O <g2:O>`; let :g:`/ L O / <g2:/ L O />`, :g:`/ M O / <g2:/ M O />`, :g:`/ N O / <g2:/ N O />` be joined;

I say that :g:`/ A B / <g1:/ A B />` is greater than :g:`/ L O / <g2:/ L O />`.

.. picture:: g2.svg
   :alt: Proposition 23, Figure 2

.. subclause::

   For, if not, :g:`/ A B / <g1:/ A B />` is either :eq:`equal <g1:/ A B / = g2:/ L O />` to :g:`/ L O / <g2:/ L O />`, or less.

.. subclause::

   First, let it be :eq:`equal <g1:/ A B / = g2:/ L O />`.

.. subclause::

   Then, since :g:`/ A B / <g1:/ A B />` is :eq:`equal <g1:/ A B / = g2:/ L O />` to :g:`/ L O / <g2:/ L O />`, while :g:`/ A B / <g1:/ A B />` is :eq:`equal <g1:/ A B / = g1:/ B C /; g2:/ O L / = g2:/ O M />` to :g:`/ B C / <g1:/ B C />`, and :g:`/ O L / <g2:/ O L />` to :g:`/ O M / <g2:/ O M />`, the two sides :g:`/ A B / <g1:/ A B />`, :g:`/ B C / <g1:/ B C />` are :eq:`equal <g1:/ A B / = g2:/ L O /; g1:/ B C / = g2:/ O M />` to the two sides :g:`/ L O / <g2:/ L O />`, :g:`/ O M / <g2:/ O M />` respectively; and, by hypothesis, the base :g:`/ A C / <g1:/ A C />` is :eq:`equal <g1:/ A C / = g2:/ L M />` to the base :g:`/ L M / <g2:/ L M />`;

.. assertion:: [G.28] <G.28>

   therefore the angle :g:`< A B C ) <g1:< A B C )>` is :eq:`equal <g1:< A B C ) = g2:< L O M )>` to the angle :g:`< L O M ) <g2:< L O M )>`.

.. assertion::

   For the same reason the angle :g:`< D E F ) <g1:< D E F )>` is also :eq:`equal <g1:< D E F ) = g2:< M O N ); g1:< G H K ) = g2:< N O L )>` to the angle :g:`< M O N ) <g2:< M O N )>`, and further the angle :g:`< G H K ) <g1:< G H K )>` to the angle :g:`< N O L ) <g2:< N O L )>`;

.. assertion::

   therefore the three angles :g:`< A B C ) <g1:< A B C )>`, :g:`< D E F ) <g1:< D E F )>`, :g:`< G H K ) <g1:< G H K )>` are :eq:`equal <g1:< A B C ) = g2:< L O M ); g1:< D E F ) = g2:< M O N ); g1:< G H K ) = g2:< N O L )>` to the three angles :g:`< L O M ) <g2:< L O M )>`, :g:`< M O N ) <g2:< M O N )>`, :g:`< N O L ) <g2:< N O L )>`.

.. subclause::

   But the three angles :g:`< L O M ) <g2:< L O M )>`, :g:`< M O N ) <g2:< M O N )>`, :g:`< N O L ) <g2:< N O L )>` are equal to four right angles;

.. assertion::

   therefore the angles :g:`< A B C ) <g1:< A B C )>`, :g:`< D E F ) <g1:< D E F )>`, :g:`< G H K ) <g1:< G H K )>` are equal to four right angles.

.. assertion::

   But they are also, by hypothesis, less than four right angles: which is absurd.

.. assertion::

   Therefore :g:`/ A B / <g1:/ A B />` is not equal to :g:`/ L O / <g2:/ L O />`.

I say next that neither is :g:`/ A B / <g1:/ A B />` less than :g:`/ L O / <g2:/ L O />`.

For, if possible, let it be so, and let :g:`/ O P / <g2:/ O P />` be made :eq:`equal <g2:/ O P / = g1:/ A B />` to :g:`/ A B / <g1:/ A B />`, and :g:`/ O Q / <g2:/ O Q />` :eq:`equal <g2:/ O Q / = g1:/ B C />` to :g:`/ B C / <g1:/ B C />`, and let :g:`/ P Q / <g2:/ P Q />` be joined.

.. subclause::

   Then, since :g:`/ A B / <g1:/ A B />` is :eq:`equal <g1:/ A B / = g1:/ B C />` to :g:`/ B C / <g1:/ B C />`, :g:`/ O P / <g2:/ O P />` is also :eq:`equal <g2:/ O P / = g2:/ O Q />` to :g:`/ O Q / <g2:/ O Q />`, so that the remainder :g:`/ L P / <g2:/ L P />` is :eq:`equal <g2:/ L P / = g2:/ Q M />` to :g:`/ Q M / <g2:/ Q M />`.

.. assertion::

   Therefore :g:`/ L M / <g2:/ L M />` is :term:`parallel <G.52>` to :g:`/ P Q / <g2:/ P Q />`, :just:`[G.211] <G.211>` and :g:`< L M O > <g2:< L M O >>` is equiangular with :g:`< P Q O > <g2:< P Q O >>`; :just:`[G.56] <G.56>` therefore, as :g:`/ O L / <g2:/ O L />` is to :g:`/ L M / <g2:/ L M />`, so is :g:`/ O P / <g2:/ O P />` to :g:`/ P Q / <g2:/ P Q />`; :just:`[G.213] <G.213>` and :term:`alternately <G.194>`, as :g:`/ L O / <g2:/ L O />` is to :g:`/ O P / <g2:/ O P />`, so is :g:`/ L M / <g2:/ L M />` to :g:`/ P Q / <g2:/ P Q />`. :just:`[G.195] <G.195>`

.. subclause::

   But :g:`/ L O / <g2:/ L O />` is greater than :g:`/ O P / <g2:/ O P />`;

.. assertion::

   therefore :g:`/ L M / <g2:/ L M />` is also greater than :g:`/ P Q / <g2:/ P Q />`.

.. subclause::

   But :g:`/ L M / <g2:/ L M />` was made :eq:`equal <g2:/ L M / = g1:/ A C />` to :g:`/ A C / <g1:/ A C />`;

.. assertion::

   therefore :g:`/ A C / <g1:/ A C />` is also greater than :g:`/ P Q / <g2:/ P Q />`.

.. subclause::

   Since, then, the two sides :g:`/ A B / <g1:/ A B />`, :g:`/ B C / <g1:/ B C />` are :eq:`equal <g1:/ A B / = g2:/ P O /; g1:/ B C / = g2:/ O Q />` to the two sides :g:`/ P O / <g2:/ P O />`, :g:`/ O Q / <g2:/ O Q />`, and the base :g:`/ A C / <g1:/ A C />` is greater than the base :g:`/ P Q / <g2:/ P Q />`,

.. assertion:: [G.50] <G.50>

   therefore the angle :g:`< A B C ) <g1:< A B C )>` is greater than the angle :g:`< P O Q ) <g2:< P O Q )>`.

.. assertion::

   Similarly we can prove that the angle :g:`< D E F ) <g1:< D E F )>` is also greater than the angle :g:`< M O N ) <g2:< M O N )>`, and the angle :g:`< G H K ) <g1:< G H K )>` greater than the angle :g:`< N O L ) <g2:< N O L )>`.

.. assertion::

   Therefore the three angles :g:`< A B C ) <g1:< A B C )>`, :g:`< D E F ) <g1:< D E F )>`, :g:`< G H K ) <g1:< G H K )>` are greater than the three angles :g:`< L O M ) <g2:< L O M )>`, :g:`< M O N ) <g2:< M O N )>`, :g:`< N O L ) <g2:< N O L )>`.

.. subclause::

   But, by hypothesis, the angles :g:`< A B C ) <g1:< A B C )>`, :g:`< D E F ) <g1:< D E F )>`, :g:`< G H K ) <g1:< G H K )>` are less than four right angles;

.. assertion::

   therefore the angles :g:`< L O M ) <g2:< L O M )>`, :g:`< M O N ) <g2:< M O N )>`, :g:`< N O L ) <g2:< N O L )>` are much less than four right angles.

.. subclause::

   But they are also equal to four right angles:

.. assertion::

   which is absurd. Therefore :g:`/ A B / <g1:/ A B />` is not less than :g:`/ L O / <g2:/ L O />`.

.. subclause::

   And it was proved that neither is it equal;

.. assertion::

   therefore :g:`/ A B / <g1:/ A B />` is greater than :g:`/ L O / <g2:/ L O />`.

Let then :g:`/ O R / <g2:/ O R />` be set up from the :term:`point <G.1>` :g:`O <g2:O>` :term:`at right angles to the plane <G.505>` of the circle :g:`( L M N ) <g2:( L M N )>`, :just:`[G.514] <G.514>` and let the :term:`square <G.63>` on :g:`/ O R / <g2:/ O R />` be equal to that area by which the square on :g:`/ A B / <g1:/ A B />` is greater than the square on :g:`/ L O / <g2:/ L O />`; :just:`[Lemma]` let :g:`/ R L / <g2:/ R L />`, :g:`/ R M / <g2:/ R M />`, :g:`/ R N / <g2:/ R N />` be joined.

.. subclause::

   Then, since :g:`/ R O / <g2:/ R O />` is at right angles to the plane of the circle :g:`( L M N ) <g2:( L M N )>`,

.. assertion::

   therefore :g:`/ R O / <g2:/ R O />` is also at right angles to each of the straight lines :g:`/ L O / <g2:/ L O />`, :g:`/ M O / <g2:/ M O />`, :g:`/ N O / <g2:/ N O />`.

.. subclause::

   And, since :g:`/ L O / <g2:/ L O />` is :eq:`equal <g2:/ L O / = g2:/ O M />` to :g:`/ O M / <g2:/ O M />`, while :g:`/ O R / <g2:/ O R />` is common and at right angles,

.. assertion:: [G.24] <G.24>

   therefore the base :g:`/ R L / <g2:/ R L />` is :eq:`equal <g2:/ R L / = g2:/ R M />` to the base :g:`/ R M / <g2:/ R M />`.

.. subclause::

   For the same reason :g:`/ R N / <g2:/ R N />` is also :eq:`equal <g2:/ R N / = g2:/ R L / = g2:/ R M />` to each of the straight lines :g:`/ R L / <g2:/ R L />`, :g:`/ R M / <g2:/ R M />`;

.. assertion::

   therefore the three straight lines :g:`/ R L / <g2:/ R L />`, :g:`/ R M / <g2:/ R M />`, :g:`/ R N / <g2:/ R N />` are :eq:`equal <g2:/ R L / = g2:/ R M / = g2:/ R N />` to one another.

.. subclause::

   Next, since by hypothesis the square on :g:`/ O R / <g2:/ O R />` is equal to that area by which the square on :g:`/ A B / <g1:/ A B />` is greater than the square on :g:`/ L O / <g2:/ L O />`,

.. assertion::

   therefore the square on :g:`/ A B / <g1:/ A B />` is equal to the squares on :g:`/ L O / <g2:/ L O />`, :g:`/ O R / <g2:/ O R />`.

.. subclause::

   But the square on :g:`/ L R / <g2:/ L R />` is equal to the squares on :g:`/ L O / <g2:/ L O />`, :g:`/ O R / <g2:/ O R />`, for the angle :g:`< L O R ) <g2:< L O R )>` is right; :just:`[G.79] <G.79>`

.. assertion::

   therefore the square on :g:`/ A B / <g1:/ A B />` is :eq:`equal <g1:/ A B / = g2:/ R L />` to the square on :g:`/ R L / <g2:/ R L />`; therefore :g:`/ A B / <g1:/ A B />` is :eq:`equal <g1:/ A B / = g2:/ R L />` to :g:`/ R L / <g2:/ R L />`.

.. subclause::

   But each of the straight lines :g:`/ B C / <g1:/ B C />`, :g:`/ D E / <g1:/ D E />`, :g:`/ E F / <g1:/ E F />`, :g:`/ G H / <g1:/ G H />`, :g:`/ H K / <g1:/ H K />` is :eq:`equal <g1:/ B C / = g1:/ D E / = g1:/ E F / = g1:/ G H / = g1:/ H K / = g1:/ A B />` to :g:`/ A B / <g1:/ A B />`, while each of the straight lines :g:`/ R M / <g2:/ R M />`, :g:`/ R N / <g2:/ R N />` is :eq:`equal <g2:/ R M / = g2:/ R N / = g2:/ R L />` to :g:`/ R L / <g2:/ R L />`;

.. assertion::

   therefore each of the straight lines :g:`/ A B / <g1:/ A B />`, :g:`/ B C / <g1:/ B C />`, :g:`/ D E / <g1:/ D E />`, :g:`/ E F / <g1:/ E F />`, :g:`/ G H / <g1:/ G H />`, :g:`/ H K / <g1:/ H K />` is :eq:`equal <g1:/ A B / = g1:/ B C / = g1:/ D E / = g1:/ E F / = g1:/ G H / = g1:/ H K / = g2:/ R L / = g2:/ R M / = g2:/ R N />` to each of the straight lines :g:`/ R L / <g2:/ R L />`, :g:`/ R M / <g2:/ R M />`, :g:`/ R N / <g2:/ R N />`.

.. subclause::

   And, since the two sides :g:`/ L R / <g2:/ L R />`, :g:`/ R M / <g2:/ R M />` are :eq:`equal <g2:/ L R / = g1:/ A B /; g2:/ R M / = g1:/ B C />` to the two sides :g:`/ A B / <g1:/ A B />`, :g:`/ B C / <g1:/ B C />`, and the base :g:`/ L M / <g2:/ L M />` is by hypothesis :eq:`equal <g2:/ L M / = g1:/ A C />` to the base :g:`/ A C / <g1:/ A C />`,

.. assertion:: [G.28] <G.28>

   therefore the angle :g:`< L R M ) <g2:< L R M )>` is :eq:`equal <g2:< L R M ) = g1:< A B C )>` to the angle :g:`< A B C ) <g1:< A B C )>`.

.. subclause::

   For the same reason

.. assertion::

   the angle :g:`< M R N ) <g2:< M R N )>` is also :eq:`equal <g2:< M R N ) = g1:< D E F ); g2:< L R N ) = g1:< G H K )>` to the angle :g:`< D E F ) <g1:< D E F )>`, and the angle :g:`< L R N ) <g2:< L R N )>` to the angle :g:`< G H K ) <g1:< G H K )>`.

.. assertion::

   Therefore, out of the three plane angles :g:`< L R M ) <g2:< L R M )>`, :g:`< M R N ) <g2:< M R N )>`, :g:`< L R N ) <g2:< L R N )>`, which are :eq:`equal <g2:< L R M ) = g1:< A B C ); g2:< M R N ) = g1:< D E F ); g2:< L R N ) = g1:< G H K )>` to the three given angles :g:`< A B C ) <g1:< A B C )>`, :g:`< D E F ) <g1:< D E F )>`, :g:`< G H K ) <g1:< G H K )>`, the solid angle at :g:`R <g2:R>` has been constructed, which is contained by the angles :g:`< L R M ) <g2:< L R M )>`, :g:`< M R N ) <g2:< M R N )>`, :g:`< L R N ) <g2:< L R N )>`.

.. qed::

   :just:`Q. E. F.`

LEMMA.
~~~~~~

But how it is possible to take the square on :g:`/ O R / <g2:/ O R />` equal to that area by which the square on :g:`/ A B / <g3:/ A B />` is greater than the square on :g:`/ L O / <g2:/ L O />`, we can show as follows.

Let the straight lines :g:`/ A B / <g3:/ A B />`, :g:`/ L O / <g2:/ L O />` be set out, and let :g:`/ A B / <g3:/ A B />` be the greater; let the :term:`semicircle <G.96>` :g:`( A B C ) <g3:( A B C )>` be described on :g:`/ A B / <g3:/ A B />`, and into the semicircle :g:`( A B C ) <g3:( A B C )>` let :g:`/ A C / <g3:/ A C />` be fitted :eq:`equal <g3:/ A C / = g2:/ L O />` to the straight line :g:`/ L O / <g2:/ L O />`, not being greater than the :term:`diameter <G.61>` :g:`/ A B / <g3:/ A B />`; :just:`[G.147] <G.147>` let :g:`/ C B / <g3:/ C B />` be joined.

.. picture:: g3.svg
   :alt: Proposition 23, Lemma

.. subclause::

   Since then the angle :g:`< A C B ) <g3:< A C B )>` is an :term:`angle in the semicircle <G.138>` :g:`( A C B ) <g3:( A C B )>`,

.. assertion:: [G.139] <G.139>

   therefore the angle :g:`< A C B ) <g3:< A C B )>` is right.

.. assertion::

   Therefore the square on :g:`/ A B / <g3:/ A B />` is equal to the squares on :g:`/ A C / <g3:/ A C />`, :g:`/ C B / <g3:/ C B />`. :just:`[G.79] <G.79>`

.. assertion::

   Hence the square on :g:`/ A B / <g3:/ A B />` is greater than the square on :g:`/ A C / <g3:/ A C />` by the square on :g:`/ C B / <g3:/ C B />`.

.. subclause::

   But :g:`/ A C / <g3:/ A C />` is :eq:`equal <g3:/ A C / = g2:/ L O />` to :g:`/ L O / <g2:/ L O />`.

.. assertion::

   Therefore the square on :g:`/ A B / <g3:/ A B />` is greater than the square on :g:`/ L O / <g2:/ L O />` by the square on :g:`/ C B / <g3:/ C B />`.

.. assertion::

   If then we cut off :g:`/ O R / <g2:/ O R />` :eq:`equal <g2:/ O R / = g3:/ B C />` to :g:`/ B C / <g3:/ B C />`, the square on :g:`/ A B / <g3:/ A B />` will be greater than the square on :g:`/ L O / <g2:/ L O />` by the square on :g:`/ O R / <g2:/ O R />`.

.. qed::

   :just:`Q. E. F.`
