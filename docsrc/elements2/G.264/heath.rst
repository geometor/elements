G.264 whole whole number — Heath
================================

.. rubric:: `VII.11 <https://geometor.github.io/euclid/heath/volume_II/book_vii/propositions/11/>`_

.. enunciation::

   If, as whole is to whole, so is a :term:`number <G.248>` subtracted to a number subtracted, the remainder will also be to the remainder as whole to whole.

As the whole :g:`/ A B / <g1:/ A B />` is to the whole :g:`/ C D / <g1:/ C D />`, so let :g:`/ A E / <g1:/ A E />` subtracted be to :g:`/ C F / <g1:/ C F />` subtracted;

I say that the remainder :g:`/ E B / <g1:/ E B />` is also to the remainder :g:`/ F D / <g1:/ F D />` as the whole :g:`/ A B / <g1:/ A B />` to the whole :g:`/ C D / <g1:/ C D />`.

.. picture:: g1.svg
   :alt: Book VII, Proposition 11

.. subclause::

   Since, as :g:`/ A B / <g1:/ A B />` is to :g:`/ C D / <g1:/ C D />`, so is :g:`/ A E / <g1:/ A E />` to :g:`/ C F / <g1:/ C F />`,

.. assertion::

   whatever part or parts :g:`/ A B / <g1:/ A B />` is of :g:`/ C D / <g1:/ C D />`, the :term:`same part <G.253>` or the :term:`same parts <G.254>` is :g:`/ A E / <g1:/ A E />` of :g:`/ C F / <g1:/ C F />` also; :just:`[G.263] <G.263>`

.. assertion::

   Therefore also the remainder :g:`/ E B / <g1:/ E B />` is the same part or parts of :g:`/ F D / <g1:/ F D />` that :g:`/ A B / <g1:/ A B />` is of :g:`/ C D / <g1:/ C D />`. :just:`[G.259, G.260] <G.259, G.260>`

.. assertion:: [G.263] <G.263>

   Therefore, as :g:`/ E B / <g1:/ E B />` is to :g:`/ F D / <g1:/ F D />`, so is :g:`/ A B / <g1:/ A B />` to :g:`/ C D / <g1:/ C D />`.

.. qed::

   Therefore etc. :just:`Q. E. D.`
