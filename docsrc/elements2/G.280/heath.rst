G.280 — Heath
=============

.. rubric:: `IX.10 <https://geometor.github.io/euclid/heath/volume_II/book_ix/propositions/10/>`_

.. enunciation::

   If as many numbers as we please beginning from an unit be in continued proportion, and the number after the unit be not square, neither will any other be square except the third from the unit and all those which leave out one. And, if the number after the unit be not cube, neither will any other be cube except the fourth from the unit and all those which leave out two.

Let there be as many numbers as we please, :g:`A <g1:A>`, :g:`B <g1:B>`, :g:`C <g1:C>`, :g:`D <g1:D>`, :g:`E <g1:E>`, :g:`F <g1:F>`, beginning from an unit and in continued proportion, and let :g:`A <g1:A>`, the number after the unit, not be square ;

I say that neither will any other be square except the third from the unit <and those which leave out one>.

.. picture:: g1.svg
   :alt: Proposition 10 Diagram

.. subclause::

   For, if possible, let :g:`C <g1:C>` be square.

.. subclause:: [G.278] <G.278>

   But :g:`B <g1:B>` is also square ;

.. assertion::

   [therefore :g:`B <g1:B>`, :g:`C <g1:C>` have to one another the ratio which a square number has to a square number].

.. subclause::

   And, as :g:`B <g1:B>` is to :g:`C <g1:C>`, so is :g:`A <g1:A>` to :g:`B <g1:B>` ;

.. assertion::

   therefore :g:`A <g1:A>`, :g:`B <g1:B>` have to one another the ratio which a square number has to a square number ;

.. assertion:: [G.268] <G.268>

   [so that :g:`A <g1:A>`, :g:`B <g1:B>` are similar plane numbers].

.. subclause::

   And :g:`B <g1:B>` is square ;

.. assertion::

   therefore :g:`A <g1:A>` is also square : which is contrary to the hypothesis.

.. assertion::

   Therefore :g:`C <g1:C>` is not square.

.. assertion::

   Similarly we can prove that neither is any other of the numbers square except the third from the unit and those which leave out one.

Next, let :g:`A <g1:A>` not be cube ;

I say that neither will any other be cube except the fourth from the unit and those which leave out two.

.. subclause::

   For, if possible, let :g:`D <g1:D>` be cube.

.. subclause:: [G.278] <G.278>

   Now :g:`C <g1:C>` is also cube ; for it is fourth from the unit.

.. subclause::

   And, as :g:`C <g1:C>` is to :g:`D <g1:D>`, so is :g:`B <g1:B>` to :g:`C <g1:C>` ;

.. assertion::

   therefore :g:`B <g1:B>` also has to :g:`C <g1:C>` the ratio which a cube has to a cube.

.. subclause::

   And :g:`C <g1:C>` is cube ;

.. assertion:: [G.267] <G.267>

   therefore :g:`B <g1:B>` is also cube.

.. subclause::

   And since, as the unit is to :g:`A <g1:A>`, so is :g:`A <g1:A>` to :g:`B <g1:B>`, and the unit measures :g:`A <g1:A>` according to the units in it,

.. assertion::

   therefore :g:`A <g1:A>` also measures :g:`B <g1:B>` according to the units in itself ;

.. assertion::

   therefore :g:`A <g1:A>` by multiplying itself has made the cube number :g:`B <g1:B>`.

.. subclause::

   But, if a number by multiplying itself make a cube number, it is also itself cube. :just:`[G.275] <G.275>`

.. assertion::

   Therefore :g:`A <g1:A>` is also cube : which is contrary to the hypothesis.

.. assertion::

   Therefore :g:`D <g1:D>` is not cube.

.. assertion::

   Similarly we can prove that neither is any other of the numbers cube except the fourth from the unit and those which leave out two.

.. qed::

   :just:`Q. E. D.`
