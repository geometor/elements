G.201 whole whole part — Heath
==============================

.. rubric:: `V.19 <https://geometor.github.io/euclid/heath/volume_II/book_v/propositions/19/>`_

.. enunciation::

   If, as a whole is to a whole, so is a part subtracted to a part subtracted, the remainder will also be to the remainder as whole to whole.

For, as the whole :g:`/ A B / <g1:/ A B />` is to the whole :g:`/ C D / <g1:/ C D />`, so let the part :g:`/ A E / <g1:/ A E />` subtracted be to the part :g:`/ C F / <g1:/ C F />` subtracted ;

I say that the remainder :g:`/ E B / <g1:/ E B />` will also be to the remainder :g:`/ F D / <g1:/ F D />` as the whole :g:`/ A B / <g1:/ A B />` to the whole :g:`/ C D / <g1:/ C D />`.

.. picture:: g1.svg
   :alt: Proposition 19

For since, as :g:`/ A B / <g1:/ A B />` is to :g:`/ C D / <g1:/ C D />`, so is :g:`/ A E / <g1:/ A E />` to :g:`/ C F / <g1:/ C F />`,

.. assertion:: [G.195] <G.195>

   :term:`alternately <G.194>` also, as :g:`/ A B / <g1:/ A B />` is to :g:`/ A E / <g1:/ A E />`, so is :g:`/ C D / <g1:/ C D />` to :g:`/ C F / <g1:/ C F />`.

And, since the magnitudes are :term:`proportional <G.180>` :term:`*componendo* <G.196>`, they will also be proportional :term:`*separando* <G.197>`, :just:`[G.198] <G.198>`

that is, as :g:`/ E B / <g1:/ E B />` is to :g:`/ A E / <g1:/ A E />`, so is :g:`/ F D / <g1:/ F D />` to :g:`/ C F / <g1:/ C F />`, and, alternately,

.. assertion:: [G.195] <G.195>

   as :g:`/ E B / <g1:/ E B />` is to :g:`/ F D / <g1:/ F D />`, so is :g:`/ A E / <g1:/ A E />` to :g:`/ C F / <g1:/ C F />`.

But, as :g:`/ A E / <g1:/ A E />` is to :g:`/ C F / <g1:/ C F />`, so by hypothesis is the whole :g:`/ A B / <g1:/ A B />` to the whole :g:`/ C D / <g1:/ C D />`.

.. assertion::

   Therefore also the remainder :g:`/ E B / <g1:/ E B />` will be to the remainder :g:`/ F D / <g1:/ F D />` as the whole :g:`/ A B / <g1:/ A B />` is to the whole :g:`/ C D / <g1:/ C D />`. :just:`[G.189] <G.189>`

Therefore etc.

.. porism::

   From this it is manifest that, if magnitudes be proportional :term:`*componendo* <G.196>`, they will also be proportional :term:`*convertendo* <G.200>`.

.. qed::

   :just:`Q. E. D.`
