G.46
====

.. rubric:: `I.33 <https://geometor.github.io/euclid/heath/volume_I/book_i/propositions/33/>`_

.. enunciation::

   The straight lines joining equal and parallel straight lines (at the extremities which are) in the same directions (respectively)\ [#f1]_ are themselves also equal and parallel.

Let :g:`/ A B /; 0337.g1:/ A B / <0336.g1:/ A B /; 0337.g1:/ A B />`, :g:`/ C D /; 0337.g1:/ C D / <0336.g1:/ C D /; 0337.g1:/ C D />` be :eq:`equal <0337.g1:/ A B / = 0337.g1:/ C D />` and parallel, and let the straight lines :g:`/ A C /; 0337.g1:/ A C / <0336.g1:/ A C /; 0337.g1:/ A C />`, :g:`/ B D /; 0337.g1:/ B D / <0336.g1:/ B D /; 0337.g1:/ B D />` join them (at the extremities which are) in the same directions (respectively);

I say that :g:`/ A C / <0337.g1:/ A C />`, :g:`/ B D / <0337.g1:/ B D />` are also :eq:`equal <0337.g1:/ A C / = 0337.g1:/ B D />` and parallel.

Let :g:`/ B C / <0337.g1:/ B C />` be joined.

.. picture:: 0337.g1.svg
   :alt: Folio 0337 Figure 1 - Proposition 33

Then, since :g:`/ A B / <0337.g1:/ A B />` is parallel to :g:`/ C D / <0337.g1:/ C D />`, and :g:`/ B C / <0337.g1:/ B C />` has fallen upon them,

.. assertion:: [G.42] <G.42>

   the alternate angles :g:`< A B C ) <0337.g1:< A B C )>`, :g:`< B C D ) <0337.g1:< B C D )>` are :eq:`equal <0337.g1:< A B C ) = 0337.g1:< B C D )>` to one another.

And, since :g:`/ A B / <0337.g1:/ A B />` is :eq:`equal <0337.g1:/ A B / = 0337.g1:/ C D />` to :g:`/ C D / <0337.g1:/ C D />`, and :g:`/ B C / <0337.g1:/ B C />` is common, the two sides :g:`/ A B / <0337.g1:/ A B />`, :g:`/ B C / <0337.g1:/ B C />` are :eq:`equal <0337.g1:/ A B / = 0337.g1:/ D C /; 0337.g1:/ B C / = 0337.g1:/ C B />` to the two sides :g:`/ D C / <0337.g1:/ D C />`, :g:`/ C B / <0337.g1:/ C B />`;\ [#f2]_ and the angle :g:`< A B C ) <0337.g1:< A B C )>` is :eq:`equal <0337.g1:< A B C ) = 0337.g1:< B C D )>` to the angle :g:`< B C D ) <0337.g1:< B C D )>`;

.. subclause::

   therefore the base :g:`/ A C / <0337.g1:/ A C />` is :eq:`equal <0337.g1:/ A C / = 0337.g1:/ B D />` to the base :g:`/ B D / <0337.g1:/ B D />`,

.. subclause::

   and the triangle :g:`< A B C > <0337.g1:< A B C >>` is :eq:`equal <0337.g1:< A B C > = 0337.g1:< D C B >>` to the triangle :g:`< D C B > <0337.g1:< D C B >>`,

.. subclause::

   and the remaining angles will be :eq:`equal <0337.g1:< A C B ) = 0337.g1:< C B D ); 0337.g1:< B A C ) = 0337.g1:< C D B )>` to the remaining angles respectively, namely those which the :eq:`equal <0337.g1:/ A B / = 0337.g1:/ C D /; 0337.g1:/ B C / = 0337.g1:/ C B />` sides subtend; :just:`[G.11] <G.11>`

.. assertion::

   therefore the angle :g:`< A C B ) <0337.g1:< A C B )>` is :eq:`equal <0337.g1:< A C B ) = 0337.g1:< C B D )>` to the angle :g:`< C B D ) <0337.g1:< C B D )>`.

And, since the straight line :g:`/ B C / <0337.g1:/ B C />` falling on the two straight lines :g:`/ A C / <0337.g1:/ A C />`, :g:`/ B D / <0337.g1:/ B D />` has made the alternate angles :eq:`equal <0337.g1:< A C B ) = 0337.g1:< C B D )>` to one another,

.. assertion:: [G.39] <G.39>

   :g:`/ A C / <0337.g1:/ A C />` is parallel to :g:`/ B D / <0337.g1:/ B D />`.

.. assertion::

   And it was also proved :eq:`equal <0337.g1:/ A C / = 0337.g1:/ B D />` to it.

.. qed::

   Therefore etc. :just:`Q. E. D.`

.. [#f1] **joining...(at the extremities which are) in the same directions (respectively).** I have for clearness' sake inserted the words in brackets though they are not in the original Greek, which has “joining...in the same directions” or “on the same sides,” ἐπὶ τὰ αὐτὰ μέρη ἐπιζευγνύουσαι. The expression “towards the same parts,” though usage has sanctioned it, is perhaps not quite satisfactory.

.. [#f2] **DC, CB and DCB.** The Greek has “:g:`/ B C / <0337.g1:/ B C />`, :g:`/ C D / <0337.g1:/ C D />`” and “:g:`< B C D > <0337.g1:< B C D >>`” in these places respectively. :person:`Euclid <euclid>` is not always careful to write in corresponding order the letters denoting corresponding points in congruent figures. On the contrary, he evidently prefers the alphabetical order, and seems to disdain to alter it for the sake of beginners or others who might be confused by it. In the case of angles alteration is perhaps unnecessary; but in the case of triangles and pairs of corresponding sides I have ventured to alter the order to that which the mathematician of to-day expects.
