G.168 inscribe a regular pentadecagon in a circle — Heath
=========================================================

.. rubric:: `IV.16 <https://geometor.github.io/euclid/heath/volume_II/book_iv/propositions/16/>`_

.. enunciation::

   In a given :term:`circle <G.10>` to inscribe a fifteen-angled :term:`figure <G.9>` which shall be both :term:`equilateral <G.13>` and equiangular.

Let :g:`( A B C D ) <g1:( A B C D )>` be the given circle;
thus it is required to :term:`inscribe in the circle <G.148>` :g:`( A B C D ) <g1:( A B C D )>` a fifteen-angled
figure which shall be
both equilateral and equiangular
.

In the circle :g:`( A B C D ) <g1:( A B C D )>` let
there be inscribed a side :g:`/ A C / <g1:/ A C />`
of the equilateral triangle
inscribed in it, and a side :g:`/ A B / <g1:/ A B />`
of an equilateral pentagon;
therefore, of the equal segments
of which there are
fifteen in the circle :g:`( A B C D ) <g1:( A B C D )>`,
there will be five in the circumference
:g:`( A B C ) <g1:( A B C )>` which is
one-third of the circle, and
there will be three in the circumference
:g:`( A B ) <g1:( A B )>` which is one-fifth of the circle;

.. picture:: g1.svg
   :alt: Book IV Proposition 16: Fifteen-angled figure inscribed in circle ABCD using triangle side AC and pentagon side AB

.. assertion::

   therefore in the remainder :g:`( B C ) <g1:( B C )>` there will be two of the equal segments.

Let :g:`( B C ) <g1:( B C )>` be :eq:`bisected <g1:( B E ) = g1:( E C )>` at :g:`E <g1:E>`; :just:`[G.137] <G.137>`

.. assertion::

   therefore each of the circumferences :g:`( B E ) <g1:( B E )>`, :g:`( E C ) <g1:( E C )>` is a fifteenth of the circle :g:`( A B C D ) <g1:( A B C D )>`.

.. qed::

   If therefore we join :g:`/ B E / <g1:/ B E />`, :g:`/ E C / <g1:/ E C />` and :term:`fit into the circle <G.146>` :g:`( A B C D ) <g1:( A B C D )>` :term:`straight lines <G.4>` equal to them and in contiguity, a fifteen-angled figure which is both equilateral and equiangular will have been inscribed in it. :just:`Q. E. F.`

And, in like manner as in the case of the pentagon, if
through the :term:`points <G.1>` of division on the circle we draw
tangents to the circle, there will be circumscribed about the
circle a fifteen-angled figure which is equilateral and equiangular
.

And further, by proofs similar to those in the case of the
pentagon, we can both :term:`inscribe a circle in <G.153>` the given fifteen-angled
figure and circumscribe one about it.
