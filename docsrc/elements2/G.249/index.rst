G.249
=====

.. rubric:: `VIII.9 <https://geometor.github.io/euclid/heath/volume_II/book_viii/propositions/09/>`_

.. enunciation::

   If two numbers be prime to one another, and numbers fall between them in continued proportion, then, however many numbers fall between them in continued proportion, so many will also fall between each of them and an unit in continued proportion.

.. picture:: g1.svg
   :alt: Book VIII Proposition 9

.. step:: given

   :g:`A <g1:A>`, :g:`B <g1:B>` be two numbers prime to one another

.. step:: assert

   Let :g:`C <g1:C>`, :g:`D <g1:D>` fall between them in continued proportion

.. step:: assert

   Let the unit :g:`E <g1:E>` be set out

.. step:: construct [G.242] <G.242>

   For let two numbers :g:`F <g1:F>`, :g:`G <g1:G>`, the least that are in the ratio of :g:`A <g1:A>`, :g:`C <g1:C>`, :g:`D <g1:D>`, :g:`B <g1:B>`, be taken, three numbers :g:`H <g1:H>`, :g:`K <g1:K>`, :g:`L <g1:L>` with the same property, and others more by one continually, until their multitude is equal to the multitude of :g:`A <g1:A>`, :g:`C <g1:C>`, :g:`D <g1:D>`, :g:`B <g1:B>`.

.. step:: construct

   Let them be taken

.. step:: assert

   Let them be :g:`M <g1:M>`, :g:`N <g1:N>`, :g:`O <g1:O>`, :g:`P <g1:P>`.

.. step:: assert [G.242] <G.242>

   It is now manifest that :g:`F <g1:F>` by multiplying itself has made :g:`H <g1:H>` and by multiplying :g:`H <g1:H>` has made :g:`M <g1:M>`, while :g:`G <g1:G>` by multiplying itself has made :g:`L <g1:L>` and by multiplying :g:`L <g1:L>` has made :g:`P <g1:P>`.

.. step:: assert [G.241] <G.241>

   And, since :g:`M <g1:M>`, :g:`N <g1:N>`, :g:`O <g1:O>`, :g:`P <g1:P>` are the least of those which have the same ratio with :g:`F <g1:F>`, :g:`G <g1:G>`, and :g:`A <g1:A>`, :g:`C <g1:C>`, :g:`D <g1:D>`, :g:`B <g1:B>` are also the least of those which have the same ratio with :g:`F <g1:F>`, :g:`G <g1:G>`, while the multitude of the numbers :g:`M <g1:M>`, :g:`N <g1:N>`, :g:`O <g1:O>`, :g:`P <g1:P>` is equal to the multitude of the numbers :g:`A <g1:A>`, :g:`C <g1:C>`, :g:`D <g1:D>`, :g:`B <g1:B>`.

.. step:: assert

   Therefore :g:`M <g1:M>`, :g:`N <g1:N>`, :g:`O <g1:O>`, :g:`P <g1:P>` are :eq:`equal <g1:M = g1:A; g1:N = g1:C; g1:O = g1:D; g1:P = g1:B>` to :g:`A <g1:A>`, :g:`C <g1:C>`, :g:`D <g1:D>`, :g:`B <g1:B>` respectively ; therefore :g:`M <g1:M>` is :eq:`equal <g1:M = g1:A; g1:P = g1:B>` to :g:`A <g1:A>`, and :g:`P <g1:P>` to :g:`B <g1:B>`.

.. step:: assert

   Since :g:`F <g1:F>` by multiplying itself has made :g:`H <g1:H>`,

.. step:: assert

   Therefore :g:`F <g1:F>` measures :g:`H <g1:H>` according to the units in :g:`F <g1:F>`.

.. step:: assert

   The unit :g:`E <g1:E>` also measures :g:`F <g1:F>` according to the units in it ;

.. step:: assert

   Therefore the unit :g:`E <g1:E>` measures the number :g:`F <g1:F>` the same number of times as :g:`F <g1:F>` measures :g:`H <g1:H>`.

.. step:: assert [G.210] <G.210>

   Therefore, as the unit :g:`E <g1:E>` is to the number :g:`F <g1:F>`, so is :g:`F <g1:F>` to :g:`H <g1:H>`.

.. step:: assert

   Since :g:`F <g1:F>` by multiplying :g:`H <g1:H>` has made :g:`M <g1:M>`,

.. step:: assert

   Therefore :g:`H <g1:H>` measures :g:`M <g1:M>` according to the units in :g:`F <g1:F>`.

.. step:: assert

   The unit :g:`E <g1:E>` also measures the number :g:`F <g1:F>` according to the units in it ;

.. step:: assert

   Therefore the unit :g:`E <g1:E>` measures the number :g:`F <g1:F>` the same number of times as :g:`H <g1:H>` measures :g:`M <g1:M>`.

.. step:: assert

   Therefore, as the unit :g:`E <g1:E>` is to the number :g:`F <g1:F>`, so is :g:`H <g1:H>` to :g:`M <g1:M>`.

.. step:: assert

   It was also proved that, as the unit :g:`E <g1:E>` is to the number :g:`F <g1:F>`, so is :g:`F <g1:F>` to :g:`H <g1:H>`;

.. step:: assert

   Therefore also, as the unit :g:`E <g1:E>` is to the number :g:`F <g1:F>`, so is :g:`F <g1:F>` to :g:`H <g1:H>`, and :g:`H <g1:H>` to :g:`M <g1:M>`.

.. step:: assert

   :g:`M <g1:M>` is :eq:`equal <g1:M = g1:A>` to :g:`A <g1:A>` ;

.. step:: assert

   Therefore, as the unit :g:`E <g1:E>` is to the number :g:`F <g1:F>`, so is :g:`F <g1:F>` to :g:`H <g1:H>`, and :g:`H <g1:H>` to :g:`A <g1:A>`.

.. step:: assert

   For the same reason also,

.. step:: assert

   As the unit :g:`E <g1:E>` is to the number :g:`G <g1:G>`, so is :g:`G <g1:G>` to :g:`L <g1:L>` and :g:`L <g1:L>` to :g:`B <g1:B>`.

.. step:: conclude

   Therefore, as many numbers as have fallen between :g:`A <g1:A>`, :g:`B <g1:B>` in continued proportion, so many numbers also have fallen between each of the numbers :g:`A <g1:A>`, :g:`B <g1:B>` and the unit :g:`E <g1:E>` in continued proportion.
