G.12
====

.. rubric:: `I.5 <https://geometor.github.io/euclid/heath/volume_I/book_i/propositions/05/>`_

.. enunciation::

   In isosceles triangles the angles at the base are equal to one another, and, if the equal straight lines\ [#f1]_ be produced further, the angles under the base will be equal to one another.

.. picture:: 0265.g1.svg
   :alt: Proposition 5 figure

Let :g:`< A B C > <0265.g1:< A B C >>` be an :eq:`isosceles <0265.g1:/ A B / = 0265.g1:/ A C />` triangle having the side :g:`/ A B / <0265.g1:/ A B />` :eq:`equal <0265.g1:/ A B / = 0265.g1:/ A C />` to the side :g:`/ A C / <0265.g1:/ A C />`;

and let the straight lines :g:`/ B D / <0265.g1:/ B D />`, :g:`/ C E / <0265.g1:/ C E />` be produced further in a straight line with :g:`/ A B / <0265.g1:/ A B />`, :g:`/ A C / <0265.g1:/ A C />`. :just:`[G.7] <G.7>`

I say that the angle :g:`< A B C ) <0265.g1:< A B C )>` is :eq:`equal <0265.g1:< A B C ) = 0265.g1:< A C B ); 0265.g1:< C B D ) = 0265.g1:< B C E )>` to the angle :g:`< A C B ) <0265.g1:< A C B )>`, and the angle :g:`< C B D ) <0265.g1:< C B D )>` to the angle :g:`< B C E ) <0265.g1:< B C E )>`.

Let a point :g:`F <0265.g1:F>` be taken at random on :g:`/ B D / <0265.g1:/ B D />`;\ [#f2]_ from :g:`/ A E / <0265.g1:/ A E />` the greater let :g:`/ A G / <0265.g1:/ A G />` be cut off :eq:`equal <0265.g1:/ A G / = 0265.g1:/ A F />` to :g:`/ A F / <0265.g1:/ A F />` the less; :just:`[G.9] <G.9>`

and let the straight lines :g:`/ F C / <0265.g1:/ F C />`, :g:`/ G B / <0265.g1:/ G B />` be joined. :just:`[G.3] <G.3>`

Then, since :g:`/ A F / <0265.g1:/ A F />` is :eq:`equal <0265.g1:/ A F / = 0265.g1:/ A G /; 0265.g1:/ A B / = 0265.g1:/ A C />` to :g:`/ A G / <0265.g1:/ A G />` and :g:`/ A B / <0265.g1:/ A B />` to :g:`/ A C / <0265.g1:/ A C />`,

.. subclause::

   the two sides :g:`/ F A / <0265.g1:/ F A />`, :g:`/ A C / <0265.g1:/ A C />` are :eq:`equal <0265.g1:/ F A / = 0265.g1:/ G A /; 0265.g1:/ A C / = 0265.g1:/ A B />` to the two sides :g:`/ G A / <0265.g1:/ G A />`, :g:`/ A B / <0265.g1:/ A B />`, respectively;\ [#f3]_

and they contain a common angle, the angle :g:`< F A G ) <0265.g1:< F A G )>`.

.. assertion::

   Therefore the base :g:`/ F C / <0265.g1:/ F C />` is :eq:`equal <0265.g1:/ F C / = 0265.g1:/ G B />` to the base :g:`/ G B / <0265.g1:/ G B />`,

and the triangle :g:`< A F C > <0265.g1:< A F C >>` is :eq:`equal <0265.g1:< A F C > = 0265.g1:< A G B >>` to the triangle :g:`< A G B > <0265.g1:< A G B >>`, and the remaining angles will be :eq:`equal <0265.g1:< A C F ) = 0265.g1:< A B G ); 0265.g1:< A F C ) = 0265.g1:< A G B )>` to the remaining angles respectively, namely those which the :eq:`equal <0265.g1:/ A F / = 0265.g1:/ A G /; 0265.g1:/ A C / = 0265.g1:/ A B />` sides subtend,

.. subclause::

   that is, the angle :g:`< A C F ) <0265.g1:< A C F )>` to the angle :g:`< A B G ) <0265.g1:< A B G )>`,

.. subclause:: [G.11] <G.11>

   and the angle :g:`< A F C ) <0265.g1:< A F C )>` to the angle :g:`< A G B ) <0265.g1:< A G B )>`.

And, since the whole :g:`/ A F / <0265.g1:/ A F />` is :eq:`equal <0265.g1:/ A F / = 0265.g1:/ A G />` to the whole :g:`/ A G / <0265.g1:/ A G />`, and in these :g:`/ A B / <0265.g1:/ A B />` is :eq:`equal <0265.g1:/ A B / = 0265.g1:/ A C />` to :g:`/ A C / <0265.g1:/ A C />`,

.. assertion::

   the remainder :g:`/ B F / <0265.g1:/ B F />` is :eq:`equal <0265.g1:/ B F / = 0265.g1:/ C G />` to the remainder :g:`/ C G / <0265.g1:/ C G />`.

But :g:`/ F C / <0265.g1:/ F C />` was also proved :eq:`equal <0265.g1:/ F C / = 0265.g1:/ G B />` to :g:`/ G B / <0265.g1:/ G B />`; therefore the two sides :g:`/ B F / <0265.g1:/ B F />`, :g:`/ F C / <0265.g1:/ F C />` are :eq:`equal <0265.g1:/ B F / = 0265.g1:/ C G /; 0265.g1:/ F C / = 0265.g1:/ G B />` to the two sides :g:`/ C G / <0265.g1:/ C G />`, :g:`/ G B / <0265.g1:/ G B />` respectively; and the angle :g:`< B F C ) <0265.g1:< B F C )>` is :eq:`equal <0265.g1:< B F C ) = 0265.g1:< C G B )>` to the angle :g:`< C G B ) <0265.g1:< C G B )>`,

.. subclause::

   while the base :g:`/ B C / <0265.g1:/ B C />` is common to them;\ [#f4]_

therefore the triangle :g:`< B F C > <0265.g1:< B F C >>` is also :eq:`equal <0265.g1:< B F C > = 0265.g1:< C G B >>` to the triangle :g:`< C G B > <0265.g1:< C G B >>`, and the remaining angles will be :eq:`equal <0265.g1:< F B C ) = 0265.g1:< G C B ); 0265.g1:< B C F ) = 0265.g1:< C B G )>` to the remaining
angles respectively, namely those which the :eq:`equal <0265.g1:/ B F / = 0265.g1:/ C G /; 0265.g1:/ F C / = 0265.g1:/ G B />` sides subtend;

.. subclause::

   therefore the angle :g:`< F B C ) <0265.g1:< F B C )>` is :eq:`equal <0265.g1:< F B C ) = 0265.g1:< G C B ); 0265.g1:< B C F ) = 0265.g1:< C B G )>` to the angle :g:`< G C B ) <0265.g1:< G C B )>`,

.. subclause::

   and the angle :g:`< B C F ) <0265.g1:< B C F )>` to the angle :g:`< C B G ) <0265.g1:< C B G )>`.

Accordingly, since the whole angle :g:`< A B G ) <0265.g1:< A B G )>` was proved :eq:`equal <0265.g1:< A B G ) = 0265.g1:< A C F )>` to the angle :g:`< A C F ) <0265.g1:< A C F )>`, and in these the angle :g:`< C B G ) <0265.g1:< C B G )>` is :eq:`equal <0265.g1:< C B G ) = 0265.g1:< B C F )>` to the angle :g:`< B C F ) <0265.g1:< B C F )>`, the remaining angle :g:`< A B C ) <0265.g1:< A B C )>` is :eq:`equal <0265.g1:< A B C ) = 0265.g1:< A C B )>` to the remaining angle :g:`< A C B ) <0265.g1:< A C B )>`;

.. subclause::

   and they are at the base of the triangle :g:`< A B C > <0265.g1:< A B C >>`.

But the angle :g:`< F B C ) <0265.g1:< F B C )>` was also proved :eq:`equal <0265.g1:< F B C ) = 0265.g1:< G C B )>` to the angle :g:`< G C B ) <0265.g1:< G C B )>`;

.. subclause::

   and they are under the base.

.. qed::

   Therefore etc.\ [#f5]_ :just:`Q. E. D.`

.. [#f1] **the equal straight lines** (meaning the equal *sides*). Cf. note on the similar expression in Prop. 4, lines 2, 3.

.. [#f2] **Let a point F be taken at random on BD,** εἰλήφθω ἐπὶ τῆς ΒΔ τυχὸν :term:`σημεῖον <point>` τὸ Ζ, where τυχὸν :term:`σημεῖον <point>` means “a chance point.”

.. [#f3] **the two sides FA, AC are equal to the two sides GA, AB respectively,** δύο αἱ ΖΑ, ΑΓ δυσὶ ταῖς ΗΑ, ΑΒ ἴσαι εἰσὶν ἑκατέρα ἑκατέρᾳ. Here, and in numberless later passages, I have inserted the word “sides” for the reason given in the note on I. 1, line 20. It would have been permissible to supply either “straight lines” or “sides”; but on the whole “sides” seems to be more in accordance with the phraseology of I. 4.

.. [#f4] **the base BC is common to them,** i.e., apparently, common to the angles, as the αὐτῶν in :term:`βάσις <basis>` αὐτῶν κοινὴ can only refer to γωνίᾳ and γωνίᾳ preceding. :person:`Simson <simson>` wrote “and the base :g:`/ B C / <0265.g1:/ B C />` is common to the two triangles :g:`< B F C > <0265.g1:< B F C >>`, :g:`< C G B > <0265.g1:< C G B >>`”; :person:`Todhunter <todhunter>` left out these words as being of no use and tending to perplex a beginner. But :person:`Euclid <euclid>` evidently chose to quote the conclusion of I. 4 exactly; the first phrase of that conclusion is that the bases (of the two triangles) are equal, and, as the equal bases are here the *same* base, :person:`Euclid <euclid>` naturally substitutes the word “common” for “equal.”

.. [#f5] As “(Being) what it was required to prove” (or “do”) is somewhat long, I shall henceforth write the time-honoured “Q. E. D.” and “Q. E. F.” for :term:`ὅπερ ἔδει δεῖξαι <hoper-edei-deixai>` and :term:`ὅπερ ἔδει ποιῆσαι <hoper-edei-poiesai>`.
