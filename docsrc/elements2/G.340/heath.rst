G.340 many numbers please — Heath
=================================

.. rubric:: `IX.11 <https://geometor.github.io/euclid/heath/volume_II/book_ix/propositions/11/>`_

.. enunciation::

   If as many :term:`numbers <G.248>` as we please beginning from an :term:`unit <G.247>` be in :term:`continued proportion <G.180>`, the less :term:`measures <G.253>` the greater according to some one of the numbers which have place among the proportional numbers.

Let there be as many numbers as we please, :g:`B <g1:B>`, :g:`C <g1:C>`, :g:`D <g1:D>`, :g:`E <g1:E>`, beginning from the unit :g:`A <g1:A>` and in continued proportion ;

I say that :g:`B <g1:B>`, the least of the numbers :g:`B <g1:B>`, :g:`C <g1:C>`, :g:`D <g1:D>`, :g:`E <g1:E>`, measures :g:`E <g1:E>` according to some one of the numbers :g:`C <g1:C>`, :g:`D <g1:D>`.

.. picture:: g1.svg
   :alt: Proposition 11 Diagram

.. subclause::

   For since, as the unit :g:`A <g1:A>` is to :g:`B <g1:B>`, so is :g:`D <g1:D>` to :g:`E <g1:E>`,

.. assertion::

   therefore the unit :g:`A <g1:A>` measures the number :g:`B <g1:B>` the same number of times as :g:`D <g1:D>` measures :g:`E <g1:E>`;

.. assertion::

   therefore, :term:`alternately <G.194>`, the unit :g:`A <g1:A>` measures :g:`D <g1:D>` the same number of times as :g:`B <g1:B>` measures :g:`E <g1:E>`. :just:`[G.268] <G.268>`

.. subclause::

   But the unit :g:`A <g1:A>` measures :g:`D <g1:D>` according to the units in it;

.. assertion::

   therefore :g:`B <g1:B>` also measures :g:`E <g1:E>` according to the units in :g:`D <g1:D>`;

.. assertion::

   so that :g:`B <g1:B>` the less measures :g:`E <g1:E>` the greater according to some number of those which have place among the proportional numbers.—

.. assertion::

   PORISM. And it is manifest that, whatever place the measuring number has, reckoned from the unit, the same place also has the number according to which it measures, reckoned from the number measured, in the direction of the number before it.—

.. qed::

   :just:`Q. E. D.`
