G.310
=====

.. rubric:: `IX.35 <https://geometor.github.io/euclid/heath/volume_II/book_ix/propositions/35/>`_

.. enunciation::

   If as many numbers as we please be in continued proportion, and there be subtracted from the second and the last numbers equal to the first, then, as the excess of the second is to the first, so will the excess of the last be to all those before it.

Let there be as many numbers as we please in continued proportion, :g:`A <0426.g1:A>`, :g:`/ B C / <0426.g1:/ B C />`, :g:`D <0426.g1:D>`, :g:`/ E F / <0426.g1:/ E F />`, beginning from :g:`A <0426.g1:A>` as least, and let there be subtracted from :g:`/ B C / <0426.g1:/ B C />` and :g:`/ E F / <0426.g1:/ E F />` the numbers :g:`/ B G / <0426.g1:/ B G />`, :g:`/ F H / <0426.g1:/ F H />`, each :eq:`equal <0426.g1:/ B G / = 0426.g1:/ F H / = 0426.g1:A>` to :g:`A <0426.g1:A>`;

I say that, as :g:`/ C G / <0426.g1:/ C G />` is to :g:`A <0426.g1:A>`, so is :g:`/ E H / <0426.g1:/ E H />` to :g:`A <0426.g1:A>`, :g:`/ B C / <0426.g1:/ B C />`, :g:`D <0426.g1:D>`.

.. picture:: 0426.g1.svg
   :alt: Proposition 35 Diagram

For let :g:`/ F K / <0426.g1:/ F K />` be made :eq:`equal <0426.g1:/ F K / = 0426.g1:/ B C />` to :g:`/ B C / <0426.g1:/ B C />`, and :g:`/ F L / <0426.g1:/ F L />` :eq:`equal <0426.g1:/ F L / = 0426.g1:D>` to :g:`D <0426.g1:D>`.

.. subclause::

   Then, since :g:`/ F K / <0426.g1:/ F K />` is :eq:`equal <0426.g1:/ F K / = 0426.g1:/ B C />` to :g:`/ B C / <0426.g1:/ B C />`, and of these the part :g:`/ F H / <0426.g1:/ F H />` is :eq:`equal <0426.g1:/ F H / = 0426.g1:/ B G />` to the part :g:`/ B G / <0426.g1:/ B G />`,

.. assertion::

   therefore the remainder :g:`/ H K / <0426.g1:/ H K />` is :eq:`equal <0426.g1:/ H K / = 0426.g1:/ C G />` to the remainder :g:`/ C G / <0426.g1:/ C G />`.

.. subclause::

   And since, as :g:`/ E F / <0426.g1:/ E F />` is to :g:`D <0426.g1:D>`, so is :g:`D <0426.g1:D>` to :g:`/ B C / <0426.g1:/ B C />`, and :g:`/ B C / <0426.g1:/ B C />` to :g:`A <0426.g1:A>`, while :g:`D <0426.g1:D>` is :eq:`equal <0426.g1:D = 0426.g1:/ F L /; 0426.g1:/ B C / = 0426.g1:/ F K /; 0426.g1:A = 0426.g1:/ F H />` to :g:`/ F L / <0426.g1:/ F L />`, :g:`/ B C / <0426.g1:/ B C />` to :g:`/ F K / <0426.g1:/ F K />`, and :g:`A <0426.g1:A>` to :g:`/ F H / <0426.g1:/ F H />`,

.. assertion::

   therefore, as :g:`/ E F / <0426.g1:/ E F />` is to :g:`/ F L / <0426.g1:/ F L />`, so is :g:`/ F L / <0426.g1:/ F L />` to :g:`/ F K / <0426.g1:/ F K />`, and :g:`/ F K / <0426.g1:/ F K />` to :g:`/ F H / <0426.g1:/ F H />`.

.. assertion::

   Separando, as :g:`/ E L / <0426.g1:/ E L />` is to :g:`/ F L / <0426.g1:/ F L />`, so is :g:`/ K L / <0426.g1:/ K L />` to :g:`/ F K / <0426.g1:/ F K />`, and :g:`/ H K / <0426.g1:/ H K />` to :g:`/ F H / <0426.g1:/ F H />`. :just:`[G.211, G.213] <G.211, G.213>`

.. assertion::

   Therefore also, as one of the antecedents is to one of the consequents, so are all the antecedents to all the consequents; :just:`[G.212] <G.212>` therefore, as :g:`/ H K / <0426.g1:/ H K />` is to :g:`/ F H / <0426.g1:/ F H />`, so are :g:`/ E L / <0426.g1:/ E L />`, :g:`/ K L / <0426.g1:/ K L />`, :g:`/ H K / <0426.g1:/ H K />` to :g:`/ F L / <0426.g1:/ F L />`, :g:`/ F K / <0426.g1:/ F K />`, :g:`/ F H / <0426.g1:/ F H />`.

.. subclause::

   But :g:`/ H K / <0426.g1:/ H K />` is :eq:`equal <0426.g1:/ H K / = 0426.g1:/ C G /; 0426.g1:/ F H / = 0426.g1:A; 0426.g1:/ F L / = 0426.g1:D; 0426.g1:/ F K / = 0426.g1:/ B C />` to :g:`/ C G / <0426.g1:/ C G />`, :g:`/ F H / <0426.g1:/ F H />` to :g:`A <0426.g1:A>`, and :g:`/ F L / <0426.g1:/ F L />`, :g:`/ F K / <0426.g1:/ F K />`, :g:`/ F H / <0426.g1:/ F H />` to :g:`D <0426.g1:D>`, :g:`/ B C / <0426.g1:/ B C />`, :g:`A <0426.g1:A>`;

.. assertion::

   therefore, as :g:`/ C G / <0426.g1:/ C G />` is to :g:`A <0426.g1:A>`, so is :g:`/ E H / <0426.g1:/ E H />` to :g:`D <0426.g1:D>`, :g:`/ B C / <0426.g1:/ B C />`, :g:`A <0426.g1:A>`.

.. assertion::

   Therefore, as the excess of the second is to the first, so is the excess of the last to all those before it.

.. qed::

   :just:`Q. E. D.`
