G.525 — Heath
=============

.. rubric:: `XIII.18 <https://geometor.github.io/euclid/heath/volume_III/book_xiii/propositions/18/>`_

.. enunciation::

   To set out the sides of the five figures and to compare them with one another.

Let :g:`/ A B / <g1:/ A B />`, the diameter of the given sphere, be set out, and let it be cut at :g:`C <g1:C>` so that :g:`/ A C / <g1:/ A C />` is :eq:`equal <g1:/ A C / = g1:/ C B />` to :g:`/ C B / <g1:/ C B />`, and at :g:`D <g1:D>` so that :g:`/ A D / <g1:/ A D />` is double of :g:`/ D B / <g1:/ D B />`; let the semicircle :g:`( A E B ) <g1:( A E B )>` be described on :g:`/ A B / <g1:/ A B />`, from :g:`C <g1:C>`, :g:`D <g1:D>` let :g:`/ C E / <g1:/ C E />`, :g:`/ D F / <g1:/ D F />` be drawn at right angles to :g:`/ A B / <g1:/ A B />`, and let :g:`/ A F / <g1:/ A F />`, :g:`/ F B / <g1:/ F B />`, :g:`/ E B / <g1:/ E B />` be joined.

.. assertion::

   Then, since :g:`/ A D / <g1:/ A D />` is double of :g:`/ D B / <g1:/ D B />`, therefore :g:`/ A B / <g1:/ A B />` is triple of :g:`/ D B / <g1:/ D B />`.

.. assertion::

   *Convertendo*, therefore, :g:`/ A B / <g1:/ A B />` is one and a half times :g:`/ A D / <g1:/ A D />`.

.. picture:: g1.svg
   :alt: Proposition 18 Semicircle Construction Diagram

.. subclause::

   But, as :g:`/ A B / <g1:/ A B />` is to :g:`/ A D / <g1:/ A D />`, so is the square on :g:`/ A B / <g1:/ A B />` to the square on :g:`/ A F / <g1:/ A F />`, :just:`[G.182, G.171] <G.182, G.171>` for the triangle :g:`< A F B > <g1:< A F B >>` is equiangular with the triangle :g:`< A F D > <g1:< A F D >>`;

.. assertion::

   therefore the square on :g:`/ A B / <g1:/ A B />` is one and a half times the square on :g:`/ A F / <g1:/ A F />`.

.. subclause::

   But the square on the diameter of the sphere is also one and a half times the square on the side of the pyramid. :just:`[G.520] <G.520>`

.. subclause::

   And :g:`/ A B / <g1:/ A B />` is the diameter of the sphere;

.. assertion::

   therefore :g:`/ A F / <g1:/ A F />` is equal to the side of the pyramid.

.. subclause::

   Again, since :g:`/ A D / <g1:/ A D />` is double of :g:`/ D B / <g1:/ D B />`,

.. assertion::

   therefore :g:`/ A B / <g1:/ A B />` is triple of :g:`/ D B / <g1:/ D B />`.

.. subclause::

   But, as :g:`/ A B / <g1:/ A B />` is to :g:`/ D B / <g1:/ D B />`, so is the square on :g:`/ A B / <g1:/ A B />` to the square on :g:`/ F B / <g1:/ F B />`; :just:`[G.171, G.182] <G.171, G.182>`

.. assertion::

   therefore the square on :g:`/ A B / <g1:/ A B />` is triple of the square on :g:`/ F B / <g1:/ F B />`.

.. subclause::

   But the square on the diameter of the sphere is also triple of the square on the side of the cube. :just:`[G.522] <G.522>`

.. subclause::

   And :g:`/ A B / <g1:/ A B />` is the diameter of the sphere;

.. assertion::

   therefore :g:`/ F B / <g1:/ F B />` is the side of the cube.

.. subclause::

   And, since :g:`/ A C / <g1:/ A C />` is :eq:`equal <g1:/ A C / = g1:/ C B />` to :g:`/ C B / <g1:/ C B />`,

.. assertion::

   therefore :g:`/ A B / <g1:/ A B />` is double of :g:`/ C B / <g1:/ C B />`.

.. subclause::

   But, as :g:`/ A B / <g1:/ A B />` is to :g:`/ C B / <g1:/ C B />`, so is the square on :g:`/ A B / <g1:/ A B />` to the square on :g:`/ E B / <g1:/ E B />`;

.. assertion::

   therefore the square on :g:`/ A B / <g1:/ A B />` is double of the square on :g:`/ E B / <g1:/ E B />`.

.. subclause::

   But the square on the diameter of the sphere is also double of the square on the side of the octahedron. :just:`[G.521] <G.521>`

.. subclause::

   And :g:`/ A B / <g1:/ A B />` is the diameter of the given sphere;

.. assertion::

   therefore :g:`/ E B / <g1:/ E B />` is the side of the octahedron.

Next, let :g:`/ A G / <g1:/ A G />` be drawn from the point :g:`A <g1:A>` at right angles to the straight line :g:`/ A B / <g1:/ A B />`, let :g:`/ A G / <g1:/ A G />` be made :eq:`equal <g1:/ A G / = g1:/ A B />` to :g:`/ A B / <g1:/ A B />`, let :g:`/ G C / <g1:/ G C />` be joined, and from :g:`H <g1:H>` let :g:`/ H K / <g1:/ H K />` be drawn perpendicular to :g:`/ A B / <g1:/ A B />`.

.. subclause::

   Then, since :g:`/ A G / <g1:/ A G />` is double of :g:`/ A C / <g1:/ A C />`, for :g:`/ A G / <g1:/ A G />` is :eq:`equal <g1:/ A G / = g1:/ A B />` to :g:`/ A B / <g1:/ A B />`, and, as :g:`/ A G / <g1:/ A G />` is to :g:`/ A C / <g1:/ A C />`, so is :g:`/ H K / <g1:/ H K />` to :g:`/ C K / <g1:/ C K />`,

.. assertion::

   therefore :g:`/ H K / <g1:/ H K />` is also double of :g:`/ C K / <g1:/ C K />`.

.. assertion::

   Therefore the square on :g:`/ H K / <g1:/ H K />` is quadruple of the square on :g:`/ C K / <g1:/ C K />`; therefore the squares on :g:`/ H K / <g1:/ H K />`, :g:`/ C K / <g1:/ C K />`, that is, the square on :g:`/ H C / <g1:/ H C />`, is five times the square on :g:`/ C K / <g1:/ C K />`.

.. subclause::

   But :g:`/ H C / <g1:/ H C />` is :eq:`equal <g1:/ H C / = g1:/ C B />` to :g:`/ C B / <g1:/ C B />`;

.. assertion::

   therefore the square on :g:`/ C B / <g1:/ C B />` is five times the square on :g:`/ C K / <g1:/ C K />`.

.. subclause::

   And, since :g:`/ A B / <g1:/ A B />` is double of :g:`/ C B / <g1:/ C B />`, and, in them, :g:`/ A D / <g1:/ A D />` is double of :g:`/ D B / <g1:/ D B />`,

.. assertion::

   therefore the remainder :g:`/ D B / <g1:/ D B />` is double of the remainder :g:`/ C D / <g1:/ C D />`.

.. assertion::

   Therefore :g:`/ C B / <g1:/ C B />` is triple of :g:`/ C D / <g1:/ C D />`; therefore the square on :g:`/ C B / <g1:/ C B />` is nine times the square on :g:`/ C D / <g1:/ C D />`.

.. subclause::

   But the square on :g:`/ C B / <g1:/ C B />` is five times the square on :g:`/ C K / <g1:/ C K />`;

.. assertion::

   therefore the square on :g:`/ C K / <g1:/ C K />` is greater than the square on :g:`/ C D / <g1:/ C D />`; therefore :g:`/ C K / <g1:/ C K />` is greater than :g:`/ C D / <g1:/ C D />`.

Let :g:`/ C L / <g1:/ C L />` be made :eq:`equal <g1:/ C L / = g1:/ C K />` to :g:`/ C K / <g1:/ C K />`, from :g:`L <g1:L>` let :g:`/ L M / <g1:/ L M />` be drawn at right angles to :g:`/ A B / <g1:/ A B />`, and let :g:`/ M B / <g1:/ M B />` be joined.

.. subclause::

   Now, since the square on :g:`/ C B / <g1:/ C B />` is five times the square on :g:`/ C K / <g1:/ C K />`, and :g:`/ A B / <g1:/ A B />` is double of :g:`/ C B / <g1:/ C B />`, and :g:`/ K L / <g1:/ K L />` double of :g:`/ C K / <g1:/ C K />`,

.. assertion::

   therefore the square on :g:`/ A B / <g1:/ A B />` is five times the square on :g:`/ K L / <g1:/ K L />`.

.. subclause::

   But the square on the diameter of the sphere is also five times the square on the radius of the circle from which the icosahedron has been described. :just:`[G.523] <G.523>`

.. subclause::

   And :g:`/ A B / <g1:/ A B />` is the diameter of the sphere;

.. assertion::

   therefore :g:`/ K L / <g1:/ K L />` is the radius of the circle from which the icosahedron has been described; therefore :g:`/ K L / <g1:/ K L />` is a side of the hexagon in the said circle. :just:`[G.133] <G.133>`

.. subclause::

   And, since the diameter of the sphere is made up of the side of the hexagon and two of the sides of the decagon inscribed in the same circle, :just:`[G.523] <G.523>` and :g:`/ A B / <g1:/ A B />` is the diameter of the sphere, while :g:`/ K L / <g1:/ K L />` is a side of the hexagon, and :g:`/ A K / <g1:/ A K />` is :eq:`equal <g1:/ A K / = g1:/ L B />` to :g:`/ L B / <g1:/ L B />`,

.. assertion::

   therefore each of the straight lines :g:`/ A K / <g1:/ A K />`, :g:`/ L B / <g1:/ L B />` is a side of the decagon inscribed in the circle from which the icosahedron has been described.

.. subclause::

   And, since :g:`/ L B / <g1:/ L B />` belongs to a decagon, and :g:`/ L M / <g1:/ L M />` to a hexagon, for :g:`/ L M / <g1:/ L M />` is :eq:`equal <g1:/ L M / = g1:/ K L />` to :g:`/ K L / <g1:/ K L />`, since it is also :eq:`equal <g1:/ L M / = g1:/ H K />` to :g:`/ H K / <g1:/ H K />`, being the same distance from the centre, and each of the straight lines :g:`/ H K / <g1:/ H K />`, :g:`/ K L / <g1:/ K L />` is double of :g:`/ C K / <g1:/ C K />`,

.. assertion:: [G.517] <G.517>

   therefore :g:`/ M B / <g1:/ M B />` belongs to a pentagon.

.. subclause::

   But the side of the pentagon is the side of the icosahedron ; :just:`[G.523] <G.523>`

.. assertion::

   therefore :g:`/ M B / <g1:/ M B />` belongs to the icosahedron.

.. subclause::

   Now, since :g:`/ F B / <g1:/ F B />` is a side of the cube, let it be cut in extreme and mean ratio at :g:`N <g1:N>`, and let :g:`/ N B / <g1:/ N B />` be the greater segment ;

.. assertion:: [G.524] <G.524>

   therefore :g:`/ N B / <g1:/ N B />` is a side of the dodecahedron.

.. subclause::

   And, since the square on the diameter of the sphere was proved to be one and a half times the square on the side :g:`/ A F / <g1:/ A F />` of the pyramid, double of the square on the side :g:`/ E B / <g1:/ E B />` of the octahedron and triple of the side :g:`/ F B / <g1:/ F B />` of the cube,

.. assertion::

   therefore, of parts of which the square on the diameter of the sphere contains six, the square on the side of the pyramid contains four, the square on the side of the octahedron three, and the square on the side of the cube two.

.. assertion::

   Therefore the square on the side of the pyramid is four-thirds of the square on the side of the octahedron, and double of the square on the side of the cube ; and the square on the side of the octahedron is one and a half times the square on the side of the cube.

.. assertion::

   The said sides, therefore, of the three figures, I mean the pyramid, the octahedron and the cube, are to one another in rational ratios.

.. assertion::

   But the remaining two, I mean the side of the icosahedron and the side of the dodecahedron, are not in rational ratios either to one another or to the aforesaid sides ; for they are irrational, the one being minor :just:`[G.523] <G.523>` and the other an apotome :just:`[G.524] <G.524>`.

.. assertion::

   That the side :g:`/ M B / <g1:/ M B />` of the icosahedron is greater than the side :g:`/ N B / <g1:/ N B />` of the dodecahedron we can prove thus.

.. subclause::

   For, since the triangle :g:`< F D B > <g1:< F D B >>` is equiangular with the triangle :g:`< A F B > <g1:< A F B >>`, :just:`[G.171] <G.171>`

.. assertion:: [G.166] <G.166>

   proportionally, as :g:`/ D B / <g1:/ D B />` is to :g:`/ F B / <g1:/ F B />`, so is :g:`/ F B / <g1:/ F B />` to :g:`/ A B / <g1:/ A B />`.

.. subclause::

   And, since the three straight lines are proportional, as the first is to the third, so is the square on the first to the square on the second ; :just:`[G.182, G.185] <G.182, G.185>`

.. assertion::

   therefore, as :g:`/ D B / <g1:/ D B />` is to :g:`/ A B / <g1:/ A B />`, so is the square on :g:`/ D B / <g1:/ D B />` to the square on :g:`/ F B / <g1:/ F B />`;

.. assertion::

   therefore, inversely, as :g:`/ A B / <g1:/ A B />` is to :g:`/ D B / <g1:/ D B />`, so is the square on :g:`/ F B / <g1:/ F B />` to the square on :g:`/ D B / <g1:/ D B />`.

.. subclause::

   But :g:`/ A B / <g1:/ A B />` is triple of :g:`/ D B / <g1:/ D B />` ;

.. assertion::

   therefore the square on :g:`/ F B / <g1:/ F B />` is triple of the square on :g:`/ D B / <g1:/ D B />`.

.. subclause::

   But the square on :g:`/ A D / <g1:/ A D />` is also quadruple of the square on :g:`/ D B / <g1:/ D B />`, for :g:`/ A D / <g1:/ A D />` is double of :g:`/ D B / <g1:/ D B />` ;

.. assertion::

   therefore the square on :g:`/ A D / <g1:/ A D />` is greater than the square on :g:`/ F B / <g1:/ F B />` ; therefore :g:`/ A D / <g1:/ A D />` is greater than :g:`/ F B / <g1:/ F B />` ; therefore :g:`/ A L / <g1:/ A L />` is by far greater than :g:`/ F B / <g1:/ F B />`.

.. subclause::

   And, when :g:`/ A L / <g1:/ A L />` is cut in extreme and mean ratio, :g:`/ K L / <g1:/ K L />` is the greater segment, inasmuch as :g:`/ K L / <g1:/ K L />` belongs to a hexagon, and :g:`/ A K / <g1:/ A K />` to a decagon ; :just:`[G.516] <G.516>` and, when :g:`/ F B / <g1:/ F B />` is cut in extreme and mean ratio, :g:`/ N B / <g1:/ N B />` is the greater segment ;

.. assertion::

   therefore :g:`/ K L / <g1:/ K L />` is greater than :g:`/ N B / <g1:/ N B />`.

.. subclause::

   But :g:`/ K L / <g1:/ K L />` is :eq:`equal <g1:/ K L / = g1:/ L M />` to :g:`/ L M / <g1:/ L M />` ;

.. assertion::

   therefore :g:`/ L M / <g1:/ L M />` is greater than :g:`/ N B / <g1:/ N B />`.

.. assertion::

   Therefore :g:`/ M B / <g1:/ M B />`, which is a side of the icosahedron, is by far greater than :g:`/ N B / <g1:/ N B />` which is a side of the dodecahedron.

.. qed::

   :just:`Q. E. D.`
