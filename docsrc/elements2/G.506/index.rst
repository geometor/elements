G.506
=====

.. rubric:: `XII.18 <https://geometor.github.io/euclid/heath/volume_III/book_xii/propositions/18/>`_

.. enunciation::

   Spheres are to one another in the triplicate ratio of their respective diameters.

Let the spheres :g:`( A B C ) <0439.g1:( A B C )>`, :g:`( D E F ) <0439.g1:( D E F )>` be conceived, and let :g:`/ B C / <0439.g1:/ B C />`, :g:`/ E F / <0439.g1:/ E F />` be their diameters; I say that the sphere :g:`( A B C ) <0439.g1:( A B C )>` has to the sphere :g:`( D E F ) <0439.g1:( D E F )>` the ratio triplicate of that which :g:`/ B C / <0439.g1:/ B C />` has to :g:`/ E F / <0439.g1:/ E F />`.

.. subclause::

   For, if the sphere :g:`( A B C ) <0439.g1:( A B C )>` has not to the sphere :g:`( D E F ) <0439.g1:( D E F )>` the ratio triplicate of that which :g:`/ B C / <0439.g1:/ B C />` has to :g:`/ E F / <0439.g1:/ E F />`,

.. assertion::

   then the sphere :g:`( A B C ) <0439.g1:( A B C )>` will have either to some less sphere than the sphere :g:`( D E F ) <0439.g1:( D E F )>`, or to a greater, the ratio triplicate of that which :g:`/ B C / <0439.g1:/ B C />` has to :g:`/ E F / <0439.g1:/ E F />`.

First, let it have that ratio to a less sphere :g:`( G H K ) <0439.g1:( G H K )>`, let :g:`( D E F ) <0439.g1:( D E F )>` be conceived about the same centre with :g:`( G H K ) <0439.g1:( G H K )>`, let there be inscribed in the greater sphere :g:`( D E F ) <0439.g1:( D E F )>` a polyhedral solid which does not touch the lesser sphere :g:`( G H K ) <0439.g1:( G H K )>` at its surface, :just:`[G.505] <G.505>`
and let there also be inscribed in the sphere :g:`( A B C ) <0439.g1:( A B C )>` a polyhedral solid similar to the polyhedral solid in the sphere :g:`( D E F ) <0439.g1:( D E F )>`;

.. assertion::

   therefore the polyhedral solid in :g:`( A B C ) <0439.g1:( A B C )>` has to the polyhedral solid in :g:`( D E F ) <0439.g1:( D E F )>` the ratio triplicate of that which :g:`/ B C / <0439.g1:/ B C />` has to :g:`/ E F / <0439.g1:/ E F />`. :just:`[G.505] <G.505>`

.. picture:: 0439.g1.svg
   :alt: Book XII, Proposition 18

.. subclause::

   But the sphere :g:`( A B C ) <0439.g1:( A B C )>` also has to the sphere :g:`( G H K ) <0439.g1:( G H K )>` the ratio triplicate of that which :g:`/ B C / <0439.g1:/ B C />` has to :g:`/ E F / <0439.g1:/ E F />`;

.. assertion::

   therefore, as the sphere :g:`( A B C ) <0439.g1:( A B C )>` is to the sphere :g:`( G H K ) <0439.g1:( G H K )>`, so is the polyhedral solid in the sphere :g:`( A B C ) <0439.g1:( A B C )>` to the polyhedral solid in the sphere :g:`( D E F ) <0439.g1:( D E F )>`; and, alternately, as the sphere :g:`( A B C ) <0439.g1:( A B C )>` is to the polyhedron in it, so is the sphere :g:`( G H K ) <0439.g1:( G H K )>` to the polyhedral solid in the sphere :g:`( D E F ) <0439.g1:( D E F )>`. :just:`[G.153] <G.153>`

.. subclause::

   But the sphere :g:`( A B C ) <0439.g1:( A B C )>` is greater than the polyhedron in it;

.. assertion::

   therefore the sphere :g:`( G H K ) <0439.g1:( G H K )>` is also greater than the polyhedron in the sphere :g:`( D E F ) <0439.g1:( D E F )>`.

.. assertion::

   But it is also less, for it is enclosed by it.

.. assertion::

   Therefore the sphere :g:`( A B C ) <0439.g1:( A B C )>` has not to a less sphere than the sphere :g:`( D E F ) <0439.g1:( D E F )>` the ratio triplicate of that which the diameter :g:`/ B C / <0439.g1:/ B C />` has to :g:`/ E F / <0439.g1:/ E F />`.

Similarly we can prove that neither has the sphere :g:`( D E F ) <0439.g1:( D E F )>` to a less sphere than the sphere :g:`( A B C ) <0439.g1:( A B C )>` the ratio triplicate of that which :g:`/ E F / <0439.g1:/ E F />` has to :g:`/ B C / <0439.g1:/ B C />`.

I say next that neither has the sphere :g:`( A B C ) <0439.g1:( A B C )>` to any greater sphere than the sphere :g:`( D E F ) <0439.g1:( D E F )>` the ratio triplicate of that which :g:`/ B C / <0439.g1:/ B C />` has to :g:`/ E F / <0439.g1:/ E F />`.

.. subclause::

   For, if possible, let it have that ratio to a greater, :g:`( L M N ) <0439.g1:( L M N )>`;

.. assertion::

   therefore, inversely, the sphere :g:`( L M N ) <0439.g1:( L M N )>` has to the sphere :g:`( A B C ) <0439.g1:( A B C )>` the ratio triplicate of that which the diameter :g:`/ E F / <0439.g1:/ E F />` has to the diameter :g:`/ B C / <0439.g1:/ B C />`.

.. subclause::

   But, inasmuch as :g:`( L M N ) <0439.g1:( L M N )>` is greater than :g:`( D E F ) <0439.g1:( D E F )>`,

.. assertion::

   therefore, as the sphere :g:`( L M N ) <0439.g1:( L M N )>` is to the sphere :g:`( A B C ) <0439.g1:( A B C )>`, so is the sphere :g:`( D E F ) <0439.g1:( D E F )>` to some less sphere than the sphere :g:`( A B C ) <0439.g1:( A B C )>`, as was before proved. :just:`[G.488] <G.488>`

.. assertion::

   Therefore the sphere :g:`( D E F ) <0439.g1:( D E F )>` also has to some less sphere than the sphere :g:`( A B C ) <0439.g1:( A B C )>` the ratio triplicate of that which :g:`/ E F / <0439.g1:/ E F />` has to :g:`/ B C / <0439.g1:/ B C />` : which was proved impossible.

.. assertion::

   Therefore the sphere :g:`( A B C ) <0439.g1:( A B C )>` has not to any sphere greater than the sphere :g:`( D E F ) <0439.g1:( D E F )>` the ratio triplicate of that which :g:`/ B C / <0439.g1:/ B C />` has to :g:`/ E F / <0439.g1:/ E F />`.

.. subclause::

   But it was proved that neither has it that ratio to a less sphere.

.. assertion::

   Therefore the sphere :g:`( A B C ) <0439.g1:( A B C )>` has to the sphere :g:`( D E F ) <0439.g1:( D E F )>` the ratio triplicate of that which :g:`/ B C / <0439.g1:/ B C />` has to :g:`/ E F / <0439.g1:/ E F />`.

.. qed::

   :just:`Q. E. D.`
