G.375 commensurable magnitudes find
===================================

.. rubric:: `X.4 <https://geometor.github.io/euclid/heath/volume_III/book_x/propositions/004/>`_

.. enunciation::

   Given three :term:`commensurable <G.372>` magnitudes, to find their greatest common :term:`measure <G.169>`.

.. signature:: problem

   | :fn:`commensurable_magnitudes_find_x_4 <G.375>`\ (:g:`A <g1:A>`, :g:`B <g1:B>`, :g:`C <g1:C>`)
   | **given** :g:`A <g1:A>`, :g:`B <g1:B>`, :g:`C <g1:C>` be the three given commensurable magnitudes
   | **construct** PORISM. From this it is manifest that, if a magnitude measure three magnitudes, it will also measure their greatest common measure

.. picture:: g1.svg
   :alt: Proposition 4 diagram

.. step:: given

   :g:`A <g1:A>`, :g:`B <g1:B>`, :g:`C <g1:C>` be the three given commensurable magnitudes

.. step:: construct

   Let the greatest common measure of the two magnitudes :g:`A <g1:A>`, :g:`B <g1:B>` be taken

.. step:: assert ∵ commensurable_magnitudes_find <G.374>

   Let it be :g:`D <g1:D>`

.. step:: assert

   Then :g:`D <g1:D>` either measures :g:`C <g1:C>`, or does not measure it

.. step:: assert

   First, let it measure it

.. step:: assert

   then :g:`D <g1:D>` measures :g:`C <g1:C>`, while it also measures :g:`A <g1:A>`, :g:`B <g1:B>`,

.. step:: assert

   :g:`D <g1:D>` is a common measure of :g:`A <g1:A>`, :g:`B <g1:B>`, :g:`C <g1:C>`

.. step:: assert

   It is manifest that it is also the greatest ; for a greater magnitude than the magnitude :g:`D <g1:D>` does not measure :g:`A <g1:A>`, :g:`B <g1:B>`

.. step:: assert

   Next, let :g:`D <g1:D>` not measure :g:`C <g1:C>`

.. step:: assert

   I say first that :g:`C <g1:C>`, :g:`D <g1:D>` are commensurable

.. step:: assert

   :g:`A <g1:A>`, :g:`B <g1:B>`, :g:`C <g1:C>` are commensurable, some magnitude will measure them, and this will of course measure :g:`A <g1:A>`, :g:`B <g1:B>` also

.. step:: assert ∵ commensurable_magnitudes_find <G.374>

   So that it will also measure the greatest common measure of :g:`A <g1:A>`, :g:`B <g1:B>`, namely :g:`D <g1:D>`

.. step:: assert

   It also measures :g:`C <g1:C>`

.. step:: assert

   So that the said magnitude will measure :g:`C <g1:C>`, :g:`D <g1:D>` ; therefore :g:`C <g1:C>`, :g:`D <g1:D>` are commensurable

.. step:: construct

   Now let their greatest common measure be taken

.. step:: assert ∵ commensurable_magnitudes_find <G.374>

   Let it be :g:`E <g1:E>`

.. step:: assert

   then :g:`E <g1:E>` measures :g:`D <g1:D>`, while :g:`D <g1:D>` measures :g:`A <g1:A>`, :g:`B <g1:B>`,

.. step:: assert

   :g:`E <g1:E>` will also measure :g:`A <g1:A>`, :g:`B <g1:B>`

.. step:: assert

   It measures :g:`C <g1:C>` also

.. step:: assert

   :g:`E <g1:E>` measures :g:`A <g1:A>`, :g:`B <g1:B>`, :g:`C <g1:C>` ; therefore :g:`E <g1:E>` is a common measure of :g:`A <g1:A>`, :g:`B <g1:B>`, :g:`C <g1:C>`

.. step:: assert

   I say next that it is also the greatest

.. step:: assert

   If possible, let there be some magnitude :g:`F <g1:F>` greater than :g:`E <g1:E>`, and let it measure :g:`A <g1:A>`, :g:`B <g1:B>`, :g:`C <g1:C>`

.. step:: assert ∵ commensurable_magnitudes_find <G.374>

   :g:`F <g1:F>` measures :g:`A <g1:A>`, :g:`B <g1:B>`, :g:`C <g1:C>`, it will also measure :g:`A <g1:A>`, :g:`B <g1:B>`, and will measure the greatest common measure of :g:`A <g1:A>`, :g:`B <g1:B>`

.. step:: assert

   The greatest common measure of :g:`A <g1:A>`, :g:`B <g1:B>` is :g:`D <g1:D>`

.. step:: assert

   :g:`F <g1:F>` measures :g:`D <g1:D>`

.. step:: assert

   It measures :g:`C <g1:C>` also

.. step:: assert ∵ commensurable_magnitudes_find <G.374>

   :g:`F <g1:F>` measures :g:`C <g1:C>`, :g:`D <g1:D>` ; therefore :g:`F <g1:F>` will also measure the greatest common measure of :g:`C <g1:C>`, :g:`D <g1:D>`

.. step:: assert

   That is :g:`E <g1:E>`

.. step:: assert

   :g:`F <g1:F>` will measure :g:`E <g1:E>`, the greater the less ⇒⇐

.. step:: assert

   no magnitude greater than the magnitude :g:`E <g1:E>` will measure :g:`A <g1:A>`, :g:`B <g1:B>`, :g:`C <g1:C>` ; therefore :g:`E <g1:E>` is the greatest common measure of :g:`A <g1:A>`, :g:`B <g1:B>`, :g:`C <g1:C>` if :g:`D <g1:D>` do not measure :g:`C <g1:C>`, and, if it measure it, :g:`D <g1:D>` is itself the greatest common measure

.. step:: assert

   the greatest common measure of the three given commensurable magnitudes has been found

.. step:: conclude

   PORISM. From this it is manifest that, if a magnitude measure three magnitudes, it will also measure their greatest common measure
