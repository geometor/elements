G.467
=====

.. rubric:: `XI.22 <https://geometor.github.io/euclid/heath/volume_III/book_xi/propositions/22/>`_

.. enunciation::

   If there be three plane angles of which two, taken together in any manner, are greater than the remaining one, and they are contained by equal straight lines, it is possible to construct a triangle out of the straight lines joining the extremities of the equal straight lines.

Let there be three plane angles :g:`< A B C ) <0317.g1:< A B C )>`, :g:`< D E F ) <0317.g1:< D E F )>`, :g:`< G H K ) <0317.g1:< G H K )>`, of
which two, taken together in any manner, are greater than the remaining one, namely the angles :g:`< A B C ) <0317.g1:< A B C )>`, :g:`< D E F ) <0317.g1:< D E F )>` greater than the angle :g:`< G H K ) <0317.g1:< G H K )>`, the angles :g:`< D E F ) <0317.g1:< D E F )>`, :g:`< G H K ) <0317.g1:< G H K )>` greater than the angle :g:`< A B C ) <0317.g1:< A B C )>`, and, further, the angles :g:`< G H K ) <0317.g1:< G H K )>`, :g:`< A B C ) <0317.g1:< A B C )>` greater than the angle :g:`< D E F ) <0317.g1:< D E F )>`; let the straight lines :g:`/ A B / <0317.g1:/ A B />`, :g:`/ B C / <0317.g1:/ B C />`, :g:`/ D E / <0317.g1:/ D E />`, :g:`/ E F / <0317.g1:/ E F />`, :g:`/ G H / <0317.g1:/ G H />`, :g:`/ H K / <0317.g1:/ H K />` be :eq:`equal <0317.g1:/ A B / = 0317.g1:/ B C / = 0317.g1:/ D E / = 0317.g1:/ E F / = 0317.g1:/ G H / = 0317.g1:/ H K />`, and let :g:`/ A C / <0317.g1:/ A C />`, :g:`/ D F / <0317.g1:/ D F />`, :g:`/ G K / <0317.g1:/ G K />` be joined;

I say that it is possible to construct a triangle out of straight lines equal to :g:`/ A C / <0317.g1:/ A C />`, :g:`/ D F / <0317.g1:/ D F />`, :g:`/ G K / <0317.g1:/ G K />`, that is, that any two of the straight lines :g:`/ A C / <0317.g1:/ A C />`, :g:`/ D F / <0317.g1:/ D F />`, :g:`/ G K / <0317.g1:/ G K />` are greater than the remaining one.

.. picture:: 0317.g1.svg
   :alt: Proposition 22, Figure 1

.. assertion::

   Now, if the angles :g:`< A B C ) <0317.g1:< A B C )>`, :g:`< D E F ) <0317.g1:< D E F )>`, :g:`< G H K ) <0317.g1:< G H K )>` are :eq:`equal <0317.g1:< A B C ) = 0317.g1:< D E F ) = 0317.g1:< G H K )>` to one another, it is manifest that, :g:`/ A C / <0317.g1:/ A C />`, :g:`/ D F / <0317.g1:/ D F />`, :g:`/ G K / <0317.g1:/ G K />` being :eq:`equal <0317.g1:/ A C / = 0317.g1:/ D F / = 0317.g1:/ G K />` also, it is possible to construct a triangle out of straight lines equal to :g:`/ A C / <0317.g1:/ A C />`, :g:`/ D F / <0317.g1:/ D F />`, :g:`/ G K / <0317.g1:/ G K />`.

But, if not, let them be unequal, and on the straight line :g:`/ H K / <0317.g2:/ H K />`, and at the point :g:`H <0317.g2:H>` on it, let the angle :g:`< K H L ) <0317.g2:< K H L )>` be constructed :eq:`equal <0317.g2:< K H L ) = 0317.g1:< A B C )>` to the angle :g:`< A B C ) <0317.g1:< A B C )>`; let :g:`/ H L / <0317.g2:/ H L />` be made :eq:`equal <0317.g2:/ H L / = 0317.g1:/ A B / = 0317.g1:/ B C / = 0317.g1:/ D E / = 0317.g1:/ E F / = 0317.g2:/ G H / = 0317.g2:/ H K />` to one of the straight lines :g:`/ A B / <0317.g1:/ A B />`, :g:`/ B C / <0317.g1:/ B C />`, :g:`/ D E / <0317.g1:/ D E />`, :g:`/ E F / <0317.g1:/ E F />`, :g:`/ G H / <0317.g2:/ G H />`, :g:`/ H K / <0317.g2:/ H K />`, and let :g:`/ K L / <0317.g2:/ K L />`, :g:`/ G L / <0317.g2:/ G L />` be joined.

.. picture:: 0317.g2.svg
   :alt: Proposition 22, Figure 2

.. subclause::

   Now, since the two sides :g:`/ A B / <0317.g1:/ A B />`, :g:`/ B C / <0317.g1:/ B C />` are :eq:`equal <0317.g1:/ A B / = 0317.g2:/ K H /; 0317.g1:/ B C / = 0317.g2:/ H L />` to the two sides :g:`/ K H / <0317.g2:/ K H />`, :g:`/ H L / <0317.g2:/ H L />`, and the angle at :g:`B <0317.g1:B>` is :eq:`equal <0317.g1:< A B C ) = 0317.g2:< K H L )>` to the angle :g:`< K H L ) <0317.g2:< K H L )>`,

.. assertion:: [G.11] <G.11>

   therefore the base :g:`/ A C / <0317.g1:/ A C />` is :eq:`equal <0317.g1:/ A C / = 0317.g2:/ K L />` to the base :g:`/ K L / <0317.g2:/ K L />`.

.. subclause::

   *And*, since the angles :g:`< A B C ) <0317.g1:< A B C )>`, :g:`< G H K ) <0317.g2:< G H K )>` are greater than the angle :g:`< D E F ) <0317.g1:< D E F )>`,

.. subclause::

   while the angle :g:`< A B C ) <0317.g1:< A B C )>` is :eq:`equal <0317.g1:< A B C ) = 0317.g2:< K H L )>` to the angle :g:`< K H L ) <0317.g2:< K H L )>`,

.. assertion::

   therefore the angle :g:`< G H L ) <0317.g2:< G H L )>` is greater than the angle :g:`< D E F ) <0317.g1:< D E F )>`.

.. subclause::

   And, since the two sides :g:`/ G H / <0317.g2:/ G H />`, :g:`/ H L / <0317.g2:/ H L />` are :eq:`equal <0317.g2:/ G H / = 0317.g1:/ D E /; 0317.g2:/ H L / = 0317.g1:/ E F />` to the two sides :g:`/ D E / <0317.g1:/ D E />`, :g:`/ E F / <0317.g1:/ E F />`, and the angle :g:`< G H L ) <0317.g2:< G H L )>` is greater than the angle :g:`< D E F ) <0317.g1:< D E F )>`,

.. assertion:: [G.35] <G.35>

   therefore the base :g:`/ G L / <0317.g2:/ G L />` is greater than the base :g:`/ D F / <0317.g1:/ D F />`.

.. subclause::

   But :g:`/ G K / <0317.g2:/ G K />`, :g:`/ K L / <0317.g2:/ K L />` are greater than :g:`/ G L / <0317.g2:/ G L />`.

.. assertion::

   Therefore :g:`/ G K / <0317.g2:/ G K />`, :g:`/ K L / <0317.g2:/ K L />` are much greater than :g:`/ D F / <0317.g1:/ D F />`.

.. subclause::

   But :g:`/ K L / <0317.g2:/ K L />` is :eq:`equal <0317.g2:/ K L / = 0317.g1:/ A C />` to :g:`/ A C / <0317.g1:/ A C />`;

.. assertion::

   therefore :g:`/ A C / <0317.g1:/ A C />`, :g:`/ G K / <0317.g1:/ G K />` are greater than the remaining straight line :g:`/ D F / <0317.g1:/ D F />`.

.. assertion::

   Similarly we can prove that :g:`/ A C / <0317.g1:/ A C />`, :g:`/ D F / <0317.g1:/ D F />` are greater than :g:`/ G K / <0317.g1:/ G K />`, and further :g:`/ D F / <0317.g1:/ D F />`, :g:`/ G K / <0317.g1:/ G K />` are greater than :g:`/ A C / <0317.g1:/ A C />`.

.. assertion::

   Therefore it is possible to construct a triangle out of straight lines equal to :g:`/ A C / <0317.g1:/ A C />`, :g:`/ D F / <0317.g1:/ D F />`, :g:`/ G K / <0317.g1:/ G K />`.

.. qed::

   :just:`Q. E. D.`
