G.130
=====

.. rubric:: `IV.12 <https://geometor.github.io/euclid/heath/volume_II/book_iv/propositions/12/>`_

.. enunciation::

   About a given circle to circumscribe an equilateral and equiangular pentagon.

Let :g:`( A B C D E ) <0108.g2:( A B C D E )>` be the given circle;
thus it is required to circumscribe an equilateral and equiangular
pentagon about the circle
:g:`( A B C D E ) <0108.g2:( A B C D E )>`.

Let :g:`A <0108.g2:A>`, :g:`B <0108.g2:B>`, :g:`C <0108.g2:C>`, :g:`D <0108.g2:D>`, :g:`E <0108.g2:E>` be conceived to
be the angular points of the inscribed
pentagon, so that the circumferences
:g:`( A B ) <0108.g2:( A B )>`, :g:`( B C ) <0108.g2:( B C )>`, :g:`( C D ) <0108.g2:( C D )>`, :g:`( D E ) <0108.g2:( D E )>`, :g:`( E A ) <0108.g2:( E A )>` are :eq:`equal <0108.g2:( A B ) = 0108.g2:( B C ) = 0108.g2:( C D ) = 0108.g2:( D E ) = 0108.g2:( E A )>`;
:just:`[G.129] <G.129>`
through :g:`A <0108.g2:A>`, :g:`B <0108.g2:B>`, :g:`C <0108.g2:C>`, :g:`D <0108.g2:D>`, :g:`E <0108.g2:E>` let :g:`/ G H / <0108.g2:/ G H />`, :g:`/ H K / <0108.g2:/ H K />`,
:g:`/ K L / <0108.g2:/ K L />`, :g:`/ L M / <0108.g2:/ L M />`, :g:`/ M G / <0108.g2:/ M G />` be drawn touching the
circle;
:just:`[G.94] <G.94>`

.. picture:: 0108.g2.svg
   :alt: Proposition 12 diagram

let the centre :g:`F <0108.g2:F>` of the circle :g:`( A B C D E ) <0108.g2:( A B C D E )>` be taken :just:`[G.76] <G.76>`, and
let :g:`/ F B / <0108.g2:/ F B />`, :g:`/ F K / <0108.g2:/ F K />`, :g:`/ F C / <0108.g2:/ F C />`, :g:`/ F L / <0108.g2:/ F L />`, :g:`/ F D / <0108.g2:/ F D />` be joined.

Then, since the straight line :g:`/ K L / <0108.g2:/ K L />` touches the circle :g:`( A B C D E ) <0108.g2:( A B C D E )>`
at :g:`C <0108.g2:C>`,
and :g:`/ F C / <0108.g2:/ F C />` has been joined from the centre :g:`F <0108.g2:F>` to the point of
contact at :g:`C <0108.g2:C>`,

.. assertion:: [G.96] <G.96>

   therefore :g:`/ F C / <0108.g2:/ F C />` is perpendicular to :g:`/ K L / <0108.g2:/ K L />`;

.. assertion::

   therefore each of the angles at :g:`< K C L ) <0108.g2:< K C L )>` is right.

For the same reason

.. assertion::

   the angles at the points :g:`< F B K ) <0108.g2:< F B K )>`, :g:`< F D L ) <0108.g2:< F D L )>` are also :eq:`right <0108.g2:< F B K ) = 0108.g2:< F D L )>`.

And, since the angle :g:`< F C K ) <0108.g2:< F C K )>` is right,

.. assertion::

   therefore the square on :g:`/ F K / <0108.g2:/ F K />` is equal to the squares on :g:`/ F C / <0108.g2:/ F C />`, :g:`/ C K / <0108.g2:/ C K />`.

For the same reason :just:`[G.60] <G.60>`

.. assertion::

   the square on :g:`/ F K / <0108.g2:/ F K />` is also equal to the squares on :g:`/ F B / <0108.g2:/ F B />`, :g:`/ B K / <0108.g2:/ B K />`;

so that the squares on :g:`/ F C / <0108.g2:/ F C />`, :g:`/ C K / <0108.g2:/ C K />` are equal to the squares
on :g:`/ F B / <0108.g2:/ F B />`, :g:`/ B K / <0108.g2:/ B K />`,

.. subclause::

   of which the square on :g:`/ F C / <0108.g2:/ F C />` is :eq:`equal <0108.g2:/ F C / = 0108.g2:/ F B />` to the square on :g:`/ F B / <0108.g2:/ F B />`;

.. assertion::

   therefore the square on :g:`/ C K / <0108.g2:/ C K />` which remains is :eq:`equal <0108.g2:/ C K / = 0108.g2:/ B K />` to the square on :g:`/ B K / <0108.g2:/ B K />`.

.. assertion::

   Therefore :g:`/ B K / <0108.g2:/ B K />` is :eq:`equal <0108.g2:/ B K / = 0108.g2:/ C K />` to :g:`/ C K / <0108.g2:/ C K />`.

And, since :g:`/ F B / <0108.g2:/ F B />` is :eq:`equal <0108.g2:/ F B / = 0108.g2:/ F C />` to :g:`/ F C / <0108.g2:/ F C />`,
and :g:`/ F K / <0108.g2:/ F K />` common,
the two sides :g:`/ B F / <0108.g2:/ B F />`, :g:`/ F K / <0108.g2:/ F K />` are :eq:`equal <0108.g2:/ B F / = 0108.g2:/ C F /; 0108.g2:/ F K / = 0108.g2:/ F K />` to the two sides :g:`/ C F / <0108.g2:/ C F />`, :g:`/ F K / <0108.g2:/ F K />`;
and the base :g:`/ B K / <0108.g2:/ B K />` :eq:`equal <0108.g2:/ B K / = 0108.g2:/ C K />` to the base :g:`/ C K / <0108.g2:/ C K />`;

.. assertion::

   therefore the angle :g:`< B F K ) <0108.g2:< B F K )>` is :eq:`equal <0108.g2:< B F K ) = 0108.g2:< K F C )>` to the angle :g:`< K F C ) <0108.g2:< K F C )>`, :just:`[G.15] <G.15>` and the angle :g:`< B K F ) <0108.g2:< B K F )>` :eq:`to <0108.g2:< B K F ) = 0108.g2:< F K C )>` the angle :g:`< F K C ) <0108.g2:< F K C )>`.

.. assertion::

   Therefore the angle :g:`< B F C ) <0108.g2:< B F C )>` is double of the angle :g:`< K F C ) <0108.g2:< K F C )>`, and the angle :g:`< B K C ) <0108.g2:< B K C )>` of the angle :g:`< F K C ) <0108.g2:< F K C )>`.

For the same reason

.. assertion::

   the angle :g:`< C F D ) <0108.g2:< C F D )>` is also double of the angle :g:`< C F L ) <0108.g2:< C F L )>`, and the angle :g:`< D L C ) <0108.g2:< D L C )>` of the angle :g:`< F L C ) <0108.g2:< F L C )>`.

Now, since the circumference :g:`( B C ) <0108.g2:( B C )>` is :eq:`equal <0108.g2:( B C ) = 0108.g2:( C D )>` to :g:`( C D ) <0108.g2:( C D )>`,

.. assertion:: [G.106] <G.106>

   the angle :g:`< B F C ) <0108.g2:< B F C )>` is also :eq:`equal <0108.g2:< B F C ) = 0108.g2:< C F D )>` to the angle :g:`< C F D ) <0108.g2:< C F D )>`.

And the angle :g:`< B F C ) <0108.g2:< B F C )>` is double of the angle :g:`< K F C ) <0108.g2:< K F C )>`, and the
angle :g:`< D F C ) <0108.g2:< D F C )>` of the angle :g:`< L F C ) <0108.g2:< L F C )>`;

.. assertion::

   therefore the angle :g:`< K F C ) <0108.g2:< K F C )>` is also :eq:`equal <0108.g2:< K F C ) = 0108.g2:< L F C )>` to the angle :g:`< L F C ) <0108.g2:< L F C )>`.

But the angle :g:`< F C K ) <0108.g2:< F C K )>` is also :eq:`equal <0108.g2:< F C K ) = 0108.g2:< F C L )>` to the angle :g:`< F C L ) <0108.g2:< F C L )>`;
therefore :g:`< F K C > <0108.g2:< F K C >>`, :g:`< F L C > <0108.g2:< F L C >>` are two triangles having two angles
equal to two angles and one side equal to one side, namely
:g:`/ F C / <0108.g2:/ F C />` which is common to them;
therefore they will also have the remaining sides equal to the
remaining sides, and the remaining angle to the remaining
angle; :just:`[G.37] <G.37>`

.. assertion::

   therefore the straight line :g:`/ K C / <0108.g2:/ K C />` is :eq:`equal <0108.g2:/ K C / = 0108.g2:/ C L />` to :g:`/ C L / <0108.g2:/ C L />`, and the angle :g:`< F K C ) <0108.g2:< F K C )>` :eq:`to <0108.g2:< F K C ) = 0108.g2:< F L C )>` the angle :g:`< F L C ) <0108.g2:< F L C )>`.

And, since :g:`/ K C / <0108.g2:/ K C />` is :eq:`equal <0108.g2:/ K C / = 0108.g2:/ C L />` to :g:`/ C L / <0108.g2:/ C L />`,

.. assertion::

   therefore :g:`/ K L / <0108.g2:/ K L />` is double of :g:`/ K C / <0108.g2:/ K C />`.

For the same reason it can be proved that

.. assertion::

   :g:`/ H K / <0108.g2:/ H K />` is also double of :g:`/ B K / <0108.g2:/ B K />`.

And :g:`/ B K / <0108.g2:/ B K />` is :eq:`equal <0108.g2:/ B K / = 0108.g2:/ K C />` to :g:`/ K C / <0108.g2:/ K C />`;

.. assertion::

   therefore :g:`/ H K / <0108.g2:/ H K />` is also :eq:`equal <0108.g2:/ H K / = 0108.g2:/ K L />` to :g:`/ K L / <0108.g2:/ K L />`.

Similarly each of the straight lines :g:`/ H G / <0108.g2:/ H G />`, :g:`/ G M / <0108.g2:/ G M />`, :g:`/ M L / <0108.g2:/ M L />` can also
be proved :eq:`equal <0108.g2:/ H G / = 0108.g2:/ G M / = 0108.g2:/ M L / = 0108.g2:/ H K / = 0108.g2:/ K L />` to each of the straight lines :g:`/ H K / <0108.g2:/ H K />`, :g:`/ K L / <0108.g2:/ K L />`;

.. assertion::

   therefore the pentagon :g:`< G H K L M > <0108.g2:< G H K L M >>` is :eq:`equilateral <0108.g2:/ G H / = 0108.g2:/ H K / = 0108.g2:/ K L / = 0108.g2:/ L M / = 0108.g2:/ M G />`.

I say next that it is also :eq:`equiangular <0108.g2:< G H K ) = 0108.g2:< H K L ) = 0108.g2:< K L M ) = 0108.g2:< L M G ) = 0108.g2:< M G H )>`.

For, since the angle :g:`< F K C ) <0108.g2:< F K C )>` is :eq:`equal <0108.g2:< F K C ) = 0108.g2:< F L C )>` to the angle :g:`< F L C ) <0108.g2:< F L C )>`,
and the angle :g:`< H K L ) <0108.g2:< H K L )>` was proved double of the angle :g:`< F K C ) <0108.g2:< F K C )>`,
and the angle :g:`< K L M ) <0108.g2:< K L M )>` double of the angle :g:`< F L C ) <0108.g2:< F L C )>`,

.. assertion::

   therefore the angle :g:`< H K L ) <0108.g2:< H K L )>` is also :eq:`equal <0108.g2:< H K L ) = 0108.g2:< K L M )>` to the angle :g:`< K L M ) <0108.g2:< K L M )>`.

Similarly each of the angles :g:`< K H G ) <0108.g2:< K H G )>`, :g:`< H G M ) <0108.g2:< H G M )>`, :g:`< G M L ) <0108.g2:< G M L )>` can also
be proved :eq:`equal <0108.g2:< K H G ) = 0108.g2:< H G M ) = 0108.g2:< G M L ) = 0108.g2:< H K L ) = 0108.g2:< K L M )>` to each of the angles :g:`< H K L ) <0108.g2:< H K L )>`, :g:`< K L M ) <0108.g2:< K L M )>`;

.. assertion::

   therefore the five angles :g:`< G H K ) <0108.g2:< G H K )>`, :g:`< H K L ) <0108.g2:< H K L )>`, :g:`< K L M ) <0108.g2:< K L M )>`, :g:`< L M G ) <0108.g2:< L M G )>`, :g:`< M G H ) <0108.g2:< M G H )>` are :eq:`equal <0108.g2:< G H K ) = 0108.g2:< H K L ) = 0108.g2:< K L M ) = 0108.g2:< L M G ) = 0108.g2:< M G H )>` to one another.

.. assertion::

   Therefore the pentagon :g:`< G H K L M > <0108.g2:< G H K L M >>` is :eq:`equiangular <0108.g2:< G H K ) = 0108.g2:< H K L ) = 0108.g2:< K L M ) = 0108.g2:< L M G ) = 0108.g2:< M G H )>`.

And it was also proved :eq:`equilateral <0108.g2:/ G H / = 0108.g2:/ H K / = 0108.g2:/ K L / = 0108.g2:/ L M / = 0108.g2:/ M G />`; and it has been
circumscribed about the circle :g:`( A B C D E ) <0108.g2:( A B C D E )>`.

.. qed::

   :just:`Q. E. F.`
