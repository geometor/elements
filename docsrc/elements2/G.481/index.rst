G.481
=====

.. rubric:: `XI.34 <https://geometor.github.io/euclid/heath/volume_III/book_xi/propositions/34/>`_

.. enunciation::

   In equal parallelepipedal solids the bases are reciprocally proportional to the heights; and those parallelepipedal solids in which the bases are reciprocally proportional to the heights are equal.

Let :g:`< A B > <0350.g1:< A B >>`, :g:`< C D > <0350.g1:< C D >>` be :eq:`equal <0350.g1:< A B > = 0350.g1:< C D >>` parallelepipedal solids; I say that in the parallelepipedal solids :g:`< A B > <0350.g1:< A B >>`, :g:`< C D > <0350.g1:< C D >>` the bases are reciprocally proportional to the heights, that is, as the base :g:`< E H > <0350.g1:< E H >>` is to the base :g:`< N Q > <0350.g1:< N Q >>`, so is the height of the solid :g:`< C D > <0350.g1:< C D >>` to the height of the solid :g:`< A B > <0350.g1:< A B >>`.

First, let the sides which stand up, namely :g:`/ A G / <0350.g1:/ A G />`, :g:`/ E F / <0350.g1:/ E F />`, :g:`/ L B / <0350.g1:/ L B />`, :g:`/ H K / <0350.g1:/ H K />`, :g:`/ C M / <0350.g1:/ C M />`, :g:`/ N O / <0350.g1:/ N O />`, :g:`/ P D / <0350.g1:/ P D />`, :g:`/ Q R / <0350.g1:/ Q R />`, be at :eq:`right angles <0350.g1:/ A G / = 0350.g1:< E H >; 0350.g1:/ E F / = 0350.g1:< E H >; 0350.g1:/ L B / = 0350.g1:< E H >; 0350.g1:/ H K / = 0350.g1:< E H >; 0350.g1:/ C M / = 0350.g1:< N Q >; 0350.g1:/ N O / = 0350.g1:< N Q >; 0350.g1:/ P D / = 0350.g1:< N Q >; 0350.g1:/ Q R / = 0350.g1:< N Q >>` to their bases; I say that, as the base :g:`< E H > <0350.g1:< E H >>` is to the base :g:`< N Q > <0350.g1:< N Q >>`, so is :g:`/ C M / <0350.g1:/ C M />` to :g:`/ A G / <0350.g1:/ A G />`.

.. subclause::

   If now the base :g:`< E H > <0350.g1:< E H >>` is :eq:`equal <0350.g1:< E H > = 0350.g1:< N Q >>` to the base :g:`< N Q > <0350.g1:< N Q >>`, while the solid :g:`< A B > <0350.g1:< A B >>` is also :eq:`equal <0350.g1:< A B > = 0350.g1:< C D >>` to the solid :g:`< C D > <0350.g1:< C D >>`,

.. assertion::

   :g:`/ C M / <0350.g1:/ C M />` will also be :eq:`equal <0350.g1:/ C M / = 0350.g1:/ A G />` to :g:`/ A G / <0350.g1:/ A G />`.

.. assertion::

   For parallelepipedal solids of the same height are to one another as the bases; :just:`[G.479] <G.479>` and, as the base :g:`< E H > <0350.g1:< E H >>` is to :g:`< N Q > <0350.g1:< N Q >>`, so will :g:`/ C M / <0350.g1:/ C M />` be to :g:`/ A G / <0350.g1:/ A G />`, and it is manifest that in the parallelepipedal solids :g:`< A B > <0350.g1:< A B >>`, :g:`< C D > <0350.g1:< C D >>` the bases are reciprocally proportional to the heights.

Next, let the base :g:`< E H > <0350.g1:< E H >>` not be equal to the base :g:`< N Q > <0350.g1:< N Q >>`, but let :g:`< E H > <0350.g1:< E H >>` be greater.

.. picture:: 0350.g1.svg
   :alt: Proposition 34, Diagram 1

.. subclause::

   Now the solid :g:`< A B > <0350.g1:< A B >>` is :eq:`equal <0350.g1:< A B > = 0350.g1:< C D >>` to the solid :g:`< C D > <0350.g1:< C D >>`;

.. assertion::

   therefore :g:`/ C M / <0350.g1:/ C M />` is also greater than :g:`/ A G / <0350.g1:/ A G />`.

Let then :g:`/ C T / <0350.g1:/ C T />` be made :eq:`equal <0350.g1:/ C T / = 0350.g1:/ A G />` to :g:`/ A G / <0350.g1:/ A G />`, and let the parallelepipedal solid :g:`< V C > <0350.g1:< V C >>` be completed on :g:`< N Q > <0350.g1:< N Q >>` as base and with :g:`/ C T / <0350.g1:/ C T />` as height.

.. subclause::

   Now, since the solid :g:`< A B > <0350.g1:< A B >>` is :eq:`equal <0350.g1:< A B > = 0350.g1:< C D >>` to the solid :g:`< C D > <0350.g1:< C D >>`, and :g:`< C V > <0350.g1:< C V >>` is outside them, while equals have to the same the same ratio, :just:`[G.142] <G.142>`

.. assertion::

   therefore, as the solid :g:`< A B > <0350.g1:< A B >>` is to the solid :g:`< C V > <0350.g1:< C V >>`, so is the solid :g:`< C D > <0350.g1:< C D >>` to the solid :g:`< C V > <0350.g1:< C V >>`.

.. subclause::

   But, as the solid :g:`< A B > <0350.g1:< A B >>` is to the solid :g:`< C V > <0350.g1:< C V >>`, so is the base :g:`< E H > <0350.g1:< E H >>` to the base :g:`< N Q > <0350.g1:< N Q >>`, for the solids :g:`< A B > <0350.g1:< A B >>`, :g:`< C V > <0350.g1:< C V >>` are of equal height; :just:`[G.479] <G.479>` and, as the solid :g:`< C D > <0350.g1:< C D >>` is to the solid :g:`< C V > <0350.g1:< C V >>`, so is the base :g:`< M Q > <0350.g1:< M Q >>` to the base :g:`< T Q > <0350.g1:< T Q >>` :just:`[G.470] <G.470>` and :g:`/ C M / <0350.g1:/ C M />` to :g:`/ C T / <0350.g1:/ C T />` :just:`[G.163] <G.163>`;

.. assertion::

   therefore also, as the base :g:`< E H > <0350.g1:< E H >>` is to the base :g:`< N Q > <0350.g1:< N Q >>`, so is :g:`/ M C / <0350.g1:/ M C />` to :g:`/ C T / <0350.g1:/ C T />`.

.. subclause::

   But :g:`/ C T / <0350.g1:/ C T />` is :eq:`equal <0350.g1:/ C T / = 0350.g1:/ A G />` to :g:`/ A G / <0350.g1:/ A G />`;

.. assertion::

   therefore also, as the base :g:`< E H > <0350.g1:< E H >>` is to the base :g:`< N Q > <0350.g1:< N Q >>`, so is :g:`/ M C / <0350.g1:/ M C />` to :g:`/ A G / <0350.g1:/ A G />`.

.. assertion::

   Therefore in the parallelepipedal solids :g:`< A B > <0350.g1:< A B >>`, :g:`< C D > <0350.g1:< C D >>` the bases are reciprocally proportional to the heights.

Again, in the parallelepipedal solids :g:`< A B > <0350.g1:< A B >>`, :g:`< C D > <0350.g1:< C D >>` let the bases be reciprocally proportional to the heights, that is, as the base :g:`< E H > <0350.g1:< E H >>` is to the base :g:`< N Q > <0350.g1:< N Q >>`, so let the height of the solid :g:`< C D > <0350.g1:< C D >>` be to the height of the solid :g:`< A B > <0350.g1:< A B >>`; I say that the solid :g:`< A B > <0350.g1:< A B >>` is :eq:`equal <0350.g1:< A B > = 0350.g1:< C D >>` to the solid :g:`< C D > <0350.g1:< C D >>`.

Let the sides which stand up be again at right angles to the bases.

.. subclause::

   Now, if the base :g:`< E H > <0350.g1:< E H >>` is :eq:`equal <0350.g1:< E H > = 0350.g1:< N Q >>` to the base :g:`< N Q > <0350.g1:< N Q >>`, and, as the base :g:`< E H > <0350.g1:< E H >>` is to the base :g:`< N Q > <0350.g1:< N Q >>`, so is the height of the solid :g:`< C D > <0350.g1:< C D >>` to the height of the solid :g:`< A B > <0350.g1:< A B >>`,

.. assertion::

   therefore the height of the solid :g:`< C D > <0350.g1:< C D >>` is also equal to the height of the solid :g:`< A B > <0350.g1:< A B >>`.

.. subclause::

   But parallelepipedal solids on equal bases and of the same height are equal to one another; :just:`[G.478] <G.478>`

.. assertion::

   therefore the solid :g:`< A B > <0350.g1:< A B >>` is :eq:`equal <0350.g1:< A B > = 0350.g1:< C D >>` to the solid :g:`< C D > <0350.g1:< C D >>`.

.. subclause::

   Next, let the base :g:`< E H > <0350.g1:< E H >>` not be equal to the base :g:`< N Q > <0350.g1:< N Q >>`, but let :g:`< E H > <0350.g1:< E H >>` be greater;

.. assertion::

   therefore the height of the solid :g:`< C D > <0350.g1:< C D >>` is also greater than the height of the solid :g:`< A B > <0350.g1:< A B >>`, that is, :g:`/ C M / <0350.g1:/ C M />` is greater than :g:`/ A G / <0350.g1:/ A G />`.

Let :g:`/ C T / <0350.g1:/ C T />` be again made :eq:`equal <0350.g1:/ C T / = 0350.g1:/ A G />` to :g:`/ A G / <0350.g1:/ A G />`, and let the solid :g:`< C V > <0350.g1:< C V >>` be similarly completed.

.. subclause::

   Since, as the base :g:`< E H > <0350.g1:< E H >>` is to the base :g:`< N Q > <0350.g1:< N Q >>`, so is :g:`/ M C / <0350.g1:/ M C />` to :g:`/ A G / <0350.g1:/ A G />`, while :g:`/ A G / <0350.g1:/ A G />` is :eq:`equal <0350.g1:/ A G / = 0350.g1:/ C T />` to :g:`/ C T / <0350.g1:/ C T />`,

.. assertion::

   therefore, as the base :g:`< E H > <0350.g1:< E H >>` is to the base :g:`< N Q > <0350.g1:< N Q >>`, so is :g:`/ C M / <0350.g1:/ C M />` to :g:`/ C T / <0350.g1:/ C T />`.

.. subclause::

   But, as the base :g:`< E H > <0350.g1:< E H >>` is to the base :g:`< N Q > <0350.g1:< N Q >>`, so is the solid :g:`< A B > <0350.g1:< A B >>` to the solid :g:`< C V > <0350.g1:< C V >>`, for the solids :g:`< A B > <0350.g1:< A B >>`, :g:`< C V > <0350.g1:< C V >>` are of equal height; :just:`[G.479] <G.479>` and, as :g:`/ C M / <0350.g1:/ C M />` is to :g:`/ C T / <0350.g1:/ C T />`, so is the base :g:`< M Q > <0350.g1:< M Q >>` to the base :g:`< Q T > <0350.g1:< Q T >>` :just:`[G.163] <G.163>` and the solid :g:`< C D > <0350.g1:< C D >>` to the solid :g:`< C V > <0350.g1:< C V >>`. :just:`[G.470] <G.470>`

.. assertion::

   Therefore also, as the solid :g:`< A B > <0350.g1:< A B >>` is to the solid :g:`< C V > <0350.g1:< C V >>`, so is the solid :g:`< C D > <0350.g1:< C D >>` to the solid :g:`< C V > <0350.g1:< C V >>`; therefore each of the solids :g:`< A B > <0350.g1:< A B >>`, :g:`< C D > <0350.g1:< C D >>` has to :g:`< C V > <0350.g1:< C V >>` the same ratio.

.. assertion:: [G.146] <G.146>

   Therefore the solid :g:`< A B > <0352.g1:< A B >>` is :eq:`equal <0352.g1:< A B > = 0352.g1:< C D >>` to the solid :g:`< C D > <0352.g1:< C D >>`.

Now let the sides which stand up, :g:`/ F E / <0352.g1:/ F E />`, :g:`/ B L / <0352.g1:/ B L />`, :g:`/ G A / <0352.g1:/ G A />`, :g:`/ H K / <0352.g1:/ H K />`, :g:`/ O N / <0352.g1:/ O N />`, :g:`/ D P / <0352.g1:/ D P />`, :g:`/ M C / <0352.g1:/ M C />`, :g:`/ R Q / <0352.g1:/ R Q />`, not be at right angles to their bases; let perpendiculars be drawn from the points :g:`F <0352.g1:F>`, :g:`G <0352.g1:G>`, :g:`B <0352.g1:B>`, :g:`K <0352.g1:K>`, :g:`O <0352.g1:O>`, :g:`M <0352.g1:M>`, :g:`D <0352.g1:D>`, :g:`R <0352.g1:R>` to the planes through :g:`< E H > <0352.g1:< E H >>`, :g:`< N Q > <0352.g1:< N Q >>`, and let them meet the planes at :g:`S <0352.g1:S>`, :g:`T <0352.g1:T>`, :g:`U <0352.g1:U>`, :g:`V <0352.g1:V>`, :g:`W <0352.g1:W>`, :g:`X <0352.g1:X>`, :g:`Y <0352.g1:Y>`, :g:`a <0352.g1:a>`, and let the solids :g:`< F V > <0352.g1:< F V >>`, :g:`< O a > <0352.g1:< O a >>` be completed; I say that, in this case too, if the solids :g:`< A B > <0352.g1:< A B >>`, :g:`< C D > <0352.g1:< C D >>` are :eq:`equal <0352.g1:< A B > = 0352.g1:< C D >>`, the bases are reciprocally proportional to the heights, that is, as the base :g:`< E H > <0352.g1:< E H >>` is to the base :g:`< N Q > <0352.g1:< N Q >>`, so is the height of the solid :g:`< C D > <0352.g1:< C D >>` to the height of the solid :g:`< A B > <0352.g1:< A B >>`.

.. picture:: 0352.g1.svg
   :alt: Proposition 34, Diagram 2

.. subclause::

   Since the solid :g:`< A B > <0352.g1:< A B >>` is :eq:`equal <0352.g1:< A B > = 0352.g1:< C D >>` to the solid :g:`< C D > <0352.g1:< C D >>`, while :g:`< A B > <0352.g1:< A B >>` is :eq:`equal <0352.g1:< A B > = 0352.g1:< B T >>` to :g:`< B T > <0352.g1:< B T >>`, for they are on the same base :g:`< F K > <0352.g1:< F K >>` and of the same height; :just:`[G.476, G.477] <G.476, G.477>` and the solid :g:`< C D > <0352.g1:< C D >>` is :eq:`equal <0352.g1:< C D > = 0352.g1:< D X >>` to :g:`< D X > <0352.g1:< D X >>`, for they are again on the same base :g:`< R O > <0352.g1:< R O >>` and of the same height; :just:`[G.476, G.477] <G.476, G.477>`

.. assertion::

   therefore the solid :g:`< B T > <0352.g1:< B T >>` is also :eq:`equal <0352.g1:< B T > = 0352.g1:< D X >>` to the solid :g:`< D X > <0352.g1:< D X >>`.

.. assertion::

   Therefore, as the base :g:`< F K > <0352.g1:< F K >>` is to the base :g:`< O R > <0352.g1:< O R >>`, so is the height of the solid :g:`< D X > <0352.g1:< D X >>` to the height of the solid :g:`< B T > <0352.g1:< B T >>`. :just:`[Part 1.]`

.. subclause::

   But the base :g:`< F K > <0352.g1:< F K >>` is :eq:`equal <0352.g1:< F K > = 0352.g1:< E H >; 0352.g1:< O R > = 0352.g1:< N Q >>` to the base :g:`< E H > <0352.g1:< E H >>`, and the base :g:`< O R > <0352.g1:< O R >>` to the base :g:`< N Q > <0352.g1:< N Q >>`;

.. assertion::

   therefore, as the base :g:`< E H > <0352.g1:< E H >>` is to the base :g:`< N Q > <0352.g1:< N Q >>`, so is the height of the solid :g:`< D X > <0352.g1:< D X >>` to the height of the solid :g:`< B T > <0352.g1:< B T >>`.

.. subclause::

   But the solids :g:`< D X > <0352.g1:< D X >>`, :g:`< B T > <0352.g1:< B T >>` and the solids :g:`< D C > <0352.g1:< D C >>`, :g:`< B A > <0352.g1:< B A >>` have the same heights respectively;

.. assertion::

   therefore, as the base :g:`< E H > <0352.g1:< E H >>` is to the base :g:`< N Q > <0352.g1:< N Q >>`, so is the height of the solid :g:`< D C > <0352.g1:< D C >>` to the height of the solid :g:`< A B > <0352.g1:< A B >>`.

.. assertion::

   Therefore in the parallelepipedal solids :g:`< A B > <0352.g1:< A B >>`, :g:`< C D > <0352.g1:< C D >>` the bases are reciprocally proportional to the heights.

Again, in the parallelepipedal solids :g:`< A B > <0352.g1:< A B >>`, :g:`< C D > <0352.g1:< C D >>` let the bases be reciprocally proportional to the heights, that is, as the base :g:`< E H > <0352.g1:< E H >>` is to the base :g:`< N Q > <0352.g1:< N Q >>`, so let the height of the solid :g:`< C D > <0352.g1:< C D >>` be to the height of the solid :g:`< A B > <0352.g1:< A B >>`; I say that the solid :g:`< A B > <0352.g1:< A B >>` is :eq:`equal <0352.g1:< A B > = 0352.g1:< C D >>` to the solid :g:`< C D > <0352.g1:< C D >>`.

.. subclause::

   For, with the same construction, since, as the base :g:`< E H > <0352.g1:< E H >>` is to the base :g:`< N Q > <0352.g1:< N Q >>`, so is the height of the solid :g:`< C D > <0352.g1:< C D >>` to the height of the solid :g:`< A B > <0352.g1:< A B >>`, while the base :g:`< E H > <0352.g1:< E H >>` is :eq:`equal <0352.g1:< E H > = 0352.g1:< F K >; 0352.g1:< N Q > = 0352.g1:< O R >>` to the base :g:`< F K > <0352.g1:< F K >>`, and :g:`< N Q > <0352.g1:< N Q >>` to :g:`< O R > <0352.g1:< O R >>`,

.. assertion::

   therefore, as the base :g:`< F K > <0352.g1:< F K >>` is to the base :g:`< O R > <0352.g1:< O R >>`, so is the height of the solid :g:`< C D > <0352.g1:< C D >>` to the height of the solid :g:`< A B > <0352.g1:< A B >>`.

.. subclause::

   But the solids :g:`< A B > <0352.g1:< A B >>`, :g:`< C D > <0352.g1:< C D >>` and :g:`< B T > <0352.g1:< B T >>`, :g:`< D X > <0352.g1:< D X >>` have the same heights respectively;

.. assertion::

   therefore, as the base :g:`< F K > <0352.g1:< F K >>` is to the base :g:`< O R > <0352.g1:< O R >>`, so is the height of the solid :g:`< D X > <0352.g1:< D X >>` to the height of the solid :g:`< B T > <0352.g1:< B T >>`.

.. assertion::

   Therefore in the parallelepipedal solids :g:`< B T > <0352.g1:< B T >>`, :g:`< D X > <0352.g1:< D X >>` the bases are reciprocally proportional to the heights; therefore the solid :g:`< B T > <0352.g1:< B T >>` is :eq:`equal <0352.g1:< B T > = 0352.g1:< D X >>` to the solid :g:`< D X > <0352.g1:< D X >>`. :just:`[Part 1.]`

.. subclause::

   But :g:`< B T > <0352.g1:< B T >>` is :eq:`equal <0352.g1:< B T > = 0352.g1:< B A >>` to :g:`< B A > <0352.g1:< B A >>`, for they are on the same base :g:`< F K > <0352.g1:< F K >>` and of the same height; :just:`[G.476, G.477] <G.476, G.477>` and the solid :g:`< D X > <0352.g1:< D X >>` is :eq:`equal <0352.g1:< D X > = 0352.g1:< D C >>` to the solid :g:`< D C > <0352.g1:< D C >>`. :just:`[G.476, G.477] <G.476, G.477>`

.. qed::

   Therefore the solid :g:`< A B > <0352.g1:< A B >>` is also :eq:`equal <0352.g1:< A B > = 0352.g1:< C D >>` to the solid :g:`< C D > <0352.g1:< C D >>`. :just:`Q. E. D.`
