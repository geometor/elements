G.361
=====

.. rubric:: `X.46 <https://geometor.github.io/euclid/heath/volume_III/book_x/propositions/046/>`_

.. enunciation::

   The side of a rational plus a medial area is divided at one point only.

Let :g:`/ A B / <0103.g1:/ A B />` be the side of a rational plus a medial area divided at :g:`C <0103.g1:C>`, so that :g:`/ A C / <0103.g1:/ A C />`, :g:`/ C B / <0103.g1:/ C B />` are incommensurable in square and make the sum of the squares on :g:`/ A C / <0103.g1:/ A C />`, :g:`/ C B / <0103.g1:/ C B />` medial, but twice the rectangle :g:`/ A C / <0103.g1:/ A C />`, :g:`/ C B / <0103.g1:/ C B />` rational; :just:`[G.355] <G.355>` I say that :g:`/ A B / <0103.g1:/ A B />` is not so divided at another point.

.. picture:: 0103.g1.svg
   :alt: Proposition 46 diagram

For, if possible, let it be divided at :g:`D <0103.g1:D>` also, so that :g:`/ A D / <0103.g1:/ A D />`, :g:`/ D B / <0103.g1:/ D B />` are also incommensurable in square and make the sum of the squares on :g:`/ A D / <0103.g1:/ A D />`, :g:`/ D B / <0103.g1:/ D B />` medial, but twice the rectangle :g:`/ A D / <0103.g1:/ A D />`, :g:`/ D B / <0103.g1:/ D B />` rational.

.. subclause::

   Since then that by which twice the rectangle :g:`/ A C / <0103.g1:/ A C />`, :g:`/ C B / <0103.g1:/ C B />` differs from twice the rectangle :g:`/ A D / <0103.g1:/ A D />`, :g:`/ D B / <0103.g1:/ D B />` is also that by which the squares on :g:`/ A D / <0103.g1:/ A D />`, :g:`/ D B / <0103.g1:/ D B />` differ from the squares on :g:`/ A C / <0103.g1:/ A C />`, :g:`/ C B / <0103.g1:/ C B />`,

.. subclause::

   while twice the rectangle :g:`/ A C / <0103.g1:/ A C />`, :g:`/ C B / <0103.g1:/ C B />` exceeds twice the rectangle :g:`/ A D / <0103.g1:/ A D />`, :g:`/ D B / <0103.g1:/ D B />` by a rational area,

.. assertion::

   therefore the squares on :g:`/ A D / <0103.g1:/ A D />`, :g:`/ D B / <0103.g1:/ D B />` also exceed the squares on :g:`/ A C / <0103.g1:/ A C />`, :g:`/ C B / <0103.g1:/ C B />` by a rational area, though they are medial:

.. assertion:: [G.341] <G.341>

   which is impossible.

.. qed::

   Therefore the side of a rational plus a medial area is not divided at different points; therefore it is divided at one point only. :just:`Q. E. D.`
