G.37
====

.. rubric:: `I.26 <https://geometor.github.io/euclid/heath/volume_I/book_i/propositions/26/>`_

.. enunciation::

   If two triangles have the two angles equal to two angles respectively, and one side equal to one side, namely, either the side adjoining the equal angles,\ [#f1]_ or that subtending one of the equal angles, they will also have the remaining sides equal to the remaining sides and the remaining angle to the remaining angle.

Let :g:`< A B C > <0316.g1:< A B C >>`, :g:`< D E F > <0316.g1:< D E F >>` be two triangles having the two angles :g:`< A B C ) <0316.g1:< A B C )>`, :g:`< B C A ) <0316.g1:< B C A )>` :eq:`equal <0316.g1:< A B C ) = 0316.g1:< D E F ); 0316.g1:< B C A ) = 0316.g1:< E F D )>` to the two angles :g:`< D E F ) <0316.g1:< D E F )>`, :g:`< E F D ) <0316.g1:< E F D )>` respectively, namely the angle :g:`< A B C ) <0316.g1:< A B C )>` to the angle :g:`< D E F ) <0316.g1:< D E F )>`, and the angle :g:`< B C A ) <0316.g1:< B C A )>` to the angle :g:`< E F D ) <0316.g1:< E F D )>`; and let them also have one side :eq:`equal <0316.g1:/ B C / = 0316.g1:/ E F />` to one side, first that adjoining the :eq:`equal <0316.g1:< A B C ) = 0316.g1:< D E F ); 0316.g1:< B C A ) = 0316.g1:< E F D )>` angles, namely :g:`/ B C / <0316.g1:/ B C />` to :g:`/ E F / <0316.g1:/ E F />`;

I say that they will also have the remaining sides :eq:`equal <0316.g1:/ A B / = 0316.g1:/ D E /; 0316.g1:/ A C / = 0316.g1:/ D F /; 0316.g1:< B A C ) = 0316.g1:< E D F )>` to the remaining sides respectively, namely :g:`/ A B / <0316.g1:/ A B />` to :g:`/ D E / <0316.g1:/ D E />` and :g:`/ A C / <0316.g1:/ A C />` to :g:`/ D F / <0316.g1:/ D F />`, and the remaining angle to the remaining angle, namely the angle :g:`< B A C ) <0316.g1:< B A C )>` to the angle :g:`< E D F ) <0316.g1:< E D F )>`.

.. picture:: 0316.g1.svg
   :alt: Folio 0316 Figure 1 - Proposition 26

For, if :g:`/ A B / <0316.g1:/ A B />` is unequal to :g:`/ D E / <0316.g1:/ D E />`, one of them is greater.

Let :g:`/ A B / <0316.g1:/ A B />` be greater, and let :g:`/ B G / <0316.g1:/ B G />` be made :eq:`equal <0316.g1:/ B G / = 0316.g1:/ D E />` to :g:`/ D E / <0316.g1:/ D E />`;

and let :g:`/ G C / <0316.g1:/ G C />` be joined. Then, since :g:`/ B G / <0316.g1:/ B G />` is :eq:`equal <0316.g1:/ B G / = 0316.g1:/ D E /; 0316.g1:/ B C / = 0316.g1:/ E F />` to :g:`/ D E / <0316.g1:/ D E />`, and :g:`/ B C / <0316.g1:/ B C />` to :g:`/ E F / <0316.g1:/ E F />`, the two sides :g:`/ G B / <0316.g1:/ G B />`, :g:`/ B C / <0316.g1:/ B C />` are :eq:`equal <0316.g1:/ G B / = 0316.g1:/ D E /; 0316.g1:/ B C / = 0316.g1:/ E F />` to the two sides :g:`/ D E / <0316.g1:/ D E />`, :g:`/ E F / <0316.g1:/ E F />` respectively; and the angle :g:`< G B C ) <0316.g1:< G B C )>` is :eq:`equal <0316.g1:< G B C ) = 0316.g1:< D E F )>` to the angle :g:`< D E F ) <0316.g1:< D E F )>`;

.. subclause::

   therefore the base :g:`/ G C / <0316.g1:/ G C />` is :eq:`equal <0316.g1:/ G C / = 0316.g1:/ D F />` to the base :g:`/ D F / <0316.g1:/ D F />`,

.. subclause::

   and the triangle :g:`< G B C > <0316.g1:< G B C >>` is :eq:`equal <0316.g1:< G B C > = 0316.g1:< D E F >>` to the triangle :g:`< D E F > <0316.g1:< D E F >>`,

.. subclause:: [G.11] <G.11>

   and the remaining angles will be equal to the remaining angles, namely those which the equal sides subtend;

.. assertion::

   therefore the angle :g:`< G C B ) <0316.g1:< G C B )>` is :eq:`equal <0316.g1:< G C B ) = 0316.g1:< D F E )>` to the angle :g:`< D F E ) <0316.g1:< D F E )>`.

But the angle :g:`< D F E ) <0316.g1:< D F E )>` is by hypothesis :eq:`equal <0316.g1:< D F E ) = 0316.g1:< B C A )>`\ [#f2]_ to the angle :g:`< B C A ) <0316.g1:< B C A )>`;

.. assertion::

   therefore the angle :g:`< B C G ) <0316.g1:< B C G )>` is :eq:`equal <0316.g1:< B C G ) = 0316.g1:< B C A )>` to the angle :g:`< B C A ) <0316.g1:< B C A )>`,

.. assertion::

   the less to the greater: which is impossible.

.. assertion::

   Therefore :g:`/ A B / <0316.g1:/ A B />` is not unequal to :g:`/ D E / <0316.g1:/ D E />`,

.. assertion::

   and is therefore :eq:`equal <0316.g1:/ A B / = 0316.g1:/ D E />` to it.

But :g:`/ B C / <0316.g1:/ B C />` is also :eq:`equal <0316.g1:/ B C / = 0316.g1:/ E F />` to :g:`/ E F / <0316.g1:/ E F />`; therefore the two sides :g:`/ A B / <0316.g1:/ A B />`, :g:`/ B C / <0316.g1:/ B C />` are :eq:`equal <0316.g1:/ A B / = 0316.g1:/ D E /; 0316.g1:/ B C / = 0316.g1:/ E F />` to the two sides :g:`/ D E / <0316.g1:/ D E />`, :g:`/ E F / <0316.g1:/ E F />` respectively, and the angle :g:`< A B C ) <0316.g1:< A B C )>` is :eq:`equal <0316.g1:< A B C ) = 0316.g1:< D E F )>` to the angle :g:`< D E F ) <0316.g1:< D E F )>`;

.. assertion::

   therefore the base :g:`/ A C / <0316.g1:/ A C />` is :eq:`equal <0316.g1:/ A C / = 0316.g1:/ D F />` to the base :g:`/ D F / <0316.g1:/ D F />`,

.. assertion:: [G.11] <G.11>

   and the remaining angle :g:`< B A C ) <0316.g1:< B A C )>` is :eq:`equal <0316.g1:< B A C ) = 0316.g1:< E D F )>` to the remaining angle :g:`< E D F ) <0316.g1:< E D F )>`.

Again, let sides subtending :eq:`equal <0316.g1:< A B C ) = 0316.g1:< D E F ); 0316.g1:< B C A ) = 0316.g1:< E F D )>` angles be :eq:`equal <0316.g1:/ A B / = 0316.g1:/ D E />`, as :g:`/ A B / <0316.g1:/ A B />` to :g:`/ D E / <0316.g1:/ D E />`;

I say again that the remaining sides will be :eq:`equal <0316.g1:/ A C / = 0316.g1:/ D F /; 0316.g1:/ B C / = 0316.g1:/ E F />` to the remaining sides, namely :g:`/ A C / <0316.g1:/ A C />` to :g:`/ D F / <0316.g1:/ D F />` and :g:`/ B C / <0316.g1:/ B C />` to :g:`/ E F / <0316.g1:/ E F />`, and further the remaining angle :g:`< B A C ) <0316.g1:< B A C )>` is :eq:`equal <0316.g1:< B A C ) = 0316.g1:< E D F )>` to the remaining angle :g:`< E D F ) <0316.g1:< E D F )>`.

For, if :g:`/ B C / <0316.g1:/ B C />` is unequal to :g:`/ E F / <0316.g1:/ E F />`, one of them is greater.

Let :g:`/ B C / <0316.g1:/ B C />` be greater, if possible, and let :g:`/ B H / <0316.g1:/ B H />` be made :eq:`equal <0316.g1:/ B H / = 0316.g1:/ E F />` to :g:`/ E F / <0316.g1:/ E F />`; let :g:`/ A H / <0316.g1:/ A H />` be joined. Then, since :g:`/ B H / <0316.g1:/ B H />` is :eq:`equal <0316.g1:/ B H / = 0316.g1:/ E F /; 0316.g1:/ A B / = 0316.g1:/ D E />` to :g:`/ E F / <0316.g1:/ E F />`, and :g:`/ A B / <0316.g1:/ A B />` to :g:`/ D E / <0316.g1:/ D E />`, the two sides :g:`/ A B / <0316.g1:/ A B />`, :g:`/ B H / <0316.g1:/ B H />` are :eq:`equal <0316.g1:/ A B / = 0316.g1:/ D E /; 0316.g1:/ B H / = 0316.g1:/ E F />` to the two sides :g:`/ D E / <0316.g1:/ D E />`, :g:`/ E F / <0316.g1:/ E F />` respectively, and they contain :eq:`equal <0316.g1:< A B C ) = 0316.g1:< D E F )>` angles;

.. subclause::

   therefore the base :g:`/ A H / <0316.g1:/ A H />` is :eq:`equal <0316.g1:/ A H / = 0316.g1:/ D F />` to the base :g:`/ D F / <0316.g1:/ D F />`,

.. subclause::

   and the triangle :g:`< A B H > <0316.g1:< A B H >>` is :eq:`equal <0316.g1:< A B H > = 0316.g1:< D E F >>` to the triangle :g:`< D E F > <0316.g1:< D E F >>`,

.. subclause:: [G.11] <G.11>

   and the remaining angles will be equal to the remaining angles, namely those which the equal sides subtend;

.. assertion::

   therefore the angle :g:`< B H A ) <0316.g1:< B H A )>` is :eq:`equal <0316.g1:< B H A ) = 0316.g1:< E F D )>` to the angle :g:`< E F D ) <0316.g1:< E F D )>`.

But the angle :g:`< E F D ) <0316.g1:< E F D )>` is :eq:`equal <0316.g1:< E F D ) = 0316.g1:< B C A )>` to the angle :g:`< B C A ) <0316.g1:< B C A )>`;

.. assertion::

   therefore, in the triangle :g:`< A H C > <0316.g1:< A H C >>`, the exterior angle :g:`< B H A ) <0316.g1:< B H A )>` is :eq:`equal <0316.g1:< B H A ) = 0316.g1:< B C A )>` to the interior and opposite angle :g:`< B C A ) <0316.g1:< B C A )>`:

.. assertion:: [G.27] <G.27>

   which is impossible.

.. assertion::

   Therefore :g:`/ B C / <0316.g1:/ B C />` is not unequal to :g:`/ E F / <0316.g1:/ E F />`,

.. assertion::

   and is therefore :eq:`equal <0316.g1:/ B C / = 0316.g1:/ E F />` to it.

But :g:`/ A B / <0316.g1:/ A B />` is also :eq:`equal <0316.g1:/ A B / = 0316.g1:/ D E />` to :g:`/ D E / <0316.g1:/ D E />`; therefore the two sides :g:`/ A B / <0316.g1:/ A B />`, :g:`/ B C / <0316.g1:/ B C />` are :eq:`equal <0316.g1:/ A B / = 0316.g1:/ D E /; 0316.g1:/ B C / = 0316.g1:/ E F />` to the two sides :g:`/ D E / <0316.g1:/ D E />`, :g:`/ E F / <0316.g1:/ E F />` respectively, and they contain :eq:`equal <0316.g1:< A B C ) = 0316.g1:< D E F )>` angles;

.. subclause::

   therefore the base :g:`/ A C / <0316.g1:/ A C />` is :eq:`equal <0316.g1:/ A C / = 0316.g1:/ D F />` to the base :g:`/ D F / <0316.g1:/ D F />`,

.. subclause::

   the triangle :g:`< A B C > <0316.g1:< A B C >>` :eq:`equal <0316.g1:< A B C > = 0316.g1:< D E F >>` to the triangle :g:`< D E F > <0316.g1:< D E F >>`,

.. assertion:: [G.11] <G.11>

   and the remaining angle :g:`< B A C ) <0316.g1:< B A C )>` :eq:`equal <0316.g1:< B A C ) = 0316.g1:< E D F )>` to the remaining angle :g:`< E D F ) <0316.g1:< E D F )>`.

.. qed::

   Therefore etc. :just:`Q. E. D.`

.. [#f1] **the side adjoining the equal angles,** πλευρὰν τὴν πρὸς ταῖς ἴσαις γωνίαις.

.. [#f2] **is by hypothesis equal.** ὑπόκειται ἴση, according to the elegant Greek idiom. ὑπόκειμαι is used for the passive of ὑποτίθημι, as κεῖμαι is used for the passive of τίθημι, and so with the other compounds. Cf. προσκεῖσθαι, “to be added.”
