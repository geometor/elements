G.336
=====

.. rubric:: `X.22 <https://geometor.github.io/euclid/heath/volume_III/book_x/propositions/022/>`_

.. enunciation::

   The square on a medial straight line, if applied to a rational straight line, produces as breadth a straight line rational and incommensurable in length with that to which it is applied.

.. picture:: 0055.g1.svg
   :alt: Proposition 22

Let :g:`A <0055.g1:A>` be medial and :g:`/ C B / <0055.g1:/ C B />` rational, and let a rectangular area :g:`< B D > <0055.g1:< B D >>` equal to the square on :g:`A <0055.g1:A>` be applied to :g:`/ B C / <0055.g1:/ B C />`, producing :g:`/ C D / <0055.g1:/ C D />` as breadth;

I say that :g:`/ C D / <0055.g1:/ C D />` is rational and incommensurable in length with :g:`/ C B / <0055.g1:/ C B />`.

.. subclause::

   For, since :g:`A <0055.g1:A>` is medial, the square on it is equal to a rectangular area contained by rational straight lines commensurable in square only. :just:`[G.335] <G.335>`

Let the square on it be equal to :g:`< G F > <0055.g1:< G F >>`.

.. subclause::

   But the square on it is also equal to :g:`< B D > <0055.g1:< B D >>`;

.. assertion::

   therefore :g:`< B D > <0055.g1:< B D >>` is :eq:`equal <0055.g1:< B D > = 0055.g1:< G F >>` to :g:`< G F > <0055.g1:< G F >>`.

.. subclause::

   But it is also equiangular with it; and in equal and equiangular parallelograms the sides about the equal angles are reciprocally proportional; :just:`[G.177] <G.177>`

.. assertion::

   therefore, proportionally, as :g:`/ B C / <0055.g1:/ B C />` is to :g:`/ E G / <0055.g1:/ E G />`, so is :g:`/ E F / <0055.g1:/ E F />` to :g:`/ C D / <0055.g1:/ C D />`.

.. assertion::

   Therefore also, as the square on :g:`/ B C / <0055.g1:/ B C />` is to the square on :g:`/ E G / <0055.g1:/ E G />`, so is the square on :g:`/ E F / <0055.g1:/ E F />` to the square on :g:`/ C D / <0055.g1:/ C D />`. :just:`[G.187] <G.187>`

.. subclause::

   But the square on :g:`/ C B / <0055.g1:/ C B />` is commensurable with the square on :g:`/ E G / <0055.g1:/ E G />`, for each of these straight lines is rational;

.. assertion::

   therefore the square on :g:`/ E F / <0055.g1:/ E F />` is also commensurable with the square on :g:`/ C D / <0055.g1:/ C D />`. :just:`[G.323] <G.323>`

.. subclause::

   But the square on :g:`/ E F / <0055.g1:/ E F />` is rational;

.. assertion:: [G.332] <G.332>

   therefore the square on :g:`/ C D / <0055.g1:/ C D />` is also rational;

.. assertion::

   therefore :g:`/ C D / <0055.g1:/ C D />` is rational.

.. subclause::

   And, since :g:`/ E F / <0055.g1:/ E F />` is incommensurable in length with :g:`/ E G / <0055.g1:/ E G />`, for they are commensurable in square only, and, as :g:`/ E F / <0055.g1:/ E F />` is to :g:`/ E G / <0055.g1:/ E G />`, so is the square on :g:`/ E F / <0055.g1:/ E F />` to the rectangle :g:`/ F E / <0055.g1:/ F E />`, :g:`/ E G / <0055.g1:/ E G />`, :just:`[Lemma]`

.. assertion::

   therefore the square on :g:`/ E F / <0055.g1:/ E F />` is incommensurable with the rectangle :g:`/ F E / <0055.g1:/ F E />`, :g:`/ E G / <0055.g1:/ E G />`. :just:`[G.323] <G.323>`

.. subclause::

   But the square on :g:`/ C D / <0055.g1:/ C D />` is commensurable with the square on :g:`/ E F / <0055.g1:/ E F />`, for the straight lines are rational in square; and the rectangle :g:`/ D C / <0055.g1:/ D C />`, :g:`/ C B / <0055.g1:/ C B />` is commensurable with the rectangle :g:`/ F E / <0055.g1:/ F E />`, :g:`/ E G / <0055.g1:/ E G />`, for they are equal to the square on :g:`A <0055.g1:A>`;

.. assertion::

   therefore the square on :g:`/ C D / <0055.g1:/ C D />` is also incommensurable with the rectangle :g:`/ D C / <0055.g1:/ D C />`, :g:`/ C B / <0055.g1:/ C B />`. :just:`[G.326] <G.326>`

.. subclause::

   But, as the square on :g:`/ C D / <0055.g1:/ C D />` is to the rectangle :g:`/ D C / <0055.g1:/ D C />`, :g:`/ C B / <0055.g1:/ C B />`, so is :g:`/ D C / <0055.g1:/ D C />` to :g:`/ C B / <0055.g1:/ C B />`; :just:`[Lemma]`

.. assertion:: [G.323] <G.323>

   therefore :g:`/ D C / <0055.g1:/ D C />` is incommensurable in length with :g:`/ C B / <0055.g1:/ C B />`.

.. qed::

   Therefore :g:`/ C D / <0055.g1:/ C D />` is rational and incommensurable in length with :g:`/ C B / <0055.g1:/ C B />`. :just:`Q. E. D.`
