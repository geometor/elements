G.165
=====

.. rubric:: `VI.3 <https://geometor.github.io/euclid/heath/volume_II/book_vi/propositions/03/>`_

.. enunciation::

   If an angle of a triangle be bisected and the straight line cutting the angle cut the base also, the segments of the base will have the same ratio as the remaining sides of the triangle; and, if the segments of the base have the same ratio as the

.. enunciation::

   remaining sides of the triangle, the straight line joined from the vertex to the point of section will bisect the angle of the triangle.

Let :g:`< A B C > <0202.g1:< A B C >>` be a triangle, and let the angle :g:`< B A C ) <0202.g1:< B A C )>` be :eq:`bisected <0202.g1:< B A D ) = 0202.g1:< C A D )>` by the straight line :g:`/ A D / <0202.g1:/ A D />`;

I say that, as :g:`/ B D / <0202.g1:/ B D />` is to :g:`/ C D / <0202.g1:/ C D />`, so is :g:`/ B A / <0202.g1:/ B A />` to :g:`/ A C / <0202.g1:/ A C />`.

.. picture:: 0202.g1.svg
   :alt: Proposition 3

For let :g:`/ C E / <0202.g1:/ C E />` be drawn through :g:`C <0202.g1:C>` parallel to :g:`/ D A / <0202.g1:/ D A />`, and let :g:`/ B A / <0202.g1:/ B A />` be carried through and meet it at :g:`E <0202.g1:E>`.

Then, since the straight line :g:`/ A C / <0202.g1:/ A C />` falls upon the parallels :g:`/ A D / <0202.g1:/ A D />`, :g:`/ E C / <0202.g1:/ E C />`,

.. assertion:: [G.42] <G.42>

   the angle :g:`< A C E ) <0202.g1:< A C E )>` is :eq:`equal <0202.g1:< A C E ) = 0202.g1:< C A D )>` to the angle :g:`< C A D ) <0202.g1:< C A D )>`.

But the angle :g:`< C A D ) <0202.g1:< C A D )>` is by hypothesis :eq:`equal <0202.g1:< C A D ) = 0202.g1:< B A D )>` to the angle :g:`< B A D ) <0202.g1:< B A D )>`;

.. assertion::

   therefore the angle :g:`< B A D ) <0202.g1:< B A D )>` is also :eq:`equal <0202.g1:< B A D ) = 0202.g1:< A C E )>` to the angle :g:`< A C E ) <0202.g1:< A C E )>`.

Again, since the straight line :g:`/ B A E / <0202.g1:/ B A E />` falls upon the parallels :g:`/ A D / <0202.g1:/ A D />`, :g:`/ E C / <0202.g1:/ E C />`,

.. assertion::

   the exterior angle :g:`< B A D ) <0202.g1:< B A D )>` is :eq:`equal <0202.g1:< B A D ) = 0202.g1:< A E C )>` to the interior angle :g:`< A E C ) <0202.g1:< A E C )>`. :just:`[G.42] <G.42>`

But the angle :g:`< A C E ) <0202.g1:< A C E )>` was also proved :eq:`equal <0202.g1:< A C E ) = 0202.g1:< B A D )>` to the angle :g:`< B A D ) <0202.g1:< B A D )>`;

.. assertion::

   therefore the angle :g:`< A C E ) <0202.g1:< A C E )>` is also :eq:`equal <0202.g1:< A C E ) = 0202.g1:< A E C )>` to the angle :g:`< A E C ) <0202.g1:< A E C )>`,

.. assertion:: [G.13] <G.13>

   so that the side :g:`/ A E / <0202.g1:/ A E />` is also :eq:`equal <0202.g1:/ A E / = 0202.g1:/ A C />` to the side :g:`/ A C / <0202.g1:/ A C />`.

And, since :g:`/ A D / <0202.g1:/ A D />` has been drawn parallel to :g:`/ E C / <0202.g1:/ E C />`, one of the sides of the triangle :g:`< B C E > <0202.g1:< B C E >>`,

.. assertion::

   therefore, proportionally, as :g:`/ B D / <0202.g1:/ B D />` is to :g:`/ D C / <0202.g1:/ D C />`, so is :g:`/ B A / <0202.g1:/ B A />` to :g:`/ A E / <0202.g1:/ A E />`. :just:`[G.164] <G.164>`

But :g:`/ A E / <0202.g1:/ A E />` is :eq:`equal <0202.g1:/ A E / = 0202.g1:/ A C />` to :g:`/ A C / <0202.g1:/ A C />`;

.. assertion::

   therefore, as :g:`/ B D / <0202.g1:/ B D />` is to :g:`/ D C / <0202.g1:/ D C />`, so is :g:`/ B A / <0202.g1:/ B A />` to :g:`/ A C / <0202.g1:/ A C />`.

Again, let :g:`/ B A / <0202.g1:/ B A />` be to :g:`/ A C / <0202.g1:/ A C />` as :g:`/ B D / <0202.g1:/ B D />` to :g:`/ D C / <0202.g1:/ D C />`, and let :g:`/ A D / <0202.g1:/ A D />` be joined;

I say that the angle :g:`< B A C ) <0202.g1:< B A C )>` has been :eq:`bisected <0202.g1:< B A D ) = 0202.g1:< C A D )>` by the straight line :g:`/ A D / <0202.g1:/ A D />`.

For, with the same construction, since, as :g:`/ B D / <0202.g1:/ B D />` is to :g:`/ D C / <0202.g1:/ D C />`, so is :g:`/ B A / <0202.g1:/ B A />` to :g:`/ A C / <0202.g1:/ A C />`,
and also, as :g:`/ B D / <0202.g1:/ B D />` is to :g:`/ D C / <0202.g1:/ D C />`, so is :g:`/ B A / <0202.g1:/ B A />` to :g:`/ A E / <0202.g1:/ A E />`: for :g:`/ A D / <0202.g1:/ A D />` has been drawn parallel to :g:`/ E C / <0202.g1:/ E C />`, one of the sides of the triangle :g:`< B C E > <0202.g1:< B C E >>`: :just:`[G.164] <G.164>`

.. assertion:: [G.148] <G.148>

   therefore also, as :g:`/ B A / <0202.g1:/ B A />` is to :g:`/ A C / <0202.g1:/ A C />`, so is :g:`/ B A / <0202.g1:/ B A />` to :g:`/ A E / <0202.g1:/ A E />`.

.. assertion::

   Therefore :g:`/ A C / <0202.g1:/ A C />` is :eq:`equal <0202.g1:/ A C / = 0202.g1:/ A E />` to :g:`/ A E / <0202.g1:/ A E />`, :just:`[G.146] <G.146>` so that the angle :g:`< A E C ) <0202.g1:< A E C )>` is also :eq:`equal <0202.g1:< A E C ) = 0202.g1:< A C E )>` to the angle :g:`< A C E ) <0202.g1:< A C E )>`. :just:`[G.12] <G.12>`

But the angle :g:`< A E C ) <0202.g1:< A E C )>` is :eq:`equal <0202.g1:< A E C ) = 0202.g1:< B A D )>` to the exterior angle :g:`< B A D ) <0202.g1:< B A D )>`, :just:`[G.42] <G.42>`

and the angle :g:`< A C E ) <0202.g1:< A C E )>` is :eq:`equal <0202.g1:< A C E ) = 0202.g1:< C A D )>` to the alternate angle :g:`< C A D ) <0202.g1:< C A D )>`; :just:`[G.42] <G.42>`

.. assertion::

   therefore the angle :g:`< B A D ) <0202.g1:< B A D )>` is also :eq:`equal <0202.g1:< B A D ) = 0202.g1:< C A D )>` to the angle :g:`< C A D ) <0202.g1:< C A D )>`.

.. assertion::

   Therefore the angle :g:`< B A C ) <0202.g1:< B A C )>` has been :eq:`bisected <0202.g1:< B A D ) = 0202.g1:< C A D )>` by the straight line :g:`/ A D / <0202.g1:/ A D />`.

.. qed::

   Therefore etc. :just:`Q. E. D.`
