G.560 equal pyramids triangular — Code
======================================

.. rubric:: `XII.9 <https://geometor.github.io/euclid/heath/volume_III/book_xii/propositions/09/>`_

.. enunciation::

   In equal :term:`pyramids <G.553>` which have triangular bases the bases are :term:`reciprocally proportional <G.224>` to the :term:`heights <G.209>`; and those pyramids in which the bases are reciprocally proportional to the heights are equal.
