G.44
====

.. rubric:: `I.31 <https://geometor.github.io/euclid/heath/volume_I/book_i/propositions/31/>`_

.. enunciation::

   Through a given point to draw a straight line parallel to a given straight line.

Let :g:`A <0330.g1:A>` be the given point, and :g:`/ B C / <0330.g1:/ B C />` the given straight line;

thus it is required to draw through the point :g:`A <0330.g1:A>` a straight line parallel to the straight line :g:`/ B C / <0330.g1:/ B C />`.

.. picture:: 0330.g1.svg
   :alt: Folio 0330 Figure 1 - Proposition 31

Let a point :g:`D <0330.g1:D>` be taken at random on :g:`/ B C / <0330.g1:/ B C />`, and let :g:`/ A D / <0330.g1:/ A D />` be joined; on the straight line :g:`/ D A / <0330.g1:/ D A />`, and at the point :g:`A <0330.g1:A>` on it, let the angle :g:`< D A E ) <0330.g1:< D A E )>` be constructed :eq:`equal <0330.g1:< D A E ) = 0330.g1:< A D C )>` to the angle :g:`< A D C ) <0330.g1:< A D C )>` :just:`[G.34] <G.34>`;

and let the straight line :g:`/ A F / <0330.g1:/ A F />` be produced in a straight line with :g:`/ E A / <0330.g1:/ E A />`.

Then, since the straight line :g:`/ A D / <0330.g1:/ A D />` falling on the two straight lines :g:`/ B C / <0330.g1:/ B C />`, :g:`[ E F ] <0330.g1:[ E F ]>` has made the alternate angles :g:`< E A D ) <0330.g1:< E A D )>`, :g:`< A D C ) <0330.g1:< A D C )>` :eq:`equal <0330.g1:< E A D ) = 0330.g1:< A D C )>` to one another,

.. assertion:: [G.39] <G.39>

   therefore :g:`/ E A F / <0330.g1:/ E A F />` is parallel to :g:`/ B C / <0330.g1:/ B C />`.

Therefore through the given point :g:`A <0330.g1:A>` the straight line :g:`/ E A F / <0330.g1:/ E A F />` has been drawn parallel to the given straight line :g:`/ B C / <0330.g1:/ B C />`.

.. qed::

   Q. E. F.
