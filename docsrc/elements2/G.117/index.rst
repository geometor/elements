G.117
=====

.. rubric:: `IV.1 <https://geometor.github.io/euclid/heath/volume_II/book_iv/propositions/01/>`_

.. enunciation::

   Into a given circle to fit a straight line equal to a given straight line which is not greater than the diameter of the circle.

Let :g:`( A B C ) <0086.g1:( A B C )>` be the given circle, and :g:`D <0086.g1:D>` the given straight
line not greater than the diameter
of the circle;
thus it is required to fit into the
circle :g:`( A B C ) <0086.g1:( A B C )>` a straight line :eq:`equal <0086.g1:/ C A / = 0086.g1:D>`
to the straight line :g:`D <0086.g1:D>`.

.. picture:: 0086.g1.svg
   :alt: Diagram for Proposition 1

Let a diameter :g:`/ B C / <0086.g1:/ B C />` of the
circle :g:`( A B C ) <0086.g1:( A B C )>` be drawn.

Then, if :g:`/ B C / <0086.g1:/ B C />` is :eq:`equal <0086.g1:/ B C / = 0086.g1:D>` to :g:`D <0086.g1:D>`,
that which was enjoined will have
been done; for :g:`/ B C / <0086.g1:/ B C />` has been fitted into the circle :g:`( A B C ) <0086.g1:( A B C )>` :eq:`equal <0086.g1:/ B C / = 0086.g1:D>`
to the straight line :g:`D <0086.g1:D>`.

But, if :g:`/ B C / <0086.g1:/ B C />` is greater than :g:`D <0086.g1:D>`,
let :g:`/ C E / <0086.g1:/ C E />` be made :eq:`equal <0086.g1:/ C E / = 0086.g1:D>` to :g:`D <0086.g1:D>`, and with centre :g:`C <0086.g1:C>` and distance
:g:`/ C E / <0086.g1:/ C E />` let the circle :g:`( E A F ) <0086.g1:( E A F )>` be described;
let :g:`/ C A / <0086.g1:/ C A />` be joined.

Then, since the point :g:`C <0086.g1:C>` is the centre of the circle :g:`( E A F ) <0086.g1:( E A F )>`,

.. assertion::

   :g:`/ C A / <0086.g1:/ C A />` is :eq:`equal <0086.g1:/ C A / = 0086.g1:/ C E />` to :g:`/ C E / <0086.g1:/ C E />`.

But :g:`/ C E / <0086.g1:/ C E />` is :eq:`equal <0086.g1:/ C E / = 0086.g1:D>` to :g:`D <0086.g1:D>`;

.. assertion::

   therefore :g:`D <0086.g1:D>` is also :eq:`equal <0086.g1:D = 0086.g1:/ C A />` to :g:`/ C A / <0086.g1:/ C A />`.

Therefore into the given circle :g:`( A B C ) <0086.g1:( A B C )>` there has been fitted
:g:`/ C A / <0086.g1:/ C A />` :eq:`equal <0086.g1:/ C A / = 0086.g1:D>` to the given straight line :g:`D <0086.g1:D>`.
