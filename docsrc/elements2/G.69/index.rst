G.69
====

.. rubric:: `II.8 <https://geometor.github.io/euclid/heath/volume_I/book_ii/propositions/08/>`_

.. enunciation::

   If a straight line be cut at random, four times the rectangle contained by the whole and one of the segments together with the square on the remaining segment is equal to the square described on the whole and the aforesaid segment as on one straight line.

For let a straight line :g:`/ A B / <0404.g1:/ A B />` be cut at random at the point :g:`C <0404.g1:C>`;

I say that four times the rectangle contained by :g:`/ A B / <0404.g1:/ A B />`, :g:`/ B C / <0404.g1:/ B C />` together with the square on :g:`/ A C / <0404.g1:/ A C />` is equal to the square described on :g:`/ A B / <0404.g1:/ A B />`, :g:`/ B C / <0404.g1:/ B C />` as on one straight line.

For let [the straight line] :g:`/ B D / <0404.g1:/ B D />` be produced in a straight line [with :g:`/ A B / <0404.g1:/ A B />`], and let :g:`/ B D / <0404.g1:/ B D />` be made :eq:`equal <0404.g1:/ B D / = 0404.g1:/ C B />` to :g:`/ C B / <0404.g1:/ C B />`; let the square :g:`< A E F D > <0404.g1:< A E F D >>` be described on :g:`/ A D / <0404.g1:/ A D />`, and let the figure be drawn double.

.. picture:: 0404.g1.svg
   :alt: Diagram

Then, since :g:`/ C B / <0404.g1:/ C B />` is :eq:`equal <0404.g1:/ C B / = 0404.g1:/ B D />` to :g:`/ B D / <0404.g1:/ B D />`, while :g:`/ C B / <0404.g1:/ C B />` is :eq:`equal <0404.g1:/ C B / = 0404.g1:/ G K /; 0404.g1:/ B D / = 0404.g1:/ K N />` to :g:`/ G K / <0404.g1:/ G K />`, and :g:`/ B D / <0404.g1:/ B D />` to :g:`/ K N / <0404.g1:/ K N />`, therefore :g:`/ G K / <0404.g1:/ G K />` is also :eq:`equal <0404.g1:/ G K / = 0404.g1:/ K N />` to :g:`/ K N / <0404.g1:/ K N />`.

.. assertion::

   For the same reason :g:`/ Q R / <0404.g1:/ Q R />` is also :eq:`equal <0404.g1:/ Q R / = 0404.g1:/ R P />` to :g:`/ R P / <0404.g1:/ R P />`.

And, since :g:`/ B C / <0404.g1:/ B C />` is :eq:`equal <0404.g1:/ B C / = 0404.g1:/ B D /; 0404.g1:/ G K / = 0404.g1:/ K N />` to :g:`/ B D / <0404.g1:/ B D />`, and :g:`/ G K / <0404.g1:/ G K />` to :g:`/ K N / <0404.g1:/ K N />`, therefore :g:`< C K > <0404.g1:< C K >>` is also :eq:`equal <0404.g1:< C K > = 0404.g1:< K D >; 0404.g1:< G R > = 0404.g1:< R N >>` to :g:`< K D > <0404.g1:< K D >>`, and :g:`< G R > <0404.g1:< G R >>` to :g:`< R N > <0404.g1:< R N >>`. :just:`[G.49] <G.49>`

But :g:`< C K > <0404.g1:< C K >>` is :eq:`equal <0404.g1:< C K > = 0404.g1:< R N >>` to :g:`< R N > <0404.g1:< R N >>`, for they are complements of the parallelogram :g:`< C P > <0404.g1:< C P >>`; :just:`[G.56] <G.56>`

therefore :g:`< K D > <0404.g1:< K D >>` is also :eq:`equal <0404.g1:< K D > = 0404.g1:< G R >>` to :g:`< G R > <0404.g1:< G R >>`; therefore the four areas :g:`< D K > <0404.g1:< D K >>`, :g:`< C K > <0404.g1:< C K >>`, :g:`< G R > <0404.g1:< G R >>`, :g:`< R N > <0404.g1:< R N >>` are :eq:`equal <0404.g1:< D K > = 0404.g1:< C K > = 0404.g1:< G R > = 0404.g1:< R N >>` to one another.

.. assertion::

   Therefore the four are quadruple of :g:`< C K > <0404.g1:< C K >>`.

Again, since :g:`/ C B / <0404.g1:/ C B />` is :eq:`equal <0404.g1:/ C B / = 0404.g1:/ B D />` to :g:`/ B D / <0404.g1:/ B D />`, while :g:`/ B D / <0404.g1:/ B D />` is :eq:`equal <0404.g1:/ B D / = 0404.g1:/ B K / = 0404.g1:/ C G />` to :g:`/ B K / <0404.g1:/ B K />`, that is :g:`/ C G / <0404.g1:/ C G />`, and :g:`/ C B / <0404.g1:/ C B />` is :eq:`equal <0404.g1:/ C B / = 0404.g1:/ G K / = 0404.g1:/ G Q />` to :g:`/ G K / <0404.g1:/ G K />`, that is :g:`/ G Q / <0404.g1:/ G Q />`,

.. assertion::

   therefore :g:`/ C G / <0404.g1:/ C G />` is also :eq:`equal <0404.g1:/ C G / = 0404.g1:/ G Q />` to :g:`/ G Q / <0404.g1:/ G Q />`.

And, since :g:`/ C G / <0404.g1:/ C G />` is :eq:`equal <0404.g1:/ C G / = 0404.g1:/ G Q /; 0404.g1:/ Q R / = 0404.g1:/ R P />` to :g:`/ G Q / <0404.g1:/ G Q />`, and :g:`/ Q R / <0404.g1:/ Q R />` to :g:`/ R P / <0404.g1:/ R P />`, :g:`< A G > <0404.g1:< A G >>` is also :eq:`equal <0404.g1:< A G > = 0404.g1:< M Q >; 0404.g1:< Q L > = 0404.g1:< R F >>` to :g:`< M Q > <0404.g1:< M Q >>`, and :g:`< Q L > <0404.g1:< Q L >>` to :g:`< R F > <0404.g1:< R F >>`. :just:`[G.49] <G.49>`

But :g:`< M Q > <0404.g1:< M Q >>` is :eq:`equal <0404.g1:< M Q > = 0404.g1:< Q L >>` to :g:`< Q L > <0404.g1:< Q L >>`, for they are complements of the parallelogram :g:`< M L > <0404.g1:< M L >>`; :just:`[G.56] <G.56>`

therefore :g:`< A G > <0404.g1:< A G >>` is also :eq:`equal <0404.g1:< A G > = 0404.g1:< R F >>` to :g:`< R F > <0404.g1:< R F >>`; therefore the four areas :g:`< A G > <0404.g1:< A G >>`, :g:`< M Q > <0404.g1:< M Q >>`, :g:`< Q L > <0404.g1:< Q L >>`, :g:`< R F > <0404.g1:< R F >>` are :eq:`equal <0404.g1:< A G > = 0404.g1:< M Q > = 0404.g1:< Q L > = 0404.g1:< R F >>` to one another.

.. assertion::

   Therefore the four are quadruple of :g:`< A G > <0404.g1:< A G >>`.

But the four areas :g:`< C K > <0404.g1:< C K >>`, :g:`< K D > <0404.g1:< K D >>`, :g:`< G R > <0404.g1:< G R >>`, :g:`< R N > <0404.g1:< R N >>` were proved to be quadruple of :g:`< C K > <0404.g1:< C K >>`;

.. assertion::

   therefore the eight areas, which contain the gnomon :g:`< S T U > <0404.g1:< S T U >>`, are quadruple of :g:`< A K > <0404.g1:< A K >>`.

Now, since :g:`< A K > <0404.g1:< A K >>` is the rectangle :g:`/ A B / <0404.g1:/ A B />`, :g:`/ B D / <0404.g1:/ B D />`, for :g:`/ B K / <0404.g1:/ B K />` is :eq:`equal <0404.g1:/ B K / = 0404.g1:/ B D />` to :g:`/ B D / <0404.g1:/ B D />`,
therefore four times the rectangle :g:`/ A B / <0404.g1:/ A B />`, :g:`/ B D / <0404.g1:/ B D />` is quadruple of :g:`< A K > <0404.g1:< A K >>`.

But the gnomon :g:`< S T U > <0404.g1:< S T U >>` was also proved to be quadruple of :g:`< A K > <0404.g1:< A K >>`;

.. assertion::

   therefore four times the rectangle :g:`/ A B / <0404.g1:/ A B />`, :g:`/ B D / <0404.g1:/ B D />` is equal to the gnomon :g:`< S T U > <0404.g1:< S T U >>`.

Let :g:`< O H > <0404.g1:< O H >>`, which is equal to the square on :g:`/ A C / <0404.g1:/ A C />`, be added to each;

.. assertion::

   therefore four times the rectangle :g:`/ A B / <0404.g1:/ A B />`, :g:`/ B D / <0404.g1:/ B D />` together with the square on :g:`/ A C / <0404.g1:/ A C />` is equal to the gnomon :g:`< S T U > <0404.g1:< S T U >>` and :g:`< O H > <0404.g1:< O H >>`.

But the gnomon :g:`< S T U > <0404.g1:< S T U >>` and :g:`< O H > <0404.g1:< O H >>` are the whole square :g:`< A E F D > <0404.g1:< A E F D >>`, which is described on :g:`/ A D / <0404.g1:/ A D />`;

.. assertion::

   therefore four times the rectangle :g:`/ A B / <0404.g1:/ A B />`, :g:`/ B D / <0404.g1:/ B D />` together with the square on :g:`/ A C / <0404.g1:/ A C />` is equal to the square on :g:`/ A D / <0404.g1:/ A D />`.

But :g:`/ B D / <0404.g1:/ B D />` is :eq:`equal <0404.g1:/ B D / = 0404.g1:/ B C />` to :g:`/ B C / <0404.g1:/ B C />`;

.. assertion::

   therefore four times the rectangle contained by :g:`/ A B / <0404.g1:/ A B />`, :g:`/ B C / <0404.g1:/ B C />` together with the square on :g:`/ A C / <0404.g1:/ A C />` is equal to the square on :g:`/ A D / <0404.g1:/ A D />`, that is to the square described on :g:`/ A B / <0404.g1:/ A B />` and :g:`/ B C / <0404.g1:/ B C />` as on one straight line.

.. qed::

   Therefore etc. :just:`Q. E. D.`
