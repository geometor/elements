G.544 equal parallelepipedal solids — Heath
===========================================

.. rubric:: `XI.34 <https://geometor.github.io/euclid/heath/volume_III/book_xi/propositions/34/>`_

.. enunciation::

   In equal parallelepipedal :term:`solids <G.529>` the bases are :term:`reciprocally proportional <G.224>` to the :term:`heights <G.209>`; and those parallelepipedal solids in which the bases are reciprocally proportional to the heights are equal.

Let :g:`< A B > <g1:< A B >>`, :g:`< C D > <g1:< C D >>` be :eq:`equal <g1:< A B > = g1:< C D >>` parallelepipedal solids; I say that in the parallelepipedal solids :g:`< A B > <g1:< A B >>`, :g:`< C D > <g1:< C D >>` the bases are reciprocally proportional to the heights, that is, as the base :g:`< E H > <g1:< E H >>` is to the base :g:`< N Q > <g1:< N Q >>`, so is the height of the solid :g:`< C D > <g1:< C D >>` to the height of the solid :g:`< A B > <g1:< A B >>`.

First, let the sides which stand up, namely :g:`/ A G / <g1:/ A G />`, :g:`/ E F / <g1:/ E F />`, :g:`/ L B / <g1:/ L B />`, :g:`/ H K / <g1:/ H K />`, :g:`/ C M / <g1:/ C M />`, :g:`/ N O / <g1:/ N O />`, :g:`/ P D / <g1:/ P D />`, :g:`/ Q R / <g1:/ Q R />`, be at :eq:`right angles <g1:/ A G / = g1:< E H >; g1:/ E F / = g1:< E H >; g1:/ L B / = g1:< E H >; g1:/ H K / = g1:< E H >; g1:/ C M / = g1:< N Q >; g1:/ N O / = g1:< N Q >; g1:/ P D / = g1:< N Q >; g1:/ Q R / = g1:< N Q >>` to their bases; I say that, as the base :g:`< E H > <g1:< E H >>` is to the base :g:`< N Q > <g1:< N Q >>`, so is :g:`/ C M / <g1:/ C M />` to :g:`/ A G / <g1:/ A G />`.

.. subclause::

   If now the base :g:`< E H > <g1:< E H >>` is :eq:`equal <g1:< E H > = g1:< N Q >>` to the base :g:`< N Q > <g1:< N Q >>`, while the solid :g:`< A B > <g1:< A B >>` is also :eq:`equal <g1:< A B > = g1:< C D >>` to the solid :g:`< C D > <g1:< C D >>`,

.. assertion::

   :g:`/ C M / <g1:/ C M />` will also be :eq:`equal <g1:/ C M / = g1:/ A G />` to :g:`/ A G / <g1:/ A G />`.

.. assertion::

   For parallelepipedal solids of the same height are to one another as the bases; :just:`[G.542] <G.542>` and, as the base :g:`< E H > <g1:< E H >>` is to :g:`< N Q > <g1:< N Q >>`, so will :g:`/ C M / <g1:/ C M />` be to :g:`/ A G / <g1:/ A G />`, and it is manifest that in the parallelepipedal solids :g:`< A B > <g1:< A B >>`, :g:`< C D > <g1:< C D >>` the bases are reciprocally proportional to the heights.

Next, let the base :g:`< E H > <g1:< E H >>` not be equal to the base :g:`< N Q > <g1:< N Q >>`, but let :g:`< E H > <g1:< E H >>` be greater.

.. picture:: g1.svg
   :alt: Proposition 34, Diagram 1

.. subclause::

   Now the solid :g:`< A B > <g1:< A B >>` is :eq:`equal <g1:< A B > = g1:< C D >>` to the solid :g:`< C D > <g1:< C D >>`;

.. assertion::

   therefore :g:`/ C M / <g1:/ C M />` is also greater than :g:`/ A G / <g1:/ A G />`.

Let then :g:`/ C T / <g1:/ C T />` be made :eq:`equal <g1:/ C T / = g1:/ A G />` to :g:`/ A G / <g1:/ A G />`, and let the parallelepipedal solid :g:`< V C > <g1:< V C >>` be completed on :g:`< N Q > <g1:< N Q >>` as base and with :g:`/ C T / <g1:/ C T />` as height.

.. subclause::

   Now, since the solid :g:`< A B > <g1:< A B >>` is :eq:`equal <g1:< A B > = g1:< C D >>` to the solid :g:`< C D > <g1:< C D >>`, and :g:`< C V > <g1:< C V >>` is outside them, while equals have to the same the :term:`same ratio <G.176>`, :just:`[G.183] <G.183>`

.. assertion::

   therefore, as the solid :g:`< A B > <g1:< A B >>` is to the solid :g:`< C V > <g1:< C V >>`, so is the solid :g:`< C D > <g1:< C D >>` to the solid :g:`< C V > <g1:< C V >>`.

.. subclause::

   But, as the solid :g:`< A B > <g1:< A B >>` is to the solid :g:`< C V > <g1:< C V >>`, so is the base :g:`< E H > <g1:< E H >>` to the base :g:`< N Q > <g1:< N Q >>`, for the solids :g:`< A B > <g1:< A B >>`, :g:`< C V > <g1:< C V >>` are of equal height; :just:`[G.542] <G.542>` and, as the solid :g:`< C D > <g1:< C D >>` is to the solid :g:`< C V > <g1:< C V >>`, so is the base :g:`< M Q > <g1:< M Q >>` to the base :g:`< T Q > <g1:< T Q >>` :just:`[G.531] <G.531>` and :g:`/ C M / <g1:/ C M />` to :g:`/ C T / <g1:/ C T />` :just:`[G.210] <G.210>`;

.. assertion::

   therefore also, as the base :g:`< E H > <g1:< E H >>` is to the base :g:`< N Q > <g1:< N Q >>`, so is :g:`/ M C / <g1:/ M C />` to :g:`/ C T / <g1:/ C T />`.

.. subclause::

   But :g:`/ C T / <g1:/ C T />` is :eq:`equal <g1:/ C T / = g1:/ A G />` to :g:`/ A G / <g1:/ A G />`;

.. assertion::

   therefore also, as the base :g:`< E H > <g1:< E H >>` is to the base :g:`< N Q > <g1:< N Q >>`, so is :g:`/ M C / <g1:/ M C />` to :g:`/ A G / <g1:/ A G />`.

.. assertion::

   Therefore in the parallelepipedal solids :g:`< A B > <g1:< A B >>`, :g:`< C D > <g1:< C D >>` the bases are reciprocally proportional to the heights.

Again, in the parallelepipedal solids :g:`< A B > <g1:< A B >>`, :g:`< C D > <g1:< C D >>` let the bases be reciprocally proportional to the heights, that is, as the base :g:`< E H > <g1:< E H >>` is to the base :g:`< N Q > <g1:< N Q >>`, so let the height of the solid :g:`< C D > <g1:< C D >>` be to the height of the solid :g:`< A B > <g1:< A B >>`; I say that the solid :g:`< A B > <g1:< A B >>` is :eq:`equal <g1:< A B > = g1:< C D >>` to the solid :g:`< C D > <g1:< C D >>`.

Let the sides which stand up be again :term:`at right angles <G.33>` to the bases.

.. subclause::

   Now, if the base :g:`< E H > <g1:< E H >>` is :eq:`equal <g1:< E H > = g1:< N Q >>` to the base :g:`< N Q > <g1:< N Q >>`, and, as the base :g:`< E H > <g1:< E H >>` is to the base :g:`< N Q > <g1:< N Q >>`, so is the height of the solid :g:`< C D > <g1:< C D >>` to the height of the solid :g:`< A B > <g1:< A B >>`,

.. assertion::

   therefore the height of the solid :g:`< C D > <g1:< C D >>` is also equal to the height of the solid :g:`< A B > <g1:< A B >>`.

.. subclause::

   But parallelepipedal solids on equal bases and of the same height are equal to one another; :just:`[G.541] <G.541>`

.. assertion::

   therefore the solid :g:`< A B > <g1:< A B >>` is :eq:`equal <g1:< A B > = g1:< C D >>` to the solid :g:`< C D > <g1:< C D >>`.

.. subclause::

   Next, let the base :g:`< E H > <g1:< E H >>` not be equal to the base :g:`< N Q > <g1:< N Q >>`, but let :g:`< E H > <g1:< E H >>` be greater;

.. assertion::

   therefore the height of the solid :g:`< C D > <g1:< C D >>` is also greater than the height of the solid :g:`< A B > <g1:< A B >>`, that is, :g:`/ C M / <g1:/ C M />` is greater than :g:`/ A G / <g1:/ A G />`.

Let :g:`/ C T / <g1:/ C T />` be again made :eq:`equal <g1:/ C T / = g1:/ A G />` to :g:`/ A G / <g1:/ A G />`, and let the solid :g:`< C V > <g1:< C V >>` be similarly completed.

.. subclause::

   Since, as the base :g:`< E H > <g1:< E H >>` is to the base :g:`< N Q > <g1:< N Q >>`, so is :g:`/ M C / <g1:/ M C />` to :g:`/ A G / <g1:/ A G />`, while :g:`/ A G / <g1:/ A G />` is :eq:`equal <g1:/ A G / = g1:/ C T />` to :g:`/ C T / <g1:/ C T />`,

.. assertion::

   therefore, as the base :g:`< E H > <g1:< E H >>` is to the base :g:`< N Q > <g1:< N Q >>`, so is :g:`/ C M / <g1:/ C M />` to :g:`/ C T / <g1:/ C T />`.

.. subclause::

   But, as the base :g:`< E H > <g1:< E H >>` is to the base :g:`< N Q > <g1:< N Q >>`, so is the solid :g:`< A B > <g1:< A B >>` to the solid :g:`< C V > <g1:< C V >>`, for the solids :g:`< A B > <g1:< A B >>`, :g:`< C V > <g1:< C V >>` are of equal height; :just:`[G.542] <G.542>` and, as :g:`/ C M / <g1:/ C M />` is to :g:`/ C T / <g1:/ C T />`, so is the base :g:`< M Q > <g1:< M Q >>` to the base :g:`< Q T > <g1:< Q T >>` :just:`[G.210] <G.210>` and the solid :g:`< C D > <g1:< C D >>` to the solid :g:`< C V > <g1:< C V >>`. :just:`[G.531] <G.531>`

.. assertion::

   Therefore also, as the solid :g:`< A B > <g1:< A B >>` is to the solid :g:`< C V > <g1:< C V >>`, so is the solid :g:`< C D > <g1:< C D >>` to the solid :g:`< C V > <g1:< C V >>`; therefore each of the solids :g:`< A B > <g1:< A B >>`, :g:`< C D > <g1:< C D >>` has to :g:`< C V > <g1:< C V >>` the same ratio.

.. assertion:: [G.187] <G.187>

   Therefore the solid :g:`< A B > <g2:< A B >>` is :eq:`equal <g2:< A B > = g2:< C D >>` to the solid :g:`< C D > <g2:< C D >>`.

Now let the sides which stand up, :g:`/ F E / <g2:/ F E />`, :g:`/ B L / <g2:/ B L />`, :g:`/ G A / <g2:/ G A />`, :g:`/ H K / <g2:/ H K />`, :g:`/ O N / <g2:/ O N />`, :g:`/ D P / <g2:/ D P />`, :g:`/ M C / <g2:/ M C />`, :g:`/ R Q / <g2:/ R Q />`, not be at right angles to their bases; let perpendiculars be drawn from the :term:`points <G.1>` :g:`F <g2:F>`, :g:`G <g2:G>`, :g:`B <g2:B>`, :g:`K <g2:K>`, :g:`O <g2:O>`, :g:`M <g2:M>`, :g:`D <g2:D>`, :g:`R <g2:R>` to the :term:`planes <G.7>` through :g:`< E H > <g2:< E H >>`, :g:`< N Q > <g2:< N Q >>`, and let them meet the planes at :g:`S <g2:S>`, :g:`T <g2:T>`, :g:`U <g2:U>`, :g:`V <g2:V>`, :g:`W <g2:W>`, :g:`X <g2:X>`, :g:`Y <g2:Y>`, :g:`a <g2:a>`, and let the solids :g:`< F V > <g2:< F V >>`, :g:`< O a > <g2:< O a >>` be completed; I say that, in this case too, if the solids :g:`< A B > <g2:< A B >>`, :g:`< C D > <g2:< C D >>` are :eq:`equal <g2:< A B > = g2:< C D >>`, the bases are reciprocally proportional to the heights, that is, as the base :g:`< E H > <g2:< E H >>` is to the base :g:`< N Q > <g2:< N Q >>`, so is the height of the solid :g:`< C D > <g2:< C D >>` to the height of the solid :g:`< A B > <g2:< A B >>`.

.. picture:: g2.svg
   :alt: Proposition 34, Diagram 2

.. subclause::

   Since the solid :g:`< A B > <g2:< A B >>` is :eq:`equal <g2:< A B > = g2:< C D >>` to the solid :g:`< C D > <g2:< C D >>`, while :g:`< A B > <g2:< A B >>` is :eq:`equal <g2:< A B > = g2:< B T >>` to :g:`< B T > <g2:< B T >>`, for they are on the same base :g:`< F K > <g2:< F K >>` and of the same height; :just:`[G.539, G.540] <G.539, G.540>` and the solid :g:`< C D > <g2:< C D >>` is :eq:`equal <g2:< C D > = g2:< D X >>` to :g:`< D X > <g2:< D X >>`, for they are again on the same base :g:`< R O > <g2:< R O >>` and of the same height; :just:`[G.539, G.540] <G.539, G.540>`

.. assertion::

   therefore the solid :g:`< B T > <g2:< B T >>` is also :eq:`equal <g2:< B T > = g2:< D X >>` to the solid :g:`< D X > <g2:< D X >>`.

.. assertion::

   Therefore, as the base :g:`< F K > <g2:< F K >>` is to the base :g:`< O R > <g2:< O R >>`, so is the height of the solid :g:`< D X > <g2:< D X >>` to the height of the solid :g:`< B T > <g2:< B T >>`. :just:`[Part 1.]`

.. subclause::

   But the base :g:`< F K > <g2:< F K >>` is :eq:`equal <g2:< F K > = g2:< E H >; g2:< O R > = g2:< N Q >>` to the base :g:`< E H > <g2:< E H >>`, and the base :g:`< O R > <g2:< O R >>` to the base :g:`< N Q > <g2:< N Q >>`;

.. assertion::

   therefore, as the base :g:`< E H > <g2:< E H >>` is to the base :g:`< N Q > <g2:< N Q >>`, so is the height of the solid :g:`< D X > <g2:< D X >>` to the height of the solid :g:`< B T > <g2:< B T >>`.

.. subclause::

   But the solids :g:`< D X > <g2:< D X >>`, :g:`< B T > <g2:< B T >>` and the solids :g:`< D C > <g2:< D C >>`, :g:`< B A > <g2:< B A >>` have the same heights respectively;

.. assertion::

   therefore, as the base :g:`< E H > <g2:< E H >>` is to the base :g:`< N Q > <g2:< N Q >>`, so is the height of the solid :g:`< D C > <g2:< D C >>` to the height of the solid :g:`< A B > <g2:< A B >>`.

.. assertion::

   Therefore in the parallelepipedal solids :g:`< A B > <g2:< A B >>`, :g:`< C D > <g2:< C D >>` the bases are reciprocally proportional to the heights.

Again, in the parallelepipedal solids :g:`< A B > <g2:< A B >>`, :g:`< C D > <g2:< C D >>` let the bases be reciprocally proportional to the heights, that is, as the base :g:`< E H > <g2:< E H >>` is to the base :g:`< N Q > <g2:< N Q >>`, so let the height of the solid :g:`< C D > <g2:< C D >>` be to the height of the solid :g:`< A B > <g2:< A B >>`; I say that the solid :g:`< A B > <g2:< A B >>` is :eq:`equal <g2:< A B > = g2:< C D >>` to the solid :g:`< C D > <g2:< C D >>`.

.. subclause::

   For, with the same construction, since, as the base :g:`< E H > <g2:< E H >>` is to the base :g:`< N Q > <g2:< N Q >>`, so is the height of the solid :g:`< C D > <g2:< C D >>` to the height of the solid :g:`< A B > <g2:< A B >>`, while the base :g:`< E H > <g2:< E H >>` is :eq:`equal <g2:< E H > = g2:< F K >; g2:< N Q > = g2:< O R >>` to the base :g:`< F K > <g2:< F K >>`, and :g:`< N Q > <g2:< N Q >>` to :g:`< O R > <g2:< O R >>`,

.. assertion::

   therefore, as the base :g:`< F K > <g2:< F K >>` is to the base :g:`< O R > <g2:< O R >>`, so is the height of the solid :g:`< C D > <g2:< C D >>` to the height of the solid :g:`< A B > <g2:< A B >>`.

.. subclause::

   But the solids :g:`< A B > <g2:< A B >>`, :g:`< C D > <g2:< C D >>` and :g:`< B T > <g2:< B T >>`, :g:`< D X > <g2:< D X >>` have the same heights respectively;

.. assertion::

   therefore, as the base :g:`< F K > <g2:< F K >>` is to the base :g:`< O R > <g2:< O R >>`, so is the height of the solid :g:`< D X > <g2:< D X >>` to the height of the solid :g:`< B T > <g2:< B T >>`.

.. assertion::

   Therefore in the parallelepipedal solids :g:`< B T > <g2:< B T >>`, :g:`< D X > <g2:< D X >>` the bases are reciprocally proportional to the heights; therefore the solid :g:`< B T > <g2:< B T >>` is :eq:`equal <g2:< B T > = g2:< D X >>` to the solid :g:`< D X > <g2:< D X >>`. :just:`[Part 1.]`

.. subclause::

   But :g:`< B T > <g2:< B T >>` is :eq:`equal <g2:< B T > = g2:< B A >>` to :g:`< B A > <g2:< B A >>`, for they are on the same base :g:`< F K > <g2:< F K >>` and of the same height; :just:`[G.539, G.540] <G.539, G.540>` and the solid :g:`< D X > <g2:< D X >>` is :eq:`equal <g2:< D X > = g2:< D C >>` to the solid :g:`< D C > <g2:< D C >>`. :just:`[G.539, G.540] <G.539, G.540>`

.. qed::

   Therefore the solid :g:`< A B > <g2:< A B >>` is also :eq:`equal <g2:< A B > = g2:< C D >>` to the solid :g:`< C D > <g2:< C D >>`. :just:`Q. E. D.`
