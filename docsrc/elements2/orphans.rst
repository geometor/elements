**Heath ID:** `XI.def.18 <https://geometor.github.io/euclid/heath/volume_III/book_xi/definitions/#xi-def-18>`_

When, one side of those about the right angle in a right-angled triangle remaining fixed, the triangle is carried round and restored again to the same position from which it began to be moved, the figure so comprehended is a :term:`**cone** <cone>`.

And, if the straight line which remains fixed be equal to the remaining side about the right angle which is carried round, the cone will be :term:`**right-angled** <right-angled-cone>`; if less, :term:`**obtuse-angled** <obtuse-angled-cone>`; and if greater, :term:`**acute-angled** <acute-angled-cone>`.

----

The :term:`**axis of the cone** <axis-of-cone>` is the straight line which remains fixed and about which the triangle is turned.

XI.def.21
---------

When, one side of those about the right angle in a rectangular parallelogram remaining fixed, the parallelogram is carried round and restored again to the same position from which it began to be moved, the figure so comprehended is a :term:`**cylinder** <cylinder>`.

----
