G.547 segments proportional parallelepipedal
============================================

.. rubric:: `XI.37 <https://geometor.github.io/euclid/heath/volume_III/book_xi/propositions/37/>`_

.. enunciation::

   If four :term:`segments <G.4>` be :term:`proportional <G.180>`, the parallelepipedal :term:`solids <G.529>` on them which are similar and :term:`similarly described <G.217>` is proportional; and, if the parallelepipedal solids on them which are similar and similarly described be proportional, the segments will themselves also be proportional.

.. signature:: theorem

   | :fn:`segments_proportional_parallelepipedal_xi_37 <G.547>`\ (:g:`/ A B / <g1:/ A B />`, :g:`/ C D / <g1:/ C D />`, :g:`/ E F / <g1:/ E F />`, :g:`/ G H / <g1:/ G H />`)
   | **given** :g:`/ A B / <g1:/ A B />`, :g:`/ C D / <g1:/ C D />`, :g:`/ E F / <g1:/ E F />`, :g:`/ G H / <g1:/ G H />` be four segments in proportion, so that, as :g:`/ A B / <g1:/ A B />` is to :g:`/ C D / <g1:/ C D />`, so is :g:`/ E F / <g1:/ E F />` to :g:`/ G H / <g1:/ G H />`
   | **prove** also, as :g:`/ A B / <g1:/ A B />` is to :g:`/ C D / <g1:/ C D />`, so is :g:`/ E F / <g1:/ E F />` to :g:`/ G H / <g1:/ G H />`

.. step:: given

   :g:`/ A B / <g1:/ A B />`, :g:`/ C D / <g1:/ C D />`, :g:`/ E F / <g1:/ E F />`, :g:`/ G H / <g1:/ G H />` be four segments in proportion, so that, as :g:`/ A B / <g1:/ A B />` is to :g:`/ C D / <g1:/ C D />`, so is :g:`/ E F / <g1:/ E F />` to :g:`/ G H / <g1:/ G H />`

.. step:: construct

   And let there be described on :g:`/ A B / <g1:/ A B />`, :g:`/ C D / <g1:/ C D />`, :g:`/ E F / <g1:/ E F />`, :g:`/ G H / <g1:/ G H />` the similar and similarly situated parallelepipedal solids :g:`< K A > <g1:< K A >>`, :g:`< L C > <g1:< L C >>`, :g:`< M E > <g1:< M E >>`, :g:`< N G > <g1:< N G >>`

.. step:: assert

   I say that, as :g:`< K A > <g1:< K A >>` is to :g:`< L C > <g1:< L C >>`, so is :g:`< M E > <g1:< M E >>` to :g:`< N G > <g1:< N G >>`

.. step:: assert

   the parallelepipedal solid :g:`< K A > <g1:< K A >>` is similar to :g:`< L C > <g1:< L C >>`,

.. step:: assert ∵ similar_parallelepipedal_solids <G.543>

   :g:`< K A > <g1:< K A >>` has to :g:`< L C > <g1:< L C >>` the ratio triplicate of that which :g:`/ A B / <g1:/ A B />` has to :g:`/ C D / <g1:/ C D />`

.. step:: assert ∵ similar_parallelepipedal_solids <G.543>

   For the same reason :g:`< M E > <g1:< M E >>` also has to :g:`< N G > <g1:< N G >>` the :term:`ratio <G.173>` triplicate of that which :g:`/ E F / <g1:/ E F />` has to :g:`/ G H / <g1:/ G H />`

.. step:: assert

   as :g:`/ A B / <g1:/ A B />` is to :g:`/ C D / <g1:/ C D />`, so is :g:`/ E F / <g1:/ E F />` to :g:`/ G H / <g1:/ G H />`

.. step:: assert

   also, as :g:`< A K > <g1:< A K >>` is to :g:`< L C > <g1:< L C >>`, so is :g:`< M E > <g1:< M E >>` to :g:`< N G > <g1:< N G >>`

.. step:: assert

   Next, as the solid :g:`< A K > <g1:< A K >>` is to the solid :g:`< L C > <g1:< L C >>`, so let the solid :g:`< M E > <g1:< M E >>` be to the solid :g:`< N G > <g1:< N G >>`

.. step:: assert

   I say that, as :g:`/ A B / <g1:/ A B />` is to :g:`/ C D / <g1:/ C D />`, so is :g:`/ E F / <g1:/ E F />` to :g:`/ G H / <g1:/ G H />`

.. step:: assert ∵ similar_parallelepipedal_solids <G.543>

   For since, again, :g:`< K A > <g1:< K A >>` has to :g:`< L C > <g1:< L C >>` the ratio triplicate of that which :g:`/ A B / <g1:/ A B />` has to :g:`/ C D / <g1:/ C D />`, and :g:`< M E > <g1:< M E >>` also has to :g:`< N G > <g1:< N G >>` the ratio triplicate of that which :g:`/ E F / <g1:/ E F />` has to :g:`/ G H / <g1:/ G H />`, and, as :g:`< K A > <g1:< K A >>` is to :g:`< L C > <g1:< L C >>`, so is :g:`< M E > <g1:< M E >>` to :g:`< N G > <g1:< N G >>`

.. step:: conclude

   also, as :g:`/ A B / <g1:/ A B />` is to :g:`/ C D / <g1:/ C D />`, so is :g:`/ E F / <g1:/ E F />` to :g:`/ G H / <g1:/ G H />`
