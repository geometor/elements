G.514
=====

.. rubric:: `XIII.7 <https://geometor.github.io/euclid/heath/volume_III/book_xiii/propositions/07/>`_

.. enunciation::

   If three angles of an equilateral pentagon, taken either in order or not in order, be equal, the pentagon will be equiangular.

For in the :eq:`equilateral <0455.g1:/ A B / = 0455.g1:/ B C / = 0455.g1:/ C D / = 0455.g1:/ D E / = 0455.g1:/ E A />` pentagon :g:`< A B C D E > <0455.g1:< A B C D E >>` let, first, three angles taken in order, those at :g:`A <0455.g1:A>`, :g:`B <0455.g1:B>`, :g:`C <0455.g1:C>`, be :eq:`equal <0455.g1:< B A E ) = 0455.g1:< C B A ) = 0455.g1:< B C D )>` to one another; I say that the pentagon :g:`< A B C D E > <0455.g1:< A B C D E >>` is equiangular.

.. picture:: 0455.g1.svg
   :alt: Book XIII, Proposition 7

For let :g:`/ A C / <0455.g1:/ A C />`, :g:`/ B E / <0455.g1:/ B E />`, :g:`/ F D / <0455.g1:/ F D />` be joined.

.. subclause::

   Now, since the two sides :g:`/ C B / <0455.g1:/ C B />`, :g:`/ B A / <0455.g1:/ B A />` are :eq:`equal <0455.g1:/ C B / = 0455.g1:/ B A / = 0455.g1:/ A E />` to the two sides :g:`/ B A / <0455.g1:/ B A />`, :g:`/ A E / <0455.g1:/ A E />` respectively, and the angle :g:`< C B A ) <0455.g1:< C B A )>` is :eq:`equal <0455.g1:< C B A ) = 0455.g1:< B A E )>` to the angle :g:`< B A E ) <0455.g1:< B A E )>`,

.. assertion::

   therefore the base :g:`/ A C / <0455.g1:/ A C />` is :eq:`equal <0455.g1:/ A C / = 0455.g1:/ B E />` to the base :g:`/ B E / <0455.g1:/ B E />`, the triangle :g:`< A B C > <0455.g1:< A B C >>` is :eq:`equal <0455.g1:< A B C > = 0455.g1:< A B E >>` to the triangle :g:`< A B E > <0455.g1:< A B E >>`, and the remaining angles will be :eq:`equal <0455.g1:< B C A ) = 0455.g1:< B E A ); 0455.g1:< A B E ) = 0455.g1:< C A B )>` to the remaining angles, namely those which the equal sides subtend, :just:`[G.11] <G.11>` that is, the angle :g:`< B C A ) <0455.g1:< B C A )>` to the angle :g:`< B E A ) <0455.g1:< B E A )>`, and the angle :g:`< A B E ) <0455.g1:< A B E )>` to the angle :g:`< C A B ) <0455.g1:< C A B )>`;

.. assertion:: [G.13] <G.13>

   hence the side :g:`/ A F / <0455.g1:/ A F />` is also :eq:`equal <0455.g1:/ A F / = 0455.g1:/ B F />` to the side :g:`/ B F / <0455.g1:/ B F />`.

.. subclause::

   But the whole :g:`/ A C / <0455.g1:/ A C />` was also proved :eq:`equal <0455.g1:/ A C / = 0455.g1:/ B E />` to the whole :g:`/ B E / <0455.g1:/ B E />`;

.. assertion::

   therefore the remainder :g:`/ F C / <0455.g1:/ F C />` is also :eq:`equal <0455.g1:/ F C / = 0455.g1:/ F E />` to the remainder :g:`/ F E / <0455.g1:/ F E />`.

.. subclause::

   But :g:`/ C D / <0455.g1:/ C D />` is also :eq:`equal <0455.g1:/ C D / = 0455.g1:/ D E />` to :g:`/ D E / <0455.g1:/ D E />`. Therefore the two sides :g:`/ F C / <0455.g1:/ F C />`, :g:`/ C D / <0455.g1:/ C D />` are :eq:`equal <0455.g1:/ F C / = 0455.g1:/ F E /; 0455.g1:/ C D / = 0455.g1:/ E D />` to the two sides :g:`/ F E / <0455.g1:/ F E />`, :g:`/ E D / <0455.g1:/ E D />`; and the base :g:`/ F D / <0455.g1:/ F D />` is common to them;

.. assertion:: [G.15] <G.15>

   therefore the angle :g:`< F C D ) <0455.g1:< F C D )>` is :eq:`equal <0455.g1:< F C D ) = 0455.g1:< F E D )>` to the angle :g:`< F E D ) <0455.g1:< F E D )>`.

.. subclause::

   But the angle :g:`< B C A ) <0455.g1:< B C A )>` was also proved :eq:`equal <0455.g1:< B C A ) = 0455.g1:< A E B )>` to the angle :g:`< A E B ) <0455.g1:< A E B )>`;

.. assertion::

   therefore the whole angle :g:`< B C D ) <0455.g1:< B C D )>` is also :eq:`equal <0455.g1:< B C D ) = 0455.g1:< A E D )>` to the whole angle :g:`< A E D ) <0455.g1:< A E D )>`.

.. subclause::

   But, by hypothesis, the angle :g:`< B C D ) <0455.g1:< B C D )>` is :eq:`equal <0455.g1:< B C D ) = 0455.g1:< B A E ) = 0455.g1:< C B A )>` to the angles at :g:`A <0455.g1:A>`, :g:`B <0455.g1:B>`;

.. assertion::

   therefore the angle :g:`< A E D ) <0455.g1:< A E D )>` is also :eq:`equal <0455.g1:< A E D ) = 0455.g1:< B A E ) = 0455.g1:< C B A )>` to the angles at :g:`A <0455.g1:A>`, :g:`B <0455.g1:B>`.

.. assertion::

   Similarly we can prove that the angle :g:`< C D E ) <0455.g1:< C D E )>` is also :eq:`equal <0455.g1:< C D E ) = 0455.g1:< B A E ) = 0455.g1:< C B A ) = 0455.g1:< B C D )>` to the angles at :g:`A <0455.g1:A>`, :g:`B <0455.g1:B>`, :g:`C <0455.g1:C>`; therefore the pentagon :g:`< A B C D E > <0455.g1:< A B C D E >>` is equiangular.

Next, let the given equal angles not be angles taken in order, but let the angles at the points :g:`A <0455.g1:A>`, :g:`C <0455.g1:C>`, :g:`D <0455.g1:D>` be :eq:`equal <0455.g1:< B A E ) = 0455.g1:< B C D ) = 0455.g1:< C D E )>`; I say that in this case too the pentagon :g:`< A B C D E > <0455.g1:< A B C D E >>` is equiangular.

For let :g:`/ B D / <0455.g1:/ B D />` be joined.

.. subclause::

   Then, since the two sides :g:`/ B A / <0455.g1:/ B A />`, :g:`/ A E / <0455.g1:/ A E />` are :eq:`equal <0455.g1:/ B A / = 0455.g1:/ B C /; 0455.g1:/ A E / = 0455.g1:/ C D />` to the two sides :g:`/ B C / <0455.g1:/ B C />`, :g:`/ C D / <0455.g1:/ C D />`, and they contain :eq:`equal <0455.g1:< B A E ) = 0455.g1:< B C D )>` angles,

.. assertion::

   therefore the base :g:`/ B E / <0455.g1:/ B E />` is :eq:`equal <0455.g1:/ B E / = 0455.g1:/ B D />` to the base :g:`/ B D / <0455.g1:/ B D />`, the triangle :g:`< A B E > <0455.g1:< A B E >>` is :eq:`equal <0455.g1:< A B E > = 0455.g1:< B C D >>` to the triangle :g:`< B C D > <0455.g1:< B C D >>`, and the remaining angles will be equal to the remaining angles, namely those which the equal sides subtend; :just:`[G.11] <G.11>` therefore the angle :g:`< A E B ) <0455.g1:< A E B )>` is :eq:`equal <0455.g1:< A E B ) = 0455.g1:< C D B )>` to the angle :g:`< C D B ) <0455.g1:< C D B )>`.

.. subclause::

   But the angle :g:`< B E D ) <0455.g1:< B E D )>` is also :eq:`equal <0455.g1:< B E D ) = 0455.g1:< B D E )>` to the angle :g:`< B D E ) <0455.g1:< B D E )>`, since the side :g:`/ B E / <0455.g1:/ B E />` is also :eq:`equal <0455.g1:/ B E / = 0455.g1:/ B D />` to the side :g:`/ B D / <0455.g1:/ B D />`. :just:`[G.12] <G.12>`

.. assertion::

   Therefore the whole angle :g:`< A E D ) <0455.g1:< A E D )>` is :eq:`equal <0455.g1:< A E D ) = 0455.g1:< C D E )>` to the whole angle :g:`< C D E ) <0455.g1:< C D E )>`.

.. subclause::

   But the angle :g:`< C D E ) <0455.g1:< C D E )>` is, by hypothesis, :eq:`equal <0455.g1:< C D E ) = 0455.g1:< B A E ) = 0455.g1:< B C D )>` to the angles at :g:`A <0455.g1:A>`, :g:`C <0455.g1:C>`;

.. assertion::

   therefore the angle :g:`< A E D ) <0455.g1:< A E D )>` is also :eq:`equal <0455.g1:< A E D ) = 0455.g1:< B A E ) = 0455.g1:< B C D )>` to the angles at :g:`A <0455.g1:A>`, :g:`C <0455.g1:C>`.

.. assertion::

   For the same reason the angle :g:`< A B C ) <0455.g1:< A B C )>` is also :eq:`equal <0455.g1:< A B C ) = 0455.g1:< B A E ) = 0455.g1:< B C D ) = 0455.g1:< C D E )>` to the angles at :g:`A <0455.g1:A>`, :g:`C <0455.g1:C>`, :g:`D <0455.g1:D>`. Therefore the pentagon :g:`< A B C D E > <0455.g1:< A B C D E >>` is equiangular.

.. qed::

   :just:`Q. E. D.`
