G.236
=====

.. rubric:: `VII.35 <https://geometor.github.io/euclid/heath/volume_II/book_vii/propositions/35/>`_

.. enunciation::

   If two numbers measure any number, the least number measured by them will also measure the same.

For let the two numbers :g:`A <0345.g1:A>`, :g:`B <0345.g1:B>` measure any number :g:`/ C D / <0345.g1:/ C D />`, and let :g:`E <0345.g1:E>` be the least that they measure;

I say that :g:`E <0345.g1:E>` also measures :g:`/ C D / <0345.g1:/ C D />`.

.. picture:: 0345.g1.svg
   :alt: Proposition 35

.. subclause::

   For, if :g:`E <0345.g1:E>` does not measure :g:`/ C D / <0345.g1:/ C D />`, let :g:`E <0345.g1:E>`, measuring :g:`/ F D / <0345.g1:/ F D />`, leave :g:`/ C F / <0345.g1:/ C F />` less than itself.

.. subclause::

   Now, since :g:`A <0345.g1:A>`, :g:`B <0345.g1:B>` measure :g:`E <0345.g1:E>`, and :g:`E <0345.g1:E>` measures :g:`/ F D / <0345.g1:/ F D />`,

.. assertion::

   therefore :g:`A <0345.g1:A>`, :g:`B <0345.g1:B>` will also measure :g:`/ F D / <0345.g1:/ F D />`.

.. subclause::

   But they also measure the whole :g:`/ C D / <0345.g1:/ C D />`;

.. assertion::

   therefore they will also measure the remainder :g:`/ C F / <0345.g1:/ C F />` which is less than :g:`E <0345.g1:E>`: which is impossible.

.. assertion::

   Therefore :g:`E <0345.g1:E>` cannot fail to measure :g:`/ C D / <0345.g1:/ C D />`; therefore it measures it.

.. qed::

   :just:`Q. E. D.`
