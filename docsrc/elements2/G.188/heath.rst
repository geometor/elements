G.188 magnitudes ratio greater — Heath
======================================

.. rubric:: `V.10 <https://geometor.github.io/euclid/heath/volume_II/book_v/propositions/10/>`_

.. enunciation::

   Of magnitudes which :term:`have a ratio <G.184>` to the same, that which has a :term:`greater ratio <G.185>` is greater ; and that to which the same has a greater ratio is less.

For let :g:`A <g1:A>` have to :g:`C <g1:C>` a greater ratio than :g:`B <g1:B>` has to :g:`C <g1:C>` ;
I say that :g:`A <g1:A>` is greater than :g:`B <g1:B>`.

.. picture:: g1.svg
   :alt: Folio 0161 Figure 1

For, if not, :g:`A <g1:A>` is either :eq:`equal <g1:A = g1:B>` to :g:`B <g1:B>` or less.

Now :g:`A <g1:A>` is not :eq:`equal <g1:A = g1:B>` to :g:`B <g1:B>` ;
for in that case each of the magnitudes :g:`A <g1:A>`, :g:`B <g1:B>` would have
had the :term:`same ratio <G.176>` to :g:`C <g1:C>` ; :just:`[G.183] <G.183>`
but they have not ;

.. assertion::

   therefore :g:`A <g1:A>` is not :eq:`equal <g1:A = g1:B>` to :g:`B <g1:B>`.

Nor again is :g:`A <g1:A>` less than :g:`B <g1:B>` ;
for in that case :g:`A <g1:A>` would have had to :g:`C <g1:C>` a less :term:`ratio <G.173>` than :g:`B <g1:B>`
has to :g:`C <g1:C>` ; :just:`[G.186] <G.186>`
but it has not ;

.. assertion::

   therefore :g:`A <g1:A>` is not less than :g:`B <g1:B>`.

But it was proved not to be :eq:`equal <g1:A = g1:B>` either ;

.. assertion::

   therefore :g:`A <g1:A>` is greater than :g:`B <g1:B>`.

Again, let :g:`C <g1:C>` have to :g:`B <g1:B>` a greater ratio than :g:`C <g1:C>` has to :g:`A <g1:A>` ;
I say that :g:`B <g1:B>` is less than :g:`A <g1:A>`.

For, if not, it is either :eq:`equal <g1:B = g1:A>` or greater.

Now :g:`B <g1:B>` is not :eq:`equal <g1:B = g1:A>` to :g:`A <g1:A>` ;
for in that case :g:`C <g1:C>` would have had the same ratio to each of
the magnitudes :g:`A <g1:A>`, :g:`B <g1:B>` ; :just:`[G.183] <G.183>`
but it has not ;

.. assertion::

   therefore :g:`A <g1:A>` is not :eq:`equal <g1:A = g1:B>` to :g:`B <g1:B>`.

Nor again is :g:`B <g1:B>` greater than :g:`A <g1:A>` ;
for in that case :g:`C <g1:C>` would have had to :g:`B <g1:B>` a less ratio than it
has to :g:`A <g1:A>` ; :just:`[G.186] <G.186>`
but it has not ;

.. assertion::

   therefore :g:`B <g1:B>` is not greater than :g:`A <g1:A>`.

But it was proved that it is not :eq:`equal <g1:B = g1:A>` either ;

.. assertion::

   therefore :g:`B <g1:B>` is less than :g:`A <g1:A>`.

.. qed::

   Therefore etc. :just:`Q. E. D.`
