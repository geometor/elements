G.104 — Heath
=============

.. rubric:: `III.25 <https://geometor.github.io/euclid/heath/volume_II/book_iii/propositions/25/>`_

.. enunciation::

   Given a segment of a circle, to describe the complete circle of which it is a segment.

Let :g:`( A B C ) <g1:( A B C )>` be the given segment of a circle;
thus it is required to describe the complete circle belonging
to the segment :g:`( A B C ) <g1:( A B C )>`, that is, of which it is a segment.

For let :g:`/ A C / <g1:/ A C />` be :eq:`bisected <g1:/ A D / = g1:/ D C />` at :g:`D <g1:D>`, let :g:`/ D B / <g1:/ D B />` be drawn from the
point :g:`D <g1:D>` at right angles to :g:`/ A C / <g1:/ A C />`, and let :g:`/ A B / <g1:/ A B />` be joined;

the angle :g:`< A B D ) <g1:< A B D )>` is then greater than, equal to, or less
than the angle :g:`< B A D ) <g1:< B A D )>`.

First let it be greater;
and on the straight line :g:`/ B A / <g1:/ B A />`, and at the point :g:`A <g1:A>` on it, let
the angle :g:`< B A E ) <g1:< B A E )>` be constructed :eq:`equal <g1:< B A E ) = g1:< A B D )>` to
the angle :g:`< A B D ) <g1:< A B D )>`; let :g:`/ D B / <g1:/ D B />` be drawn through
to :g:`E <g1:E>`, and let :g:`/ E C / <g1:/ E C />` be joined.

.. picture:: g1.svg
   :alt: Diagram for Proposition 25, Case 1

Then, since the angle :g:`< A B E ) <g1:< A B E )>` is :eq:`equal <g1:< A B E ) = g1:< B A E )>` to
the angle :g:`< B A E ) <g1:< B A E )>`,
the straight line :g:`/ E B / <g1:/ E B />` is also :eq:`equal <g1:/ E B / = g1:/ E A />` to
:g:`/ E A / <g1:/ E A />`. :just:`[G.13] <G.13>`

And, since :g:`/ A D / <g1:/ A D />` is :eq:`equal <g1:/ A D / = g1:/ D C />` to :g:`/ D C / <g1:/ D C />`,
and :g:`/ D E / <g1:/ D E />` is common,
the two sides :g:`/ A D / <g1:/ A D />`, :g:`/ D E / <g1:/ D E />` are :eq:`equal <g1:/ A D / = g1:/ C D />` to the two sides :g:`/ C D / <g1:/ C D />`, :g:`/ D E / <g1:/ D E />`
respectively;
and the angle :g:`< A D E ) <g1:< A D E )>` is :eq:`equal <g1:< A D E ) = g1:< C D E )>` to the angle :g:`< C D E ) <g1:< C D E )>`, for each is
:eq:`right <g1:< A D E ) = g1:< C D E )>`;

.. assertion::

   therefore the base :g:`/ A E / <g1:/ A E />` is :eq:`equal <g1:/ A E / = g1:/ C E />` to the base :g:`/ C E / <g1:/ C E />`.

But :g:`/ A E / <g1:/ A E />` was proved :eq:`equal <g1:/ A E / = g1:/ B E />` to :g:`/ B E / <g1:/ B E />`;

.. assertion::

   therefore :g:`/ B E / <g1:/ B E />` is also :eq:`equal <g1:/ B E / = g1:/ C E />` to :g:`/ C E / <g1:/ C E />`;

therefore the three straight lines :g:`/ A E / <g1:/ A E />`, :g:`/ E B / <g1:/ E B />`, :g:`/ E C / <g1:/ E C />` are :eq:`equal <g1:/ A E / = g1:/ E B / = g1:/ E C />` to
one another.

Therefore the circle drawn with centre :g:`E <g1:E>` and distance
one of the straight lines :g:`/ A E / <g1:/ A E />`, :g:`/ E B / <g1:/ E B />`, :g:`/ E C / <g1:/ E C />` will also pass through
the remaining points and will have been completed. :just:`[G.84] <G.84>`

Therefore, given a segment of a circle, the complete circle
has been described.

And it is manifest that the segment :g:`( A B C ) <g1:( A B C )>` is less than a
semicircle, because the centre :g:`E <g1:E>` happens to be outside it.

Similarly, even if the angle :g:`< A B D ) <g2:< A B D )>` be :eq:`equal <g2:< A B D ) = g2:< B A D )>` to the angle
:g:`< B A D ) <g2:< B A D )>`,
:g:`/ A D / <g2:/ A D />` being :eq:`equal <g2:/ A D / = g2:/ B D / = g2:/ D C />` to each of the two :g:`/ B D / <g2:/ B D />`, :g:`/ D C / <g2:/ D C />`,

.. picture:: g2.svg
   :alt: Diagram for Proposition 25, Case 2

the three straight lines :g:`/ D A / <g2:/ D A />`, :g:`/ D B / <g2:/ D B />`, :g:`/ D C / <g2:/ D C />` will
be :eq:`equal <g2:/ D A / = g2:/ D B / = g2:/ D C />` to one another,
:g:`D <g2:D>` will be the centre of the completed circle,
and :g:`( A B C ) <g2:( A B C )>` will clearly be a semicircle.

But, if the angle :g:`< A B D ) <g3:< A B D )>` be less than the angle :g:`< B A D ) <g3:< B A D )>`,
and if we construct, on the straight line :g:`/ B A / <g3:/ B A />`
and at the point :g:`A <g3:A>` on it, an angle :eq:`equal <g3:< B A E ) = g3:< A B D )>` to
the angle :g:`< A B D ) <g3:< A B D )>`, the centre will fall on :g:`/ D B / <g3:/ D B />`
within the segment :g:`( A B C ) <g3:( A B C )>`, and the segment
:g:`( A B C ) <g3:( A B C )>` will clearly be greater than a semicircle
.

.. picture:: g3.svg
   :alt: Diagram for Proposition 25, Case 3

Therefore, given a segment of a circle,
the complete circle has been described.

.. qed::

   :just:`Q. E. F.`
