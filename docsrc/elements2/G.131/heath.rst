G.131 — Heath
=============

.. rubric:: `IV.13 <https://geometor.github.io/euclid/heath/volume_II/book_iv/propositions/13/>`_

.. enunciation::

   In a given pentagon, which is equilateral and equiangular, to inscribe a circle.

Let :g:`< A B C D E > <g1:< A B C D E >>` be the given equilateral and equiangular
pentagon;
thus it is required to inscribe a circle in the pentagon
:g:`< A B C D E > <g1:< A B C D E >>`.

For let the angles :g:`< B C D ) <g1:< B C D )>`, :g:`< C D E ) <g1:< C D E )>` be bisected by the
straight lines :g:`/ C F / <g1:/ C F />`, :g:`/ D F / <g1:/ D F />` respectively; and from the point :g:`F <g1:F>`, at
which the straight lines :g:`/ C F / <g1:/ C F />`, :g:`/ D F / <g1:/ D F />` meet one another, let the
straight lines :g:`/ F B / <g1:/ F B />`, :g:`/ F A / <g1:/ F A />`, :g:`/ F E / <g1:/ F E />` be joined.

Then, since :g:`/ B C / <g1:/ B C />` is :eq:`equal <g1:/ B C / = g1:/ C D />` to :g:`/ C D / <g1:/ C D />`,
and :g:`/ C F / <g1:/ C F />` common,
the two sides :g:`/ B C / <g1:/ B C />`, :g:`/ C F / <g1:/ C F />` are :eq:`equal <g1:/ B C / = g1:/ D C /; g1:/ C F / = g1:/ C F />` to the
two sides :g:`/ D C / <g1:/ D C />`, :g:`/ C F / <g1:/ C F />`;
and the angle :g:`< B C F ) <g1:< B C F )>` is :eq:`equal <g1:< B C F ) = g1:< D C F )>` to the
angle :g:`< D C F ) <g1:< D C F )>`;
therefore the base :g:`/ B F / <g1:/ B F />` is :eq:`equal <g1:/ B F / = g1:/ D F />`
to the base :g:`/ D F / <g1:/ D F />`,
and the triangle :g:`< B C F > <g1:< B C F >>` is :eq:`equal <g1:< B C F > = g1:< D C F >>` to the
triangle :g:`< D C F > <g1:< D C F >>`,
and the remaining angles will be equal to the remaining angles,
namely those which the equal sides subtend. :just:`[G.11] <G.11>`

.. picture:: g1.svg
   :alt: Book IV Proposition 13: Circle GHKLM inscribed in regular pentagon ABCDE

.. assertion::

   Therefore the angle :g:`< C B F ) <g1:< C B F )>` is :eq:`equal <g1:< C B F ) = g1:< C D F )>` to the angle :g:`< C D F ) <g1:< C D F )>`.

And, since the angle :g:`< C D E ) <g1:< C D E )>` is double of the angle :g:`< C D F ) <g1:< C D F )>`,
and the angle :g:`< C D E ) <g1:< C D E )>` is :eq:`equal <g1:< C D E ) = g1:< A B C )>` to the angle :g:`< A B C ) <g1:< A B C )>`,

.. subclause::

   while the angle :g:`< C D F ) <g1:< C D F )>` is :eq:`equal <g1:< C D F ) = g1:< C B F )>` to the angle :g:`< C B F ) <g1:< C B F )>`;

.. assertion::

   therefore the angle :g:`< C B A ) <g1:< C B A )>` is also double of the angle :g:`< C B F ) <g1:< C B F )>`;

.. assertion::

   therefore the angle :g:`< A B F ) <g1:< A B F )>` is :eq:`equal <g1:< A B F ) = g1:< F B C )>` to the angle :g:`< F B C ) <g1:< F B C )>`;

.. assertion::

   therefore the angle :g:`< A B C ) <g1:< A B C )>` has been :eq:`bisected <g1:< A B F ) = g1:< F B C )>` by the straight line :g:`/ B F / <g1:/ B F />`.

Similarly it can be proved that
the angles :g:`< B A E ) <g1:< B A E )>`, :g:`< A E D ) <g1:< A E D )>` have also been bisected by the straight
lines :g:`/ F A / <g1:/ F A />`, :g:`/ F E / <g1:/ F E />` respectively.

Now let :g:`/ F G / <g1:/ F G />`, :g:`/ F H / <g1:/ F H />`, :g:`/ F K / <g1:/ F K />`, :g:`/ F L / <g1:/ F L />`, :g:`/ F M / <g1:/ F M />` be drawn from the point
:g:`F <g1:F>` perpendicular to the straight lines :g:`/ A B / <g1:/ A B />`, :g:`/ B C / <g1:/ B C />`, :g:`/ C D / <g1:/ C D />`, :g:`/ D E / <g1:/ D E />`, :g:`/ E A / <g1:/ E A />`.

Then, since the angle :g:`< H C F ) <g1:< H C F )>` is :eq:`equal <g1:< H C F ) = g1:< K C F )>` to the angle :g:`< K C F ) <g1:< K C F )>`,
and the right angle :g:`< F H C ) <g1:< F H C )>` is also :eq:`equal <g1:< F H C ) = g1:< F K C )>` to the angle :g:`< F K C ) <g1:< F K C )>`,
:g:`< F H C > <g1:< F H C >>`, :g:`< F K C > <g1:< F K C >>` are two triangles having two angles equal to two
angles and one side equal to one side, namely :g:`/ F C / <g1:/ F C />` which is
common to them and subtends one of the equal angles;
therefore they will also have the remaining sides equal to the
remaining sides; :just:`[G.37] <G.37>`

.. assertion::

   therefore the perpendicular :g:`/ F H / <g1:/ F H />` is :eq:`equal <g1:/ F H / = g1:/ F K />` to the perpendicular :g:`/ F K / <g1:/ F K />`.

Similarly it can be proved that
each of the straight lines :g:`/ F L / <g1:/ F L />`, :g:`/ F M / <g1:/ F M />`, :g:`/ F G / <g1:/ F G />` is also :eq:`equal <g1:/ F L / = g1:/ F M / = g1:/ F G / = g1:/ F H / = g1:/ F K />` to each
of the straight lines :g:`/ F H / <g1:/ F H />`, :g:`/ F K / <g1:/ F K />`;

.. assertion::

   therefore the five straight lines :g:`/ F G / <g1:/ F G />`, :g:`/ F H / <g1:/ F H />`, :g:`/ F K / <g1:/ F K />`, :g:`/ F L / <g1:/ F L />`, :g:`/ F M / <g1:/ F M />` are :eq:`equal <g1:/ F G / = g1:/ F H / = g1:/ F K / = g1:/ F L / = g1:/ F M />` to one another.

Therefore the circle described with centre :g:`F <g1:F>` and distance
one of the straight lines :g:`/ F G / <g1:/ F G />`, :g:`/ F H / <g1:/ F H />`, :g:`/ F K / <g1:/ F K />`, :g:`/ F L / <g1:/ F L />`, :g:`/ F M / <g1:/ F M />` will pass
also through the remaining points;
and it will touch the straight lines :g:`/ A B / <g1:/ A B />`, :g:`/ B C / <g1:/ B C />`, :g:`/ C D / <g1:/ C D />`, :g:`/ D E / <g1:/ D E />`, :g:`/ E A / <g1:/ E A />`,
because the angles at the points :g:`< F G B ) <g1:< F G B )>`, :g:`< F H C ) <g1:< F H C )>`, :g:`< F K C ) <g1:< F K C )>`, :g:`< F L D ) <g1:< F L D )>`, :g:`< F M E ) <g1:< F M E )>` are right.

For, if it does not touch them, but cuts them,
it will result that the straight line drawn at right angles to
the diameter of the circle from its extremity falls within the
circle: which was proved absurd. :just:`[G.94] <G.94>`

Therefore the circle described with centre :g:`F <g1:F>` and distance
one of the straight lines :g:`/ F G / <g1:/ F G />`, :g:`/ F H / <g1:/ F H />`, :g:`/ F K / <g1:/ F K />`, :g:`/ F L / <g1:/ F L />`, :g:`/ F M / <g1:/ F M />` will not
cut the straight lines :g:`/ A B / <g1:/ A B />`, :g:`/ B C / <g1:/ B C />`, :g:`/ C D / <g1:/ C D />`, :g:`/ D E / <g1:/ D E />`, :g:`/ E A / <g1:/ E A />`;

.. assertion::

   therefore it will touch them.

Let it be described, as :g:`( G H K L M ) <g1:( G H K L M )>`.

.. qed::

   Therefore in the given pentagon, which is equilateral and equiangular, a circle has been inscribed. :just:`Q. E. F.`
