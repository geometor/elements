G.164 circumscribe about a given circle an equilateral and — Heath
==================================================================

.. rubric:: `IV.12 <https://geometor.github.io/euclid/heath/volume_II/book_iv/propositions/12/>`_

.. enunciation::

   About a given :term:`circle <G.10>` to circumscribe an :term:`equilateral <G.13>` and equiangular pentagon.

Let :g:`( A B C D E ) <g1:( A B C D E )>` be the given circle;
thus it is required to circumscribe an equilateral and equiangular
pentagon about the circle
:g:`( A B C D E ) <g1:( A B C D E )>`.

Let :g:`A <g1:A>`, :g:`B <g1:B>`, :g:`C <g1:C>`, :g:`D <g1:D>`, :g:`E <g1:E>` be conceived to
be the angular :term:`points <G.1>` of the inscribed
pentagon, so that the circumferences
:g:`( A B ) <g1:( A B )>`, :g:`( B C ) <g1:( B C )>`, :g:`( C D ) <g1:( C D )>`, :g:`( D E ) <g1:( D E )>`, :g:`( E A ) <g1:( E A )>` are :eq:`equal <g1:( A B ) = g1:( B C ) = g1:( C D ) = g1:( D E ) = g1:( E A )>`;
:just:`[G.163] <G.163>`
through :g:`A <g1:A>`, :g:`B <g1:B>`, :g:`C <g1:C>`, :g:`D <g1:D>`, :g:`E <g1:E>` let :g:`/ G H / <g1:/ G H />`, :g:`/ H K / <g1:/ H K />`,
:g:`/ K L / <g1:/ K L />`, :g:`/ L M / <g1:/ L M />`, :g:`/ M G / <g1:/ M G />` be drawn touching the
circle;
:just:`[G.118] <G.118>`

.. picture:: g1.svg
   :alt: Proposition 12 diagram

let the :term:`centre <G.11>` :g:`F <g1:F>` of the circle :g:`( A B C D E ) <g1:( A B C D E )>` be taken :just:`[G.98] <G.98>`, and
let :g:`/ F B / <g1:/ F B />`, :g:`/ F K / <g1:/ F K />`, :g:`/ F C / <g1:/ F C />`, :g:`/ F L / <g1:/ F L />`, :g:`/ F D / <g1:/ F D />` be joined.

Then, since the :term:`straight line <G.4>` :g:`/ K L / <g1:/ K L />` :term:`touches the circle <G.111>` :g:`( A B C D E ) <g1:( A B C D E )>`
at :g:`C <g1:C>`,
and :g:`/ F C / <g1:/ F C />` has been joined from the centre :g:`F <g1:F>` to the point of
contact at :g:`C <g1:C>`,

.. assertion:: [G.120] <G.120>

   therefore :g:`/ F C / <g1:/ F C />` is :term:`perpendicular <G.33>` to :g:`/ K L / <g1:/ K L />`;

.. assertion::

   therefore each of the :term:`angles <G.22>` at :g:`< K C L ) <g1:< K C L )>` is right.

For the same reason

.. assertion::

   the angles at the points :g:`< F B K ) <g1:< F B K )>`, :g:`< F D L ) <g1:< F D L )>` are also :eq:`right <g1:< F B K ) = g1:< F D L )>`.

And, since the angle :g:`< F C K ) <g1:< F C K )>` is right,

.. assertion::

   therefore the :term:`square <G.63>` on :g:`/ F K / <g1:/ F K />` is equal to the squares on :g:`/ F C / <g1:/ F C />`, :g:`/ C K / <g1:/ C K />`.

For the same reason :just:`[G.79] <G.79>`

.. assertion::

   the square on :g:`/ F K / <g1:/ F K />` is also equal to the squares on :g:`/ F B / <g1:/ F B />`, :g:`/ B K / <g1:/ B K />`;

so that the squares on :g:`/ F C / <g1:/ F C />`, :g:`/ C K / <g1:/ C K />` are equal to the squares
on :g:`/ F B / <g1:/ F B />`, :g:`/ B K / <g1:/ B K />`,

.. subclause::

   of which the square on :g:`/ F C / <g1:/ F C />` is :eq:`equal <g1:/ F C / = g1:/ F B />` to the square on :g:`/ F B / <g1:/ F B />`;

.. assertion::

   therefore the square on :g:`/ C K / <g1:/ C K />` which remains is :eq:`equal <g1:/ C K / = g1:/ B K />` to the square on :g:`/ B K / <g1:/ B K />`.

.. assertion::

   Therefore :g:`/ B K / <g1:/ B K />` is :eq:`equal <g1:/ B K / = g1:/ C K />` to :g:`/ C K / <g1:/ C K />`.

And, since :g:`/ F B / <g1:/ F B />` is :eq:`equal <g1:/ F B / = g1:/ F C />` to :g:`/ F C / <g1:/ F C />`,
and :g:`/ F K / <g1:/ F K />` common,
the two sides :g:`/ B F / <g1:/ B F />`, :g:`/ F K / <g1:/ F K />` are :eq:`equal <g1:/ B F / = g1:/ C F /; g1:/ F K / = g1:/ F K />` to the two sides :g:`/ C F / <g1:/ C F />`, :g:`/ F K / <g1:/ F K />`;
and the base :g:`/ B K / <g1:/ B K />` :eq:`equal <g1:/ B K / = g1:/ C K />` to the base :g:`/ C K / <g1:/ C K />`;

.. assertion::

   therefore the angle :g:`< B F K ) <g1:< B F K )>` is :eq:`equal <g1:< B F K ) = g1:< K F C )>` to the angle :g:`< K F C ) <g1:< K F C )>`, :just:`[G.29] <G.29>` and the angle :g:`< B K F ) <g1:< B K F )>` :eq:`to <g1:< B K F ) = g1:< F K C )>` the angle :g:`< F K C ) <g1:< F K C )>`.

.. assertion::

   Therefore the angle :g:`< B F C ) <g1:< B F C )>` is double of the angle :g:`< K F C ) <g1:< K F C )>`, and the angle :g:`< B K C ) <g1:< B K C )>` of the angle :g:`< F K C ) <g1:< F K C )>`.

For the same reason

.. assertion::

   the angle :g:`< C F D ) <g1:< C F D )>` is also double of the angle :g:`< C F L ) <g1:< C F L )>`, and the angle :g:`< D L C ) <g1:< D L C )>` of the angle :g:`< F L C ) <g1:< F L C )>`.

Now, since the circumference :g:`( B C ) <g1:( B C )>` is :eq:`equal <g1:( B C ) = g1:( C D )>` to :g:`( C D ) <g1:( C D )>`,

.. assertion:: [G.134] <G.134>

   the angle :g:`< B F C ) <g1:< B F C )>` is also :eq:`equal <g1:< B F C ) = g1:< C F D )>` to the angle :g:`< C F D ) <g1:< C F D )>`.

And the angle :g:`< B F C ) <g1:< B F C )>` is double of the angle :g:`< K F C ) <g1:< K F C )>`, and the
angle :g:`< D F C ) <g1:< D F C )>` of the angle :g:`< L F C ) <g1:< L F C )>`;

.. assertion::

   therefore the angle :g:`< K F C ) <g1:< K F C )>` is also :eq:`equal <g1:< K F C ) = g1:< L F C )>` to the angle :g:`< L F C ) <g1:< L F C )>`.

But the angle :g:`< F C K ) <g1:< F C K )>` is also :eq:`equal <g1:< F C K ) = g1:< F C L )>` to the angle :g:`< F C L ) <g1:< F C L )>`;
therefore :g:`< F K C > <g1:< F K C >>`, :g:`< F L C > <g1:< F L C >>` are two :term:`triangles <G.12>` having two angles
equal to two angles and one side equal to one side, namely
:g:`/ F C / <g1:/ F C />` which is common to them;
therefore they will also have the remaining sides equal to the
remaining sides, and the remaining angle to the remaining
angle; :just:`[G.51] <G.51>`

.. assertion::

   therefore the straight line :g:`/ K C / <g1:/ K C />` is :eq:`equal <g1:/ K C / = g1:/ C L />` to :g:`/ C L / <g1:/ C L />`, and the angle :g:`< F K C ) <g1:< F K C )>` :eq:`to <g1:< F K C ) = g1:< F L C )>` the angle :g:`< F L C ) <g1:< F L C )>`.

And, since :g:`/ K C / <g1:/ K C />` is :eq:`equal <g1:/ K C / = g1:/ C L />` to :g:`/ C L / <g1:/ C L />`,

.. assertion::

   therefore :g:`/ K L / <g1:/ K L />` is double of :g:`/ K C / <g1:/ K C />`.

For the same reason it can be proved that

.. assertion::

   :g:`/ H K / <g1:/ H K />` is also double of :g:`/ B K / <g1:/ B K />`.

And :g:`/ B K / <g1:/ B K />` is :eq:`equal <g1:/ B K / = g1:/ K C />` to :g:`/ K C / <g1:/ K C />`;

.. assertion::

   therefore :g:`/ H K / <g1:/ H K />` is also :eq:`equal <g1:/ H K / = g1:/ K L />` to :g:`/ K L / <g1:/ K L />`.

Similarly each of the straight lines :g:`/ H G / <g1:/ H G />`, :g:`/ G M / <g1:/ G M />`, :g:`/ M L / <g1:/ M L />` can also
be proved :eq:`equal <g1:/ H G / = g1:/ G M / = g1:/ M L / = g1:/ H K / = g1:/ K L />` to each of the straight lines :g:`/ H K / <g1:/ H K />`, :g:`/ K L / <g1:/ K L />`;

.. assertion::

   therefore the pentagon :g:`< G H K L M > <g1:< G H K L M >>` is :eq:`equilateral <g1:/ G H / = g1:/ H K / = g1:/ K L / = g1:/ L M / = g1:/ M G />`.

I say next that it is also :eq:`equiangular <g1:< G H K ) = g1:< H K L ) = g1:< K L M ) = g1:< L M G ) = g1:< M G H )>`.

For, since the angle :g:`< F K C ) <g1:< F K C )>` is :eq:`equal <g1:< F K C ) = g1:< F L C )>` to the angle :g:`< F L C ) <g1:< F L C )>`,
and the angle :g:`< H K L ) <g1:< H K L )>` was proved double of the angle :g:`< F K C ) <g1:< F K C )>`,
and the angle :g:`< K L M ) <g1:< K L M )>` double of the angle :g:`< F L C ) <g1:< F L C )>`,

.. assertion::

   therefore the angle :g:`< H K L ) <g1:< H K L )>` is also :eq:`equal <g1:< H K L ) = g1:< K L M )>` to the angle :g:`< K L M ) <g1:< K L M )>`.

Similarly each of the angles :g:`< K H G ) <g1:< K H G )>`, :g:`< H G M ) <g1:< H G M )>`, :g:`< G M L ) <g1:< G M L )>` can also
be proved :eq:`equal <g1:< K H G ) = g1:< H G M ) = g1:< G M L ) = g1:< H K L ) = g1:< K L M )>` to each of the angles :g:`< H K L ) <g1:< H K L )>`, :g:`< K L M ) <g1:< K L M )>`;

.. assertion::

   therefore the five angles :g:`< G H K ) <g1:< G H K )>`, :g:`< H K L ) <g1:< H K L )>`, :g:`< K L M ) <g1:< K L M )>`, :g:`< L M G ) <g1:< L M G )>`, :g:`< M G H ) <g1:< M G H )>` are :eq:`equal <g1:< G H K ) = g1:< H K L ) = g1:< K L M ) = g1:< L M G ) = g1:< M G H )>` to one another.

.. assertion::

   Therefore the pentagon :g:`< G H K L M > <g1:< G H K L M >>` is :eq:`equiangular <g1:< G H K ) = g1:< H K L ) = g1:< K L M ) = g1:< L M G ) = g1:< M G H )>`.

And it was also proved :eq:`equilateral <g1:/ G H / = g1:/ H K / = g1:/ K L / = g1:/ L M / = g1:/ M G />`; and it has been
:term:`circumscribed about the circle <G.150>` :g:`( A B C D E ) <g1:( A B C D E )>`.

.. qed::

   :just:`Q. E. F.`
